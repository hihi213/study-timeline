# ✅ Obsidian 마스터 체크리스트
> 개념화 → 흐름 확장 → 연결 → 복습 → 통찰 → 리팩토링  
> 내 지식 시스템을 지속 가능하게 유지하기 위한 점검 루틴

---

## 🧠 1. 개념 노트 관리

- [ ] 한 줄 요약 → 상세 설명 → 질문 구조의 Zettel 템플릿 사용
- [ ] 노트에 `분야`, `출처`, `#개념`, `#추상/xxx` 태그 작성
- [ ] 제목은 가능한 한 “핵심 키워드 중심으로 명명”
- [ ] 노트 작성 전에 `⌘+O` 또는 Quick Switcher로 유사 개념 확인
- [ ] 작성 후 다른 개념이나 흐름 노트에 반드시 링크로 연결

---

## 🔁 2. 흐름 / 비교 / 하위 개념 확장

- [ ] 큰 개념에서 파생된 흐름 노트를 따로 분리 (예: `[[xxx_흐름]]`)
- [ ] 유사/혼동 개념은 비교 노트로 분리 (예: `[[xxx_vs_yyy]]`)
- [ ] 상세 개념은 하위 Zettel로 분리하고 원 개념에서 링크로 연결
- [ ] 큰 개념 노트에 Dataview로 파생 노트 자동 목록화
- [ ] 흐름은 Mermaid 또는 Excalidraw로 시각화

---

## 🧭 3. 연결 및 네트워크 구성

- [ ] `#추상/xxx` 태그로 여러 분야 공통 개념을 메타 개념으로 연결
- [ ] Meta 개념 노트(`05_meta_concepts/`)에 Dataview로 연관 개념 자동 나열
- [ ] 개별 개념 노트에서 추상 개념 노트로 역링크 추가
- [ ] Excalibrain으로 개념 간 연결 시각화하여 구조 점검
- [ ] Tag Wrangler나 Dataview로 태그 기반 탐색 가능하도록 구성

---

## 🔁 4. 복습 자동화 (핵심 개념만)

- [ ] 핵심 개념 노트에 `sr-due`, `sr-interval`, `sr-ease`, `level` 필드 설정
- [ ] Dataview로 "오늘 복습할 개념" 대시보드 구성
- [ ] Daily Note에 최근 작성 노트 및 복습 예정 자동 표시
- [ ] Spaced Repetition 플러그인 설치 및 기본 설정 완료

---

## 💭 5. 생각 흐름 & 비개념 노트

- [ ] Daily Note에 `오늘의 통찰` 또는 `왜 이걸 정리했는가?` 로그 남김
- [ ] 개념 노트 하단에 “깨달음” 또는 “생각 흐름” 필드 추가
- [ ] 철학, 시사점, 질문 등은 `#통찰`, `#질문`, `#시사` 태그로 별도 정리
- [ ] 비개념 노트도 연결 기반으로 개념 노트와 연동되도록 구성

---

## 🔄 6. 리팩토링 루틴 (매주 또는 격주)

- [ ] 유사 개념 통합 여부 확인
- [ ] 고아 노트 존재 여부 점검 및 연결
- [ ] 비교 노트가 필요한 경우 분리
- [ ] `리팩토링 예정` 태그 또는 Checklist 노트로 관리
- [ ] 오래된 Daily Note에서 흐름 미완성 노트 점검
- [ ] 태그 오탈자, 불필요 태그, 중복 링크 정리
