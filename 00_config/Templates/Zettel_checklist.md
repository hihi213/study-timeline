# ✅ Zettel 품질 점검 체크리스트

## 📌 구조 점검

- [ ] 한 줄 요약(내 언어) → 예시 → 왜 중요한가? 구성이 되어 있는가?
- [ ] '생각 흐름 로그'와 '깨달음:' 필드가 포함되어 있는가?
- [ ] 흐름도(Mermaid 또는 Excalidraw)를 사용했는가?
- [ ] 리스트 형식을 통해 핵심 내용을 구조적으로 정리했는가?

---

## 🔗 연결 상태

- [ ] Dataview나 태그를 통해 이 노트가 연결되어 있는가?
- [ ] 상위 개념(예: 추상적 개념), 하위 개념(예: 구체적 개념)과 연결되어 있는가?
- [ ] 관련 개념이나 유사 개념과의 비교 또는 참조가 있는가?
