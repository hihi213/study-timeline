졸프 기능 추가하지말고
playground로 검토하는걸로 진행하자
그리고 에세이에 이런식의 흐름으로 진행했다고 모두 잡았다고 강조


- 거주자 로그인·세션 흐름(로그인, 토큰 재발급, 로그아웃, 내 프로필 조회)은 모두 REST 엔드포인트로 구현돼 있습니다.
- 포장 슬롯 조회, 포장/아이템 생성·수정·삭제, 검색 파라미터 등 냉장고 CRUD가 완비돼 있고, 타층 접근 차단과 용량 초과 검사도 서비스 레벨에서 처리합니다.
- 검사 세션 생성·참여·행동 기록·제출 및 층별 권한 검증, 진행 중 세션 조회 등이 구현돼 있어 단독 검사 플로우와 층별장 범위 구분 요건을 충족합니다.
- 검사 결과 알림 생성과 사용자 알림함(목록, 읽음 처리, 개별 설정 토글)이 서비스·컨트롤러에 구현돼 있습니다.
- 관리자 대시보드 조회, 층별장 임명/해임, 사용자 상태 변경 등 관리 기능이 구현돼 있어 1-5 항목을 포괄합니다.
- 관리자용 냉장고 자원 관리(칸 현황 조회, 허용량/상태 수정), 재배치 시뮬레이션·적용, 삭제 포장 이력 조회 등도 별도 엔드포인트로 제공 중입니다.
- 검사 일정 생성·수정·삭제 및 다음 일정 조회가 별도 모듈로 구현돼, 실제 운용 시나리오를 지원합니다.
- 알림 환경설정 토글, 백그라운드 허용 제어, 알림 만료 처리 등 세부 기능도 있으며, 이는 단순 “검사 결과 알림” 범위를 넘어섭니다.
- 관리자 정책(알림 배치 시각·발송 상한·벌점 템플릿) 갱신, 사용자 비활성화, 데모 데이터 초기화 등 운영 보조 기능이 추가로 구현돼 있습니다





아래 순서로 나누면 전체를 빠짐없이 살필 수 있어요. 한 단위씩 검토 요청을 주시면 그 범위에 대해 상세히 확인하겠습니다.

1. **백엔드 공통 인프라**
    
    - Spring 설정, 인증/세션, 글로벌 에러/보안, 공통 유틸·리포지토리.
2. **백엔드 냉장고 기본 도메인**
    
    - 슬롯/포장/라벨/호실 매핑(Service·Controller·Entity·Migration).
3. **백엔드 검사·일정·알림·벌점**
    
    - 검사 세션/조치/일정, 알림 발행·선호, 벌점 연동, 배치 스케줄러.
4. **백엔드 관리자 기능 및 시드/운영**
    
    - 관리자 API(칸 설정·재배분·데모 시드), ops 관련 스크립트.
5. **프런트 공통·홈·인증**
    
    - 홈 대시보드, auth 훅/스토어, PWA/서비스 워커 등 공통 로직.
6. **프런트 거주자 냉장고 UI**
    
    - 내 냉장고 슬롯/포장/검색 흐름과 관련 컴포넌트·스토어.
7. **프런트 층별장 검사 화면**
    
    - 검사 시작/조치/제출 페이지, 일정 관리, 필터, 로컬 드래프트.
8. **프런트 관리자 포털**
    
    - 관리자 대시보드, 냉장고 자원/역할/알림 정책 화면 및 API 어댑터.
9. **데이터/배포 인프라**
    
    - Docker Compose, .env, Flyway 마이그레이션, seed SQL, 배포 스크립트.
10. **테스트·자동화·문서**
    
    - 백엔드/프런트 테스트 스위트, Playwright 계획, ops 상태보드/문서 싱크.

원하시는 순서대로 “단위 n 검토해 달라”고 말씀해 주세요!
