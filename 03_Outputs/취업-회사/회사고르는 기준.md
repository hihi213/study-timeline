| 구분    | B2B (Business to Business)       | B2C (Business to Consumer)    |
| ----- | -------------------------------- | ----------------------------- |
| 뜻     | 기업이 **다른 기업**을 대상으로 제품이나 서비스를 제공 | 기업이 **개인 소비자**에게 제품이나 서비스를 제공 |
| 고객    | 제약사, 병원, 보험사, 정부기관 등             | 환자, 보호자, 일반 소비자               |
| 예시    | 환자 모니터링 시스템, 복약 데이터 분석 대시보드      | 복약 리마인더 앱, 보호자용 알림 서비스        |
| 특징    | 정교한 데이터, 분석, 계약 기반               | 직관적 UI, 사용자 경험, 접근성 중심        |
| 수익 구조 | 계약, 구독, 서비스 제공료                  | 광고, 유료 기능, 보험 연동 등            |

## 🧑‍💻 실무에서의 차이점

- B2B 개발자는 **기업을 위한 솔루션**으로 API, 데이터 보안, 복잡한 비즈니스 로직, 대시보드 등을 구축합니다.
- B2C 개발자는 **일반 사용자를 위한 솔루션**으로 직관적 UX, 빠른 반응성, 알림 시스템, 접근성 높은 UI 등을 설계합니다.

	 직종에 따라 연봉 차이도 좀 크다.
	
	 회사의 주 분야는 좀 고민해볼 필요가 있다.
	
	 개발을 예로 들면 개발, SE(유지 보수, 신규 구축 엔지니어), SI(개발 + SE) ….
	
	 다 같은 개발 직무인줄 알고 지원하는 순간 생각하는 것과 다른 업무를 하게 될 가능성이 높다..!

	=> 서비스(B2C)나 솔루션(B2B)을 직접 구현하고 개선하는 직무

	- 서버 개발 (백엔드) : 백엔드 로직을 개발하는 직무. 데이터베이스와 연동, API 설계, 인증/보안 등 처리.
		- 사용하는 언어: Java, Python, Node.js, Go등
		- 사용하는 프레임워크: Spring, Django, Express 등
		- 관련 기술: REST API, DB 설계, 클라우드, 컨테이너, 다양한 OS 환경에 맞춘 배포/운영 능력(운영체제 환경에 대한 이해) 등
	- 웹 개발 (프론트엔드): 사용자가 보게 될 웹 페이지의 UI/UX를 개발하는 직무. (트렌드가 굉장히 빨리 바뀐다)
		- 사용하는 언어: HTML, CSS, JavaScript
		- 사용하는 프레임워크: React, Vue, Angular 등
		- 관련 기술: 웹 접근성, 반응형 디자인 등
	- iOS 개발: 애플 기기(iPhone, iPad, iMac 등)용 앱, SDK, 프로그램 개발.
		- 사용하는 언어: Swift, Objective-C, Go (요즘 서비스쪽에서는 Flutter로도 많이 대체 중)
		- 사용하는 도구: Xcode
		- 관련 기술: UIKit, SwiftUI, CoreData 등
	- 안드로이드 개발: 안드로이드 운영체제용 앱, SDK 개발.
		- 사용하는 언어: Kotlin, Java, Go (요즘 서비스쪽에서는 Flutter로도 많이 대체 중)
		- 사용하는 도구: Android Studio
		- 관련 기술: Jetpack, Room, LiveData 등
	- 클라이언트 개발 (데스크탑 앱 등): PC용 프로그램을 만드는 직무. (예: 윈도우용 소프트웨어, 게임 등)
		- 사용하는 언어: C#, C++, Electron 등

- 1-2. 엔지니어
	
	 "개발자는 코드를 짜고, 만든 제품을 기반으로 엔지니어는 시스템을 구축하고 운영한다"는 식으로 구분
	
	- 서버 엔지니어 (SE): 서버 시스템을 설계, 구축, 유지보수. 네트워크와 보안도 중요.
		- 예: 리눅스 서버 설정, 웹 서버(Nginx, Apache), 클러스터 관리 등
		- 주요 역량: 시스템 아키텍처, 스크립트 언어(bash, Python), 자동화 툴 등
	- 네트워크 엔지니어: 네트워크 인프라(라우터, 스위치, 방화벽 등)를 설계하고 운영.
		- 주요 지식: TCP/IP, 라우팅 프로토콜, VLAN, VPN 등
		- 자격증: CCNA, CCNP
		- 클라우드 엔지니어: AWS, Azure, GCP 등의 클라우드 환경을 설계/운영
		- 주요 기술: IaC(Terraform, CloudFormation), Docker, Kubernetes 등
	- 플랫폼 엔지니어: Android/iOS SDK와 같은 공통 모듈의 환경 설정 및 통합, 각 플랫폼에 맞는 빌드/배포
		- 주요 지식 : Android/iOS SDK 적용 및 통합, Android/iOS 개발에 대한 이해(데모 개발 등)
		- 보안 엔지니어: 시스템과 네트워크 보안을 설계하고 강화.
		- 주요 작업: 방화벽 설정, 침입 탐지 시스템, 패치 관리 등
		- 자격증: CISSP, CISA
- 1-3. 개발 + 엔지니어
	
	 SI (System Integration)
	
	 기업 맞춤형 시스템을 기획·개발·구축
	
	- 쉽게 말하면, 고객(기업)의 요구에 맞는 시스템을 설계하고 개발해서 납품(배포)하는 것.
	- 예: 병원 전산시스템, 관공서 행정 시스템, 기업 회계시스템 등
	- SI업체에서는 개발자, 기획자, 엔지니어가 함께 일함.
	- 특징: 고객사 일정에 따라 일이 유동적, 파견 근무 많음, 기술도 중요하지만 커뮤니케이션 능력이 매우 중요
	- 대표 업체 : 삼성 SDS, LG CNS 등..
1. 관제 직무
	실시간으로 시스템/네트워크를 감시하고 이상 징후를 탐지·분석하는 역할
	
	- 보안 관제: 침입 탐지 시스템(IDS), 방화벽, 보안 로그 등을 실시간으로 감시
		- 주요 업무 : 이상 징후 탐지, 로그 분석, 대응 보고서 작성 등
		- 특징 : 24시간 교대 근무가 많음
		- 대표 기업 : 안랩, 윈스, 이글루 시큐리티 등 보안 회사
	- 네트워크 관제: 네트워크 장비 상태와 트래픽을 모니터링, 서비스 다운 여부 확인 등
		- 주요 업무 : 스위치/라우터 상태 체크, 트래픽 과부하 탐지 등
		- 특징 : 실시간 서비스의 경우 교대 근무 있음
		- 대표 기업 : 통신사, 금융사, 공공기관, 대기업 관제센터

2. 분석 직무
	
	 데이터를 기반으로 문제를 진단하고 해결 방안을 찾는 직무
	
	- 데이터 분석 (Data Science): 로그, 사용자 행동, 매출 등의 데이터를 분석(AI 관련 직무)
		- 머신러닝, 통계, BI툴 사용
		- 사용하는 도구: Python, R, SQL, Tableau 등
	- 악성코드 분석: 바이러스, 랜섬웨어, 스파이웨어 등의 악성 프로그램을 분석(최신 악성행위 끊임 없이 분석)
		- 정적 분석(코드 분석), 동적 분석(실행하면서 분석)
		- 사용하는 도구: IDA, OllyDbg, Wireshark 등
		- 특징 : 모바일(안드로이드, iOS), PC(Window, Linux) 분야가 굉장히 세부적으로 나뉜다.
	- 취약점 분석 (모의 해킹): 시스템의 보안 취약점을 찾아내는 직무. (당장 접근이 어려운 직무)
		- 화이트 해커의 역할.
		- 사용하는 도구: Metasploit, Burp Suite 등
		- 관련 자격증: CEH, OSCP 등
		- 특징 : 굉장히 전문적이고 보통 고등학교때부터 대회에 나가는 사람들이 하는 경우가 많다.
		회사 팀에 소속된 이후에도 국제 대회 성적을 위해 대회에 많이 나가는 편.

3. 관리 직무
	
	=> IT 자산, 보안 정책, 인증 관련 등 회사의 IT 환경을 관리하는 직무
	
	- 인증 심사 (보안 인증/감사): ISO 27001, ISMS-P 같은 보안 인증을 준비하고 심사를 대응
		- 문서화, 규정 관리, 로그 기록 등
		- 관련 실무 경험 및 자격증 필수 => 따라서 무조건 다른 직무에 대한 경험 이후 접근 가능
