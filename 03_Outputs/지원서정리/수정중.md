## 알고리즘 테스트 필수 자바 문법 완벽 정리

알고리즘 테스트에서 자주 사용하고 헷갈리는 자바 문법을 카테고리별로 정리했습니다. 실전에서 바로 활용할 수 있도록 예제 코드와 함께 설명합니다.
### 0. int vs Integer (Wrapper 클래스)

#### 핵심 차이

```java
// int - 기본형 (Primitive Type)
int a = 10;           // Null 불가, Default 0
int[] arr1 = {1,2,3}; // 기본형 배열 가능

// Integer - 래퍼 클래스 (Reference Type)
Integer b = 10;       // Null 허용
Integer b = null;     // 가능
```




```java
// 자동 박싱/언박싱
Integer num = 100;        // 자동 박싱 (int → Integer)
int value = num;          // 자동 언박싱 (Integer → int)

// Collection은 Integer 사용
ArrayList<Integer> list = new ArrayList<>();
list.add(1);              // int를 넣어도 자동 박싱
```
### 1. 입력 처리: Scanner vs BufferedReader
#### Scanner 기본 사용법

SSAFY 문제는 일반적으로 **Scanner를 통한 표준 입력**을 사용합니다.[1]

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        
        int a = sc.nextInt();           // 정수 입력
        String str = sc.next();          // 공백 구분 문자열 입력
        String line = sc.nextLine();     // 한 줄 전체 입력 (개행까지 포함)
        double d = sc.nextDouble();      // 실수 입력
        long l = sc.nextLong();          // 긴 정수 입력
    }
}
```

#### 주의할 점

**nextInt()와 nextLine() 혼용 시 개행 문제**[2]

```java
int n = sc.nextInt();      // "5\n" 입력
String s = sc.nextLine();  // 개행 문자만 받음 (버그!)

// 해결책
int n = sc.nextInt();
sc.nextLine();             // 버퍼의 개행 제거
String s = sc.nextLine();  // 이제 정상 작동
```
#### Scanner의 장단점

**장점**: 사용이 간단하고 다양한 타입 직접 파싱 가능[1]
**단점**: 입력량이 많으면 시간 초과 발생 가능[1][2]

```java
import java.util.Scanner;

Scanner sc = new Scanner(System.in);
int a = sc.nextInt();
String str = sc.next();
```
#### nextInt() 후 nextLine() 버그

```java
Scanner sc = new Scanner(System.in);

int n = sc.nextInt();      // "5\n" 입력 시
String s = sc.nextLine();  // 개행만 받음 (버그!)

// ✓ 해결책
int n = sc.nextInt();
sc.nextLine();             // 버퍼의 개행 제거
String s = sc.nextLine();  // 이제 정상 작동
```

```java
import java.io.*;
import java.util.StringTokenizer;

BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
String line = br.readLine();

// 공백으로 구분된 입력 처리

```

**실전 팁**: 입력이 10개 이하라면 Scanner를 사용해도 무방하지만, 그 이상이면 BufferedReader를 권장합니다.[3]

### 2. StringBuilder (문자열 조작)

**String은 불변(immutable)이므로 반복적인 연결 시 StringBuilder를 사용해야 시간 초과를 방지할 수 있습니다.**[2]

```java
StringBuilder sb = new StringBuilder();

// 문자열 추가
sb.append("hello");            // "hello"
sb.append(" world");           // "hello world"

// 특정 위치에 삽입
sb.insert(5, " Java");         // "hello Java world"

// 문자열 삭제
sb.delete(5, 10);              // "hello world" (5 이상 10 미만 삭제)
sb.deleteCharAt(0);            // "ello world" (인덱스 0 삭제)

// 특정 위치 문자 변경
sb.setCharAt(0, 'H');          // "Hello world"

// 문자열 뒤집기 (팰린드롬 문제에 유용)
sb.reverse();                  // "dlrow olleH"

// 길이 조정
sb.setLength(5);               // "dlrow"

// String으로 변환
String result = sb.toString();
```

### 3. 배열(Array) 관련
#### 주요 차이점

| 항목     | 배열(Array)    | ArrayList          |
| ------ | ------------ | ------------------ |
| **크기** | 고정           | 가변                 |
| **타입** | 기본형(int) 가능  | 래퍼클래스(Integer)만 가능 |
| **성능** | 빠름           | 약간 느림 (크기 조정 오버헤드) |
| **길이** | `arr.length` | `list.size()`      |
| **접근** | `arr[i]`     | `list.get(i)`      |
#### 배열 선언 및 초기화[1]

```java
// 1차원 배열
int[] arr1 = new int[5];              // [0, 0, 0, 0, 0]
int[] arr2 = {1, 2, 3, 4, 5};
int[] arr3 = new int[]{1, 2, 3};

// 2차원 배열
int[][] arr2d = new int[3][4];        // 3행 4열
int[][] arr = {{1,2}, {3,4}, {5,6}};

// 배열 길이
arr.length;                           // 5
arr2d.length;                         // 3 (행)
arr2d[0].length;                      // 4 (열)
```

#### 배열 정렬
**내리차순 Integer로 변환필수: Collections.reverseOrder()는 Object 타입에만 작동하므로 기본형은 사용 불가합니다
```java
// 오름차순
int[] arr = {5, 2, 8, 1};
Arrays.sort(arr);  // [1, 2, 5, 8]

// 내림차순: 기본형(int)은 내림차순 불가, Integer로 변환 필수
Integer[] arr2 = {5, 2, 8, 1};
Arrays.sort(arr2, Collections.reverseOrder());  // [8, 5, 2, 1]

// int → Integer 변환
Integer[] refArr = Arrays.stream(arr).boxed().toArray(Integer[]::new);
```

#### 2차원 배열 정렬[2]

```java
int[][] arr = {{1,30}, {2,10}, {3,50}};

// 첫 번째 열 기준 오름차순
Arrays.sort(arr, (o1, o2) -> o1[0] - o2[0]);

// 두 번째 열 기준 내림차순
Arrays.sort(arr, (o1, o2) -> o2[1] - o1[1]);

// 두 조건 (첫 번째 열 오름차순, 같으면 두 번째 열 내림차순)
Arrays.sort(arr, (o1, o2) -> {
    if (o1[0] == o2[0]) return o2[1] - o1[1];
    return o1[0] - o2[0];
});
```

#### 배열 유틸리티[2]


### 4. ArrayList (동적 배열)
#### 배열 vs ArrayList

```java
// 배열 - 크기 고정
int[] arr = new int[5];
arr[0] = 1;

// ArrayList - 크기 가변
ArrayList<Integer> list = new ArrayList<>();
list.add(1);
list.add(2);
list.remove(0);  // 삭제 가능
```

**코딩테스트 팁**: 크기가 정해져 있으면 배열, 동적으로 추가/삭제가 필요하면 ArrayList를 사용합니다.[6][7]
#### 기본 메서드[1][2]

```java
List<Integer> list = new ArrayList<>();

// 추가
list.add(1);                    // [1]
list.add(0, 10);                // [10, 1] (인덱스 0에 삽입)
list.addAll(Arrays.asList(2, 3)); // [10, 1, 2, 3]

// 조회
int value = list.get(0);        // 10
int size = list.size();         // 4
boolean empty = list.isEmpty(); // false

// 수정
list.set(0, 5);                 // [5, 1, 2, 3]

// 삭제
list.remove(0);                 // [1, 2, 3] (인덱스로 삭제)
list.remove(Integer.valueOf(2)); // [1, 3] (값으로 삭제)
list.clear();                   // []
```

#### 검색 및 포함 여부[2]

```java
list.contains(1);               // true
list.indexOf(2);                // 1 (첫 등장 위치)
list.lastIndexOf(2);            // 마지막 위치

// 다른 리스트와의 연산
list.containsAll(list2);        // list가 list2의 모든 요소 포함 여부
list.removeAll(list2);          // list에서 list2 요소 모두 삭제 (차집합)
list.retainAll(list2);          // list에서 list2에 있는 것만 남김 (교집합)
```

#### ArrayList 정렬[3]

```java
// 오름차순
Collections.sort(list);

// 내림차순
Collections.sort(list, Collections.reverseOrder());

// 람다식 정렬
list.sort((a, b) -> a - b);     // 오름차순
list.sort((a, b) -> b - a);     // 내림차순
```

#### 배열 ↔ 리스트 변환[2]

```java
// 배열 → 리스트
String[] arr = {"a", "b", "c"};
List<String> list = new ArrayList<>(Arrays.asList(arr));
```

### 7. 자주 헷갈리는 문법 비교표

| 구분            | 올바른 사용                            | 틀린 사용                   | 비고               |
| ------------- | --------------------------------- | ----------------------- | ---------------- |
| **문자열 비교**    | `str.equals("test")`              | `str == "test"`         | 값 비교는 equals     |
| **배열 내림차순**   | `Integer[] arr`                   | `int[] arr`             | 기본형은 불가          |
| **리스트 정렬**    | `Collections.sort(list)`          | `Arrays.sort(list)`     | Collections 사용   |
| **배열 정렬**     | `Arrays.sort(arr)`                | `Collections.sort(arr)` | Arrays 사용        |
| **문자열 반복 추가** | `StringBuilder.append()`          | `String +=`             | StringBuilder 사용 |
| **배열 길이**     | `arr.length`                      | `arr.length()`          | 괄호 없음            |
| **리스트 길이**    | `list.size()`                     | `list.length`           | 괄호 있음            |
| **값 삭제**      | `list.remove(Integer.valueOf(2))` | `list.remove(2)`        | 인덱스 vs 값 구분      |

### 8. Collections vs Arrays 비교[3][4]

| 항목 | Arrays | Collections |
|------|--------|-------------|
| **대상** | 배열 (Array) | 컬렉션 (List, Set 등) |
| **정렬** | `Arrays.sort(arr)` | `Collections.sort(list)` |
| **역순** | `Arrays.sort(arr, Collections.reverseOrder())` | `Collections.sort(list, Collections.reverseOrder())` |
| **최댓값** | 없음 (직접 구현) | `Collections.max(list)` |
| **최솟값** | 없음 (직접 구현) | `Collections.min(list)` |
| **뒤집기** | 없음 | `Collections.reverse(list)` |
| **채우기** | `Arrays.fill(arr, value)` | `Collections.fill(list, value)` |

### 5. 람다식과 스트림 (선택적이지만 알면 유용)

람다식은 **코드를 간결하게 만들지만**, 알고리즘 테스트에서 필수는 아닙니다.[9][10]

```java
// 배열 정렬 - 전통적 방법
int[] arr = {3, 1, 4, 1, 5};
Arrays.sort(arr);

// 배열 정렬 - 람다식 (내림차순)
Integer[] arr2 = {3, 1, 4, 1, 5};
Arrays.sort(arr2, (a, b) -> b - a);

// List 정렬 - 람다식
List<Integer> list = Arrays.asList(3, 1, 4, 1, 5);
Collections.sort(list, (a, b) -> b - a);

// 스트림 활용
List<Integer> filtered = list.stream()
    .filter(n -> n > 2)
    .map(n -> n * 2)
    .collect(Collectors.toList());
```
