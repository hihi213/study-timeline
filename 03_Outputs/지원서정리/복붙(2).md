## 1. int vs Integer (Wrapper 클래스)

> [!NOTE] 핵심 차이: int vs Integer
>
> - **`int` (기본형, Primitive):** 스택 메모리에 실제 값을 저장합니다. `null`을 가질 수 없으며, 기본값은 `0`입니다.
>     
> - **`Integer` (참조형, Wrapper):** 힙 메모리에 객체로 저장(참조)됩니다. `null`을 허용하며, 컬렉션(e.g., `ArrayList`)에 값을 담을 때 반드시 사용해야 합니다.
>     

기본형(int)과 참조형(Integer)의 선언

```Java
// int - 기본형 (Primitive)
int a = 10;             // e.g.: 10. 스택 메모리에 값이 직접 저장됨 (null 불가)
int[] arr1 = {1, 2, 3}; // 기본형 배열 선언

// Integer - 참조형 (Wrapper)
Integer b = 10;         // e.g.: 10. 힙 메모리에 객체로 저장됨 (null 가능)
Integer c = null;       // e.g.: null. 참조형이므로 null 할당 가능 (주의: 언박싱 시 NPE 위험)
```

자동 박싱 및 언박싱

> [!NOTE] 자동 박싱/언박싱
>
> `int`가 `Integer`로 자동 변환되는 것을 '박싱', `Integer`가 `int`로 자동 변환되는 것을 '언박싱'이라 합니다. 이는 편의를 제공하지만, `null`인 `Integer`를 `int`에 대입하려 하면 `NullPointerException`이 발생할 수 있습니다.

```Java
// 자동 박싱/언박싱
Integer boxed = 100;     // 자동 박싱 (int -> Integer)
int unboxed = boxed;     // 자동 언박싱 (Integer -> int)
```

컬렉션 사용 및 비교 연산

> [!WARNING] 래퍼 클래스 비교 (== vs equals)
>
> - `Integer`와 같은 래퍼 클래스는 객체입니다. == 연산자는 객체의 **주소 값**을 비교합니다.
>     
> - **`Integer` 캐시:** Java는 프로그램이 시작될 때 성능을 위해 -128부터 127까지의 숫자에 해당하는 `Integer` 객체 256개를 미리 전부 생성해서 "캐시 풀(cache pool)"에 보관합니다.
> - 이 범위 내에서는 == 비교가 `true`로 나올 수 있지만, 이 범위를 벗어나면 새로운 객체가 생성되므로 `false`가 나옵니다.
>     
> - **결론:** 래퍼 클래스의 '값'을 비교할 때는 반드시 `.equals()`를 사용해야 합니다.
>     
- 256인범위인이유: 1바이트의 표현범위(2^10)
```Java
// 컬렉션에는 기본형 불가 -> Integer 사용
ArrayList<Integer> list = new ArrayList<>();
boolean ok = list.add(1); // [추가 성공 여부 (boolean)]

// 주의: 래퍼 비교는 equals() 사용 (==는 주소/캐시 영향)
boolean bad = (Integer.valueOf(127) == Integer.valueOf(127)); // e.g.: true (캐시 구간 -128~127)
boolean bad2 = (Integer.valueOf(128) == Integer.valueOf(128)); // e.g.: false (캐시 범위 밖)
boolean good = Integer.valueOf(128).equals(Integer.valueOf(128)); // [값 일치 여부 (boolean)]
```

## 2. 입력: Scanner vs BufferedReader/Writer (+개행 이슈 해결)

> [!SUMMARY] Scanner vs BufferedReader
>
> - **Scanner:** 사용이 간편하나, 입력 버퍼가 작고 파싱(정규식 기반) 비용이 있어 대용량 입력 시 매우 느릴 수 있습니다. (간단한 입력에 추천)
>     
> - **BufferedReader:** 버퍼를 사용하여 한 번에 많은 데이터를 읽어(I/O 횟수 감소) 빠릅니다. (대용량 입력, 코딩 테스트 주력)
>     
> - **SSAFY 등:** 대부분 문제는 `Scanner`로도 통과 가능하지만, 시간 초과가 발생하면 `BufferedReader` 사용을 고려해야 합니다.
>     

Scanner 기본 사용

```Java
import java.util.*;

Scanner sc = new Scanner(System.in);
int a = sc.nextInt();       // [읽어들인 정수 (int)]
String word = sc.next();    // [읽어들인 단어 (String)]
String line = sc.nextLine(); // [읽어들인 한 줄 (String)]
double d = sc.nextDouble(); // [읽어들인 실수 (double)]
long l = sc.nextLong();     // [읽어들인 긴 정수 (long)]
```

> [!WARNING] `nextInt()` 이후 `nextLine()` 개행
>
> nextInt()와 같은 "Token" 기반 읽기는 '엔터' (개행 문자, \n)를 버퍼에 남겨둡니다.
>
> 이 상태에서 nextLine()을 호출하면, 버퍼에 남아있던 \n을 읽고 즉시 종료되어 빈 문자열("")을 반환합니다.

```Java
Scanner sc = new Scanner(System.in);
int n = sc.nextInt();        // e.g.: "5\n" 입력, 5만 읽고 \n은 버퍼에 남음
String sBug = sc.nextLine(); // e.g.: "" (빈 문자열), 버퍼의 \n을 읽고 종료됨
```

개행 이슈 해결법 (Scanner)

```Java
// 해결
int n2 = sc.nextInt();
sc.nextLine();             // 버퍼의 개행(\n)을 소모시킴
String s = sc.nextLine();    // [정상적으로 읽어들인 한 줄 (String)]
```

BufferedReader + StringTokenizer (대용량 입력 권장)

```Java
import java.io.*;
import java.util.*;

BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
String line2 = br.readLine(); // [읽어들인 한 줄 (String)], EOF 시 null
StringTokenizer st = new StringTokenizer(line2);
int x = Integer.parseInt(st.nextToken()); // [파싱된 정수 (int)]
int y = Integer.parseInt(st.nextToken()); // [파싱된 정수 (int)]

// 공백 기준 단순 분할은 StringTokenizer가 split보다 보통 빠름(정규식 비용 없음)
String[] tokens = line2.split(" "); // [분할된 문자열 배열 (String[])]
```
- `System.in`: 시스템의 '표준 입력 장치'를 의미합니다. (보통은 **키보드**입니다.) 문제는 키보드 입력은 1바이트(byte) 단위로 데이터를 읽어들입니다.
- `new InputStreamReader(…)`: `System.in`으로 들어온 바이트(byte) 데이터를 우리가 읽을 수 있는 문자(char) 단위로 변환해주는 다리 역할을 합니다.
- `new BufferedReader(…)`: `InputStreamReader`가 변환한 문자들을 한 글자씩 바로 읽지 않고, '버퍼(buffer)'라는 임시 저장 공간에 데이터를 모아 둡니다. 덕분에 한 줄을 통째로 읽어오는 `readLine()` 같은 메소드를 빠르고 효율적으로 사용할 수 있습니다.
- `br.readLine()`: 버퍼에서 사용자가 'Enter' 키를 누르기 전까지의 모든 문자를 **한 줄(Line) 통째로** 읽어들입니다.
- `String line2`: 읽어들인 한 줄의 문자열을 `line2`라는 변수에 저장합니다. (만약 사용자가 "10 20"을 입력하고 Enter를 쳤다면, `line2` 변수에는 `"10 20"`이라는 문자열이 저장됩니다.)
- `StringTokenizer`: 문자열을 '토큰(Token)' 단위로 쪼개주는 클래스입니다. 기본적으로 **공백(space)**을 기준으로 문자열을 분리합니다. (즉, `"10 20"`을 `"10"`과 `"20"` 두 개의 토큰으로 쪼갭니다.)
- `st.nextToken()`: `StringTokenizer`에서 **첫 번째** 토큰을 꺼냅니다. (예: `"10"`)
- `Integer.parseInt(…)`: `nextToken()`으로 꺼내온 것은 아직 **문자열** `"10"`입니다. 이 문자열을 실제 **숫자(int)** 10으로 변환합니다.
> [!NOTE] 빠른 출력 (BufferedWriter + StringBuilder)
>
> System.out.println()은 호출될 때마다 I/O가 발생하여 느립니다.
>
> StringBuilder에 모든 출력 내용을 누적한 뒤, BufferedWriter로 한 번에 출력(Flush)하는 것이 가장 빠릅니다.

```Java
import java.io.*;

BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
StringBuilder out = new StringBuilder();

out.append("answer").append('\n'); // [자기 자신 (StringBuilder)], 체이닝 가능
bw.write(out.toString()); // [반환값 없음 (void)]
bw.flush();               // [반환값 없음 (void)], 버퍼를 비워 실제 출력
```
- `System.out`: 시스템의 '표준 출력 장치'입니다. (보통은 **콘솔 화면**입니다.) 이 장치는 1바이트(byte) 단위로 데이터를 처리합니다.
- `new OutputStreamWriter(…)`: 자바의 문자(char) 데이터를 `System.out`이 알아들을 수 있는 바이트(byte) 데이터로 변환해주는 다리 역할을 합니다.
- `new BufferedWriter(…)`: `OutputStreamWriter`로 변환된 데이터를 바로바로 화면에 쏘지 않고, '버퍼(buffer)'라는 임시 저장 공간에 모아 둡니다.
- `out.append("answer")`: `StringBuilder` 객체(`out`)에 "answer"라는 문자열을 추가합니다.
- `.append('\n')`: 이어서(chaining), 줄 바꿈 문자(`\n`)를 "answer" 뒤에 바로 추가합니다.
- `out.toString()`: `StringBuilder`가 조립한 문자열(`answer\n`)을 최종적으로 하나의 `String` 객체로 변환합니다.
- `bw.write(…)`: 이 `String`을 `BufferedWriter`의 **버퍼(임시 저장소)에 씁니다.**
	- **[중요]** 이 시점까지는 **아직 화면에 아무것도 출력되지 않습니다.** 데이터는 버퍼에 쌓여있기만 합니다.
- `flush()`: "내보내기" 또는 "버퍼 비우기"라는 뜻입니다.
	- `BufferedWriter`에게 "지금까지 버퍼에 모아둔 모든 데이터를 **즉시 `System.out`(콘솔 화면)으로 전부 내보내라!**"고 명령합니다.

## 3. 문자열(String) 핵심 메서드

> [!WARNING] String의 불변성(Immutability)
>
> `String` 객체는 한 번 생성되면 변경할 수 없습니다. `replace`, `substring` 등은 모두 **새로운 String 객체를 생성**하여 반환합니다. 루프 내에서 문자열을 반복적으로 더하면(`+=`) 성능이 저하되므로 `StringBuilder` 사용이 권장됩니다.

기본 조회 (길이, 문자, 인덱스)

```Java
String str = "algorithm";

// 문자열 길이
int len = str.length();       // [문자열 길이 (int)]

// 특정 위치의 문자 가져오기
char first = str.charAt(0); // [해당 인덱스의 문자 (char)]

// 문자/문자열 인덱스 검색
int idxG = str.indexOf('g');      // [찾은 첫 인덱스 (int)], 없으면 -1
int lastI = str.lastIndexOf("i"); // [찾은 마지막 인덱스 (int)], 없으면 -1

// 값 여부 체크
boolean empty = str.isEmpty(); // [비어있는지 여부 (boolean)]
```

문자열 자르기 및 변환

```Java
// 부분 문자열
String sub1 = str.substring(0, 3); // [잘라낸 새 부분 문자열 (String)]
String sub2 = str.substring(3);    // [잘라낸 새 부분 문자열 (String)]

// 문자/문자열 치환
String rep = str.replace("a", "o");       // [치환된 새 문자열 (String)] (모든 "a"를 "o"로)
String repAll = "a1b2c3".replaceAll("\\d", ""); // [치환된 새 문자열 (String)] (정규식, 모든 숫자 제거)
String repFirst = str.replaceFirst("l", "L"); // [치환된 새 문자열 (String)] (첫 번째 "l"만 "L"로)

// 대소문자/공백
String upper = str.toUpperCase(); // [변환된 새 문자열 (String)]
String lower = str.toLowerCase(); // [변환된 새 문자열 (String)]
String trimmed = "  hello  ".trim(); // [앞뒤 공백이 제거된 새 문자열 (String)]
```

문자열 비교 (값, 포함, 순서)

> [!NOTE] 문자열 비교: == vs `equals()`
>
> |**비교 방식**|**비교 대상**|**사용 상황**|
> |---|---|---|
> | == |메모리 주소(참조값)|기본형(int, char) 비교 또는 두 객체가 '완전히' 동일한 객체인지 확인|
> |`equals()`|실제 문자열 값|**문자열의 내용(값)이 같은지 비교할 때 필수**|

```Java
// 포함 비교
boolean hasGo = str.contains("go"); // [포함 여부 (boolean)]

// 접두/접미 비교
boolean starts = str.startsWith("al"); // [접두사 일치 여부 (boolean)]
boolean ends = str.endsWith("thm"); // [접미사 일치 여부 (boolean)]

// 사전순 비교
int cmp = str.compareTo("banana"); // [사전순 비교 결과 (int)], 음수(빠름)/0(같음)/양수(느림)

// 값 비교 (==으로 비교 금지)
boolean eq = str.equals("algorithm");         // [값 일치 여부 (boolean)]
boolean eqIgnore = str.equalsIgnoreCase("ALGORITHM"); // [값 일치 여부(대소문자 무시) (boolean)]
```

문자열 분리 및 형변환

```Java
// 분할
String[] parts = "1 2 3 4 5".split(" "); // [분할된 문자열 배열 (String[])]

// char 배열로 변환
char[] chars = "hello".toCharArray(); // [변환된 문자 배열 (char[])]

// 숫자 <-> 문자열
int n = Integer.parseInt("123");     // [변환된 숫자 (int)]
long L = Long.parseLong("999999");     // [변환된 숫자 (long)]
double D = Double.parseDouble("3.14"); // [변환된 숫자 (double)]

String s1 = Integer.toString(456);     // [변환된 문자열 (String)]
String s2 = String.valueOf(789);     // [변환된 문자열 (String)]
String s3 = "" + 789;                  // e.g.: "789" (비추천: 임시 String 생성)
```

## 4. StringBuilder (문자열 누적)

> [!NOTE] StringBuilder (가변 문자열)
>
> `String`의 불변성 문제를 해결하기 위해 사용합니다. 원본 객체가 직접 변경(mutable)되므로, 루프 등에서 문자열을 누적할 때 `String +=` 대신 `StringBuilder.append()`를 사용해야 시간 초과를 피할 수 있습니다.

문자열 추가 및 삽입

```Java
StringBuilder sb = new StringBuilder();

// 문자열 추가
StringBuilder after1 = sb.append("hello"); // [자기 자신 (StringBuilder)], 체이닝 가능
StringBuilder after2 = sb.append(" world"); // [자기 자신 (StringBuilder)]

// 특정 위치에 삽입
StringBuilder after3 = sb.insert(5, " Java"); // [자기 자신 (StringBuilder)]
```

문자열 삭제 및 변경

```Java
// 문자열 삭제
StringBuilder after4 = sb.delete(5, 10);     // [자기 자신 (StringBuilder)]
StringBuilder after5 = sb.deleteCharAt(0); // [자기 자신 (StringBuilder)]

// 특정 위치 문자 변경
sb.setCharAt(0, 'H'); // [반환값 없음 (void)]
```

문자열 유틸리티 (뒤집기, 변환)

```Java
// 문자열 뒤집기 (팰린드롬 문제에 유용)
StringBuilder reversed = sb.reverse(); // [뒤집힌 자기 자신 (StringBuilder)]

// 길이 조정
sb.setLength(5); // [반환값 없음 (void)]

// String으로 변환
String result = sb.toString(); // [변환된 새 String 객체 (String)]
```

## 5. 배열(Array)

> [!NOTE] 배열 (Array)
>
> 크기가 고정된(fixed-size) 데이터 구조입니다. 기본형(`int`, `char`) 및 참조형(`String`, `Object`)을 저장할 수 있습니다. 선언 시 크기를 지정해야 하며, 길이는 `length` 필드로 접근합니다.

> [!WARNING] Comparator 정렬 시 오버플로 주의
>
> 2차원 배열이나 객체를 정렬할 때 (a, b) -> a[0] - b[0] 방식은 a[0]과 b[0]의 값 차이가 Integer.MAX_VALUE를 넘어가면 오버플로가 발생하여 정렬이 깨질 수 있습니다.
>
> 반드시 Integer.compare(a[0], b[0])를 사용하는 것이 안전합니다.

배열 선언, 초기화 및 길이

```Java
// 선언/초기화
int[] a1 = new int[5]; // [0으로 초기화된 배열 객체 (int[])]
int[] a2 = {1,2,3,4,5}; // [값이 채워진 배열 객체 (int[])]
int[] a3 = new int[]{1,2,3}; // [값이 채워진 배열 객체 (int[])]

// 2차원 배열
int[][] mat = new int[3][4]; // [2차원 배열 객체 (int[][])]
int[][] mat2 = {{1,2},{3,4},{5,6}}; // [2차원 배열 객체 (int[][])]

// 배열 길이
int lenA2 = a2.length;    // [배열의 길이 (int)]
int rows = mat.length;    // [2차원 배열의 행 길이 (int)]
int cols = mat[0].length; // [2차원 배열의 0번 행의 열 길이 (int)]
```

1차원 배열 정렬

```Java
// 오름차순 정렬
Arrays.sort(a2); // [반환값 없음 (void)]

// 내림차순 정렬: 기본형은 불가 -> Integer로 박싱 필요
```

## 6. ArrayList (동적 배열)

> [!NOTE] ArrayList (동적 배열)
>
> 크기가 가변적인(dynamic-size) 리스트입니다. 내부적으로 배열을 사용하지만, 공간이 부족하면 자동으로 크기를 늘립니다. `int`와 같은 기본형은 저장할 수 없으며, 반드시 `Integer` 같은 래퍼 클래스를 사용해야 합니다.

> [!WARNING] ArrayList.remove() 함정: 인덱스(int) vs 값(Object)
>
> ArrayList\<Integer>에서 list.remove(2)를 호출하면, '값 2'를 지우는 것이 아니라 **'2번 인덱스'**의 요소를 지웁니다.
>
> '값'을 기준으로 지우려면, list.remove(Integer.valueOf(2))와 같이 객체(래퍼) 형태로 명시해야 합니다.

ArrayList 기본 연산 (추가, 조회, 수정)

```Java
// 추가

list.addAll(Arrays.asList(2, 3)); // [추가 성공 여부 (boolean)]

// 조회
int v = list.get(0);        // [해당 인덱스의 값 (Integer)]
int sz = list.size();       // [리스트의 크기(요소 개수) (int)]
boolean isEmp = list.isEmpty(); // [리스트가 비었는지 여부 (boolean)]

// 수정
Integer old = list.set(0, 5); // [수정되기 전의 이전 값 (Integer)]
```


## 7. Map, Set, Queue, Stack

> [!NOTE] HashMap (해시 맵)
>
> **Key-Value** 쌍을 저장하는 자료구조입니다. Key의 해시값을 기반으로 값을 저장하므로, 평균 **O(1)**의 속도로 삽입, 삭제, 조회가 가능합니다. (Key는 중복될 수 없습니다.)

HashMap 기본 연산 (추가, 조회)

```Java
import java.util.*;

Map<String, Integer> map = new HashMap<>();

// put: 추가, 수정
Integer prev = map.put("apple", 100); // [삽입/수정 전의 이전 값 (Integer)], 없었으면 null

// get: 조회
Integer got = map.get("apple"); // [조회된 값 (Integer)], 없으면 null

// 조회, 없으면 기본값 반환
int def = map.getOrDefault("grape", 0); // [조회된 값 (int)], 없으면 기본값 0 반환
```

HashMap 상태 확인 및 삭제

```Java
// 존재 여부
boolean k = map.containsKey("apple"); // [키 존재 여부 (boolean)]
boolean v2 = map.containsValue(100);  // [값 존재 여부 (boolean)]

// 삭제
Integer rm = map.remove("apple"); // [삭제된 값 (Integer)], 없었으면 null

// 크기
int msize = map.size();        // [맵의 크기(엔트리 개수) (int)]
boolean mempty = map.isEmpty(); // [맵이 비었는지 여부 (boolean)]
```

HashMap 빈도수 계산 및 순회

```Java

// 위와 동일한 로직 (조회 + 1 해서 put)
map.put("kiwi", map.getOrDefault("kiwi", 0) + 1); // [삽입/수정 전의 이전 값 (Integer)]

// 키가 없을 때만 삽입
map.putIfAbsent("orange", 0); // (키가 없을 때만) [삽입된 값 (Integer)], 이미 있으면 null

// 순회

for (Map.Entry<String,Integer> e : map.entrySet()) { /* 키-값(Entry) 쌍으로 순회 (권장) */ }
```

> [!NOTE] Set, Queue, Stack
>
> - **`HashSet`:** 중복을 허용하지 않는 `Set`입니다. `HashMap`의 키셋을 이용하며, `add`, `remove`, `contains`가 평균 O(1)입니다.
>     
> - **`Queue` (FIFO):** BFS에 사용됩니다. `LinkedList`보다 `ArrayDeque`가 더 빠릅니다.
>     
> - **`Stack` (LIFO):** DFS에 사용됩니다. `java.util.Stack`은 레거시(동기화 비용)이므로, `ArrayDeque`를 `push`/`pop`으로 사용하는 것이 표준입니다.
>     

HashSet (중복 없는 집합)

```Java
Set<Integer> set = new HashSet<>();
boolean s1 = set.add(1); // [추가 성공 여부 (boolean)]
boolean s2 = set.add(1); // [추가 성공 여부 (boolean)], e.g.: false (중복)
boolean c1 = set.contains(1); // [포함 여부 (boolean)]
boolean r1 = set.remove(1); // [삭제 성공 여부 (boolean)]
int ssize = set.size(); // [셋의 크기(요소 개수) (int)]
```

Queue (FIFO, ArrayDeque 권장)

```Java
// add/offer·peek/element·poll/remove 차이 주의 (Exception vs null/false)
// BFS 등에서는 offer/poll/peek (null 반환)이 안전함
Deque<Integer> q = new ArrayDeque<>();
boolean ok1 = q.offer(1); // [추가 성공 여부 (boolean)]
q.offer(2);
Integer head = q.peek(); // [큐의 헤드(첫 요소) (Integer)], 비어있으면 null
Integer rem = q.poll(); // [큐의 헤드(첫 요소) (Integer)]를 제거하며 반환, 비어있으면 null
```

Stack (LIFO, ArrayDeque 권장)

```Java
// Stack 대체: Deque 사용 권장 (java.util.Stack은 레거시)
Deque<Integer> stack = new ArrayDeque<>();
stack.push(1); // [반환값 없음 (void)]
stack.push(2);
Integer top = stack.peek(); // [스택의 탑(첫 요소) (Integer)], 비어있으면 null
Integer pop = stack.pop(); // [스택의 탑(첫 요소) (Integer)]을 제거하며 반환, 비어있으면 null
```

## 8. PriorityQueue (우선순위 큐)

> [!SUMMARY] PriorityQueue (우선순위 큐)
>
> 힙(Heap) 자료구조를 기반으로 하며, 요소를 추가할 때마다 정렬 상태를 유지합니다.
>
> - **기본 (Min-Heap):** 가장 작은 값이 최상단에 위치합니다. (`poll` 시 최솟값 반환)
>     
> - **Max-Heap:** `Collections.reverseOrder()`를 통해 가장 큰 값이 최상단에 위치하도록 설정합니다. (`poll` 시 최댓값 반환)
>     

최소 힙 (Min-Heap, 기본)

```Java
import java.util.*;

// 최소 힙(기본)
PriorityQueue<Integer> minHeap = new PriorityQueue<>();
minHeap.offer(5);
minHeap.offer(2);
minHeap.offer(8);
Integer min = minHeap.poll(); // [우선순위가 가장 높은 값(최솟값) (Integer)]을 제거하며 반환
```

최대 힙 (Max-Heap)

```Java
// 최대 힙
PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Collections.reverseOrder());
maxHeap.offer(5); maxHeap.offer(2); maxHeap.offer(8);
Integer max = maxHeap.poll(); // [우선순위가 가장 높은 값(최댓값) (Integer)]을 제거하며 반환
```

커스텀 정렬 (Lambda, 2차원 배열)

```Java
// 커스텀 비교: (value, idx) 쌍을 value 오름차순
PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> Integer.compare(a[0], b[0]));
pq.offer(new int[]{7, 0});
pq.offer(new int[]{3, 1});
int[] best = pq.poll(); // [우선순위가 가장 높은 요소(배열) (int[])] 반환
```

## 9. 자주 헷갈리는 문법 비교표

|**구분**|**올바른 사용**|**틀린 사용**|**비고**|
|---|---|---|---|
|**문자열 비교**|str.equals("test")|str == "test"|값 비교는 `equals`|

## 11. 람다 & 스트림 (선택)

> [!NOTE] 람다(Lambda) & 스트림(Stream)
>
> - **람다:** 익명 함수를 간결하게 표현하는 방식입니다. 주로 정렬(Comparator)이나 스레드(Runnable) 구현에 사용됩니다.
>     
> - **스트림:** 컬렉션 데이터를 함수형 프로그래밍 스타일로 처리(필터링, 매핑, 집계)하는 API입니다. 코드가 간결해지지만, 루프 내에서 반복 생성 시 성능 저하가 발생할 수 있습니다.
>     

람다를 이용한 정렬

```Java
// 정렬(람다)
List<Integer> L = Arrays.asList(3,1,4,1,5);
L.sort((a,b) -> Integer.compare(a,b)); // [반환값 없음 (void)]
L.sort((a,b) -> Integer.compare(b,a)); // [반환값 없음 (void)]

List<String> S = Arrays.asList("a","bbb","cc");
S.sort((s1,s2) -> Integer.compare(s1.length(), s2.length())); // [반환값 없음 (void)]
```

스트림을 이용한 데이터 처리

```Java
// 스트림
List<Integer> filtered = L.stream()
    .filter(n -> n > 2)
    .map(n -> n * 2)
    .collect(Collectors.toList()); // [최종 연산 결과(새 리스트) (List<Integer>)]

int sum = L.stream().mapToInt(Integer::intValue).sum(); // [최종 집계 결과(합계) (int)]
long cnt = L.stream().filter(x -> x % 2 == 0).count(); // [최종 집계 결과(개수) (long)]

List<Integer> sortedDesc = L.stream()
    .sorted(Comparator.reverseOrder())
    .collect(Collectors.toList()); // [최종 연산 결과(새 리스트) (List<Integer>)]
```

## 13. 빠른 입출력 템플릿 (실전용)

> [!SUMMARY] 빠른 입출력 (Fast I/O) 템플릿
>
> `BufferedReader`로 입력을 받고 `StringTokenizer`로 파싱하는 `FastScanner` 내부 클래스를 구현한 템플릿입니다. 출력은 `StringBuilder`에 누적했다가 `System.out.print`로 한 번에 출력하여 입출력 속도를 극대화합니다.

빠른 입출력 템플릿

```Java
import java.io.*;
import java.util.*;

public class Main {
    static final FastScanner fs = new FastScanner();
    static final StringBuilder out = new StringBuilder();

    public static void main(String[] args) throws Exception {
        int n = fs.nextInt(); // [읽은 정수 (int)]
        for (int i = 0; i < n; i++) {
            int a = fs.nextInt();
            int b = fs.nextInt();
            out.append(a + b).append('\n'); // [자기 자신 (StringBuilder)]을 반환하여 체이닝
        }
        System.out.print(out.toString()); // [반환값 없음 (void)]
    }

    // BufferedReader + StringTokenizer 기반
    static final class FastScanner {
        private final BufferedReader br;
        private StringTokenizer st;

        FastScanner() { br = new BufferedReader(new InputStreamReader(System.in)); }

        String next() throws IOException {
            while (st == null || !st.hasMoreTokens()) st = new StringTokenizer(br.readLine());
            return st.nextToken(); // [다음 토큰(단어) (String)]
        }
        
        int nextInt() throws IOException { return Integer.parseInt(next()); } // [파싱된 정수 (int)]
        long nextLong() throws IOException { return Long.parseLong(next()); } // [파싱된 긴 정수 (long)]
        String nextLine() throws IOException { return br.readLine(); } // [읽어들인 한 줄 (String)]
    }
}
```

- 문자열 비교는 **equals**, 래퍼 비교도 **equals**
