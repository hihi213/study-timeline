




불안은 혼자서 진행한 졸업 프로젝트에서 현실이 되었습니다. 기숙사 시스템 기획을 위해 LG전자 문의 등 사용자 맥락은 집요하게 파고들었지만, 설계에 몰두하다 마감에 쫓겨 AI에 의존해 구현과 배포까지 마쳤습니다. 기능은 작동했으나, AI의 환각과 검증 부재로 코드의 정합성을 확신하지 못한 채 마무리를 지어야 했습니다. 제가 전시회때 선보인 프로젝트를 제것이 아니라고 느꼈고 이걸 실제 서비스 한다고 생각하니 저는 실제 운영의 안전을 보장할수없다고 느꼈고 이는 껍데기 뿐인 서비스라고 느꼈습니다 코드 한 줄에도 확신과 책임을 지는, 견고한 서버 개발자가 목표입니다. 이 과정을 통해 혼자 하는 산발적 학습이 아닌, 체계적인 교육과 동료와의 상호작용이 절실함을 깨달았습니다.

부트캠프에서 동료와 코드를 주고받으며 가장 빠르게 성장했다는 점에서, 혼자 공부하는 지금의 방식에는 한계를 느끼고 있습니다. 기숙사 생활 불편을 해결하는 졸업 프로젝트에서는 운영 주체와 직접 소통하며 요구사항을 설계했으나, 시간 관리 실패로 막판 구현을 AI에 의존해 코드의 타당성을 끝까지 검증하지 못했습니다.


코드 한 줄에도 확신과 책임을 지는 서버 개발자가 되고 싶습니다. 비동일계 편입 후(부족해서 부트캠프에 갔고 과제가 아닌 혼자서 자발적으로 작은게임만들며 실습하며 성장했고 내가 개발의 길이 맞다는 희열을 느꼈다) (혼자서 진행했다는것도 졸업 프로젝트의 실패 요인이라고 생각한다
편입했음에 위축되어 주위에 바운더리에 개발자들 없다 졸업후 더 좁아질 바운더리을 싸피를 통해 넓히고싶다)함께 몰입할 때 가장 빠르게 성장함을 체감했습니다. 하지만 복학 후 혼자 하는 학습은 한계가 명확했습니다. AI를 활용해 복습노트를 생성해 효율을 높여 준수한 성적은 거두었지만, 경쟁과 피드백이 부재한 환경에서 제 실력은 검증되지 않은 채 고립되었습니다. 졸업프로젝트의 기획과 설계에 몰두하다 마감에 쫓겨 AI에 의존해 기능만 구현했고, 테스트와 보안, 장애 대응을 스스로 설명하지 못한 채 전시를 마쳤습니다. 실제 서비스를 운영한다면 감당할 수 없다는 두려움이 남았습니다. 독학으로는 설계와 운영 전반을 검증할 기준과 피드백이 부족하다는 것을 깨달았습니다. 이 과정을 통해, ‘요령’이 아닌 ‘진짜 실력’을 쌓기 위해서는 체계적인 시스템이 절실함을 깨달았습니다.
산발적인 저의 학습은 '열심히'를 '실력'으로 바꾸지 못한다는 한계를 깨달았습니다. 체계적인 교육과 동료와의 상호 피드백이 절실합니다. 1년간 알고리즘과 백엔드 심화, 코드 리뷰와 협업 프로젝트를 통해 설계부터 배포 전 과정을 반복 경험하며 ‘돌아가는 코드’를 넘어 ‘설명할 수 있는 코드’를 만들겠습니다.
교육 기간 동안 졸업 프로젝트를 안정적인 서버 아키텍처로 재구축해 실사용 서비스로 운영하며, 실무에 투입 가능한 서버 개발자로 성장하겠습니다. 동료 개발자들과의 상호 피드백으로 혼자서는 만들 수 없는 기준을 세우고 싶습니다.
누구보다 치열하게 달릴 준비는 되어 있었지만, 이것저것 시도해보는 산발적인 탐구만으로는 '열심히'가 '실력'으로 직결되지 않는 한계를 느꼈습니다. 막연한 불안감 속에서 에너지를 소모하는 대신, SSAFY의 검증된 커리큘럼이라는 확실한 지도 위에서 제대로 달리고 싶습니다. 제 강점인 끈기와 몰입력을 이제는 시행착오가 아닌, 실질적인 역량을 쌓는 데 쏟아붓고 싶습니다.
단기적인 성과에 급급해 기초를 소홀히 했던 과거를 반복하고 싶지 않습니다. 경제적 고민 없이 오직 개발에만 집중할 수 있는 1년 동안, 동료들과 끊임없이 상호작용을 하며 산발적으로 흩어진 지식을 실무 역량으로 구조화하겠습니다. SSAFY라는 최적의 판에서, 저보다 뛰어난 동료들 틈에서 건전한 자극을 받으며 지금까지 쌓은 전공 기초와 졸업 프로젝트에서의 엉성한 설계를 실제 서비스 수준으로 끌어올리고, 동료와 함께 성장하는 서버 개발자로서의 역량과 자신감을 갖추고 싶습니다.

코드 한 줄에도 확신과 책임을 지는 서버 백엔드 개발자가 되고 싶습니다. 비동일계 편입 후 부트캠프에서 과제 외 작은 게임을 만들며 개발의 즐거움을 느꼈지만, 졸업 프로젝트를 혼자 진행하며 설계에만 치중한 채 마감에 쫓겨 AI에 의존해 기능만 구현했고 테스트·보안·장애 대응을 설명하지 못했습니다. 돌아가는 코드지만 환각·검증 부재로 실제 서비스 운영을 감당할 수 없다는 한계를 뚜렷이 인식했습니다. 이 격차를 SSAFY 1년 과정에 맞춰 채우겠습니다. 초반 [알고리즘]·[Web(Java)]로 기초를, [AI 강의/관통 PJT]로 AI 책임 기준을 세우겠습니다. 심화 [공통/특화 PJT]에서는 팀 코드 리뷰와 페어 프로그래밍으로 부족했던 실전 협업 역량을 극대화하고, [자율 PJT]에서 이를 집대성하여 졸업 프로젝트를 운영 가능한 서버 아키텍처로 재구축하겠습니다. 경제적 고민 없이 1년간 몰입해, [Job Fair]에서 검증받는 개발자가 되겠습니다.



코드 한 줄에도 확신과 책임을 지는 서버 백엔드 개발자가 되고 싶습니다. 졸업 프로젝트를 혼자 진행하며 복습용·구현용 프롬프트를 나눠 AI에 의존해 기능만 빠르게 구현했지만, 테스트·보안·장애 대응을 설명하지 못했고, 돌아가는 코드임에도 환각·검증 부재로 실제 서비스에 올리기 어려운 수준이라는 한계를 뚜렷이 깨달았습니다. 이 격차를 SSAFY 1년 과정으로 구조적으로 메우겠습니다. 초기 알고리즘 과정에서 자료구조·문제 해결력을, Web(Java)에서 예외 처리·테스트를 반복해 ‘기능만 있는 코드’를 ‘신뢰할 수 있는 코드’로 다듬고, AI 강의와 SW·AI 관통 프로젝트에서는 생성형 AI를 코딩 어시스턴트·API로 활용하되 검증·로그까지 제가 설계하며 AI 활용의 책임 범위를 분명히 하겠습니다. 심화 [공통/특화 PJT]에서는 팀 코드 리뷰와 페어 프로그래밍으로 부족했던 실전 협업 역량을 극대화하고, [자율 PJT]에서 이를 집대성하여 졸업 프로젝트를 운영 가능한 서버 아키텍처로 재구축해 GitHub 포트폴리오와 Job Fair에서 그 결과를 외부에서 검증받겠습니다. 경제적 고민 없이 1년간 통학과 자기주도 학습·동료 피드백을 루틴화해 혼자서는 만들지 못했던 기준을 갖춘 백엔드 개발자로 성장하겠습니다.
