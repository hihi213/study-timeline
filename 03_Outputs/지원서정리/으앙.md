#### 기본 메서드[1][2]

```java
List<Integer> list = new ArrayList<>();

// 추가
list.add(1);                    // [1]
list.add(0, 10);                // [10, 1] (인덱스 0에 삽입)
list.addAll(Arrays.asList(2, 3)); // [10, 1, 2, 3]

// 조회
int value = list.get(0);        // 10
int size = list.size();         // 4
boolean empty = list.isEmpty(); // false

// 수정
list.set(0, 5);                 // [5, 1, 2, 3]

// 삭제
list.remove(0);                 // [1, 2, 3] (인덱스로 삭제)
list.remove(Integer.valueOf(2)); // [1, 3] (값으로 삭제)
list.clear();                   // []
```

#### 검색 및 포함 여부[2]

```java
list.contains(1);               // true
list.indexOf(2);                // 1 (첫 등장 위치)
list.lastIndexOf(2);            // 마지막 위치

// 다른 리스트와의 연산
list.containsAll(list2);        // list가 list2의 모든 요소 포함 여부
list.removeAll(list2);          // list에서 list2 요소 모두 삭제 (차집합)
list.retainAll(list2);          // list에서 list2에 있는 것만 남김 (교집합)
```

#### 배열 ↔ 리스트 변환[2]

```java
// 배열 → 리스트
String[] arr = {"a", "b", "c"};
List<String> list = new ArrayList<>(Arrays.asList(arr));

// int 배열 → 리스트 (특별 처리 필요)
int[] intArr = {1, 2, 3};
List<Integer> intList = Arrays.stream(intArr).boxed().collect(Collectors.toList());

// 리스트 → 배열
String[] newArr = list.toArray(new String[list.size()]);

// 리스트(Integer) → int 배열
int[] newIntArr = intList.stream().mapToInt(x -> x).toArray();
```

### 5. Map, Set, Queue, Stack

#### HashMap[1]

```java
Map<String, Integer> map = new HashMap<>();

// 추가/수정
map.put("apple", 100);
map.put("banana", 200);

// 조회
int value = map.get("apple");           // 100
int defaultVal = map.getOrDefault("grape", 0);  // 없으면 0 반환

// 존재 여부
map.containsKey("apple");               // true
map.containsValue(100);                 // true

// 삭제
map.remove("apple");

// 순회
for (String key : map.keySet()) {
    System.out.println(key + ": " + map.get(key));
}

for (Map.Entry<String, Integer> entry : map.entrySet()) {
    System.out.println(entry.getKey() + ": " + entry.getValue());
}

// 크기
map.size();
map.isEmpty();
```

#### HashSet[1]

```java
Set<Integer> set = new HashSet<>();

// 추가
set.add(1);
set.add(2);
set.add(1);  // 중복 무시

// 포함 여부
set.contains(1);  // true

// 삭제
set.remove(1);

// 크기
set.size();

// 순회
for (int num : set) {
    System.out.println(num);
}
```

#### Queue (BFS에서 필수)[1]

```java
Queue<Integer> queue = new LinkedList<>();

// 추가
queue.offer(1);  // 또는 queue.add(1)
queue.offer(2);

// 조회 (제거 안 함)
int front = queue.peek();  // 1

// 제거하면서 조회
int removed = queue.poll();  // 1

// 크기
queue.size();
queue.isEmpty();
```

#### Stack (DFS에서 사용)[1]

```java
Stack<Integer> stack = new Stack<>();

// 추가
stack.push(1);
stack.push(2);

// 조회 (제거 안 함)
int top = stack.peek();  // 2

// 제거하면서 조회
int popped = stack.pop();  // 2

// 크기
stack.size();
stack.isEmpty();
```

### 7. 자주 헷갈리는 문법 비교표

| 구분            | 올바른 사용                            | 틀린 사용                   | 비고               |
| ------------- | --------------------------------- | ----------------------- | ---------------- |
| **문자열 비교**    | `str.equals("test")`              | `str == "test"`         | 값 비교는 equals     |
| **배열 내림차순**   | `Integer[] arr`                   | `int[] arr`             | 기본형은 불가          |
| **리스트 정렬**    | `Collections.sort(list)`          | `Arrays.sort(list)`     | Collections 사용   |
| **배열 정렬**     | `Arrays.sort(arr)`                | `Collections.sort(arr)` | Arrays 사용        |
| **문자열 반복 추가** | `StringBuilder.append()`          | `String +=`             | StringBuilder 사용 |
| **배열 길이**     | `arr.length`                      | `arr.length()`          | 괄호 없음            |
| **리스트 길이**    | `list.size()`                     | `list.length`           | 괄호 있음            |
| **값 삭제**      | `list.remove(Integer.valueOf(2))` | `list.remove(2)`        | 인덱스 vs 값 구분      |

### 8. Collections vs Arrays 비교[3][4]

| 항목 | Arrays | Collections |
|------|--------|-------------|
| **대상** | 배열 (Array) | 컬렉션 (List, Set 등) |
| **정렬** | `Arrays.sort(arr)` | `Collections.sort(list)` |
| **역순** | `Arrays.sort(arr, Collections.reverseOrder())` | `Collections.sort(list, Collections.reverseOrder())` |
| **최댓값** | 없음 (직접 구현) | `Collections.max(list)` |
| **최솟값** | 없음 (직접 구현) | `Collections.min(list)` |
| **뒤집기** | 없음 | `Collections.reverse(list)` |
| **채우기** | `Arrays.fill(arr, value)` | `Collections.fill(list, value)` |

```java
int sum = list.stream().mapToInt(Integer::intValue).sum();
```

### 5. 람다식과 스트림 (선택적이지만 알면 유용)

람다식은 **코드를 간결하게 만들지만**, 알고리즘 테스트에서 필수는 아닙니다.[9][10]

```java
// 배열 정렬 - 전통적 방법
int[] arr = {3, 1, 4, 1, 5};
Arrays.sort(arr);

// 배열 정렬 - 람다식 (내림차순)
Integer[] arr2 = {3, 1, 4, 1, 5};
Arrays.sort(arr2, (a, b) -> b - a);

// List 정렬 - 람다식
List<Integer> list = Arrays.asList(3, 1, 4, 1, 5);
Collections.sort(list, (a, b) -> b - a);

// 스트림 활용
List<Integer> filtered = list.stream()
    .filter(n -> n > 2)
    .map(n -> n * 2)
    .collect(Collectors.toList());
```
