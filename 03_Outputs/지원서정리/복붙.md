### 0. int vs Integer (Wrapper 클래스)



```Java
// int - 기본형 (Primitive)
int a = 10;                 // (null 불가, 기본값 0)
int[] arr1 = {1, 2, 3};     // 기본형 배열 가능

// Integer - 참조형 (Wrapper)
Integer b = 10;             // (null 허용)
Integer c = null;           // 가능 (주의: 언박싱 시 NPE 위험)

// 자동 박싱/언박싱
Integer boxed = 100;        // (자동 박싱) int -> Integer
int unboxed = boxed;        // (자동 언박싱) Integer -> int
```

**중요한 차이점**:
- **int는 Null을 가질 수 없지만 Integer는 가능**
- **Collections는 Integer만 사용 가능** (ArrayList\<int> 불가)
- int는 스택 메모리, Integer는 힙 메모리 사용
- 자동 박싱/언박싱으로 혼용 가능하지만 성능상 차이 존재
```Java
// 컬렉션에는 기본형 불가 -> Integer 사용
ArrayList<Integer> list = new ArrayList<>();
boolean ok = list.add(1);   // (반환타입: boolean) true, int를 넣어도 자동 박싱되어 들어감

// 주의: 래퍼 비교는 equals() 사용 (==는 주소/캐시 영향)
boolean bad = (Integer.valueOf(127) == Integer.valueOf(127)); // true일 수도 있음(캐시 구간 -128~127)
boolean bad2 = (Integer.valueOf(128) == Integer.valueOf(128)); // false일 수도 있음
boolean good = Integer.valueOf(128).equals(Integer.valueOf(128)); // (반환타입: boolean) true
```

### **1) 입력: Scanner vs BufferedReader/Writer (+개행 이슈 해결)**

> **SSAFY 등 대부분 문제는 Scanner로 채점 가능**하지만, **대용량 입력은 BufferedReader가 보통 더 빠름**(실측 예: Scanner 약 4.8초 vs BufferedReader 약 0.68초 수준).

> **10줄 이하**면 Scanner, 그 이상/대용량은 **BufferedReader 권장**.

```Java
// Scanner 기본 사용
import java.util.*;

Scanner sc = new Scanner(System.in);
int a = sc.nextInt();             // (반환타입: int)
String word = sc.next();          // (반환타입: String) 공백 단위
String line = sc.nextLine();      // (반환타입: String) 개행까지 포함한 한줄
double d = sc.nextDouble();       // (반환타입: double)
long l = sc.nextLong();           // (반환타입: long)
```

**nextInt() 이후 nextLine() 개행 이슈**

```Java
// 문제 상황
Scanner sc = new Scanner(System.in);
int n = sc.nextInt();             // 입력: "5\n"
String sBug = sc.nextLine();      // 개행만 읽어옴 -> 빈 문자열(버그 느낌)

// 해결
int n2 = sc.nextInt();
sc.nextLine();                    // 버퍼의 개행 제거
String s = sc.nextLine();         // 이제 정상 작동
```

### **3)** StringBuilder (문자열 누적)

```Java
StringBuilder sb = new StringBuilder();

// 문자열 추가
StringBuilder after1 = sb.append("hello");     // (반환타입: StringBuilder) "hello"
```

### **4) 배열(Array)**

```Java
// 선언/초기화
int[] a1 = new int[5];                    // [0,0,0,0,0]
int[] a2 = {1,2,3,4,5};
int[] a3 = new int[]{1,2,3};

int[][] mat = new int[3][4];              // 3행 4열
int[][] mat2 = {{1,2},{3,4},{5,6}};

// 길이
int lenA2 = a2.length;                    // 5
int rows = mat.length;                    // 3
int cols = mat[0].length;                 // 4

// 정렬
java.util.Arrays.sort(a2);                // (반환타입: void) 오름차순

// 내림차순: 기본형은 불가 -> Integer로 박싱 필요
Integer[] desc = {5,2,8,1};
java.util.Arrays.sort(desc, java.util.Collections.reverseOrder()); // [8,5,2,1]

// int[] -> Integer[] (내림차순/컬렉션 연동 시)
Integer[] boxed = java.util.Arrays.stream(a2).boxed().toArray(Integer[]::new);

// 2차원 배열 정렬 (권장: 비교 안전하게 Integer.compare)
int[][] items = {{1,30}, {2,10}, {3,50}};
java.util.Arrays.sort(items, (x, y) -> Integer.compare(x[0], y[0])); // 첫 열 오름차순
java.util.Arrays.sort(items, (x, y) -> Integer.compare(y[1], x[1])); // 둘째 열 내림차순
java.util.Arrays.sort(items, (x, y) -> {
    int c = Integer.compare(x[0], y[0]);
    if (c != 0) return c;
    return Integer.compare(y[1], x[1]); // 첫 열 같으면 둘째 열 내림차순
});

// 유틸
String oneD = java.util.Arrays.toString(a2);       // (반환타입: String) "[1, 2, 3, 4, 5]"
String twoD = java.util.Arrays.deepToString(mat2); // "[[1, 2], [3, 4], [5, 6]]"
java.util.Arrays.fill(a1, -1);                     // 전체 -1
java.util.Arrays.fill(a1, 1, 3, 0);                // 인덱스 [1,3) -> 1,2를 0으로
int[] cp1 = java.util.Arrays.copyOf(a2, a2.length);
int[] cp2 = a2.clone();
boolean same = java.util.Arrays.equals(cp1, a2);   // true

int pos = java.util.Arrays.binarySearch(a2, 3);    // (반환타입: int) 찾으면 인덱스, 없으면 -(삽입위치)-1
```

> **주의**: 비교에서 o1[0]-o2[0] 식은 **오버플로** 위험 → Integer.compare 사용 권장.

```Java
import java.util.*;

// 최소 힙(기본)
PriorityQueue<Integer> minHeap = new PriorityQueue<>();

pq.offer(new int[]{7, 0});
pq.offer(new int[]{3, 1});
int[] best = pq.poll();                            // (반환타입: int[]) {3,1}
```

### **8) 자주 헷갈리는 문법 비교표**

|**구분**|**올바른 사용**|**틀린 사용**|**비고**|
|---|---|---|---|
|**문자열 비교**|str.equals("test")|str == "test"|값 비교는 equals|
|**배열 내림차순**|Integer[] arr + Collections.reverseOrder()|int[] arr에 바로 reverse 정렬|기본형은 불가|
|**리스트 정렬**|Collections.sort(list) / list.sort(…)|Arrays.sort(list)|Arrays.sort는 배열용|
|**배열 정렬**|Arrays.sort(arr)|Collections.sort(arr)|Collections.sort는 컬렉션용|
|**문자열 누적**|StringBuilder.append()|String += 루프 사용|시간 초과 위험|
|**배열 길이**|arr.length|arr.length()|괄호 없음|
|**리스트 길이**|list.size()|list.length|메서드 호출|
|**값 삭제(ArrayList)**|list.remove(Integer.valueOf(2))|list.remove(2) (인덱스로 삭제)|인덱스/값 구분|
|**래퍼 비교**|Integer.valueOf(x).equals(y)|Integer == Integer|캐시 범위 주의|
|**Comparator**|Integer.compare(a,b)|a - b|오버플로 방지|

```Java
    .collect(Collectors.toList());                  // (반환타입: List<Integer>)

int sum = L.stream().mapToInt(Integer::intValue).sum(); // (반환타입: int)
long cnt = L.stream().filter(x -> x % 2 == 0).count();  // (반환타입: long)
List<Integer> sortedDesc = L.stream()
    .sorted(Comparator.reverseOrder())
    .collect(Collectors.toList());
```

> **주의**: 스트림은 간결하지만, **핫 루프**에서는 전통 for문이 더 빠를 수 있습니다.

### **12) 빠른 입출력 템플릿 (실전용)**

```Java
import java.io.*;
import java.util.*;

public class Main {
    static final FastScanner fs = new FastScanner();
    static final StringBuilder out = new StringBuilder();

    public static void main(String[] args) throws Exception {
        int n = fs.nextInt();                        // (반환타입: int)
        for (int i = 0; i < n; i++) {
            int a = fs.nextInt();
            int b = fs.nextInt();
            out.append(a + b).append('\n');          // (반환타입: StringBuilder)
        }
        System.out.print(out.toString());            // 한 번에 출력
    }

    // BufferedReader + StringTokenizer 기반
    static final class FastScanner {
        private final BufferedReader br;
        private StringTokenizer st;
        FastScanner() { br = new BufferedReader(new InputStreamReader(System.in)); }
        String next() throws IOException {
            while (st == null || !st.hasMoreTokens()) st = new StringTokenizer(br.readLine());
            return st.nextToken();                   // (반환타입: String)
        }
        int nextInt() throws IOException { return Integer.parseInt(next()); }
        long nextLong() throws IOException { return Long.parseLong(next()); }
        String nextLine() throws IOException { return br.readLine(); } // 라인 입력 필요 시
    }
}
```

## **실수 방지 체크리스트 (요약)**

- 입력 많으면 **BufferedReader** **+** **StringTokenizer** **+** **StringBuilder**
- nextInt() 뒤 **nextLine()** **호출 전** **sc.nextLine()****로 개행 소비**
- 문자열 비교는 **equals**, 래퍼 비교도 **equals**
- **내림차순 정렬**: Integer[] 또는 Comparator 사용
- Comparator에서는 **a - b** **대신** **Integer.compare(a,b)**
- 루프에서 문자열 누적은 **StringBuilder**
- Arrays.asList(arr)는 **크기 고정** → 가변 필요 시 new ArrayList<>(…)
- ArrayDeque를 **Queue/Stack 대체**로 사용 (빠르고 안전)
    

  

> **추가 실전 팁**

- > split은 정규식이라 반복 호출 시 느릴 수 있음 → **StringTokenizer 권장**
- > Collections.max/min은 **리스트**에서만, **배열**은 직접 탐색 또는 변환 필요
- > Integer를 언박싱할 때 **null**이면 NPE → getOrDefault 등으로 방어
