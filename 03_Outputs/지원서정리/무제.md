본 문서는 Java 개발자가 Python 코딩 테스트를 준비할 때 필요한 주요 문법 및 자료구조의 차이점을 설명합니다.

## 1. 주요 자료구조 비교

- **List (Java `ArrayList`)**
    
    - Python은 `list` 타입을 기본 자료구조로 사용합니다.
        
    - Java의 `ArrayList`와 유사하게 동적 배열 기능을 제공합니다.
        
    - Python의 `list`는 `append()`, `pop()` 메소드를 사용합니다.
        
- **Dictionary (Java `HashMap`)**
    
    - Python은 `dict` 타입을 Key-Value 저장소로 사용합니다.
        
    - Java의 `HashMap`과 동일한 해시 기반 맵 자료구조입니다.
        
    - Python은 `dict[key] <code>=</code> value` 구문으로 데이터를 삽입/갱신합니다.
        
- **Set (Java `HashSet`)**
    
    - Python은 `set` 타입을 중복 없는 원소 집합으로 사용합니다.
        
    - Java의 `HashSet`과 기능적으로 대응합니다.
        
    - Python은 `add()`, `remove()` 메소드를 사용합니다.
        

## 2. 주요 구문 비교

- **변수 선언**
    
    - Python은 변수 선언 시 타입을 명시하지 않습니다. (예: `a <code>=</code> 10`)
        
    - Java는 변수 선언 시 타입을 명시해야 합니다. (예: `int a <code>=</code> 10;`)
        
- **반복문 (Iteration)**
    
    - Python은 `for item in collection:` 구문을 사용하여 컬렉션을 순회합니다.
        
    - Java는 `for (Type item : collection)` 또는 `for (int i <code>=</code> 0; …)` 구문을 사용합니다.
        
- **조건문**
    
    - Python은 `if`, `elif`, `else` 키워드와 콜론(`:`) 및 들여쓰기를 사용합니다.
        
    - Java는 `if`, `else if`, `else` 키워드와 중괄호(`{}`)를 사용합니다.
        
- **함수 정의**
    
    - Python은 `def` 키워드를 사용하여 함수를 정의합니다.
        
    - Java는 접근 제어자, 반환 타입, 메소드명을 명시하여 메소드를 정의합니다.
        

## 3. 문제 예시: 정수 배열 합계 구하기

정수 배열 `numbers`가 주어졌을 때, 배열의 모든 원소 합계를 반환하는 문제입니다.

> [!note]- Java 및 Python 합계 계산 비교
> 
> 1. Java 해답
> 
> Java
> 
> ```
> class Solution {
>     public int sumArray(int[] numbers) {
>         int sum <code>=</code> 0;
>         for (int number : numbers) {
>             sum +<code>=</code> number;
>         }
>         return sum;
>     }
> }
> ```
> 
> **2. Python 해답**
> 
> Python
> 
> ```
> def solution(numbers):
>     # 1. 반복문 사용
>     sum_value <code>=</code> 0
>     for number in numbers:
>         sum_value +<code>=</code> number
>     return sum_value
> ```

> ```
> # 2. 내장 함수 사용 (더 간결함)
> # return sum(numbers)
> ```
> ```
> 
> **3. 해설**
> ```

> - **Java:** `int` 타입의 배열을 `for-each` 구문으로 순회하며 `sum` 변수에 누적 합산을 수행합니다.
>     
> - **Python:** `numbers` 리스트를 `for…in` 구문으로 순회하며 `sum_value` 변수에 누적 합산을 수행합니다. Python은 `sum()` 내장 함수로 동일한 기능을 더 간결하게 구현할 수 있습니다.
