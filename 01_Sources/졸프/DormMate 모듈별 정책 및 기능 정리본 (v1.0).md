# DormMate 모듈별 정책 및 기능 정리본 (v1.0)

이 문서는 DormMate 프로젝트의 모듈별 정책(냉장고, 세탁실, 도서관, 다목적실)을 핵심 요약하고, 기능(관리자/사용자 역할별), 상세 구현(스티커/등록 플로우), 데이터 모델, 세탁실 흐름, 알림 목록/정책/구현을 체계적으로 정리합니다. 내용은 기숙사 공용 시설 관리의 효율성을 강조하며, Band 앱 중복 최소화와 사용자 피로 방지를 원칙으로 합니다. MVP에서는 냉장고 중심으로 적용되며, 확장 시 공통 자원 스키마(resources)를 재사용합니다.

## 모듈별 정책 요약

### 냉장고

냉장고 정책은 칸 단위 관리와 라벨 재사용을 중심으로 하며, 검사 시 동시성 충돌을 방지합니다. 등록은 단일/묶음 지원으로 유연하게 설계되었고, 검색은 식별번호 기반으로 정확성을 보장합니다. 검사 후 자동 재번호는 검사 컨텍스트에 한정하며, 칸 이동 시 resource_id 변경과 함께 409 충돌 검사를 적용합니다.

- **스티커 표기**: S(position_order, 예: 냉장1=1) + NNN(label_no, 3자리 제로패딩). 예: 냉장1-123 (스티커: 1123). DB 저장은 compartment_id + label_no만, SNNN은 런타임 파생.

### 세탁실

세탁실 정책은 사용자 흐름 중심으로 정의되며, 미등록 사용 처리와 시간 정정을 경량화합니다. 상태 전이는 AVAILABLE → IN_USE → DONE으로 자동화되며, 고장 신고 시 사용 차단을 즉시 적용합니다. 필터 청소 요청은 건조기 한정으로 운영 효율성을 높입니다.

### 도서관

도서관은 원스톱 팝업으로 대출/반납/연장/예약을 통합하며, 알림은 반납 D-5/당일/연체/예약 가능/만료로 제한합니다. 경량화 원칙으로 예약 대기열을 1명으로 한정하여 분쟁을 최소화합니다. 관리자 기능은 도서 등록/수정/분실/삭제로 자원 관리를 지원합니다.

### 다목적실

다목적실 예약은 10분 단위로 세분화되며, 매주 월요일 00:00 KST 주간 오픈으로 공정성을 확보합니다. 합석은 뱃지 표시만으로 자동 매칭을 보류하고, 노쇼/미등록 신고는 원클릭으로 관리자 큐에 적재합니다. 관리자 강제 예약은 사용자 다이얼로그 재사용 + 스위치로 효율화됩니다.

## 기능 상세

### 관리자 공통

관리자 기능은 자원 관리(유닛 추가/편집/삭제, 이용권한 할당)와 상태 일괄 변경(다중 선택 → 상태 전환)을 기본으로 하며, 냉장고/세탁기/다목적실 공통 적용합니다. 벌점 조정과 층별장 임명/해제(기숙사생 내부)는 상벌점 시스템과 연동되며, 다목적실 강제 예약은 날짜 제한 없이 가능합니다. 휴관 모드는 일반 사용자 로그인 제한과 냉장고 물품 소프트 삭제를 통해 운영 안정성을 보장합니다.

### 냉장고

사용자 기능은 묶음 등록(식별번호 자동 발급, 스티커 부착 의무), 번호 재사용(REMOVED 상태 즉시), 조회(내 물품 기본 + 임박/만료 필터 + 식별번호 검색), 상태 변경(부분 소비/전량 제거), 물품 수정으로 구성됩니다. 층별장(검사자) 기능은 검사 모드(칸 잠금, TTL 5분), 동시 2인 검사(이력 분리), 조치(⚠️ 경고: 불일치/보관 불량/미부착 / 🗑️ 폐기: 만료/미등록), 미부착 처리, 결과 제출/수정(통계/알림 + 이력 기록)으로 위생 관리를 강조합니다. 최근 검사 후 수정 시 다음 검사 자동 분류로 효율성을 높입니다.

### 도서관

사용자 기능은 제목/저자/도서번호 검색, 인기/신규 탭(최근 N주 대출수/등록일 정렬), 원스톱 팝업(대출/반납/연장/예약)으로 간편합니다. 알림/벌점은 반납일 5일 전 알림과 연체 자동 벌점으로 준수 유도하며, 예약 대기열 1명 한정으로 경량화합니다. 관리자 기능은 도서 등록/수정/분실/삭제로 자원 유지를 지원합니다.

### 다목적실

타임라인 뷰로 시간대별 예약 현황을 표시하며, 10분 단위 예약과 매주 월요일 주간 오픈 정책을 적용합니다. 합석은 뱃지 표시만으로 유지하고, 신고(미등록/노쇼 원클릭 → 상대 알림 + 관리 큐, 벌점 수동)로 공정성을 확보합니다. 관리자 강제 예약은 사용자 다이얼로그 재사용 + 스위치로 통합합니다.

### 마이페이지

간단 통계 위젯(이번 주 이용 횟수/시간, 벌점 변화 - 막대 2~3개, 쿼리/캐시 단순)으로 개인화되며, 통합 이력(전체/모듈별/상벌점 필터, 성능 시 별도 페이지 분리)을 제공합니다. 설정은 상벌점 내역, 알림 수신 여부, 세탁 프리셋 등으로 사용자 편의를 강조합니다. 이력 조회는 감사 로그와 연동되어 추적 가능합니다.

## 상세 구현 사항

### 검사 및 스티커 구현

검사 단위는 층이 아닌 칸(Compartment) 단위로 세밀하며, 스티커 규격은 SNNN(4자리 숫자: S=칸번호 1자리, NNN=라벨 번호 3자리 제로패딩)입니다. 칸번호 S는 position_order ASC로 냉장 1..N, 냉동 N+1(기본 4)로 런타임 파생되며, DB에는 item_groups(compartment_id, label_no)만 저장합니다. 등록 플로우: 칸 선택 → compartment_id 반환 → next_free_label 추천 → 등록 요청(메타 포함) → 응답 시 display_label(예: "냉장1-123") + sticker_code("1123") 제공, UI 병기 추천.

### 묶음 등록 및 수정

단일 품목은 이름/메모/유통기한(수량 1 고정)으로 등록되며, 수량 증가 시 묶음으로 전환(세부 수정 버튼 활성: 묶음 이름/메모 + 개별 이름/유통기한 자동 입력). 최종 등록 후 고유 식별번호 발급, 스티커 부착 의무화합니다. 최근 검사 후 수정 시 다음 검사에서 자동 분류되어 이력 일관성을 유지합니다.

### 데이터 모델

초기 단일 스키마(resources, item_groups 등)로 운영하며, 후속 확장 시 모듈별 분리(예: books, rooms 테이블 추가)를 고려합니다. 공통 상태(enum: AVAILABLE/IN_USE 등)와 이력(events)로 무결성을 보장하며, 부분 인덱스(removed_at IS NULL)로 활성 데이터 최적화합니다.

### 세탁실 사용자 흐름 및 상태

사용자 흐름: 대시보드(AVAILABLE 기기 상단 + 진행바/남은 시간) → 기기 클릭 팝업(IN_USE: 메시지 목록/읽음 표시/알림 설정 표시/시간 정정;

AVAILABLE: 사용 등록 기본 시간 38/50분 + 1/10분 증감/프리셋 저장/등록하지 않은 이용 신고/필터 청소 요청;

DONE: 5분 후 "기다리고 있어요"/"세탁물 빼놨어요" 알림보내기버튼 + AVAILABLE 강제). 고장 신고는 누구나 가능(ERROR_REPORTED → OUT_OF_SERVICE). 상태: 기본 AVAILABLE → IN_USE → DONE → AVAILABLE; 특수 UNAUTHORIZED_USE(자동 복귀)/ERROR_REPORTED/OUT_OF_SERVICE. 경량화: 시간 정정 ±10분, 관리자 수동 상태시 이용중인 유저에게 알림 전송.

## 알림 목록 및 정책

### 알림 목록

시스템/관리: 상벌점 변동(상/벌점 수령), 계정 승인(관리자용). 공용 시설: 세탁실(종료 전/메시지 도착/시간 수정/상태 변경/관리/고장); 냉장고(유통기한 임박/점검 결과 경고/폐기/점검일 변경); 도서관(반납 임박/당일/연체/예약 가능/만료 자동 취소/대출 기한); 다목적실(시작/종료 15분 전/노쇼 신고 - 미등록은 Band 위임).

### 알림 정책 정리

세탁실: 종료 5분 전/상태 변경(관리/신고)/정정 알림. 냉장고: 유통기한 임박(하루 1회 묶음)/점검 결과(경고/벌점)/점검일 변경. 도서관: 반납 전/당일/연체/예약 대출 가능/만료 자동 취소. 다목적실: 시작/종료 전/노쇼 신고. 시스템/관리: 상벌점 변동(임명/공지 미발송 - Band 중복 제거). Band 중복으로 역할 임명/공지 알림 제외, 피로 최소화.

## 알림 구현

웹페이지는 메인(다목적실/세탁실 정보 + 메시지 읽음 표시/팝업), 냉장고/다목적실/도서관/세탁실 메인으로 구성되며, 알림 표시 방법은 4가지(백그라운드 푸시/메인 아이콘 유도/종 모양 버튼/하단 탭 뱃지)입니다. 읽음 상태 아닐 때만 활성화되며, 관련 페이지/팝업 진입 시 자동 읽음 처리로 피로를 줄입니다. Band 소통 중복 고려, 푸시 알림은 PWA 기반(VAPID)으로 무음 금지.

### 탭 뱃지 및 읽음 규칙

탭 뱃지는 미읽음 수(최대 9+)와 점 표시로 유도하며, 관련 화면 진입 시 소거, 24시간 자동 만료합니다.

냉장고 탭: 임박 묶음(09:00 1회 생성/소거)/폐기(영속 유지).

도서관 탭: 임박/당일/예약(09:00 1회/소거)/연체(영속).
