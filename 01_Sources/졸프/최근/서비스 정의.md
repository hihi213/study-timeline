## 🔵 MVP (Phase 1) - 우선 구현 기능

### F0. 환경 구축 (8시간)

**목표:** 개발 환경 완성

**작업 항목:**
- Spring Boot 3.1.x 프로젝트 생성
- PostgreSQL 14 설치 및 연결
- init.sql 실행 (스키마 생성)
- seed.sql 실행 (코드 테이블 초기 데이터)
- Hello World API 테스트

**완료 기준:** `http://localhost:8080/health` 응답 확인

***

### F1. 인증/계정 관리 (20시간)

**목표:** JWT 기반 인증 시스템

**주요 기능:**
- 회원가입 (아이디, 비밀번호, 호실 정보)
- 로그인 (JWT 토큰 발급, 7일 유효)
- 내 정보 조회
- 비밀번호 변경
- 역할 기반 접근 제어 (RESIDENT/INSPECTOR/ADMIN)

**핵심 로직:**
- BCrypt 비밀번호 해싱
- JWT 토큰 생성/검증
- Spring Security FilterChain
- 대소문자 무시 로그인

**완료 기준:** 회원가입 → 로그인 → 내 정보 조회 성공

***

### F2. 물품 등록 (32시간) ⭐핵심

**목표:** 라벨 발급 + 포장 등록

**주요 기능:**
- 라벨 발급 (SKIP LOCKED 동시성 제어)
- 포장 등록 (장바구니 방식)
- 물품 일괄 등록
- 스티커 코드 자동 생성 (compartmentId-labelNumber)

**핵심 로직:**
- FOR UPDATE SKIP LOCKED (동시 요청 처리)
- 트랜잭션 내 Bundle + Items 일괄 생성
- 라벨 중복 방지
- 라벨 자동 반환 (트리거)

**완료 기준:**
- 동시 20명 라벨 요청 시 중복 없이 발급
- 포장 등록 후 스티커 코드 확인

***

### F3. 물품 조회/수정/삭제 (16시간)

**목표:** CRUD 완성

**주요 기능:**
- 내 포장 목록 조회 (페이징, 필터, 검색)
- 포장 상세 조회
- 포장 수정 (포장명, 메모)
- 물품 추가/수정/삭제
- 포장 삭제 (소프트 삭제)

**필터 옵션:**
- 전체 / 임박 (D-3) / 만료

**완료 기준:** 등록 → 조회 → 수정 → 삭제 전체 플로우 동작

***

### F4. 검사 시스템 (40시간) ⭐핵심

**목표:** SSE 실시간 검사

**주요 기능:**
- 검사 세션 생성 (최대 2명)
- 검사 합류
- SSE 실시간 동기화
- 조치 처리 (통과/경고/폐기)
- 미등록 물품 처리
- 검사 제출
- 칸 잠금/해제

**핵심 로직:**
- SSE (Server-Sent Events) 구현
- 2명 동시 검사, 실시간 화면 반영
- 검사 중 칸 잠금 (다른 사용자 수정 불가)
- 검사 완료 조건 검증

**완료 기준:**
- 검사자 2명 동시 검사
- A가 조치 → B 화면에 즉시 반영 (SSE)

***

### F5. 알림 시스템 (12시간)

**목표:** 자동 알림 발송

**주요 기능:**
- 유통기한 임박 알림 (D-3, 매일 09:00)
- 검사 결과 알림 (제출 즉시)
- 알림 목록 조회
- 알림 읽음 처리
- 미읽음 개수 조회

**핵심 로직:**
- @Scheduled 배치 작업
- JSONB 알림 데이터
- dedupe_key 중복 방지
- TTL 자동 만료 (24~48시간)

**완료 기준:**
- 배치 작업으로 알림 자동 생성
- 검사 제출 후 알림 발송

***

### F6. 관리자 기능 (8시간)

**목표:** 층별장 임명 + 전체 조회

**주요 기능:**
- 층별장 임명/해제
- 전체 포장 조회 (층/칸/상태 필터)
- 전체 검사 이력 조회
- 기본 통계 (총 포장 수, 임박 물품 수 등)

**완료 기준:** 관리자 계정으로 층별장 임명 + 전체 데이터 조회

***

### F7. UI 통합 (24시간, AI 90%)

**목표:** 전체 화면 연동

**주요 화면:**
- 로그인/회원가입
- 장바구니 물품 등록
- 내 물품 목록
- 포장 상세
- 검사 화면 (SSE 연결)
- 알림 목록
- 관리자 대시보드

**개발 방식:** React + AI 생성 80% + 수동 수정 20%

**완료 기준:** 모든 기능 화면 동작 확인

***

### F8. 테스트/발표 준비 (16시간)

**목표:** 안정화 + 발표 준비

**작업 항목:**
- 통합 테스트 (전체 시나리오)
- 성능 테스트 (50명 동시 접속)
- 버그 수정

- 시연 시나리오 연습 (10회 이상)
- 예상 질문 답변 준비 (50개)

**완료 기준:**
- 시연 시나리오 완벽 숙지
- 예상 질문 모두 답변 가능

## 🎯 핵심 차별점 (발표 강조 포인트)

1. **라벨 발급 동시성 제어** (SKIP LOCKED)
   - 문제: 10명 동시 요청 시 중복 발급
   - 해결: FOR UPDATE SKIP LOCKED
   - 결과: 5초 → 0.3초 (17배 개선)

2. **SSE 실시간 검사**
   - 문제: 2명 동시 검사 시 화면 동기화
   - 해결: Server-Sent Events
   - 결과: 실시간 조치 내역 반영

3. **확장 가능한 설계**
   - 현재: 200명
   - 확장: 1000명+ (Phase 2)
   - 구조: 모듈화, 트리거, 트랜잭션 최적화
