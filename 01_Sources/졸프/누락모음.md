- 실제 검사관 처리
    - **조치**: ⚠️ 경고(정보 불일치/보관 불량/스티커 미부착-DB엔 존재), 🗑️ 폐기(유통기한 지남/DB에 없는 미부착)
## 일단 결정된것
1. 검사 조치 유형

- DDL: inspection_actions.action_type IN ('WARN','DISPOSE','NOTE') 존재.
- 문서: ‘경고(WARN)·폐기(DISPOSE)’만 기재.
- 문서대로 ㄱㄱ
2. 품목 상태 컬럼명

- item_groups.status vs item_units.state 혼용. 값 의미는 동일.

    → 명칭 불일치 사실로 확인.

- 상태 컬럼명: status로 통일.

## 내일 논의가 필요한것

3. 사용자↔공간 매핑 부재

- 문서: “호실+개인 번호(예: 201-1) 기반” 명시.
- DDL: users에 호실·개인번호 컬럼 및 매핑 테이블 없음.

    → 데이터 흐름 단절로 확인.

4. 미등록 물품 폐기 기록 불가

- 문서: “미등록 물품 폐기” 시나리오 존재.
- DDL: inspection_actions가 group_id 또는 item_id 필수. UNREGISTERED 사유는 있어도 대상 ID 없이 기록 불가.

    → 기록 경로 부재로 확인.
