# 01.회원,인증 구현
### **AUTH-01 2단계 실행 계획**

- **감사 인프라 확정**
    - DormmateAuditorAware 구현: SecurityContextHolder에서 DormUser UUID 추출, SYSTEM_USER_UUID 상수·Optional 처리 정책 확정.
    - AbstractTimestampedEntity 확장: @CreatedDate, @LastModifiedDate, @CreatedBy, @LastModifiedBy 적용 및 필드 타입(OffsetDateTime + UUID) 결정.
	    - [[00_Inbox/timestamp_자동시간기록.md|timestamp_자동시간기록]]
    - JpaConfig 점검: AuditorAware\<UUID> 빈 정상 등록, 감사 기능 활성화 확인.
    - 감사 필드 JSON 노출 가이드 마련 (@JsonIgnore 여부).
- **엔터티 필드 매핑**
    - 각 테이블(dorm_user, room, room_assignment, signup_request, role, user_role, user_session)의 컬럼 제약(FK, unique, length, nullable) → 엔터티 필드에 반영.
    - Enum/보조 타입 정리 (DormUserStatus, SignupStatus, RoomType 등 필요 항목 선언).
    - 감사 필드가 중복된 엔터티에서 중복 선언 제거, 베이스 클래스 의존으로 통일.
- **연관관계·규칙 정의**
    - 엔터티 간 관계 설정: 방향, fetch 전략, cascade, orphanRemoval 여부 결정.
    - 활성 인덱스/unique 조건 (예: signup_request pending unique, user_role active unique)에 대한 코드 표현 주석 또는 제약 보조 필드 설계.
    - @PrePersist/@PreUpdate 혹은 밸리데이션이 필요한 비즈니스 규칙 메모.
- **싱크 확인 준비**
    - 모든 엔터티 TODO 주석 업데이트: 남겨야 할 항목/완료 항목 정리.
    - docs/data-model.md와 비교 체크리스트 작성, 3단계에서 사용할 항목 메모. ^n8o334
