## 📦 2주차 (10/24~10/30) : “물품 등록 핵심 기능 완성”

### 🎯 목표  

장바구니 방식 포장 등록, 내 물품 보기, 삭제 로직 완성

### 🔧 구현 항목  
- 포장 등록 API (`POST /api/bundles`)  
  - 포장명 + 메모 + 물품 리스트 입력  
  - 라벨(SKIP LOCKED) 발급  
  - 트랜잭션 내 묶음+물품 동시 생성  
- 내 물품 목록 API (`GET /api/bundles/me`)  
  - 필터(임박/만료), 검색(품목명, 코드)  
- 포장 수정/삭제  
  - 메모 변경, 포장 삭제 시 라벨 반환  
- 물품 추가/삭제  
  - 소프트 삭제 처리 (`deleted_at`)

### 프론트엔드 초안 (AI 기반 생성)  
- ✅ 장바구니 폼 UI (이름/유통기한/수량 + 추가 버튼)  
- ✅ 목록 페이지 (포장 카드: 이름, 유통기한, 품목 수)  

### ⚡ 체크포인트

## 🔍 3주차 (10/31~11/6) : “검사 시스템 & 실시간 동기화”

### 🎯 목표  

층별장 전용 검사 모듈 구현 + SSE 실시간 반영  

### 🔧 구현 항목  
- 검사 세션 생성 (`POST /api/inspections/sessions`)  
  - 칸 잠금 활성화 (lock_acquired_at 등 필드 활용)  
- 검사 합류 (`POST /api/inspections/join/{sessionId}`)  
  - SSE 연결 (EventSource API) 구현  
- 조치 처리 (`POST /api/inspections/actions`)  
  - 경고, 폐기, 통과 action_type  
  - JSON 알림 생성 대기  
- Live 업데이트  
  - SSE 전송 (검사자 B에게 실시간 반영)  
  - “검사 후 수정됨” 플래그 반영  

### 시나리오 예시  

1️⃣ 검사자 A: 세션 생성  
2️⃣ 검사자 B: 동일 칸 합류  
3️⃣ A가 경고 → B 화면에서 즉시 표시  
4️⃣ B가 폐기 → A 화면에서도 자동 반영  

### ⚡ 체크포인트  
- [ ] SSE로 이중 브라우저 실시간 갱신 확인  
- [ ] 검사 제출 시 칸 잠금 자동 해제  
- [ ] 검사 중 타 사용자 수정 차단 동작
