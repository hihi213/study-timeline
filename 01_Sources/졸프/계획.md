# DormMate 6주 MVP 개발 계획

## 📅 전체 일정 개요

**총 작업 시간**: 6주 약 120시간 (주당 20시간)
**목표**: 냉장고 관리 시스템 핵심 기능 구현 및 배포

### 주차별 핵심 목표

| 주차 | 핵심 목표 | 완료 기준 |
|------|----------|----------|
| 1주차 | 환경 구축 + DB 설계 | 테이블 생성 완료, 샘플 데이터 삽입 성공 |
| 2주차 | 인증/권한 + 사용자 관리 | 로그인/회원가입 동작, 역할별 접근 제어 확인 |

@Test
void concurrentLabelAcquisition() {
    CountDownLatch latch = new CountDownLatch(10);
    ExecutorService executor = Executors.newFixedThreadPool(10);
    
    for (int i = 0; i < 10; i++) {

            labelService.acquireLabel(compartmentId);

}
