Phase 1: Auth 도메인(사용자·역할·세션) 엔티티와 리포지토리, 로그인/토큰/세션 무효화 API, 기본 통합 테스트 확립.

Phase 2: 냉장고 칸·포장·물품 서비스와 REST 컨트롤러, 라벨 시퀀스·용량 검증, 미등록 처리, DTO/도메인 맵퍼 정리.
Phase 3: 검사 세션/조치 도메인, 동시성 잠금 정책, 제출 집계 로직, 경고·폐기 결과를 Penalty 연동까지 포함한 이벤트 발행.

Phase 5: 관리자 API(역할 승격/해제, 최근 검사·알림 로그), 문서/테스트 싱크, OpenAPI·docs 업데이트, 시나리오별 데이터 준비.
