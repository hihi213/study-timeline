# 3. 10주 상세 계획 (체크리스트/산출물/DoD)

## Day 0 — 부트스트랩 & SSE 베이스

* [ ] `GET /healthz`, `GET /readyz` (DB 커넥션 + 마이그 버전 반영)
* [ ] SSE 베이스 엔드포인트 `GET /sse` (하트비트·재연결)
* [ ] OpenAPI 골격(로그인/리소스/아이템/검사/벌점)
* [ ] `.env.example` 작성, 환경검증
* [ ] `make schema/seed/seed-demo` 동작 보장
* **DoD**: 빈 DB에서 `schema→seed` 후 스모크 200, 브라우저에서 `EventSource` 메시지 수신

## Week 1 — 인증·인가·SSE 인증

* [ ] `POST /auth/login` (username+password → JWT Access TTL 15–30m)
* [ ] `GET /me` (역할/표시명 반환)
* [ ] RBAC 미들웨어(ADMIN/INSPECTOR/USER)
* [ ] 로그인 쿨다운/레이트리밋(연속 실패 시 429 + Retry-After)
* [ ] SSE 인증: `Authorization: Bearer <JWT>`
* **산출물**: `auth.controller.ts`, `rbac.middleware.ts`, 테스트 스펙
* **DoD**: 권한 밖 403, 만료 토큰 재연결 정상

## Week 2 — 자원·아이템(묶음) 등록/조회 + SSE

* [ ] `GET /resources?floor=2F` (리스트)
* [ ] `POST /items` (resource\_id, label\_no, name, quantity, expires\_on, memo?)
* [ ] `GET /items?owner_id=&floor=&q=` (LIKE 검색; TRGM는 포스트-MVP)
* [ ] SSE: `items.created/updated/removed`
* **DDL/인덱스**: 현 스키마 유지
* **DoD**: 활성 라벨 충돌 409, 제거 후 같은 라벨 재사용 OK, 목록이 SSE로 즉시 갱신

## Week 3 — 조정/제거 + 요청 로깅 + 경량 멱등

* [ ] `POST /items/:id/adjust` (수량/유통기한/메모)
* [ ] `POST /items/:id/remove-all`
* [ ] 헤더 `Idempotency-Key`(메모리 TTL 10m)
* [ ] 요청 요약 로그(메서드/경로/결과/지연/코릴레이션)
* **DoD**: 동일 Key 재호출은 같은 결과/응답, 리비전 트리거에 `app.user_id/app.change_reason` 주입

## Week 4 — 2인 검사 세션 + 423 락

* [ ] `POST /inspections/open` (resource\_id) → 진행중 1건 제한
* [ ] `POST /inspections/:id/join` (최대 2명, 3번째 409)
* [ ] `POST /inspections/:id/leave`
* [ ] 해당 자원에 일반 쓰기 요청 오면 423 (앱 미들웨어)
* [ ] SSE: `inspection.opened/joined/left/locked`
* **DDL**: `idx_resource_locks_expires` (만료 GC용)
* **DoD**: 락 만료 후 쓰기 허용, 경합 시 409/423 구분 명확

## Week 5 — 조치 기록 + **단일 제출** → 벌점 원본 생성

* [ ] `POST /inspections/:id/actions` (PASS/WARNING/DISCARD/DISCARD\_WITH\_PENALTY + violation\_type/note)
* [ ] `POST /inspections/:id/submit` (멱등, 재제출 동일 응답)
* [ ] 제출 후 결과 **INSERT/DELETE 금지**, UPDATE는 리비전 적재(+version)
* [ ] 제출 시 벌점 원본 자동 생성(서버에서 매핑표 상수화)
* **DoD**: 제출 후 수정 시 사유 필수, 원본 벌점 생성 확인

## Week 6 — 벌점 **조정** + 집계 API

* [ ] `POST /penalties/adjustments` (±, reason, created\_by=JWT)
* [ ] `GET /penalties/totals?user_id=&from=&to=`

  * 응답: `original_points/adjusted_points/total_points`
* **뷰**: `v_penalties_totals` 이용
* **DoD**: 합계 정확(카티전 곱 없음), 원본 벌점은 UPDATE/DELETE 차단

## Week 7 — 프론트 E2E + SSE 안정화

* [ ] 단일 탭 SSE: `BroadcastChannel`로 1개 커넥션 공유
* [ ] 서버 **최근 이벤트 링버퍼 N=500** + `Last-Event-ID` 복구
* [ ] 423 UX(토스트/버튼 비활성) 확정
* **DoD**: 오프라인→복귀 후 이벤트 재적재 OK, 다중 탭 누수 없음

## Week 8 — 계약/회귀 + 스냅샷

* [ ] OpenAPI 스냅샷 `docs/openapi/snapshots/v0.1.0.json` 잠금
* [ ] 계약 테스트(CI) 통합, 회귀 시나리오(끊김/재연결/복구)
* **DoD**: 스냅샷 diff 0, E2E 녹색

## Week 9 — 성능/경합/보안 라이트

* [ ] k6/Artillery 시나리오(로그인/목록/SSE/제출 혼합)
* [ ] 레이트리밋(사용자/IP, SSE 별도) 429 + `Retry-After`
* [ ] `pg_stat_statements`로 Top N 튜닝 포인트 기록
* [ ] VACUUM/ANALYZE 스케줄 + 인덱스 블로트 체크 스크립트
* **DoD**: p95 < 300ms(샘플 부하), 에러율 < 0.5%

## Week 10 — 폴리싱 · 문서 · 릴리즈

* [ ] README(아키/시퀀스/실행가이드), ADR, 변경로그
* [ ] **Runbook**(SSE/락/오류 대응), **릴리즈 체크리스트**
* [ ] 백업→복구 리허설(선택 테이블 복구)
* [ ] Postman/Bruno 컬렉션 + 1분 데모 영상
* [ ] 태그 `v0.1.0-mvp` + 롤백 리허설
* **DoD**: 스모크/계약/E2E 전부 녹색

# 4. API 계약(요약 스펙)

* **Auth**

  * `POST /auth/login` → `{ access_token, exp }`
  * `GET /me` → `{ user_id, username, roles }`
* **Resources**

  * `GET /resources?floor=2F`
* **Items**

  * `POST /items` (Idempotency-Key 지원)
  * `GET /items?owner_id=&floor=&q=`
  * `POST /items/:id/adjust`
  * `POST /items/:id/remove-all`
* **Inspections**

  * `POST /inspections/open`
  * `POST /inspections/:id/join|leave`
  * `POST /inspections/:id/actions`
  * `POST /inspections/:id/submit`
* **Penalties**

  * `POST /penalties/adjustments`
  * `GET /penalties/totals?user_id=&from=&to=`

> **오류 반환**: RFC7807 (`type`,`title`,`status`,`detail`,`instance`) + `code`(예: `RESOURCE_LOCKED`)

---

# 5. DDL/인덱스 추가(운영 유용 포인트)

* [ ] `idx_resource_locks_expires` (락 만료 스캔 최적화)

  ```sql
  CREATE INDEX IF NOT EXISTS idx_resource_locks_expires
    ON resource_locks(expires_at);
  ```
* [ ] TRGM/GIN 인덱스는 **포스트-MVP** 전용 마이그 파일로만 보유(실제 적용은 나중)

---

# 6. 테스트 매트릭스(샘플)

* **단위**: 해시/토큰/RBAC/락 미들웨어/리비전 트리거
* **계약**: OpenAPI 스냅샷 대비(성공/409/422/423/429)
* **E2E**: “등록→조정→검사(2인)→제출→벌점” 시나리오
* **복구**: SSE 끊김/재연결/Last-Event-ID/링버퍼
* **성능**: 20→30 rps 혼합 트래픽, p95/에러율
