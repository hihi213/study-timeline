#### **개념 콘솔리데이션**

* **연결 맵**: `하드웨어` ↔ `[ OS: 커널(Kernel) ]` ↔ `[ 인터페이스: 셸(Shell), GUI ]` ↔ `사용자/응용 프로그램`

* **핵심 용어**
    * **OS (Operating System)** — 하드웨어 자원을 효율적으로 관리하고 사용자에게 인터페이스를 제공하는 시스템 소프트웨어.
    * **Kernel (커널)** — OS의 핵심. 프로세스, 메모리, 장치 등 모든 것을 총괄 관리.
    * **CPU Scheduling (CPU 스케줄링)** — 여러 프로세스가 CPU를 공정하게 사용하도록 순서를 정하는 OS의 핵심 기능.
    * **Virtual Memory (가상 메모리)** — RAM이 부족할 때 HDD/SSD의 일부를 임시 RAM처럼 사용하는 기술.
    * **File System (파일 시스템)** — 저장 장치에 파일을 체계적으로 저장하고 관리하는 구조 (예: `NTFS`, `ext4`).
    * **Linux Distribution (배포판)** — 리눅스 커널에 각종 소프트웨어를 묶어 만든 완성형 OS (예: `Ubuntu`, `CentOS`).
    * **Shell (셸)** — 사용자의 명령을 해석하여 커널에 전달하는 명령어 해석기 (예: `Bash`).
    * **CLI / GUI** — 텍스트 기반의 **명령어 라인 인터페이스** / 아이콘 기반의 **그래픽 사용자 인터페이스**.
    * **LTS (Long Term Support)** — 안정성을 위해 장기간(5년+) 업데이트를 보장하는 '장기 지원 버전'.
    * **Virtual Machine (가상 머신)** — 기존 OS 위에 소프트웨어로 또 다른 PC를 구현하여 독립된 환경을 제공하는 기술.

#### **실습 통합 요약**

* **[S1] 내 PC 네트워크 정보 확인** — Windows의 `ipconfig` 명령어를 통해 내 PC의 IP, MAC 주소 등 기본 네트워크 구성을 파악한다.
    * **단계 요약**: 1) `cmd` 실행 2) `ipconfig /all` 입력 후 엔터 3) '물리적 주소'와 'IPv4 주소' 확인.
    * **⚠️ 주의**: 이는 Windows 명령어이며, Linux에서는 `ip a` 명령을 사용한다.
    * **근거**: [(1,P06)], [(3,P02)]

* **[S2] 바탕화면 아이콘과 부팅 속도 관계 실험** — 바탕화면에 다수의 파일을 두는 것이 시스템 부팅 성능에 미치는 영향을 체감한다.
    * **단계 요약**: 1) 현재 부팅 속도 측정 2) 바탕화면에 수많은 파일/폴더 생성 3) 재부팅 후 속도 비교.
    * **근거**: [(2,P04)]

* **[S3] 가상 머신(VMware)에 Ubuntu LTS 설치** — 앞으로의 모든 실습을 진행할 Linux 환경을 구축한다.
    * **단계 요약**: 1) VMware 설치 2) Ubuntu LTS 버전 ISO 파일 다운로드 3) 가상 머신 생성 및 Ubuntu 설치.
    * **⚠️ 주의**: LTS 버전이 아닌 최신 버전을 설치할 경우 지원 기간이 짧을 수 있다.
    * **근거**: [(2,P01)], [(3,P06)]

* **[S4] Linux에서 Windows 파일 접근 (예정)** — 가상 머신에 설치된 Linux에서 Host OS인 Windows의 파일 시스템에 접근해본다.
    * **단계 요약**: 1) VMware의 공유 폴더 기능 설정 2) Linux에서 마운트된 경로로 이동 3) Windows 파일 확인.
    * **근거**: [(3,P06)]
