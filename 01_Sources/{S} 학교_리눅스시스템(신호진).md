# 무제

## **2025-09-05 — 최종(1~3교시 통합)**

### **하루 TL;DR (5줄)**
오늘 수업에서는 운영 체제(OS)가 하드웨어와 사용자 사이의 필수적인 **인터페이스**임을 학습했습니다. OS의 핵심 기능인 **프로세스, 메모리, 파일 시스템 관리** 원리를 이해하고, **커널 모드와 사용자 모드**의 분리 이유를 배웠습니다. 특히 서버 환경의 강자인 **Linux**는 오픈 소스이자 다중 사용자를 지원하는 Unix-like 시스템이며, **가상 머신(VM)**을 통해 안전하게 설치하여 학습할 것입니다. 최종적으로, 사용자는 **셸(Shell)**을 통해 OS의 핵심인 **커널(Kernel)**과 상호작용하는 구조를 파악했습니다.

---
### **🔥 필수 질문 Top-5**
1.  시스템 보호를 위해 커널 모드와 사용자 모드를 분리하는 이유는 무엇이며, 이 둘은 어떻게 상호작용하는가?
2.  네트워크 통신에서 IP 주소, MAC 주소, 포트 번호가 각각 필요한 이유는 무엇인가?
3.  Linux 시스템에서 '셸(Shell)'과 '커널(Kernel)'의 역할은 어떻게 구분되는가?
4.  디스크 조각 모음은 어떤 원리이며, 왜 HDD에는 유용하지만 SSD에는 해로운가?
5.  기존 Windows 환경에 Linux를 설치할 때, 가상 머신(VM)을 사용하는 가장 큰 장점은 무엇인가?

---
### **📚 핵심 개념 3개**
* **운영 체제 (Operating System)**: 하드웨어 자원을 관리하고 응용 프로그램 실행 환경을 제공하는 핵심 시스템 소프트웨어.
* **커널(Kernel) & 시스템 콜(System Call)**: OS의 심장부로 모든 자원을 제어하며, 응용 프로그램은 시스템 콜을 통해서만 커널 기능에 접근 가능.
* **가상 머신 (Virtual Machine, VM)**: 물리적 컴퓨터 위에 가상의 컴퓨터를 만들어, 기존 시스템에 영향을 주지 않고 다른 OS를 설치/실행하는 기술.

**[연결맵]**
`운영 체제(OS)` → `커널(Kernel) & 시스템 콜` → `가상 머신(VM)`

---
### **💻 주요 실습 요약**
* **[S1] 네트워크 정보 확인**:
    * **목적**: Windows 명령 프롬프트에서 `ipconfig /all` 명령어를 사용하여 현재 PC의 IP 주소와 고유한 MAC 주소(물리적 주소)를 확인.
    * **단계요약**: 1) `CMD` 실행 2) `ipconfig /all` 입력 3) 'IPv4 주소' 및 '물리적 주소' 확인.
* **[2~3교시]**: 2교시와 3교시에는 VMware를 이용한 Ubuntu 설치를 위한 이론 설명과 개념 학습이 진행되었으며, 별도의 실습은 없었습니다.
