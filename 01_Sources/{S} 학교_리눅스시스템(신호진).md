# 무제

## **2025-09-05 — 최종(1~3교시 통합)**

### **하루 TL;DR (5줄)**
오늘 수업에서는 운영 체제(OS)가 하드웨어와 사용자 사이의 필수적인 **인터페이스**임을 학습했습니다. OS의 핵심 기능인 **프로세스, 메모리, 파일 시스템 관리** 원리를 이해하고, **커널 모드와 사용자 모드**의 분리 이유를 배웠습니다. 특히 서버 환경의 강자인 **Linux**는 오픈 소스이자 다중 사용자를 지원하는 Unix-like 시스템이며, **가상 머신(VM)**을 통해 안전하게 설치하여 학습할 것입니다. 최종적으로, 사용자는 **셸(Shell)**을 통해 OS의 핵심인 **커널(Kernel)**과 상호작용하는 구조를 파악했습니다.

---
### **🔥 필수 질문 Top-5**
1.  시스템 보호를 위해 커널 모드와 사용자 모드를 분리하는 이유는 무엇이며, 이 둘은 어떻게 상호작용하는가?
2.  네트워크 통신에서 IP 주소, MAC 주소, 포트 번호가 각각 필요한 이유는 무엇인가?
3.  Linux 시스템에서 '셸(Shell)'과 '커널(Kernel)'의 역할은 어떻게 구분되는가?
4.  디스크 조각 모음은 어떤 원리이며, 왜 HDD에는 유용하지만 SSD에는 해로운가?
5.  기존 Windows 환경에 Linux를 설치할 때, 가상 머신(VM)을 사용하는 가장 큰 장점은 무엇인가?

---
### **📚 핵심 개념 3개**
* **운영 체제 (Operating System)**: 하드웨어 자원을 관리하고 응용 프로그램 실행 환경을 제공하는 핵심 시스템 소프트웨어.
* **커널(Kernel) & 시스템 콜(System Call)**: OS의 심장부로 모든 자원을 제어하며, 응용 프로그램은 시스템 콜을 통해서만 커널 기능에 접근 가능.
* **가상 머신 (Virtual Machine, VM)**: 물리적 컴퓨터 위에 가상의 컴퓨터를 만들어, 기존 시스템에 영향을 주지 않고 다른 OS를 설치/실행하는 기술.

**[연결맵]**
`운영 체제(OS)` → `커널(Kernel) & 시스템 콜` → `가상 머신(VM)`

---
### **💻 주요 실습 요약**
* **[S1] 네트워크 정보 확인**:
    * **목적**: Windows 명령 프롬프트에서 `ipconfig /all` 명령어를 사용하여 현재 PC의 IP 주소와 고유한 MAC 주소(물리적 주소)를 확인.
    * **단계요약**: 1) `CMD` 실행 2) `ipconfig /all` 입력 3) 'IPv4 주소' 및 '물리적 주소' 확인.
* **[2~3교시]**: 2교시와 3교시에는 VMware를 이용한 Ubuntu 설치를 위한 이론 설명과 개념 학습이 진행되었으며, 별도의 실습은 없었습니다.

## **2025-09-12 — 최종(1~3교시 통합)**

### **하루 TL;DR (5줄)**
오늘은 Windows PC 위에 **VMware 가상 머신**을 생성하고 **Ubuntu**를 설치하여 개인용 Linux 서버 환경을 구축했습니다. 설치 후에는 **터미널**을 통해 `cd`, `ls` 등 기본 명령어를 익혔고, 파일 시스템의 **절대/상대 경로**, **권한** 및 **소유권** 개념을 학습했습니다. 마지막으로 VM에 **SSH 서버**를 설치하고 Windows에서 **PuTTY**로 접속하여, 실제 서버처럼 원격으로 제어하는 **클라이언트-서버** 모델을 완성했습니다.

---
### **🔥 필수 질문 Top-5**
1.  Ubuntu는 왜 다른 Linux처럼 `root` 계정을 직접 사용하지 않고 `sudo` 명령어를 사용하는가?
2.  Linux 터미널에서 경로를 지정할 때, `cd /etc`와 `cd ..` 방식의 차이점은 무엇인가?
3.  `ls -al` 명령의 결과에서 `drwxr-xr-x`와 `lrwxrwxrwx`의 차이점은 무엇인가?
4.  원격지에 있는 Linux 서버에 안전하게 접속하기 위해 SSH를 사용하는 이유는 무엇인가?
5.  이번 원격 접속 실습에서 Windows의 PuTTY와 Ubuntu의 SSH 서비스는 각각 어떤 역할을 하는가?

---
### **📚 핵심 개념 3개**
* **가상 머신 (Virtual Machine, VM)**: 호스트 OS(Windows)에 영향을 주지 않는 독립되고 격리된 가상 PC를 만들어주는 기술.
* **터미널 & 파일 시스템 경로**: 키보드 명령어로 Linux를 제어하는 기본 인터페이스와, 파일 위치를 지정하는 절대/상대 주소 체계.
* **SSH & 원격 접속**: 암호화된 통신을 통해 원격지의 서버(VM)를 내 PC(Host)에서 안전하게 제어하는 기술.

**[연결맵]**
`가상 머신(VM)` → `터미널 & 파일 시스템 경로` → `SSH & 원격 접속`

---
### **💻 주요 실습 요약**
* **[S1] VMware로 Ubuntu 가상 머신 생성 및 설치 준비**
    * **목적**: VMware를 사용하여 Ubuntu를 설치할 독립된 가상 PC를 만들고, 설치 미디어(ISO)를 연결.
    * **단계요약**: 1) VMware에서 'Create a New Virtual Machine' 실행 2) 'Typical' 설정 및 Ubuntu ISO 파일 지정 3) 가상 머신 생성 및 사용자 계정 설정.

* **[S2] 터미널 기본 탐색 및 경로 이해**
    * **목적**: `cd`, `ls` 명령어로 파일 시스템을 탐색하고, 절대/상대 경로의 차이와 파일 권한을 이해.
    * **단계요약**: 1) `cd /`와 `cd`로 루트/홈 디렉터리 이동 2) `ls -al`로 파일 종류(`d`, `l`), 권한(`rwx`), 소유권(`root`, 사용자) 확인 3) `cd ..`와 `cd /etc`로 상대/절대 경로 이동.

* **[S3] SSH 원격 접속 설정 및 실행**
    * **목적**: Ubuntu VM을 SSH 서버로 만들고 Windows에서 PuTTY 클라이언트로 원격 접속.
    * **단계요약**: 1) Ubuntu에 `ssh`, `net-tools` 패키지 설치 2) `ifconfig`로 IP 주소 확인 3) Windows에 PuTTY 설치 4) PuTTY에 IP 주소를 입력하여 Ubuntu VM으로 원격 로그인.
