## 시간복잡도: 시간복잡도가 10^8를 넘게 풀면 안된다
- 시간복잡도를 결정짓는 입력값이 10^4 이면 n^2으로 풀면 간당간당하다.

#### **자료구조의 메모리 구조 비교**
- **배열 (Array):**
    - 데이터가 메모리에 **연속적**으로 붙어서 저장됩니다.
    - 인덱스로 즉시 접근 가능 (Cache Hit율 높음).
- **연결 리스트 (Linked List):**
    - 데이터가 메모리에 **불연속적**으로 흩어져 저장됩니다.
    - **Node 구조:** `값(Data)` + `다음 주소(Next Pointer)`
    - **Node의 크기 계산 (64비트 시스템 예시):**
        - `Data(int)` 4 Byte + `Next(Pointer)` **8 Byte** = **12 Byte** (실제로는 패딩으로 16 Byte가 될 수있음)
    - **핵심:** 연결 리스트는 주소를 저장해야 하므로 배열보다 **메모리 공간을 더 많이 차지(Overhead)** 합니다.

## 📚 자료구조: LIST (선형 자료구조)

리스트는 데이터를 저장하는 메모리 구조에 따라 크게 두 가지로 분류됩니다.

### 1. LIST의 분류
- **배열 기반 (ArrayList):** 메모리에 **연속적**으로 할당
    - **Array (정적 배열):** 크기 고정
    - **Dynamic Array (동적 배열):** 크기 가변
- **노드 기반 (LinkedList):** 메모리에 **비연속적**으로 할당
    - **Linked List (연결 리스트):** Node(데이터+주소)의 연결
        

---

### 2. Array (정적 배열, Static Array)

**"선언 시 크기가 결정되어 고정되는(변경 불가) 리스트"**

- **메모리 구조:**
    - `데이터 타입 크기` $\times$ `배열 크기`만큼의 메모리를 한 번에 할당받아 **연속적**으로 저장합니다.
- **접근 속도 (Random Access):**
    - 배열의 이름은 **첫 번째 요소의 시작 주소(Base Address)** 를 의미합니다.
    - 물리적으로 연속되어 있으므로, 수식을 통해 단 **한 번의 연산**으로 원하는 위치에 즉시 접근합니다.
    - **공식:** $\text{Target Address} = \text{Base Address} + (\text{Index} \times \text{Data Size})$
- **예시:** C언어의 `int arr[10]`, Java의 `int[]`
### 3. Dynamic Array (동적 배열)

**"Array에 유연함(Doubling)을 더한 리스트"**

- **정의:**
    - 기본적으로 Array를 사용하되, **크기 자동 조절(Resizing)** 기능을 추가한 자료구조입니다.
- **동작 원리 (Doubling):**
    - 데이터가 가득 차면, 기존보다 **2배(또는 1.5배) 큰 새 배열**을 생성합니다.
    - 기존 데이터를 새 배열로 **모두 복사**한 후, 기존 배열을 메모리에서 삭제합니다.
- **삽입, 삭제**
- **시간 복잡도:**
    - **평균:** 끝에 데이터를 추가할 때는 $O(1)$입니다.
    - **최악 (Resizing 시):** 배열이 꽉 차서 복사가 일어날 때는 모든 데이터를 옮겨야 하므로 $O(N)$입니다.
- **사용 기준:**
    - 데이터 개수가 **확정적**일 때 $\rightarrow$ **Array** (메모리 낭비 없음)
    - 데이터 개수가 **유동적**일 때 $\rightarrow$ **Dynamic Array** (편의성)
- **예시:** Python의 `list`, Java의 `ArrayList`, C++의 `std::vector`

### 4. Node (노드)

**"연결 리스트(Linked List)를 구성하는 기본 단위"**

- **정의:** 비연속적으로 저장되는 연결 리스트에서 데이터를 담는 하나의 그릇입니다.
- **구성:**
    1. **Data:** 실제 저장하려는 값
    2. **Pointer (Next):** 다음 노드의 위치를 가리키는 주소값
        
- **특징:** 메모리상에 흩어져 있는 데이터들을 이 '주소(Pointer)'를 통해 논리적으로 연결합니다.
