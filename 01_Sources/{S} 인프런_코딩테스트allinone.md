## 시간복잡도: 시간복잡도가 10^8를 넘게 풀면 안된다
- 입력값중 시간복잡도를 결정짓는 입력값이 10^4 이면 n^2으로 풀면 간당간당

#### **자료구조의 메모리 구조 비교**
- **배열 (Array):**
    - 데이터가 메모리에 **연속적**으로 붙어서 저장됩니다.
    - 인덱스로 즉시 접근 가능 (Cache Hit율 높음).
- **연결 리스트 (Linked List):**
    - 데이터가 메모리에 **불연속적**으로 흩어져 저장됩니다.
    - **Node 구조:** `값(Data)` + `다음 주소(Next Pointer)`
    - **Node의 크기 계산 (64비트 시스템 예시):**
        - `Data(int)` 4 Byte + `Next(Pointer)` **8 Byte** = **12 Byte** (실제로는 패딩으로 16 Byte가 될 수음)
    - **핵심:** 연결 리스트는 주소를 저장해야 하므로 배열보다 **메모리 공간을 더 많이 차지(Overhead)**합니다.

### Array: 선언할때 배열크기가 결정되어 고정됨(변경x)
- <code>타입크기 x 배열크기</code> 만큼의 메모리 할당받아 연속적으로 data를 저장
- 배열의 이름이 첫번째 요소의 시작주소이며 한번의 연산(시작주소+데이터 타입만큼씩)으로 다른 요소로 즉시 접근한다.
- c언어와 자바의 \[]
### Dynamic Array: 내부가 가득차면 2배 큰 새 배열을 생성해 복사후 기존배열 삭제
- Array에 Doubling기능만 추가한 것
- 데이터 삽입시 복잡도는 1이지만 내부가 가득차면 기존 요소들을 더 큰 새 배열에 복사하기 때문에 복잡도는 N이다
- 데이터갯수가 정해져있으면 Array쓰고, 유동적일때는 Dynamic Array나 Linked list
- 파이썬의 List와 자바의 ArrayList
