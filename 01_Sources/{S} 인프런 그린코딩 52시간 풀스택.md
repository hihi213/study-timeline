			- 제목과 메타정보를 표시하는데 사용
				- title :제목
				- meta : 메타정보(웹페이지 설명하는 정보)
					- UTF-8 로 메타정보를 설정해야 한국어까지 잘 표현됨

		- h2 태그: 일반적인 크기보다 크게 텍스트를 표시하게 하는 태그

			- 웹브라우저(프론트엔드)에서 웹서버(백엔드)로 데이터를 넘기고자 할때 input태그와 같이 작성해주는 태그입니다
			- button의 type이 submit (button이면 안됨) 일때만 form 태그의 기능을 쓸수있다
	- 태그 속성: 태그에게 특별한 지시를 내리는 메모
		- id: 해당 html 태그의 그 자체

		- class: 여러 태그에 고유한 class를 부여
			- \<label id="A">했다면 A 재사용 가능

			- for ="Id" 하면 이 라벨을 클릭했을때 그 아이디의 요소가 선택됨

	- ##### 1. css박스모델: 태그 크기를 표현하는 디자인적 요소
		- content:내용물
		- padding: 뽁뽁이
		- border: 상자 두께
		- margin: 상자들 사이의 간격
	- ##### 2. css display 속성
		- html 태그들을 3차원 공간을 가진 웹브라우저에 전시하는것
		- block: 태그요소의 크기와 위치변경이 가능
			- z축을 포함한 3차원공간
			- x축 전체길이를 전부 차지
			- y축 콘텐츠 길이+마진길이만큼 차지
		- inline: 태그요소의 크기와 위치변경이 불가능(weight, height 변경이 불가 position 제한적 변경
			- z,x,y 모두 콘텐츠 길이만큼 차지
		- inline block: 블럭의 크기와 위치변경이 가능+ 콘텐츠 길이만큼만 차지
	- 태그마다 기본 display 설정이 다르기 때문에 블로그 찾아가기
	- cmd+/ 하면 주석처리됨
	- ##### 3.css position: 태그를 위치 지정하기위한 속성
		- static: 기본값으로 설정되는  top, left, right, bottom적용 x되는 속성
		- relative : 자기자신을 기준으로 적용
		- absolute : 부모기준으로 적용 (static이 아닌 부모태그중에서 가장 가까운 부모태그)
		- fixed: 스크롤을 내려도 계속 그위치를 고수하는 포지션
		- 위의 4가지 position속성과 top, left, right, bottom속성은 하나의 세트이다 근데 static은 안먹히게만들어져있다. 그래서 나머지 3속성으로 변경해야한다.
	- ##### 4. box-sizing: 
		- border-box :Padding과 border를 포함한 크기로 width, height가 매겨짐
			- 이걸로 html태그를 설정하는게 개발이 쉬워짐
		- content-box: 일반적으로 설정되는, content 자체 크기로 width, height가 매겨짐
		- 하위태그는 부모설정을 따라간다
	- ##### 5-1 flex: 자신의 자식요소들을 정렬함
		- 부모요소의 width를 100프로 차지
	- ##### 5-2 align-items: y축 중앙을 기준으로 
		- center: 내부자식요소들을 중앙에 정렬
		-  아이템이 움직일 수 있는 **세로 공간을 만들어주기 위해** 컨테이너에 `height` 값을 설정해줘야함
	- ##### 5-3 justify-content: x축 중앙을 기준으로 
	- 100vh: 웹브라우저 최대화면 높이
	- .클래스:focus
		- 포커스됐을때의 속성 조절
	- display가 block일때 마진을 0 auto로 두면 해당태그가 간격을 둔채 가운데 위치하게 됨
- 프론트: 자바스크립트(웹브라우저에서 실행되는 가장 기초적 언어)
	- 자바스크립트에서 변수를 선언하는 3가지 키워드
		- 저장공간을 만들어라는 역할을 가진 3가지 종류
		- var -> 엣날 문법으로 현업에서는 쓰는걸 매우 비추
			- 코드에서 문법적인 오류를 일으켜왔다
			- 그래서 만들어진 변수키워드가 let과 const이다
		- let
		- const
		- 동적타이핑이란 사용자가 값을 대입하고 대입한 데이터 타입에 따라 사용자가 선언한 변수의 타입이 결정되는것을 말한다.
		- 자바스크립트는 동적타이핑 형식이다.
	- 자바스크립트에서 원시 데이터타입
		- Number (정수, 실수)
		- String (문자, 문자열)
		- Boolean (참, 거짓)
		- Undefined (초기화하지 않고 선언만한 변수에 저장되는 타입)
		- Null (의도적으로 비어있음을 표현하는 타입)
	- 자바스크립트에서 참조 데이터타입
		- let obj={}
			- '문자열' 키로 데이터에 접근할때
			-  데이터의 순서가 중요하지 않을때
			- 사실 let obj = new Object();의 축약형임(엣날 문법이라 단축문법이 마련된것)
		- let map= new map();
			- '모든타입'키로 데이터에 접근
			- 데이터의 삽입순서도 중요하고, 데이터의 추가/삭제가 빈번할대
		- let array=\[]
			- '숫자' 인덱스 키로 데이터에 접근
			- 순서가 중요한 데이터 목록 
			- 사실 let array = new Array();의 축약형임(엣날 문법이라 단축문법이 마련된것)
		- let set= new set()
			- 키x
			- 컬렉션 안의 모든 값을 고유하게 유지하고 싶을때(중복 제거)
			- 특정값이 컬렉션 안에 존재하는지 여부를 빠르게 확인하고 싶을때
