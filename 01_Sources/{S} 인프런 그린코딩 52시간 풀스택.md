	- html: 텍스트, 이미지, 동영상, 버튼 등을 웹페이지에 첨부 및 저장시킬때 이용함
	- css:html이 첨부한 요소들의 위치를 변경시킨다거나 스타일을 입힐때 이용
	- js: 요소에 특정한 기능을 작동시킬때 이용
- 백엔드 영억

		- 서버를 관리하고, 저장하고 코드 조작하는 언어(백엔드 전용 개발언어)
		- 보안성이 좋다
	- springboot 프레임워크
		- 정해진 패턴과 규칙을 유지시키기위한 자바 전용개발 도구

프론트
- 태그: 암기하는게 아닌 웹개발할때마다 필요한 태그가 있을때마다 서치해서 알아내기 
	- html태그
		- html언어로 작성됨을 의미하는 태그
	- Head
		- 제목과 메타정보를 표시하는데 사용
			- title :제목
			- meta : 메타정보(웹페이지 설명하는 정보)
				- UTF-8 로 메타정보를 설정해야 한국어까지 잘 표현됨
	- p(paragraphy 문단) 태그
	- div(division 분할): 가상의, 차지하는 공간이 없는 태그
	- h2 태그: 일반적인 크기보다 크게 텍스트를 표시하게 하는 태그
	- input 태그: 입력할때 사용하는 태그
	- label 태그: 태그를 설명하는 태그
	- span 태그: css코드를 이용해서 태그에 스타일을 입히고 싶을때 구별시키기 위해서 쓴다
	- button 태그: 버튼의 기능
	- form 태그: 사용자가 버튼을 눌렀을때 input태그 안에 입력한 값은 서버(백엔드영역)->데이터베이스로 간다 이 과정을 관리하는 태그
	- 태그 속성: 태그에게 특별한 지시를 내리는 메모
		- id: 해당 html 태그의 그 자체
			- 서로 같은 태그들중 하나에만 고유한 id를 부여해서 특정한 스타일을 적용 
			- 다른 태그가 이 id 속성값 재사용 불가
			- \<label id="A">했다면 A 재사용 불가 
		- class: 여러 태그에 고유한 class를 부여
			- \<label id="A">했다면 A 재사용 가눙
