- 프론트: 자바스크립트(웹브라우저에서 실행되는 가장 기초적 언어)
	- 자바스크립트에서 변수를 선언하는 3가지 키워드
		- 저장공간을 만들어라는 역할을 가진 3가지 종류
		- var -> 엣날 문법으로 현업에서는 쓰는걸 매우 비추
			- 코드에서 문법적인 오류를 일으켜왔다
			- 그래서 만들어진 변수키워드가 let과 const이다
		- let
		- const
		- 동적타이핑이란 사용자가 값을 대입하고 대입한 데이터 타입에 따라 사용자가 선언한 변수의 타입이 결정되는것을 말한다.
		- 자바스크립트는 동적타이핑 형식이다.
	- 자바스크립트의 모든 변수는 메모리의 스택(Stack) 공간에 생성됩니다. 
	- 이 변수에 원시 타입 값이 할당되면 그 값 자체가 스택에 기록되지만, 참조 타입 값이 할당되면 데이터의 본체는 메모리의 힙(Heap)에 별도로 생성되고, 변수는 그 힙의 메모리 주소를 저장합니다
	- 그래서 복제할때 나타나는 현상 정리
		- 참조복사: const obj2 = obj1
			- 하나의 같은 객체를 가리킴 (새로운 객체를 만들지 않고, `obj1`이 가리키는 **메모리 주소**를 똑같이 전달)
		- 얕은복사: const obj2 = { ...obj1 }
			- 메모리상 별개의 새로운 객체를 만들지만, 그 객체의 요소 데이터가 **원시 타입이라면 값 자체를 복사**하지만 객체안의 객체와 같은 **참조타입은 참조복사해서(메모리 주소만을 복사)** 두 객체내부의 참조타입데이터는 공유한다
		- 깊은복사: **`_.cloneDeep()`** 메소드(**Lodash** 라이브러리)
			- 내부에 중첩된 모든 객체와 배열까지 재귀적으로 전부 복사해 완전히 독립된 복사
			- `JSON.parse(JSON.stringify(obj))` 이거는 json 변형이 안되는 데이터는 모두 사라지는 치명적 문제가 존재해서 되도록 라이브러리 이용추천
	- 자바스크립트에서 원시데이터타입: 스택에 값이 기록됨
		- Number (정수, 실수)
		- String (문자, 문자열)
		- Boolean (참, 거짓)
		- Undefined (초기화하지 않고 선언만한 변수에 저장되는 타입)
		- Null (의도적으로 비어있음을 표현하는 타입)
	- 자바스크립트에서 참조데이터타입: 힙에 값이 기록되고, 스택에 주소가 기록됨
		- let obj={}
			- '문자열' 키로 데이터에 접근할때
			-  데이터의 순서가 중요하지 않을때
			- 사실 let obj = new Object();의 축약형임(엣날 문법이라 단축문법이 마련된것)
		- let map= new map();
			- '모든타입'키로 데이터에 접근
			- 데이터의 삽입순서도 중요하고, 데이터의 추가/삭제가 빈번할때
		- let array=\[]
			- '순서숫자' 인덱스 키로 데이터에 접근
			- 순서가 중요한 모든 타입의 데이터 목록 
			- 사실 let array = new Array();의 축약형임(엣날 문법이라 단축문법이 마련된것)
		- let set= new set()
			- 키x
			- 컬렉션 안의 모든 값을 고유하게 유지하고 싶을때(중복 제거)
			- 특정값이 컬렉션 안에 존재하는지 여부를 빠르게 확인하고 싶을때
			- let set= new Set(\[1,2,3,3]) : 배열 안 요소를 하나씩 꺼내 set에 추가
			- set.add(\[1, 2, 3, 3]); :배열 자체를 한 요소로 추가
			- set의 몇번째 데이터 조회하는법 : 배열로 변경해 인덱스 조회
				- let array =Array.from(set);
	- 함수를 이용해 개발자가 직접 (명시적)형변환: 
		- Number("10") ->10
		- Boolean("가") -> true //비어있지 않고, falsy값이 아니면 true

			- "false", 0, "", '', null, undefined, NaN

					- 0/0
					- undefined와의 계산

	- ++변수: 원본을 변형후 사용
	- 변수++ : 원본 사용후 변형
	- 자바스크립트의 == 와 ===
		- var, let, const 변수가 전부 3종류인, 동적타입이라서 형변환을 하고 비교해야 같은 값인지 알수있는 자바스크립트
		- == 타입을 바꾼후에 값이 같은가? (비교하기전 형변환) 
		- === 타입과 값이 모두 같은가 (형변화 하지않고 비교)
	- 자바의 ==
		- 자바스크립트와 다르게 자바는 컴파일시점에 변수의 타입이 이미 선언시에 쭉 타입 고정이 되어있는 정적타입 언어이다 
		- 그래서 타입이 다른것 자체가 불일치이기에 컴파일에러가 발생한다. 즉 == 자체가 형변환 하지않고 비교역할이다. 
		- 이때 참조타입끼리 비교할때 == 하면 같은 메모리 주소를 가리키는지 확인하는거고, ,equals이면 두 객체의 실제 값이 같은지 확인하는거다. 
	- 자바스크립트는 당시 자바의 유명세를 이용하기위해서 이름만 그렇게 지은 언어이다.
	- if는 논리조건, 범위비교
	- switch는 '하나의 변수'가 가질 수 있는 명확하고 정해진 값들에 따라 다른 동작을 처리할때 효과적 
		- switch 일치하는 case를 찾으면 그지점부터 코드를 실행한다
			- 그렇기 때문에 해당 case에 break가 없으면 아래 case일치여부는 상관없이 모두 실행한다
		- default : 일치하는 case가 없는경우 실행됨
			- 상단 케이스에 break가 없는경우 항상 실행됨
		- for: 정해진 횟수만큼 반복할때
		- while: 특정 조건이 만족하는 동안에만 계속 반복할때
		- do while: 처음부터 거짓이라도 한번 일단 실행한다음에서야 while처럼 동작
	- 함수란 재사용 가능한 코드 묶음이다.
		- 자바: 클래스에 묶여있는 메소드
		- 자바스크립트: 독립적으로 존재하며 값처럼 다룰수있는 객체를 함수라고 한다 
		- 1. 변수에 저장할수있다
			- 저장후 변수() 이러면 함수 호출
		- 2. 다른 함수의 인자로 전달할수있다
			- 인자로 전달된 함수는 callback(); 하는 순간 실행이 된다
			- 콜백함수: 다른 함수의 매걔변수로 전달되어 그 다른 함수 내부에서 나중에 호출되는 함수
			- 콜백함수는 비동기처리의 도구로 많이 쓰인다
				- 비동기 처리: 시간이 걸리는 작업을 기다리지 않고, 다른 작업을 먼저 처리하는 방식 
		- 3. 다른 함수의 결과값으로 반환(return)할수있다
			- 즉 반환값으로 선언된 함수를 받아 나중에 써먹을수있다
			- 참고로 return 함수가 아니라 return 함수() 이렇게하면 1.함수를 실행 2. 그 함수의 반환값을 반환하라는 의미임
		- 변수에 저장 유무와 상관없이 값처럼 다룰수있다.
	- 함수를 정의하는 3가지 방법
		- 함수 선언식: function 키워드와 함수이름을 사용해 정의
			- function 이름(){}
		- 함수 표현식: 함수를 만들어 변수에 값처럼 할당
			- const 변수= function(){}
			- 함수이름 필요없음
		- 화살표 함수: 최신문법 function대신해 =>를 사용하며  this를 다루는 방식에 차이
			- const 변수= (매걔변수) =>{}
	- 자바의 this : 메소드가 소속된 클래스의 인스턴스를 가리키는걸로 고정
	- 자바스크립트의 this : 소속이 아니라 누가 호출했냐에 따라 달라짐 
		- 객체1.함수(); 의 형태로 호출하면, 함수안의 this는 객체1를 가리킴 호출한 주체가 객체1이기 때문에
		- 함수(); 의 형태로 호출되면, 호출한 주체가 명확하지 않기때문에 전역객체(window)를 this로 함
		- 호출방식과 상관없이 화살표 함수의 this는 자기가 만들어진 장소의 this를 그대로 가져다 쓴다
		- 예시
			- 암기팁 this는 그 함수 호출문의 . 앞의 객체이다 근데 .이 안쓰인채 호출하면 window가 this이고 화살표함수는 자기가 만들어진 장소의 this를 그대로 가져다 씀
			- person.sayHello(); 일땐 sayHello 내부의 this는 person를 가리키게되고,
			- const hi = person.sayHello; hi(); 일땐 sayHello 내부의 this는 window를 가리킨다
				- hi 변수에 sayHello 함수 자체를 저장한것이고, .없이 호출했으니 sayHello의 this는 window를 가리키게 된다.
