- 프론트: 자바스크립트(웹브라우저에서 실행되는 가장 기초적 언어)
	- 자바스크립트에서 변수를 선언하는 3가지 키워드
		- 저장공간을 만들어라는 역할을 가진 3가지 종류
		- var -> 엣날 문법으로 현업에서는 쓰는걸 매우 비추
			- 코드에서 문법적인 오류를 일으켜왔다
			- 그래서 만들어진 변수키워드가 let과 const이다
		- let
		- const
		- 동적타이핑이란 사용자가 값을 대입하고 대입한 데이터 타입에 따라 사용자가 선언한 변수의 타입이 결정되는것을 말한다.
		- 자바스크립트는 동적타이핑 형식이다.
	- 자바스크립트의 모든 변수는 메모리의 스택(Stack) 공간에 생성됩니다. 
	- 이 변수에 원시 타입 값이 할당되면 그 값 자체가 스택에 기록되지만, 참조 타입 값이 할당되면 데이터의 본체는 메모리의 힙(Heap)에 별도로 생성되고, 변수는 그 힙의 메모리 주소를 저장합니다
	- 그래서 복제할때 나타나는 현상 정리
		- 참조복사: const obj2 = obj1
			- 하나의 같은 객체를 가리킴 (새로운 객체를 만들지 않고, `obj1`이 가리키는 **메모리 주소**를 똑같이 전달)
		- 얕은복사: const obj2 = { ...obj1 }
			- 메모리상 별개의 새로운 객체를 만들지만, 그 객체의 요소 데이터가 **원시 타입이라면 값 자체를 복사**하지만 객체안의 객체와 같은 **참조타입은 참조복사해서(메모리 주소만을 복사)** 두 객체내부의 참조타입데이터는 공유한다
		- 깊은복사: **`_.cloneDeep()`** 메소드(**Lodash** 라이브러리)
			- 내부에 중첩된 모든 객체와 배열까지 재귀적으로 전부 복사해 완전히 독립된 복사
			- `JSON.parse(JSON.stringify(obj))` 이거는 json 변형이 안되는 데이터는 모두 사라지는 치명적 문제가 존재해서 되도록 라이브러리 이용추천
	- 자바스크립트에서 원시데이터타입: 스택에 값이 기록됨
		- Number (정수, 실수)
		- String (문자, 문자열)
		- Boolean (참, 거짓)
		- Undefined (초기화하지 않고 선언만한 변수에 저장되는 타입)
		- Null (의도적으로 비어있음을 표현하는 타입)
	- 자바스크립트에서 참조데이터타입: 힙에 값이 기록되고, 스택에 주소가 기록됨
		- let obj={}
			- '문자열' 키로 데이터에 접근할때
			-  데이터의 순서가 중요하지 않을때
			- 사실 let obj = new Object();의 축약형임(엣날 문법이라 단축문법이 마련된것)
		- let map= new map();
			- '모든타입'키로 데이터에 접근
			- 데이터의 삽입순서도 중요하고, 데이터의 추가/삭제가 빈번할때
		- let array=\[]
			- '순서숫자' 인덱스 키로 데이터에 접근
			- 순서가 중요한 모든 타입의 데이터 목록 
			- 사실 let array = new Array();의 축약형임(엣날 문법이라 단축문법이 마련된것)
		- let set= new set()
			- 키x
			- 컬렉션 안의 모든 값을 고유하게 유지하고 싶을때(중복 제거)
			- 특정값이 컬렉션 안에 존재하는지 여부를 빠르게 확인하고 싶을때
			- let set= new Set(\[1,2,3,3]) : 배열 안 요소를 하나씩 꺼내 set에 추가
			- set.add(\[1, 2, 3, 3]); :배열 자체를 한 요소로 추가
			- set의 몇번째 데이터 조회하는법 : 배열로 변경해 인덱스 조회
				- let array =Array.from(set);
	- 함수를 이용해 개발자가 직접 (명시적)형변환: 
		- Number("10") ->10
		- Boolean("가") -> true //비어있지 않고, falsy값이 아니면 true

	- 스코프: 코드가 유효하게 작용하는 범위를 의미하며, 변수와 함수마다 소속되는 스코프 규칙이 다르다
		- 블록 스코프: {} 중괄호로 둘러싸인 범위
			- let, const, (function 선언문)
		- 함수 스코프: function 키워드로 생성된 함수 내부 전체 범위
			- var, function 선언문
				- `function` 선언문은 원칙상 블록 스코프지만, 실제 동작은 함수 스코프처럼 동작하므로 이렇게 기억하는 것이 안전합니다.
	- 자바스크립트 엔진이 코드를 **한 줄씩 실행하기 전에, 먼저 전체 코드를 한번 쓱 훑어보면서 호이스팅함 
		- 이때 호이스팅이란: 코드의 위치를 물리적으로 바꾸는게 아니라 변수와 함수의 선언을 메모리에 미리 기록하는 과정이다. 이 호이스팅은 **항상 자신이 속한 스코프의 범위 안에서만** 일어남.

		- var : 함수스코프 
			- 호이스팅: 선언부만 함수 스코프의 최상단으로 호이스팅되고 즉시 undefined로 초기화됨
				- 함수 안에서 선언되면 그 함수 내부에, 함수 밖 최상위에서 선언되면 전역
			- 해당 선언줄에 도달하기전에 접근해도 에러가 발생하지 않고 undefined 값을 가진다.
		- let, const: 블록스코프
			- 호이스팅: 블록 스코프의 최상단으로 선언부가 호이스팅되고 초기화되지 않고 접근할수없음 (이 구간을 **TDZ**라함) 
			- 결과: 변수가 선언됬던 원래 줄에 도달하기전 접근하면 ReferenceError발생 
				- let a; 이라면, 해당 줄에 도달하면 undefined로 초기화됨
				- let a=10; 이라면 해당줄에 도달하면 10으로 초기화됨
		- function 선언: 블록스코프
			- 호이스팅: 예외적으로 {}안에서 선언될때 엣날자바스크립트와 호환성을 위해서 함수 스코프까지 영향력을 가지게됨 (그래도 자신이 선언된 함수 밖으로는 나가지 않음)
				- 함수선언식은 같은 선언부이면 아무 경고 없이 덮어써져 큰 버그 모르고 지나갈수있음
			- const 변수1= function(){}
				- 변수1의 선언만 호이스팅되고, 해당 줄 이후부터 호출가능
				- const로 선언하고 값을 할당한뒤 다시 값을 할당하면 에러가 발생해 실수를 막아줌

	- 자바의 클래스 상속 vs 자바스크립트의 프로토타입 상속

	- 자바스크립트의 프로토타입이란?
		- 다른 객체에게 속성과 기능(메서드)을 물려주는 **원본(부모) 객체**입니다. 자바스크립트의 모든 객체는 속성을 `{key: value}` 쌍으로 가지며, 프로토타입 역시 이 규칙을 따르는 일반 객체입니다.
			- 예를 들어, `{ sound: function() { ... } }` 와 같은 형태가 됩니다. 
	- 자바스크립트의 상속 핵심 원리: 프로토타입 체인
		- 어떤 객체의 속성을 찾을 때 그 객체에 해당 속성이 없으면, 자바스크립트는 그 객체의 프로토타입(부모)으로 계속 거슬러 올라가며 속성을 찾습니다. 이 연결고리를 **프로토타입 체인**이라고 합니다.
		- 이 체인의 종점에는 모든 객체의 최상위 조상인 **`Object.prototype`**이 있습니다.
			- **일반 객체 → `Object.prototype`**
				- 모든 일반 객체는 `Object.prototype`으로부터 **`hasOwnProperty()`**, **`toString()`**, **`isPrototypeOf()`** 와 같은 객체의 기본적인 핵심 메서드들을 물려받습니다.
			- **함수 → `Function.prototype` → `Object.prototype`**
				- 모든 함수는 일차적으로 `Function.prototype`으로부터 **`call()`**, **`bind()`**, **`apply()`** 와 같은 함수 고유의 메서드를 물려받습니다.
				- 그리고 `Function.prototype` 또한 객체이므로, 그 부모인 `Object.prototype`으로부터 `hasOwnProperty()`, `toString()` 등의 최종 기능을 물려받습니다.
	- 프로토타입 상속 관계 생성
		- 핵심은 '어떤 객체를 부모로 삼을지'와 '부모 객체에 어떤 기능을 추가할지'입니다
		- **방법 1: `Object.create(부모객체)`로 상속하기** 
			- 주어진 `부모객체`를 프로토타입으로 삼는 새로운 빈 객체를 생성하고, 그 메모리 주소를 반환합니다.
			```JavaScript
			const animal = { // 부모 객체 (프로토타입)
				sound() {
					console.log("동물이 소리를 냅니다.");
				}
			};
			
			const dog = Object.create(animal); // animal을 부모로 하는 dog 객체 생성 (animal를 부모로 삼는 빈객체를 생성하고, 메모리주소를 dog 변수에 저장한다)
			dog.sound(); // "동물이 소리를 냅니다." -> 부모의 기능을 물려받음
			```
		- **방법 2: 생성자 함수와 `new` 키워드로 상속하기** 
			- '객체 설계도' 역할을 하는 생성자 함수와 `new` 키워드를 사용하여 가장 체계적으로 상속을 구현합니다.
			1. **생성자 함수(설계도)를 정의하고, 프로토타입에 공통 기능을 추가합니다.**
				- 객체1.prototype.변수1 : 객체1에 변수1(함수의 주소를 담은)를 추가합니다
				```JavaScript
				// 1. '차'를 만드는 생성자 함수(설계도) 정의
				function Car(name) {
				  this.name = name;
				}
				// 2. 설계도의 프로토타입에 공통 기능 추가
				// Car.prototype이라는 객체에 drive라는 속성을 추가합니다.
				Car.prototype.drive = function() {
				  console.log(this.name + '가 운전합니다.');
				};
				```
				
			2. **`new` 키워드로 객체를 생성합니다.** `new` 키워드는 내부적으로 다음 네 가지 일을 수행하며 상속 관계를 자동으로 완성합니다.
				- 1. 새로운 빈 객체(`{}`)를 만듭니다.
				- 2. 새 객체의 프로토타입을 **생성자 함수의 `prototype` 속성**에 연결합니다.
					- `새객체.__proto__ = 생성자함수.prototype`
				- 3. 생성자 함수 실행 및 `this` 바인딩
					- 생성자 함수를 호출하면서, 함수 내의 `this`가 새로 만들어진 객체를 가리키도록 설정합니다.
				- 4. 별도의 반환 구문이 없으면, 이렇게 완성된 새 객체를 반환합니다.
				```JavaScript
				// 3. new 키워드로 객체 생성
				const myCar = new Car('쏘나타'); // new가 마법을 부리는 시점!
				myCar.drive(); // 쏘나타가 운전합니다.
				```
		- 위험: 내장 프로토타입 직접 확장하기
			- 모든 객체의 최상위 조상인 `Object.prototype`에 직접 기능을 추가하면, 모든 객체가 해당 기능을 상속받아 사용할 수 있게 됩니다.
			```JavaScript
			// 모든 객체의 조상인 Object.prototype에 sayHello 메소드 추가
			Object.prototype.sayHello = function() {
			  console.log("안녕하세요!");
			};
			
			const person = { name: "블랙" };
			person.sayHello(); // 출력: 안녕하세요!
			```
			- **⚠️ 경고**: 이 방법은 매우 강력하지만, 다른 코드나 라이브러리와 충돌을 일으킬 수 있어 실제 프로젝트에서는 **절대 사용해서는 안 되는 위험한 방식**입니다.	
			- 내장 프로토타입 수정 금지*`Object.prototype`, `Array.prototype` 등 내장 객체의 프로토타입을 직접 수정하는 것은 다른 코드나 라이브러리와 충돌을 일으킬 수 있어 절대 피해야 합니다.
	- 프로토타입 **조회 (Read): `Object.getPrototypeOf(객체)`**
		- 객체의 부모(프로토타입)가 누구인지 명시적으로 확인할 수 있습니다.
		- `Object.getPrototypeOf()`의 결과는 조회하는 대상의 종류에 따라 달라집니다. 하나의 객체는 단 하나의 직계 부모만 가집니다.
		 -  1. `Object.create()`로 생성한 경우
			`Object.create()`의 인자로 전달된 객체가 그대로 프로토타입이 됩니다.
			```JavaScript
			const animal = { sound() {} };
			const dog = Object.create(animal);
			
			// dog의 직계 부모는 animal 객체입니다.
			console.log(Object.getPrototypeOf(dog) === animal); // true
			```
		- 2. 생성자 함수(`new`)로 생성한 경우
			`new` 키워드는 생성자 함수의 `.prototype` 속성을 객체의 프로토타입으로 자동 설정합니다.
			```JavaScript
			function Car(name) { this.name = name; }
			const myCar = new Car('쏘나타');
			
			// myCar의 직계 부모는 Car.prototype 객체입니다.
			console.log(Object.getPrototypeOf(myCar) === Car.prototype); // true
			```
		- 3. 객체 리터럴({})로 생성한 경우
			`{}` 와 같은 객체 리터럴로 생성된 객체는 기본적으로 모든 객체의 최상위 조상인 `Object.prototype`을 프로토타입으로 가집니다.
			```JavaScript
			const person = { name: "블랙" };
			
			// person의 직계 부모는 Object.prototype 객체입니다.
			console.log(Object.getPrototypeOf(person) === Object.prototype); // true
			```

	            - 클라이언트는 이렇게 **요청(Request)**하고, 서버는 이렇게 **응답(Response)**한다"는 매우 간단하고 명확한 규칙의 집합
			- API
				- API는 HTTP라는 기반 위에서, **"어떤 주소로, 어떤 데이터를, 어떻게 요청해야"** 원하는 기능을 사용할 수 있는지에 대한 **응용 레벨의 세부 규칙**
				- 과거에는 프로그램들이 서로 독립적인 섬처럼 존재했습니다. 만약 내 쇼핑몰 앱에서 '지도' 기능을 사용하고 싶다면, 지도 서비스의 데이터베이스 구조나 내부 코드를 전부 알아야 했습니다. 이는 매우 비효율적이고, 보안에도 취약했습니다.
				- API는 **한 프로그램이 다른 프로그램의 기능이나 데이터가 필요한 모든 순간**에 동작합니다.
				- 이 문제를 해결하기 위해, 각 서비스는 자신의 기능을 외부에서 안전하고 쉽게 사용할 수 있도록 **공식적인 '메뉴판'(API)**을 제공하기 시작했습니다. 개발자들은 더 이상 서비스의 복잡한 내부를 알 필요 없이, 공개된 API의 규칙에 맞춰 요청만 보내면 원하는 기능(지도, 결제, 날씨 정보 등)을 자신의 서비스에 손쉽게 통합할 수 있게 되었습니다. ^70q6h4
                
    - **API의 주요 구성 요소**
        - **HTTP Method**: 수행할 CRUD 작업을 정의합니다. (POST, GET, PUT, DELETE)
        - **데이터 형태**: 주고받는 데이터의 형식으로, 주로 **JSON(`{key: value}`)**을 사용합니다.
        - **상태 코드**: 요청 처리 결과를 나타내는 약속된 숫자입니다. (200번대: 성공, 400번대: 클라이언트 오류)
    - **데이터 전송**
        - 위 정보들을 담은 데이터 집합체가 API 규칙에 따라 프론트엔드와 백엔드 사이를 오고 갑니다.
- **각 영역별 기술 스택**
    - 각 영역은 자신의 역할에 가장 적합한 다른 컴퓨터 언어와 기술을 사용합니다.
        - **프론트엔드**: **JavaScript**
        - **백엔드**: **Java**, Python, Node.js 등
        - **데이터베이스**: **SQL** (MySQL, PostgreSQL과 같은 시스템에서 사용)            
- **주소(URL)와 로컬호스트**
    - 데이터는 출발지와 도착지가 필요하며, 이는 **URL**로 표현됩니다.
    - 개발 환경에서 각 영역은 고유한 주소(URL)를 가집니다.
        - **프론트엔드**: `localhost:5500`
        - **백엔드**: `localhost:8080`
        - **데이터베이스**: `localhost:3306`
    - **`localhost`**는 '내 컴퓨터'를 의미하며, 서버 소프트웨어를 설치하면 개인 컴퓨터도 서버 역할을 수행할 수 있습니다
