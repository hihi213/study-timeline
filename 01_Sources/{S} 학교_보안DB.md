#### **오늘의 학습 요약 (TL;DR)**

오늘은 데이터베이스 보안의 **전략적 프레임워크 수립**부터 **실질적인 DBMS 기술 구현**까지의 전체 흐름을 학습했습니다. 1교시에는 보안 정책을 **기획, 설계, 구축, 운영**하는 4단계 프로세스와 과학적인 **위험 평가**의 중요성을 다루었고, 2교시에는 이를 오라클 DBMS에서 구현하기 위한 핵심 기술인 **인증, 권한 관리(RBAC), 암호화, 트랜잭션(ACID), 감사(Audit)** 등의 구체적인 방법을 다음 주 실습과 연계하여 살펴보았습니다.

#### **개념 통합: 전략에서 기술로**

1교시의 전략적 개념이 2교시의 DBMS 기술로 어떻게 구체화되는지 연결하면 다음과 같습니다.

* **보안 프레임워크 (1교시)**
    * `L` **접근 제어** → **인증(Authentication)** + **권한 관리(Authorization, RBAC)** [(2, P02-03)]
    * `L` **암호화** → **전송 중 암호화(TLS)** + **저장 데이터 암호화(Column-level)** [(2, P04)]
    * `L` **취약점 분석** & **운영** → **감사 및 모니터링(Audit)**, **백업 및 복구** [(2, P05, P07)]
* **DB 보안 3대 요소 (1교시)**
    * `L` **기밀성 (Confidentiality)** → **권한 관리**, **암호화**, **뷰(VIEW)**
    * `L` **무결성 (Integrity)** → **트랜잭션(ACID)**, **병행 제어**
    * `L` **가용성 (Availability)** → **백업/복구**, **장애 조치(Failover)**

#### **실습 통합 요약**

다음 주부터 진행될 오라클 기반 실습 목표는 다음과 같습니다.

* **[S1] 사용자 및 권한 관리**
    * **목적**: 최소 권한 원칙에 따라 사용자를 생성하고 역할을 부여합니다.
    * **단계 요약**: 1) `CREATE USER`로 계정 생성 → 2) `GRANT`로 접속/자원 권한 부여 → 3) `REVOKE`로 권한 회수. [(2, P09)]
* **[S2] 보안 정책(프로파일) 적용**
    * **목적**: 조직의 보안 규정에 맞게 패스워드 정책을 강제합니다.
    * **단계 요약**: 1) `CREATE PROFILE`로 정책(실패 횟수, 유효기간) 정의 → 2) `ALTER USER`로 사용자에게 프로파일 할당. [(2, P09)]
* **[S3] 객체 수준 권한 제어**
    * **목적**: 특정 테이블, 특정 칼럼에 대한 사용자의 접근 및 조작을 세밀하게 통제합니다.
    * **단계 요약**: 1) `GRANT SELECT, UPDATE ON ...` 구문으로 특정 객체/명령어 권한 부여. [(2, P09)]
* **[S4] 데이터베이스 활동 감사**
    * **목적**: 주요 데이터에 대한 접근 및 변경 이력을 추적하여 책임성을 확보합니다.
    * **단계 요약**: 1) `AUDIT` 명령으로 감사 규칙 설정 → 2) 작업 수행 → 3) 감사 로그 뷰에서 기록 확인. [(2, P09)]
* **[S5] 민감 데이터 암호화**
    * **목적**: 주민번호, 카드번호 등 민감 데이터가 유출되더라도 내용을 식별할 수 없도록 보호합니다.
    * **단계 요약**: 1) 테이블 생성(`CREATE TABLE`) 시 특정 칼럼에 암호화 함수 적용. [(2, P09)]
* **[S6] 뷰(VIEW)를 이용한 정보 은닉**
    * **목적**: 사용자에게 테이블 데이터의 일부만 가상으로 노출하여 보안을 강화합니다.
    * **단계 요약**: 1) `CREATE VIEW` 구문으로 원본 테이블에서 필요한 칼럼만 선택 → 2) 뷰에 마스킹 처리 등을 적용. [(2, P09)]
* **[S7] 트랜잭션 제어**
    * **목적**: 데이터의 무결성을 보장하는 작업 단위의 개념을 이해하고 제어합니다.
    * **단계 요약**: 1) DML 작업 수행 → 2) `COMMIT`으로 영구 저장 또는 `ROLLBACK`으로 작업 취소. [(2, P09)]
