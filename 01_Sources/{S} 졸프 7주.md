# **상단 고정(항상 적용)**

- **라벨 교체**(remove→create)는 **한 트랜잭션**에서 처리(경쟁 시 UNIQUE 409 방지). 
- **423 락**: DB엔 **근거 데이터만** 남기고, **차단 여부는 앱 미들웨어**에서 판단(락 GC는 워커/크론). 

---

# **선행 필수(0주차, 0.5d)**

- 마이그 적용 확인: event_log 테이블/인덱스, resources.floor_code(백필→NOT NULL→인덱스), resource_locks(expires_at) 인덱스, penalties_adjustments.delta_points <> 0 체크.         
- 앱 권한 확인: event_log 접근 롤(dcs_app/dcs_read) 구성 시 권한 부여. 
- **앱 필수 6가지**를 작업 항목으로 등록(이벤트 삽입, /events/poll, 응답 floor_code, OpenAPI/에러카탈로그, 권한, 실제 층코드 백필).

# **✅ 7주 실행 체크리스트(주당 10–15h, 프론트=AI)**

## **Week 1 — 부트스트랩·인증 베이스**

**백엔드**

- docker-compose, /healthz·/readyz, 요청 요약 로그(+지연). 
- OpenAPI 골격 + **RFC7807 초안**. 
- /auth/login(JWT), /me, **RBAC(ADMIN/INSPECTOR/USER)**.     
- /events/poll 스텁(sinceId/limit, 더미 1건). 
    
**프론트(AI)**
    
- “부트스트랩 프롬프트” 투입(Next.js+TS+Tailwind+shadcn/ui+React Query+Zod+MSW, E2E/Vitest).
    **Gate/DoD**: 헬스 200, 권한 밖 403, 폴링으로 hello 수신 캡처. 

## **Week 2 — 자원·아이템 + 이벤트 기록**

**백엔드**

- 리소스(냉장 칸) 목록(+ floor_code). 
- 아이템 묶음 등록/조회/검색(LIKE; TRGM 인덱스는 파일만). 
- event_log.append: items.created/updated/removed 기록, 응답/이벤트에 floor_code. 
- 페이지네이션(?limit&cursor). 
    
    **프론트(AI)**
    
- “API 계약/훅 프롬프트”로 타입(Zod)·React Query 훅 생성 + 목록/검색 화면.
    
    **Gate/DoD**: 활성 라벨 중복 409, 제거 후 재사용 OK, 폴링에 신규 이벤트 노출. 

## **Week 3 — 조정/제거 + 경량 멱등·감사**

**백엔드**

- items/:id:adjust, :remove-all. 
- **경량 Idempotency-Key**(작성계, TTL 10m). 
- **GUC 주입**(app.user_id, app.change_reason) + 이벤트 기록. 
    
    **프론트(AI)**
    
- 조정/제거 UX + 에러 매핑(409/422/423/429 배너).
    
    **Gate/DoD**: remove-all→create 라벨 교체 OK, **중복 요청 동일 응답**. 

## **Week 4 —** **2인 검사 세션** **+ 423 락**

**백엔드**

- 세션 열기/참여/나가기(자원당 진행 1건, 참가자 ≤2).   
- 검사 중 해당 칸 쓰기 **423 Locked**(미들웨어에서 판단).   
- 락 TTL(5–10m) + 만료 인덱스 + GC 잡.   
    
    **프론트(AI)**
    
- “검사 세션 프롬프트”로 2인 진행 UI + 423 배너/포커스 처리.
    
    **Gate/DoD**: 3번째 참여 409/422, 폴링에서 락 상태 즉시 확인. 

## **Week 5 — 조치 기록 + 단일 제출  → 원본 벌점**

**백엔드**

- 액션: PASS / WARNING / DISCARD / DISCARD_WITH_PENALTY. 
- 제출 1회(멱등), 제출 후 INSERT/DELETE 금지, UPDATE=리비전(+버전).   
- 제출 시 **원본 벌점 자동 생성** + 원본 벌점 불변 트리거.   
    
    **프론트(AI)**
    
- 기록→제출 흐름, 성공/재제출 동일응답 UX.
    
    **Gate/DoD**: 재제출 동일응답, 원본 벌점 생성, 수정 시 version +1. 

## **Week 6 — 벌점 조정 + 집계 API**

**백엔드**

- 조정 벌점(+/-, 사유 필수), 합산 뷰(original/adjusted/total, 기간 필터).   
- 조정값 0 금지 체크(보강). 
    
    **프론트(AI)**
    
- 벌점 요약/사용자별 테이블(필터), 프리셋 사유는 **미룸(선택)**. 
    
    **Gate/DoD**: 집계 정확(E2E/쿼리 회귀), 원본 불변 보장. 

## **Week 7 — 프런트 E2E 데모 +** 폴링 최소형 안정화**

**백엔드**

- 로그인→등록/조회→검사(2인)→제출→벌점 **엔드투엔드 시나리오**. 
- /events/poll **커서/응답 규약** 최종 고정(스펙에 sinceId/limit·payload). 
- **로컬 스토리지 커서/단일 탭 공유는 컷**(R1~R2로 슬립). 
- 임시 스테이징 예행: /healthz·/events/poll 스모크. 
    
    **프론트(AI)**
    
- E2E 연결 및 1분 데모 스크립트 반영.
    
    **Gate/DoD**: 1분 데모 OK(영상/스크립트), p95 샘플 수집(선택).

# **공통 증빙(주차 병행, 최소 세트)**

- **OpenAPI 스냅샷** + **에러 카탈로그**(409/422/423/429 예시). 
- **지표 라이트**: API p50/p95, 429 비율 샘플. 
- **1분 데모**: 로그인→등록/조회→2인검사→제출→벌점. 

---

## **프론트는 전부 AI(가드레일만 사람이 고정)**

- **요청 스택/패턴**은 매주 프롬프트에 못박기(Next14+TS+Tailwind+shadcn/ui+React Query+Zod+MSW, E2E=Playwright).
- **폴링은 최소형**: 5s 주기, **메모리 lastId 커서만**(오프라인 복구/탭공유는 R1로). 

---

## **스키마/규칙(이 체크리스트 내내 준수)**

- **아이템 라벨 충돌 방지**: 활성 상태에서 (resource_id, label_no) 유일. 
- **검사 세션 규칙**: 진행중 1건/≤2명, 제출 후 결과는 불변(리비전). 
- **벌점**: 원본은 수정/삭제 금지(트리거), 조정값 0 금지.   
- **에러 매핑 권장**: UNIQUE/경합=409, CHECK/FK=422, 검사중/락=423, 레이트=429.
