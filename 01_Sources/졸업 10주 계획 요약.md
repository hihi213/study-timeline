# 세탁실 확장 10주 체크리스트
## Week 1 — 정책·흐름 정밀 설계 & 가드 깔기
-  상태 전이 규칙 확정: `UNAUTHORIZED_USE`·`ERROR_REPORTED` 도입 시 전이 표 작성(허용/금지 매트릭스)
-  메시지/알림 카피 확정(국문): 미등록 사용 경고/알림, 고장 신고 접수/차단 안내
-  **피처 플래그** 도입: `laundry.flags.enableUnauthorizedUse`, `laundry.flags.enableErrorReport`
-  컨트롤러 가드: 플래그 OFF면 3+1 외 상태 요청 **400/409**로 차단
-  권한 매핑 재점검: 사용자·관리자·층별장 액션별 권한 명세서

**DoD**
-  전이 표/권한 표 문서化(README-ops.md)
-  플래그 OFF 시 기존 3+1만 동작, 신규 API들은 404/409로 안전 차단
---

## Week 2 — UNAUTHORIZED_USE: 신고/등록 API 1차

-  `POST /api/laundry/devices/{id}/unauthorized` (미등록 사용 발견 → 상태 전환)
    
-  `POST /api/laundry/devices/{id}/adjust-remaining` (남은시간 정정; 선택사항)
    
-  상태 이력 기록 + 도메인 이벤트 `UnauthorizedUseReported`
    
-  알림 큐 적재: “사용 등록 없이 가동 중입니다. 종료 시간 등록 또는 신고 확인 바랍니다.”
    
-  인가: 일반 사용자 가능(존 접근 허용 시), 남/여 존 규칙 준수
    

**DoD**

-  플래그 ON 환경에서 미등록 사용 신고→상태 변경→알림 READY 레코드 생성까지 E2E
    

---

## Week 3 — UNAUTHORIZED_USE: 자동 복귀 & 충돌 방지

-  **타임아웃 정책**: 신고 후 `expected_end_at` 경과 시 자동 `AVAILABLE` 복귀 잡(멱등)
    
-  `IN_USE`와 충돌 규칙: 실제 시작 API가 들어오면 `UNAUTHORIZED_USE` → `IN_USE` 대체 전환
    
-  알림: 타임아웃 복귀 시 “기기 사용 가능” 브로드캐스트(존 단위)
    
-  경합 테스트: 동시 신고/등록/종료 케이스
    

**DoD**

-  시뮬레이션: 신고→(시간 경과) 자동 복귀, 중간에 정상 시작 시 충돌 없이 전이

## Week 4 — ERROR_REPORTED: 고장 신고/차단 플로우

-  `POST /api/laundry/devices/{id}/report-error` (사용자 신고 → `ERROR_REPORTED`)
    
-  관리자 트리아지: `PATCH /api/laundry/devices/{id}/triage` → `OUT_OF_SERVICE`/무효화(원상복귀)
    
-  증빙(선택): 신고 사유/사진 URL 필드
    
-  알림: 신고 접수 시 관리자, `OUT_OF_SERVICE` 전환 시 존 사용자 브로드캐스트
    

**DoD**

-  신고→관리자 처리→상태 차단/복구 E2E + 알림 큐 적재 확인

## Week 5 — 발송 파이프라인 보강 & 리트라이/데드레터

**DoD**

## Week 6 — 실시간 갱신 강화(SSE 안정화 or WebSocket 선택)

-  **SSE 강화안(권장)**: 존별 스트림 `/api/laundry/stream?zone=`에 하트비트, 재접속 백오프, 버퍼 크기 조정
    
-  또는 **WebSocket** 선택 시: 토픽=존, 인증(JWT) 핸드셰이크, 구독/해제, 서버 스케일 고려
    
-  이벤트 축약 포맷: `deviceId,status,remainSeconds,version`
    
-  프론트: 폴링 → SSE/WS로 교체, 오프라인 시 폴백
    

**DoD**

-  30분 지속 세션에서 누락/중복 없이 상태 동기화(샘플 50 이벤트) 확인

## 참고 — 스키마/코드 가이드(요지)

-  **ENUM 6종**은 이미 선언(또는 TEXT + CHECK) 상태로 가정. 마이그레이션 불필요.
    
-  서비스 레이어에서 **허용 상태**를 피처 플래그로 분기(초기 3+1, v1.1에서 6종 활성화).
    
-  모든 상태 전이는 **도메인 이벤트** 발행 → 알림/실시간/감사 로 분리 구독(결합도 최소화).
    
-  잡/워커는 **멱등** 보장(사이클 키/버전, 상태 조건부 업데이트).
