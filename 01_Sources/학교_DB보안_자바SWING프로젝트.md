|**기능 (Action)**|**목적**|**사용 UI 요소**|
|---|---|---|
|**C: 등록 (Create)**|새로운 메뉴 정보(ID, 이름, 카테고리, 가격)를 DB에 **추가**합니다.|`JTextField`, `JComboBox`, '등록' 버튼|
|**R: 조회 (Read)**|DB에 저장된 **전체 메뉴 목록**을 불러와 화면에 **표시**합니다.|`JTable`|
|**U: 수정 (Update)**|기존 메뉴 항목을 선택하여 이름, 카테고리, 가격 정보를 **변경**합니다.|`JTable`, 입력 필드, '수정' 버튼|
|**D: 삭제 (Delete)**|`JTable`에서 선택된 메뉴 항목을 DB에서 **제거**합니다.|`JTable`, '삭제' 버튼|
