-  [[02_Notes/너는 웹서버를 만드는 게 아니라, 웹서버 위에서 돌아가는 웹앱을 만드는 것이야.스프링부트가 도와줘서, 웹서버랑 앱을 함께 실행할 수 있을 뿐이고]]
	- ### **1. 톰캣(Tomcat)은 웹서버이다**
		- HTTP 요청을 받아서, 요청 URL에 맞는 서블릿이나 컨트롤러에게 전달한다.
	    - 컨트롤러가 응답을 만들면, 그걸 다시 브라우저로 전달하는 **중간 다리** 역할을 한다.
		- 흔히 말하는 “자바 웹서버”는 Tomcat, Jetty, Undertow 같은 것들이다.
	- ### **2. 내가 만든 건 웹 애플리케이션 (Web Application)**
		- 사용자의 요청을 받아 처리하는 Controller
		- 비즈니스 로직을 담당하는 Service
		- DB에 접근하는 Repository
		→ 이런 구성요소들을 스프링으로 작성해서 만든 “웹 애플리케이션”이다.
	- ### **3. 스프링 부트는 톰캣 + 웹앱을 하나로 포장한 것**
		- 과거에는 .war 파일을 만들어 외부 Tomcat에 배포했지만,
		- 스프링 부트는 **내장 톰캣**을 .jar 파일 안에 함께 포함시킨다.
		- 따라서 .jar 파일 하나만 실행해도 톰캣이 실행되고, 웹앱도 자동으로 배치된다.
	- 출처: Gpt
