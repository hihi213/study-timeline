## 이제 리팩토링의 시간

졸업작품을 정리하면서 코드적으로 리팩토링할 부분이 많은 것을 확인하였다

![](https://velog.velcdn.com/images/hwangjeyeon/post/74d3c942-1760-4e12-a97d-1027cbc10e9c/image.jpg)

졸업작품 개발을 하면서 리팩토링을 주기적으로 할때 보이지 않던 것들이  
정리할 때는 많이 보이길래 이후 리팩토링의 시간을 가지려고 한다

현재 계획중인 리팩토링 대상은 다음과 같다.  
1. Setter 제거, 관련 메소드 사용  
2. JPQL -> QueryDSL로 대체  
3. Thymeleaf Enum 항목 하드코딩 -> Enum 형태로 리팩토링  
4. Cipher 모듈 활용한 자바 스프링 서버 <-> 파이썬 클라이언트 암호화 복호화 통신 기능 리팩토링  
5. 암호화 키 환경변수로 저장 후 관리  
6. 템플릿 클래스들 재설계  
7. 검증 통과 메세지 코드 리팩토링  
8. 로그 리팩토링  
9. user-agent 라이브러리 사용

이외에도 리팩토링을 하면서 더 발견하게 되면 더 리팩토링하고 개선해 나갈 계획이다

## 구조 개선 및 학습

![](https://velog.velcdn.com/images/hwangjeyeon/post/f2aac88c-0366-454f-bfb8-a96c74d0a943/image.png)

구조적 개선이나 인프라를 구축하면서 아쉬웠던 부분에 대해서도 더 학습하고 진행해보려고 한다

현재 계획중인 구조 개선 및 학습은 다음과 같다  
1. 부하테스트에 대한 학습  
2. 프로메테우스 이외에 핀포인트, 그라파나 로키 연결  
3. 톰캣 스레드 튜닝에 대한 학습  
4. Nginx 로드밸런싱 구현 및 테스트

## 마치며

![](https://velog.velcdn.com/images/hwangjeyeon/post/2415e052-b1a4-4ac5-bcd4-6306cbb3a12d/image.png)

개발 - 배포 - 운영(부하테스트를 통한 예측) 3단계를 모두 경험해볼 수 있는 좋은 프로젝트였다  
팀장으로서 팀을 이끌어가는데 필요한 역량을 기를 수 있었고, 리더에 대한 생각도 많이 할 수 있었다

약간 아쉽다면 코드적으로 해결한 임팩트가 적은 프로젝트였다는 점이다.

구조적으로 문제를 해결하고 인프라 구축에 신경을 더 쓴 느낌이라 인프라에 대한 지식은  
많이 쌓아갈 수 있었지만 서버 개발에 있어서는 조금 부족했지 않았나 싶다.

다음 프로젝트에서는 코드적으로 해결하는데 더 집중하는 프로젝트가 되어서  
구조적으로도 코드적으로도 문제를 모두 해결할 수 있는 더 성장하는 개발자가 되기를 바란다.
