## 🏆 절대 1순위: 이것 모르면 탈락 (출제율 80% 이상)

어떤 기업을 지원하든 반드시 하나 이상 출제되는 유형입니다.

### 1. 구현 (Implementation) & 시뮬레이션

- **핵심:** 문제에서 제시한 복잡한 규칙을 코드로 정확히 옮기는 능력.
- **세부 유형:**
    - 2차원 배열 회전/이동 (상하좌우 탐색).
    - 문자열 파싱 및 처리.
    - 완전 탐색 (Brute Force) + 조건 검증.
- **팁:** `dx`, `dy` 테크닉(방향 벡터)과 `sys.stdin.readline` 등 입출력 처리에 능숙해야 합니다.
    

### 2. DFS / BFS (그래프 탐색)

- **핵심:** 데이터를 탐색하거나 최단 거리를 구하는 능력.
- **구분:**
    - **BFS:** 미로 찾기, 최단 거리(가중치 1), 영역 넓이 구하기. (`deque` 필수)
    - **DFS:** 연결된 덩어리 개수 세기, 백트래킹(재귀), 경로의 특징 저장.
- **팁:** 삼성전자는 DFS/BFS + 구현을 섞은 문제가 거의 매번 출제됩니다.
    

### 3. 그리디 (Greedy)

- **핵심:** 현재 상황에서 가장 좋은 것을 고르는 논리력.
- **세부 유형:** 회의실 배정, 거스름돈, 최소 횟수로 만들기.
- **팁:** 주로 **정렬(Sorting)**과 결합되어 출제됩니다.

## 🥈 2순위: 당락을 결정하는 핵심 유형 (출제율 50~70%)

변별력을 위해 출제되며, 여기서 점수를 따야 합격권에 듭니다.

### 1. 해시 (Hash Table)

- **핵심:** $O(1)$의 빠른 검색 속도 활용.
- **세부 유형:** 중복 제거, 빈도수 체크, 특정 값 존재 여부 확인.
- **팁:** 파이썬의 `dict`와 `set`, `collections.Counter` 활용법을 마스터해야 합니다.
    

### 2. 정렬 (Sorting) & 이진 탐색 (Binary Search)

- **핵심:** 대량의 데이터($N \ge 100,000$)를 효율적으로 처리.
- **세부 유형:**
    - **정렬:** `lambda`를 이용한 다중 조건 정렬.
    - **이진 탐색:** 특정 값 찾기, 파라메트릭 서치(최적화 문제를 결정 문제로 변환).
- **팁:** `bisect` 라이브러리 사용법을 익혀두세요.
    

### 3. 동적 계획법 (DP) 코테 파이썬으로 풀이

- **핵심:** 점화식을 세워 문제를 쪼개 푸는 능력.
- **세부 유형:** 타일링, 배낭 문제(Knapsack), LIS(최장 증가 부분 수열).
- **팁:** "메모이제이션(Memoization)" 개념과 바텀업 방식(반복문)을 이해해야 합니다.

**구현(Implementation)** 및 **시뮬레이션(Simulation)** 유형은 문제에서 제시하는 복잡한 알고리즘이나 규칙을 코드로 정확하게 변환하는 능력을 평가합니다.

특별한 알고리즘(DFS/BFS 등)을 요구하지 않더라도, **2차원 배열 처리**, **방향 벡터 활용**, **문자열 파싱** 등의 테크닉이 필수적입니다.

---
**문자열 파싱(Parsing) 및 처리**는 주어진 문자열에서 **필요한 정보를 추출**하거나, **특정 규칙에 맞게 변형**하는 문제입니다.

파이썬은 문자열 처리에 매우 강력한 기능을 제공하며, 코딩 테스트에서는 주로 **슬라이싱**, **내장 메서드**, **정규 표현식(Regex)** 세 가지를 조합하여 해결합니다.

## 1. 기본 조작: 슬라이싱과 불변성 (Slicing & Immutability)

파이썬의 문자열은 **불변(Immutable)** 객체입니다. 한 번 생성된 문자열의 특정 인덱스 값을 직접 변경할 수 없으므로, 변경이 필요할 경우 **슬라이싱** 등을 통해 **새로운 문자열을 생성**해야 합니다.

- **인덱싱 및 슬라이싱:** `s[start:end:step]`
    
- **문자열 뒤집기:** `s[::-1]` (필수 암기)
    

Python

```
s = "Hello Python"

# 1. 슬라이싱
print(s[0:5])   # "Hello"
print(s[6:])    # "Python"

# 2. 역순 출력 (뒤집기)
print(s[::-1])  # "nohtyP olleH"

# 3. 특정 문자 변경 (직접 할당 불가 -> 슬라이싱 조합)
# s[0] = 'h'  # TypeError 발생
new_s = 'h' + s[1:] 
print(new_s)    # "hello Python"
```

## 2. 분리 및 결합 (Split & Join)

문자열을 리스트로 변환하거나, 리스트를 다시 문자열로 합칠 때 사용합니다. 가장 빈번하게 사용되는 패턴입니다.

- **`split(구분자)`:** 문자열 $\rightarrow$ 리스트
    
- **`'구분자'.join(리스트)`:** 리스트 $\rightarrow$ 문자열
    

Python

```
data = "apple,banana,orange"

# 1. 분리 (Split)
fruits = data.split(',') 
print(fruits) # ['apple', 'banana', 'orange']

# 2. 결합 (Join)
result = '-'.join(fruits)
print(result) # "apple-banana-orange"

# 활용: 리스트의 문자를 공백 없이 합칠 때
chars = ['a', 'b', 'c']
print("".join(chars)) # "abc"
```

## 3. 검색 및 변환 (Search & Replace)

특정 문자의 위치를 찾거나 다른 문자로 대체합니다.

- **`find(x)`:** $x$의 인덱스 반환 (없으면 -1 반환). **에러가 발생하지 않아 안전함.**
    
- **`index(x)`:** $x$의 인덱스 반환 (없으면 `ValueError` 발생).
    
- **`count(x)`:** $x$의 등장 횟수 반환.
    
- **`replace(old, new)`:** 문자열 내의 모든 `old`를 `new`로 바꿈.
    
- **`strip()`:** 양쪽 공백 제거 (`lstrip`, `rstrip`은 좌/우 제거).
    

Python

```
s = "  Hello World  "

# 공백 제거
s = s.strip() # "Hello World"

# 검색
print(s.find("World")) # 6
print(s.find("Python")) # -1

# 대체 (원본은 변하지 않으므로 재할당 필요)
s = s.replace("World", "Python")
print(s) # "Hello Python"
```

## 4. 문자 검사 및 아스키 코드 (ASCII)

문자열의 구성 요소를 확인하거나, 알파벳 순서를 다룰 때 사용합니다.

- **검사 메서드:**
    
    - `s.isdigit()`: 숫자로만 구성되었는지 확인.
        
    - `s.isalpha()`: 알파벳으로만 구성되었는지 확인.
        
- **아스키 코드 변환:**
    
    - `ord(문자)`: 문자를 아스키 코드(정수)로 변환. (`A`: 65, `a`: 97)
        
    - `chr(정수)`: 정수를 문자로 변환.
        

Python

```
# 알파벳 순서 문제 (카이사르 암호 등)
char = 'A'
# 'A'를 1만큼 뒤로 밀기
next_char = chr(ord(char) + 1)
print(next_char) # 'B'
```

## 5. 정규 표현식 (Regular Expression) - [심화]

복잡한 문자열 파싱(예: "문자열에서 숫자만 추출", "특수문자 제거")이 필요할 때 **`re` 모듈**을 사용합니다.

- **`re.sub(패턴, 교체어, 문자열)`:** 패턴에 맞는 부분을 교체.
    
- **`re.findall(패턴, 문자열)`:** 패턴에 맞는 모든 부분을 리스트로 반환.
    

### 주요 패턴 (암기 권장)

- `[0-9]` 또는 `\d`: 숫자
    
- `[a-z]`: 영어 소문자
    
- `[A-Z]`: 영어 대문자
    
- `[^0-9]`: 숫자가 **아닌** 것 (`^`는 부정)
    

Python

```
import re

text = "Hello! 1234 World? 5678"

# 1. 숫자만 추출 (findall)
numbers = re.findall(r'\d+', text)
print(numbers) # ['1234', '5678']

# 2. 특수문자 제거 (알파벳과 숫자가 아니면 공백으로 치환)
clean_text = re.sub(r'[^a-zA-Z0-9]', ' ', text)
print(clean_text) # "Hello  1234 World  5678"
```

## 6. 실전 문제 패턴 예시

### 패턴 A: 팰린드롬(회문) 판별

앞뒤가 똑같은 문자열인지 확인하는 문제입니다.

Python

```
def is_palindrome(s):
    # 1. 전처리: 특수문자 제거 및 소문자 변환
    s = re.sub(r'[^a-zA-Z0-9]', '', s).lower()
    
    # 2. 뒤집은 것과 비교
    return s == s[::-1]

print(is_palindrome("A man, a plan, a canal: Panama")) # True
```

### 패턴 B: 문자열 압축 (구현)

연속된 문자의 개수를 세어 압축하는 로직입니다. (예: `AAAB` $\rightarrow$ `3AB`)

Python

```
s = "AAABACC"
result = ""
count = 1

# 마지막 문자와의 비교를 위해 범위 설정 주의
for i in range(1, len(s)):
    if s[i] == s[i-1]:
        count += 1
    else:
        if count > 1:
            result += str(count)
        result += s[i-1]
        count = 1

# 마지막 문자 처리
if count > 1:
    result += str(count)
result += s[-1]

print(result) # "3AB1A2C" (문제 조건에 따라 1은 생략 가능)
```

## 💡 요약: 상황별 추천 도구

1. **단순히 자르고 붙이기:** 슬라이싱(`[:]`), `split`, `join`
    
2. **특정 문자 찾기/바꾸기:** `find`, `replace`
    
3. **복잡한 규칙(특수문자 제거, 이메일 추출 등):** **정규 표현식(`re`)**
    
4. **알파벳 순서 연산:** `ord`, `chr`

**DFS(깊이 우선 탐색)**와 **BFS(너비 우선 탐색)**는 코딩 테스트에서 그래프 탐색, 최단 거리, 완전 탐색 문제를 해결하는 가장 기초적이고 필수적인 알고리즘입니다.

두 알고리즘 모두 시간 복잡도는 **$O(V + E)$** ($V$: 노드 수, $E$: 간선 수)로 동일하지만, **탐색 순서**와 **사용하는 자료구조**에서 명확한 차이가 있습니다.

## 1. 그래프 데이터 표현 (인접 리스트)

코딩 테스트에서는 그래프를 주로 인접 리스트(Adjacency List) 형태로 표현합니다.

노드 번호가 1번부터 시작하는 경우가 많으므로, 리스트의 인덱스 0은 비워두고 크기를 $N+1$로 설정합니다.

Python

```
# 예시 그래프: 1번 노드와 연결된 노드는 2, 3, 8번
graph = [
    [],             # 0번 노드 (비워둠)
    [2, 3, 8],      # 1번 노드 인접 리스트
    [1, 7],         # 2번 노드 …
    [1, 4, 5],
    [3, 5],
    [3, 4],
    [7],
    [2, 6, 8],
    [1, 7]
]

# 방문 여부를 저장할 리스트 (False로 초기화)
visited = [False] * 9
```

## 2. DFS (Depth-First Search, 깊이 우선 탐색)

**개념:** 루트 노드(혹은 임의의 노드)에서 시작해서 다음 분기(Branch)로 넘어가기 전에, 해당 분기를 완벽하게(깊게) 탐색하는 방식입니다.

- **동작 원리:** **스택(Stack)** 또는 **재귀(Recursion)**
    
- **구현:** 코딩 테스트에서는 구현이 간결한 **재귀 함수** 방식을 선호합니다.
    
- **주의점:** 재귀 깊이가 깊어질 경우 `sys.setrecursionlimit()` 설정이 필요할 수 있습니다.
    

### 💻 DFS 파이썬 구현 (재귀 템플릿)

Python

```
import sys
sys.setrecursionlimit(10**6) # 재귀 깊이 제한 해제

def dfs(graph, v, visited):
    # 1. 현재 노드 방문 처리
    visited[v] = True
    print(v, end=' ')
    
    # 2. 현재 노드와 연결된 다른 노드를 재귀적으로 방문
    for i in graph[v]:
        if not visited[i]:
            dfs(graph, i, visited)

# 실행
visited = [False] * 9
dfs(graph, 1, visited)
# 출력 예시: 1 2 7 6 8 3 4 5
```

## 3. BFS (Breadth-First Search, 너비 우선 탐색)

**개념:** 루트 노드에서 시작해서 인접한 노드를 먼저 탐색하는 방법입니다. 시작 정점으로부터 가까운 정점을 먼저 방문하고 멀리 떨어져 있는 정점을 나중에 방문하는 순회 방법입니다.

- **동작 원리:** **큐(Queue)** (FIFO: 선입선출)
    
- **구현:** `collections` 모듈의 **`deque`**를 반드시 사용해야 합니다. (`list.pop(0)`은 $O(N)$으로 비효율적)
    
- **특징:** 간선의 가중치가 모두 1일 때, **최단 거리**를 보장합니다.
    

### 💻 BFS 파이썬 구현 (큐 템플릿)

Python

```
from collections import deque

def bfs(graph, start, visited):
    # 1. 큐 구현을 위해 deque 사용
    queue = deque([start])
    
    # 2. 현재 노드 방문 처리
    visited[start] = True
    
    # 3. 큐가 빌 때까지 반복
    while queue:
        # 큐에서 하나의 원소를 뽑아 출력 (방문)
        v = queue.popleft()
        print(v, end=' ')
        
        # 해당 원소와 연결된, 아직 방문하지 않은 원소들을 큐에 삽입
        for i in graph[v]:
            if not visited[i]:
                queue.append(i)
                visited[i] = True # 큐에 넣을 때 방문 처리 (중복 방지)

# 실행
visited = [False] * 9
bfs(graph, 1, visited)
# 출력 예시: 1 2 3 8 7 4 5 6
```

## ⚖️ DFS vs BFS 비교 및 선택 가이드

|**특징**|**DFS (깊이 우선)**|**BFS (너비 우선)**|
|---|---|---|
|**탐색 방식**|한 경로를 끝까지 파고듦|인접한 노드부터 넓게 퍼짐|
|**자료구조**|**스택 / 재귀**|**큐 (deque)**|
|**최단 경로**|보장하지 않음|**보장함** (가중치 1일 때)|
|**구현 난이도**|쉬움 (코드 간결)|보통 (큐 설정 필요)|
|**검색 속도**|느림 (모든 경로 검색 시 적합)|빠름 (목표가 가까이 있을 때)|

### 💡 문제 유형별 선택 요령

1. **최단 거리 / 최단 횟수 구하기** $\rightarrow$ **무조건 BFS**
    
    - 예: 미로 탈출, 특정 거리의 도시 찾기, 토마토 익히기
        
2. **경로의 특징 저장 / 모든 경우의 수** $\rightarrow$ **DFS**
    
    - 예: 경로에 있는 숫자를 다 더해서 이동하기, 백트래킹(N-Queen)
        
3. **연결된 덩어리(영역) 개수 세기** $\rightarrow$ **DFS/BFS 둘 다 가능**
    
    - 예: 음료수 얼려 먹기, 아파트 단지 번호 붙이기 (DFS가 구현이 더 빠름)

**그리디(Greedy, 탐욕법)** 알고리즘은 **"현재 상황에서 지금 당장 좋은 것만 고르는 방법"**입니다.

코딩 테스트에서 그리디 문제는 **정렬(Sorting)**과 함께 출제되는 경우가 매우 많으며, **'가장 큰 순서대로'** 또는 **'가장 작은 순서대로'** 선택했을 때 최적의 해가 보장되는지 파악하는 것이 핵심입니다.

## 1. 그리디 알고리즘의 핵심 전략

그리디 문제는 특별한 공식보다는 **문제 해결 아이디어**가 중요합니다.

1. **정렬(Sorting) 우선:** 대부분의 그리디 문제는 데이터를 정렬한 후, 앞에서부터 차례대로 선택하면 해결됩니다.
    
2. **기준 설정:** "가장 비싼 것부터", "가장 빨리 끝나는 것부터"와 같은 명확한 기준을 세웁니다.
    
3. **정당성 분석:** "가장 큰 것을 먼저 선택해도 전체 최적해를 해치지 않는가?"를 검토해야 합니다.

## 2. 대표 유형별 파이썬 풀이

### 유형 A: 거스름돈 문제 (가장 기본적인 유형)

가장 적은 수의 동전으로 거슬러 주려면, **'가장 큰 화폐 단위'**부터 거슬러 주면 됩니다.

- **문제:** 1260원을 500원, 100원, 50원, 10원 동전으로 거슬러 줄 때 최소 동전 개수는?
    
- **시간 복잡도:** $O(K)$ (화폐 종류의 개수만큼 반복)
    

Python

```
def min_coin_count(n):
    coins = [500, 100, 50, 10] # 큰 단위부터 정렬
    count = 0
    
    for coin in coins:
        # 해당 화폐로 거슬러 줄 수 있는 최대 개수 (몫)
        count += n // coin 
        
        # 거슬러 주고 남은 돈 (나머지)
        n %= coin 
        
    return count

print(min_coin_count(1260)) # 6
```

### 유형 B: 회의실 배정 (활동 선택 문제)

한 개의 회의실에서 최대한 많은 회의를 진행하려면 **'끝나는 시간이 가장 빠른 회의'**를 우선 선택해야 합니다. 그래야 뒤에 더 많은 회의를 배치할 수 있기 때문입니다.

- **전략:** **끝나는 시간**을 기준으로 오름차순 정렬합니다. (끝나는 시간이 같다면 시작 시간을 기준으로 정렬)
    
- **시간 복잡도:** $O(N \log N)$ (정렬 소요 시간)
    

Python

```
# 입력: (시작 시간, 종료 시간) 리스트
meetings = [(1, 4), (3, 5), (0, 6), (5, 7), (3, 8), (5, 9), (6, 10), (8, 11), (8, 12), (2, 13), (12, 14)]

def max_meetings(meetings):
    # 1. 끝나는 시간(x[1]) 오름차순, 같다면 시작 시간(x[0]) 오름차순 정렬
    meetings.sort(key=lambda x: (x[1], x[0]))
    
    count = 0
    last_end_time = 0
    
    for start, end in meetings:
        # 2. 이전에 선택한 회의가 끝난 이후에 시작하는 회의라면 선택
        if start >= last_end_time:
            count += 1
            last_end_time = end # 회의 끝나는 시간 갱신
            
    return count

print(max_meetings(meetings)) # 4
```

### 유형 C: 1이 될 때까지 (수 나누기)

어떤 수 $N$을 1로 만드는데, 1) $N$에서 1을 빼거나, 2) $N$을 $K$로 나누는 연산만 가능합니다. 최소 횟수를 구하려면 **'가능하면 많이 나누는 것'**이 유리합니다.

- **전략:** $N$이 $K$의 배수가 될 때까지 1을 빼고, 배수가 되면 나눕니다.
    

Python

```
def make_one(n, k):
    result = 0
    
    while True:
        # (N == K로 나누어떨어지는 수)가 될 때까지 1씩 빼는 횟수를 한 번에 계산
        target = (n // k) * k 
        result += (n - target)
        n = target
        
        # N이 K보다 작을 때 (더 이상 나눌 수 없을 때) 반복 종료
        if n < k:
            break
            
        # K로 나누기
        result += 1
        n //= k
        
    # 남은 수(1이 될 때까지)에 대해 1씩 빼기
    result += (n - 1)
    return result

print(make_one(25, 5)) # 2 (25 / 5 = 5 -> 5 / 5 = 1)
print(make_one(25, 3)) # 6
```

### 유형 D: 잃어버린 괄호 (문자열 파싱 + 그리디)

수식에 괄호를 쳐서 결과를 최솟값으로 만드는 문제입니다. (예: 55-50+40)

값을 최소로 만들려면 '빼기(-)' 뒤에 나오는 수들을 최대한 크게 만들어야 합니다. 즉, -가 나오면 그 뒤의 모든 + 연산을 먼저 수행하여 묶어버리면 됩니다.

- **전략:** `-`를 기준으로 문자열을 분리(`split`)한 뒤, 첫 번째 그룹은 더하고 나머지는 모두 뺍니다.
    

Python

```
expression = "55-50+40"

def min_expression(expr):
    # 1. '-'를 기준으로 분리 -> ['55', '50+40']
    groups = expr.split('-')
    
    answer = 0
    
    # 2. 첫 번째 그룹의 숫자들은 모두 더해서 초기값 설정
    # '55' -> 55
    first_group = groups[0].split('+')
    for num in first_group:
        answer += int(num)
        
    # 3. 두 번째 그룹부터는 (괄호로 묶인 효과) 내부 값을 다 더한 뒤, 전체에서 뺌
    # '50+40' -> 90 -> answer에서 뺌
    for i in range(1, len(groups)):
        sub_group = groups[i].split('+')
        temp_sum = 0
        for num in sub_group:
            temp_sum += int(num)
        answer -= temp_sum
        
    return answer

print(min_expression(expression)) # -35
```

## 💡 그리디 문제 해결 체크리스트

1. **정렬 가능성 확인:** 문제의 조건이 순서(시간, 크기, 무게 등)와 관련이 있다면 `sort()`를 먼저 고려합니다.
    
2. **극단적 선택:** 가장 큰/작은 것을 계속 선택했을 때 예외 케이스가 없는지 생각합니다.
    
3. **반례 주의:** 예를 들어 거스름돈 문제에서 화폐 단위가 `[500, 400, 100]`이고 800원을 거슬러 줘야 한다면, 그리디(500+100+100+100, 4개)보다 최적해(400+400, 2개)가 더 좋습니다. 이 경우 그리디가 아닌 **DP(동적 계획법)**로 풀어야 합니다.
    
    - **팁:** 화폐 단위가 **배수 관계**라면 그리디, 무작위라면 DP일 확률이 높습니다.


**해시(Hash)**는 키(Key)를 해시 함수(Hash Function)를 통해 고정된 크기의 주소로 변환하여 데이터를 저장하는 자료구조입니다. 코딩 테스트에서는 **빠른 데이터 검색($O(1)$)**과 **빈도수 계산**을 위해 필수적으로 사용됩니다.

파이썬에서는 **`dict` (딕셔너리)**와 **`set` (집합)**이 해시 테이블로 구현되어 있습니다.

---

## 1. 핵심 개념 및 시간 복잡도

해시 테이블의 가장 큰 장점은 데이터의 양($N$)과 무관하게 검색, 삽입, 삭제가 평균적으로 **상수 시간($O(1)$)**에 수행된다는 점입니다.

|**연산**|**리스트 (list)**|**해시 (dict / set)**|**비고**|
|---|---|---|---|
|**검색 (`x in data`)**|$O(N)$|**$O(1)$**|리스트는 전체 탐색 필요|
|**삽입/수정**|$O(1)$ (끝) / $O(N)$ (중간)|**$O(1)$**|키를 통해 즉시 접근|
|**삭제**|$O(N)$|**$O(1)$**|키를 통해 즉시 삭제|

- **주의:** 해시 충돌(Collision)이 빈번하게 발생하는 최악의 경우 $O(N)$이 될 수 있으나, 파이썬 내부적으로 충돌 제어가 잘 되어 있어 코딩 테스트에서는 $O(1)$로 간주합니다.
    
- **제약:** 딕셔너리의 키(Key)나 집합(Set)의 원소는 **변경 불가능(Immutable)**한 자료형(정수, 문자열, 튜플)이어야 합니다. 리스트는 키가 될 수 없습니다.

## 2. 파이썬 해시 활용 패턴 (라이브러리)

코딩 테스트에서 자주 사용되는 세 가지 핵심 패턴(`dict`, `Counter`, `defaultdict`)을 정리합니다.

### A. 기본 딕셔너리 (`dict`) - 조회 및 갱신

가장 기본적인 형태입니다. `get()` 메서드를 활용하여 키 에러(`KeyError`)를 방지하는 것이 중요합니다.

Python

```
# 1. 초기화
phone_book = {}

# 2. 삽입 및 수정
phone_book['Alice'] = '010-1234-5678'
phone_book['Bob'] = '010-9876-5432'

# 3. 조회 (in 연산자 활용)
if 'Alice' in phone_book:
    print(phone_book['Alice'])

# 4. 조회 (get 활용 - 권장)
# 'Charlie'가 없으면 None 반환 (에러 안 남)
print(phone_book.get('Charlie')) 
# 기본값 지정 가능: 키가 없으면 0 반환
print(phone_book.get('Charlie', 0)) 
``` 

### B. 빈도수 계산 (`collections.Counter`) - [빈출]

리스트에 있는 요소들의 개수를 셀 때 가장 효율적입니다. 반복문을 줄여줍니다.

Python

```
from collections import Counter

data = ['apple', 'banana', 'apple', 'orange', 'banana', 'apple']

# 한 줄로 빈도수 계산 완료
counts = Counter(data)

print(counts) 
# Counter({'apple': 3, 'banana': 2, 'orange': 1})

# 딕셔너리처럼 사용 가능
print(counts['apple']) # 3

# 가장 많이 등장한 n개 요소 추출
print(counts.most_common(1)) 
# [('apple', 3)]
```

### C. 그룹화 (`collections.defaultdict`)

그래프의 인접 리스트를 만들거나, 데이터를 특정 기준으로 묶을 때 사용합니다. 키가 존재하는지 확인할 필요 없이 바로 값을 추가할 수 있습니다.

Python

```
from collections import defaultdict

# 값이 리스트인 딕셔너리 생성 (초기값 자동 할당)
group = defaultdict(list)

# 키 'fruit'가 없어도 에러 없이 빈 리스트 생성 후 append
group['fruit'].append('apple')
group['fruit'].append('banana')
group['veg'].append('carrot')

print(dict(group))
# {'fruit': ['apple', 'banana'], 'veg': ['carrot']}
```

## 3. 실전 문제 유형별 풀이

### 유형 1: 중복 검사 및 존재 여부 확인 (`set` 활용)

리스트를 사용하면 $O(N)$이 걸리는 검색을 `set`을 사용하여 $O(1)$로 최적화합니다.

**문제:** 리스트 `arr`에 특정 값 `target`이 존재하는지 확인하라.

Python

```
arr = [1, 5, 7, 3, 2, 9]
target = 7

# 비효율적: O(N)
# if target in arr: …

# 효율적: O(1) (데이터가 많을 때 유리)
arr_set = set(arr) # 리스트를 집합으로 변환 (O(N))
if target in arr_set: # 검색은 O(1)
    print("존재함")
```

### 유형 2: 완주하지 못한 선수 (빈도수 차이)

두 리스트를 비교하여 차이가 나는 요소를 찾을 때 `Counter`의 **뺄셈 연산**을 사용하면 매우 간단합니다.

**문제:** 참가자(`participant`) 중 완주자(`completion`) 명단에 없는 1명을 찾아라.

Python

```
from collections import Counter

def solution(participant, completion):
    # 1. 각 리스트의 카운터 생성
    p_count = Counter(participant)
    c_count = Counter(completion)
    
    # 2. 차집합 연산 (참가자 - 완주자)
    # Counter끼리는 뺄셈이 가능하며, 개수가 0이 된 키는 사라짐
    result = p_count - c_count
    
    # 3. 남은 1명 반환 (키만 추출)
    return list(result.keys())[0]

# 테스트
print(solution(["leo", "kiki", "eden"], ["eden", "kiki"])) # "leo"
```

### 유형 3: 의상 (조합의 수 계산)

종류별로 개수를 세고 조합 공식을 적용하는 문제입니다. 해시를 이용해 **그룹화**와 **카운팅**을 동시에 수행합니다.

**문제:** 의상 이름과 종류가 주어질 때, 입을 수 있는 옷의 조합 수를 구하라. (최소 한 개의 옷은 입어야 함)

Python

```
from collections import Counter

def solution(clothes):
    # 1. 종류별 개수 세기
    # clothes = [['mask', 'face'], ['sunglasses', 'face'], ['shirt', 'top']]
    # x[1]은 종류('face', 'top')를 의미함
    
    # 종류만 추출하여 리스트 생성 -> ['face', 'face', 'top']
    kinds = [kind for name, kind in clothes]
    counter = Counter(kinds)
    
    # 2. 경우의 수 계산
    # 공식: (A종류 개수 + 1) * (B종류 개수 + 1) … - 1 (아무것도 안 입는 경우 제외)
    # +1은 해당 종류를 입지 않는 경우를 포함하기 위함
    answer = 1
    for count in counter.values():
        answer *= (count + 1)
        
    return answer - 1
```

## 💡 요약: 해시 자료구조 선택 기준

1. **데이터 조회/검색**이 빈번하다면 무조건 **`dict`** 또는 **`set`**을 사용합니다. ($O(1)$)
    
2. **개수를 세야 한다면** 반복문 대신 **`collections.Counter`**를 사용합니다.
    
3. **그룹화**가 필요하다면 **`collections.defaultdict(list)`**를 사용합니다.
    
4. **메모리 제한**이 매우 타이트한 경우 해시 테이블 사용에 주의해야 합니다. (리스트보다 메모리를 더 많이 사용함)


**정렬(Sorting)**과 **이진 탐색(Binary Search)**은 대용량 데이터를 효율적으로 처리하기 위한 필수 알고리즘입니다. 코딩 테스트에서는 두 개념이 결합되어 출제되거나, 효율성 테스트($N \ge 100,000$)의 핵심 키가 됩니다.

---

## 1. 정렬 (Sorting)

코딩 테스트에서 정렬 알고리즘을 직접 구현(퀵, 병합 정렬 등)하는 경우는 드뭅니다. 파이썬의 **강력한 내장 함수**를 자유자재로 활용하여 **복합적인 정렬 기준**을 처리하는 능력이 중요합니다.

- **시간 복잡도:** $O(N \log N)$ (Timsort 기반)
    

### A. 기본 정렬 함수 비교

|**함수**|**사용법**|**특징**|**반환값**|
|---|---|---|---|
|**`sort()`**|`data.sort()`|원본 리스트를 **직접 변경** (In-place)|`None`|
|**`sorted()`**|`sorted(data)`|원본은 유지하고 **정렬된 새 리스트** 반환|**새로운 리스트**|

### B. `key`와 `lambda`를 이용한 다중 조건 정렬 (필수)

단순 오름차순/내림차순이 아닌, 특정 기준에 따라 정렬해야 할 때 사용합니다.

Python

```
# 데이터: (이름, 점수, 학번)
students = [
    ('Steve', 75, 2021),
    ('David', 90, 2020),
    ('Alex', 90, 2022)
]

# 정렬 조건 우선순위:
# 1. 점수 높은 순 (내림차순 -> -x[1])
# 2. 점수가 같다면 학번 낮은 순 (오름차순 -> x[2])
# 3. 이름 사전 순 (오름차순 -> x[0])

result = sorted(students, key=lambda x: (-x[1], x[2], x[0]))

print(result)
# [('David', 90, 2020), ('Alex', 90, 2022), ('Steve', 75, 2021)]
```

## 2. 이진 탐색 (Binary Search)

**정렬된 데이터**에서 특정 값을 찾아내는 알고리즘입니다. 탐색 범위를 절반씩 좁혀가며 데이터를 찾습니다.

- **시간 복잡도:** $O(\log N)$
    
- **활용:** 탐색 범위가 매우 클 때(예: 0 ~ 10억), 특정 값의 개수를 셀 때.
    

### A. `bisect` 라이브러리 활용 (값 검색 및 개수 세기)

파이썬 표준 라이브러리로, **정렬된 리스트**에서 값이 들어갈 위치를 찾아줍니다. 직접 구현보다 빠르고 정확합니다.

- **`bisect_left(a, x)`**: 정렬 순서를 유지하며 $x$를 삽입할 **가장 왼쪽** 인덱스 반환.
    
- **`bisect_right(a, x)`**: 정렬 순서를 유지하며 $x$를 삽입할 **가장 오른쪽** 인덱스 반환.
    

Python

```
from bisect import bisect_left, bisect_right

# 값이 [left_value, right_value] 범위에 있는 데이터의 개수를 반환하는 함수
def count_by_range(a, left_value, right_value):
    right_index = bisect_right(a, right_value)
    left_index = bisect_left(a, left_value)
    return right_index - left_index

# 정렬된 리스트
arr = [1, 2, 3, 3, 3, 3, 4, 4, 8, 9]

# 값이 4인 데이터 개수 출력
print(count_by_range(arr, 4, 4)) # 2

# 값이 [-1, 3] 범위에 있는 데이터 개수 출력
print(count_by_range(arr, -1, 3)) # 6
```

### B. 반복문을 이용한 직접 구현 (파라메트릭 서치용)

단순히 값이 있는지를 찾는 것이 아니라, **조건을 만족하는 최댓값/최솟값(최적화 문제)**을 찾는 **파라메트릭 서치(Parametric Search)** 유형에서는 직접 구현해야 합니다.

- **예제: 떡볶이 떡 만들기 (절단기 높이 설정)**
    
    - 요청한 길이 $M$만큼의 떡을 얻기 위해 설정할 수 있는 절단기의 **최대 높이**를 구하시오.
        

Python

```
# 입력: 떡의 개수 N, 요청한 길이 M
n, m = 4, 6 
array = [19, 15, 10, 17]

# 이진 탐색을 위한 시작점과 끝점 설정
start = 0
end = max(array)
result = 0

while start <= end:
    total = 0
    mid = (start + end) // 2 # 절단기 높이
    
    # 잘린 떡의 양 계산
    for x in array:
        if x > mid:
            total += x - mid
            
    # 1. 떡의 양이 부족한 경우 -> 더 많이 잘라야 함 (높이 낮추기)
    if total < m:
        end = mid - 1
        
    # 2. 떡의 양이 충분한 경우 -> 덜 잘라도 되는지 확인 (높이 높이기)
    else:
        result = mid # 최대한 덜 잘랐을 때가 정답이므로, 여기서 기록
        start = mid + 1

print(result) # 15
```

### 💡 요약: 선택 가이드

| **상황**                | **추천 방법**          | **코드 패턴**                        |
| --------------------- | ------------------ | -------------------------------- |
| **복잡한 기준 정렬**         | **Lambda 정렬**      | `sorted(data, key=lambda x: …)`  |
| **특정 값 위치/개수 찾기**     | **`bisect` 라이브러리** | `bisect_right - bisect_left`     |
| **최적화 문제 (최대/최소 찾기)** | **이진 탐색 직접 구현**    | `while start <= end:` (파라메트릭 서치) |


**동적 계획법(Dynamic Programming, DP)**은 복잡한 문제를 작은 하위 문제로 나누어 해결하고, **그 결과를 저장(Memoization)**하여 다시 계산하지 않음으로써 효율성을 극대화하는 알고리즘 설계 기법입니다.

코딩 테스트에서는 **점화식(Recurrence Relation)**을 세우는 능력이 가장 중요합니다.

---

## 1. 핵심 개념 및 구현 방식

DP가 적용되려면 다음 두 가지 조건이 필요합니다.

1. **최적 부분 구조 (Optimal Substructure):** 큰 문제의 해답이 작은 문제의 해답으로 구성될 수 있어야 합니다.
    
2. **중복되는 부분 문제 (Overlapping Subproblems):** 동일한 작은 문제가 반복적으로 등장해야 합니다.
    

### 구현 방식 비교

|**방식**|**탑다운 (Top-Down)**|**바텀업 (Bottom-Up)**|
|---|---|---|
|**구현**|**재귀 함수** + 메모이제이션|**반복문** + DP 테이블|
|**특징**|큰 문제에서 시작해 작은 문제 호출|작은 문제부터 차근차근 답을 도출|
|**장점**|점화식 형태 그대로 구현 가능 (직관적)|재귀 호출 오버헤드가 없음 (**일반적 권장**)|
|**메모리**|재귀 깊이 제한(`sys.setrecursionlimit`) 주의|테이블 크기만큼만 사용|

---

## 2. 기초 예제: 피보나치 수열

DP의 개념을 가장 잘 보여주는 예제입니다.

- **점화식:** $a_n = a_{n-1} + a_{n-2}$
    

### A. 탑다운 (Memoization)

Python

```
import sys
sys.setrecursionlimit(10**6)

# 한 번 계산된 결과를 메모이제이션하기 위한 리스트 초기화
d = [0] * 100

def fibo(x):
    # 종료 조건 (1 혹은 2일 때 1을 반환)
    if x == 1 or x == 2:
        return 1
    
    # 이미 계산한 적 있는 문제라면 그대로 반환
    if d[x] != 0:
        return d[x]
    
    # 아직 계산하지 않았다면 점화식에 따라 피보나치 결과 반환
    d[x] = fibo(x - 1) + fibo(x - 2)
    return d[x]

print(fibo(99))
```

### B. 바텀업 (Tabulation) [권장]

Python

```
# 앞서 계산된 결과를 저장하기 위한 DP 테이블 초기화
d = [0] * 100

# 첫 번째와 두 번째 피보나치 수는 1
d[1] = 1
d[2] = 1
n = 99

# 피보나치 함수(Fibonacci Function) 반복문으로 구현
for i in range(3, n + 1):
    d[i] = d[i - 1] + d[i - 2]

print(d[n])
```

## 3. 실전 대표 유형

코딩 테스트에 자주 출제되는 DP 유형 3가지를 정리합니다.

### 유형 1: 개미 전사 (인접하지 않은 값들의 최댓값)

배열의 인접한 원소를 동시에 선택할 수 없을 때, 합의 최댓값을 구하는 문제입니다. (유사 문제: 계단 오르기, 스티커 떼기)

- **점화식:** $a_i = \max(a_{i-1}, a_{i-2} + k_i)$
    
    - 현재 창고를 터는 경우: $i-2$번째까지의 최댓값 + 현재 창고 값
        
    - 현재 창고를 안 터는 경우: $i-1$번째까지의 최댓값
        

Python

```
# 입력: 정수 N, 식량 정보 리스트 array
n = 4
array = [1, 3, 1, 5]

# DP 테이블 초기화
d = [0] * 100

# 바텀업 진행 (Bottom-Up)
d[0] = array[0]
d[1] = max(array[0], array[1]) 

for i in range(2, n):
    # (직전 창고까지의 최댓값) vs (전전 창고까지의 최댓값 + 현재 창고 값)
    d[i] = max(d[i - 1], d[i - 2] + array[i])

print(d[n - 1]) # 8
```

### 유형 2: 1로 만들기 (최소 연산 횟수)

정수 $X$가 주어졌을 때, 5, 3, 2로 나누거나 1을 빼서 1로 만드는 최소 횟수를 구합니다.

- **점화식:** $a_i = \min(a_{i-1}, a_{i/2}, a_{i/3}, a_{i/5}) + 1$
    

Python

```
x = 26
d = [0] * 30001

# 바텀업 진행
for i in range(2, x + 1):
    # 1. 현재의 수에서 1을 빼는 경우
    d[i] = d[i - 1] + 1
    
    # 2. 2로 나누어 떨어지는 경우
    if i % 2 == 0:
        d[i] = min(d[i], d[i // 2] + 1)
        
    # 3. 3으로 나누어 떨어지는 경우
    if i % 3 == 0:
        d[i] = min(d[i], d[i // 3] + 1)
        
    # 4. 5로 나누어 떨어지는 경우
    if i % 5 == 0:
        d[i] = min(d[i], d[i // 5] + 1)

print(d[x]) # 3
```

### 유형 3: 효율적인 화폐 구성 (Knapsack 변형)

$N$가지 종류의 화폐를 최소 개수로 사용하여 합계 $M$원을 만드는 문제입니다.

- **점화식:** $a_j = \min(a_j, a_{j-k} + 1)$
    
    - $a_j$: 금액 $j$를 만들기 위한 최소 화폐 개수
        
    - $k$: 화폐의 단위
        
- **초기화:** 불가능한 경우를 표현하기 위해 큰 값(예: 10001)으로 초기화합니다.
    

Python

```
# n: 화폐 종류 개수, m: 목표 금액
n, m = 2, 15
coins = [2, 3]

# DP 테이블 초기화 (불가능한 값을 10001로 설정)
d = [10001] * (m + 1)

# 0원을 만드는 방법은 0개
d[0] = 0

# 각 화폐 단위(coin)를 하나씩 확인하며 테이블 갱신
for coin in coins:
    for j in range(coin, m + 1):
        # (j - coin)원을 만드는 방법이 존재한다면
        if d[j - coin] != 10001:
            d[j] = min(d[j], d[j - coin] + 1)

# 결과 출력
if d[m] == 10001:
    print(-1)
else:
    print(d[m]) # 5
```

## 💡 DP 문제 풀이 팁

1. **문제 식별:** "최댓값/최솟값", "경우의 수", "연속된 선택" 등의 키워드가 있고, 그리디(Greedy)로 풀리지 않을 때 DP를 의심합니다.
    
2. **점화식 도출:** $N$번째 상태를 구하기 위해 $N-1$, $N-2$번째 상태를 어떻게 활용할지 관계식을 세웁니다.
    
3. **테이블 정의:** `d[i]`가 무엇을 의미하는지 명확히 정의합니다. (예: `d[i]` = $i$원을 만드는 최소 동전 개수)
    
4. **초기값 설정:** `d[0]`, `d[1]` 등 점화식의 기반이 되는 초기값을 올바르게 설정합니다.
