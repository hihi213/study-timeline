네, 물론입니다. 질문하신 `app.workspace.activeLeaf`와 같이 QuickAdd 스크립트나 옵시디언 플러그인 개발에 사용되는 `app` 객체의 주요 기능들을 정리해 드릴게요.

`app`은 옵시디언의 거의 모든 기능에 접근할 수 있는 핵심 객체입니다. 이 객체를 통해 현재 열린 파일, 전체 파일 목록, 에디터 내용, UI 요소 등을 제어할 수 있습니다. 주요 속성들을 기능별로 나누어 설명해 드리겠습니다.

---

### ## 1. 워크스페이스 및 화면 제어 (`app.workspace`)

현재 활성화된 창, 탭(리프), 에디터 등 사용자가 보고 있는 화면과 관련된 기능을 담당합니다.

|속성/메서드|설명|예시 코드|
|---|---|---|
|**`app.workspace.activeLeaf`**|현재 활성화된(커서가 있는) 탭(leaf) 객체를 가져옵니다. **사용자가 제공한 코드에 나온 부분입니다.**|`const activeLeaf = app.workspace.activeLeaf;`|
|**`app.workspace.getActiveFile()`**|현재 활성화된 파일 객체(`TFile`)를 직접 가져옵니다.|`const activeFile = app.workspace.getActiveFile();`|
|**`app.workspace.getLeaf([newPane])`**|새로운 탭(leaf)을 열거나 기존 탭을 가져옵니다. `newPane`이 `true`이면 새 창 분할.|`const newLeaf = app.workspace.getLeaf(true);`|
|**`app.workspace.openLinkText(link, path)`**|내부 링크나 외부 링크를 엽니다.|`app.workspace.openLinkText("My Note", "");`|
|**`on(event, callback)`**|특정 이벤트 발생 시 함수를 실행합니다. (예: 파일 열기, 레이아웃 변경)|`app.workspace.on('file-open', (file) => { new Notice(`${file.basename} 파일이 열렸습니다.`); });`|

---

### ## 2. 볼트(Vault) 및 파일 시스템 제어 (`app.vault`)

볼트 내의 모든 파일과 폴더를 생성, 읽기, 수정, 삭제하는 기능을 담당합니다.

| 속성/메서드                                      | 설명                              | 예시 코드                                                        |
| ------------------------------------------- | ------------------------------- | ------------------------------------------------------------ |
| **`app.vault.getAbstractFileByPath(path)`** | 주어진 경로의 파일이나 폴더 객체를 가져옵니다.      | `const file = app.vault.getAbstractFileByPath("폴더명/파일.md");` |
| **`app.vault.create(path, content)`**       | 지정된 경로에 새로운 파일을 생성하고 내용을 채웁니다.  | `app.vault.create("새 노트.md", "# 제목\n\n내용입니다.");`             |
| **`app.vault.read(file)`**                  | 파일 객체(`TFile`)의 내용을 문자열로 읽어옵니다. | `const content = await app.vault.read(activeFile);`          |
| **`app.vault.modify(file, content)`**       | 파일의 전체 내용을 수정합니다.               | `await app.vault.modify(activeFile, "# 제목이 수정되었습니다.");`      |
| **`app.vault.append(file, content)`**       | 파일의 끝에 내용을 추가합니다.               | `await app.vault.append(activeFile, "\n\n추가된 내용입니다.");`      |
| **`app.vault.trash(file, system)`**         | 파일을 옵시디언 휴지통이나 시스템 휴지통으로 보냅니다.  | `app.vault.trash(file, true);`                               |
| **`app.vault.getMarkdownFiles()`**          | 볼트 내의 모든 마크다운 파일 목록을 가져옵니다.     | `const allNotes = app.vault.getMarkdownFiles();`             |

---

### ## 3. 에디터 제어 (`editor`)

에디터는 `activeLeaf.view.editor`를 통해 접근하며, 커서 위치, 선택 영역, 텍스트 조작 등을 담당합니다.

|속성/메서드|설명|예시 코드|
|---|---|---|
|**`editor.getCursor()`**|현재 커서의 위치(줄, 칸)를 가져옵니다.|`const cursor = editor.getCursor();`|
|**`editor.getSelection()`**|현재 선택된 텍스트를 가져옵니다.|`const selectedText = editor.getSelection();`|
|**`editor.replaceSelection(text)`**|선택된 텍스트를 새로운 텍스트로 교체합니다.|`editor.replaceSelection("대체될 텍스트");`|
|**`editor.getLine(lineNumber)`**|특정 줄의 텍스트를 가져옵니다.|`const lineContent = editor.getLine(10);`|
|**`editor.setLine(lineNumber, text)`**|특정 줄의 텍스트를 수정합니다.|`editor.setLine(10, "이 줄의 내용이 바뀝니다.");`|
|**`editor.lineCount()`**|문서의 총 줄 수를 가져옵니다.|`const totalLines = editor.lineCount();`|

> 💡 **Tip:** 에디터 객체를 가져오려면 먼저 `activeLeaf`를 확인해야 합니다.
>
> JavaScript
>
> ```
> const editor = app.workspace.activeLeaf?.view?.editor;
> if (editor) {
>   // 에디터 관련 코드 실행
> }
> ```

### ## 4. 메타데이터 및 캐시 (`app.metadataCache`)

파일의 태그, 링크, 프론트매터(Frontmatter) 등 옵시디언이 내부적으로 관리하는 정보에 접근합니다.

| 속성/메서드                                     | 설명                             | 예시 코드                                                       |
| ------------------------------------------ | ------------------------------ | ----------------------------------------------------------- |
| **`app.metadataCache.getFileCache(file)`** | 파일의 캐시된 메타데이터를 가져옵니다.          | `const cache = app.metadataCache.getFileCache(activeFile);` |
| **`cache.frontmatter`**                    | 파일의 프론트매터(YAML) 정보를 객체로 가져옵니다. | `const tags = cache.frontmatter?.tags;`                     |
| **`cache.tags`**                           | 파일 내의 모든 태그 정보를 가져옵니다.         | `const allTagsInFile = cache.tags;`                         |
| **`cache.links`**                          | 파일 내의 모든 내부 링크 정보를 가져옵니다.      | `const allLinksInFile = cache.links;`                       |

### ## 5. UI 및 알림

`Notice` (간단한 알림), `Modal` (팝업창) 등 사용자 인터페이스와 관련된 기능을 제공합니다.

|속성/메서드|설명|예시 코드|
|---|---|---|
|**`new Notice(message)`**|화면 우측 상단에 잠시 나타나는 알림 메시지를 표시합니다.|`new Notice("작업이 완료되었습니다.");`|
|**`app.commands.executeCommandById(id)`**|특정 커맨드(명령어)를 실행합니다.|`app.commands.executeCommandById("app:toggle-left-sidebar");`|
