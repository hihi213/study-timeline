**목표:** 독서의 흐름을 최대한 유지하며 원재료를 수집하되, 놓치면 안 될 번뜩이는 영감의 씨앗은 바로 심는다.

**행동 절차:**

1.  **자료 준비:** `Tanenbaum2021 - Computer Networks.pdf` 파일을 `01_Sources/` 폴더에 넣습니다.
2. **명세서 생성:** `01_Sources/` 폴더에 cmd+T를 눌러 `[S] Tanenbaum - Computer Networks.md` 라는 소스노트를 생성합니다
3. **작업 환경 설정:** 옵시디언에서 왼쪽에는 PDF를, 오른쪽에는 방금 만든 소스 노트를 나란히 엽니다.
4. **원재료 수집 (기본 행동):** 뽀모도로 타이머 등을 이용해 집중해서 PDF를 읽으며, `PDF++`의 단축키(`Ctrl+Shift+C`)로 핵심 문장, 예시, 나의 질문 등을 하이라이트하여 오른쪽 소스 노트에 꾸준히 쌓아나갑니다.
    - `TCP는 신뢰성 있는, 연결 지향형 서비스를 제공한다...` -> **노란색 (핵심 개념)**
    - `UDP는 비연결형 프로토콜로, 헤더가 단순하고 오버헤드가 적다...` -> **노란색 (핵심 개념)**
    - `DNS, VoIP, 온라인 게임 등은 약간의 데이터 손실보다 속도가 중요하므로 UDP를 사용한다...` -> **초록색 (중요한 예시)**
    - `신뢰성을 보장하기 위한 TCP의 메커니즘은 정확히 어떻게 작동하는 걸까?` -> 이 문장을 읽고 떠오른 당신의 생각을 **빨간색 (질문/의문)** 으로 하이라이트하고 주석을 답니다.
5. **[분기] 영감의 씨앗 심기 (예외 행동):** 읽는 도중 **"아! 이건 지금 정리하지 않으면 사라질 것 같다!"** 싶은 강력한 통찰(예: 'UDP는 현실의 우편 시스템과 같다')이 떠오르면, 아래의 '가벼운 즉시 가공' 절차를 따릅니다.

	- `Ctrl` 키를 누른 채 링크를 클릭하여 새 탭에 노트를 엽니다.
    - 떠오른 핵심 생각 **딱 한 문장만** 적습니다.
