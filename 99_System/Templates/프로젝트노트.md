## 🧰 재료 수집 (Material Gathering)
> 이 프로젝트 노트의 YAML에 `topics`를 지정하면, 아래 쿼리가 자동으로 관련 재료들을 찾아줍니다.

### 뼈대가 되는 핵심 개념들 (`status: done`)
```dataview
TABLE creation_date AS "생성일"
FROM "" 
WHERE type = "개념" AND contains(topics, this.topics) AND status = "done"
SORT creation_date ASC
````

### 이해를 돕는 예제 및 코드 조각

코드 스니펫

```
LIST
FROM ""
WHERE type = "개념" AND contains(topics, this.topics) AND (type = "example" OR type = "code_snippet")
```
