<%*
// --- Part 1: 파일 이름 및 제목 설정 ---
// 노트 작성기(Note Composer)에서 추출 기능을 사용하면 파일 제목이 자동으로 설정됩니다.
// 만약 파일 제목이 'Untitled'로 시작하면, 사용자에게 직접 제목을 입력받습니다.
const noteTitle = tp.file.title.startsWith("Untitled") 
  ? await tp.system.prompt("✨ 노트 제목을 입력하세요:") 
  : tp.file.title;

// 파일 이름을 입력받은 제목으로 변경합니다.
await tp.file.rename(noteTitle);

// --- Part 2: 토픽 선택 기능 ---
// 현재 볼트(Vault) 내의 모든 태그를 가져와서 'topic/'으로 시작하는 태그만 필터링합니다.
// 예: #topic/javascript -> javascript
// (팁: 주요 주제 노트나 MOC에 #topic/주제명 태그를 달아두면 이 목록에 자동으로 나타납니다.)
const allTopics = Object.keys(app.metadataCache.getTags())
  .map(tag => tag.substring(1)) // 맨 앞의 '#' 제거
  .filter(tag => tag.startsWith("topic/")) 
  .map(tag => tag.replace("topic/", "")); // 'topic/' 접두사 제거

// 사용자에게 위에서 만든 토픽 목록을 보여주고, 하나 또는 여러 개를 선택할 수 있는 제안창(Suggester)을 띄웁니다.
const selectedTopics = await tp.system.suggester(
  allTopics, // 제안할 항목 목록
  allTopics, // 반환될 값 목록
  true,      // 다중 선택 허용
  "📚 이 노트의 주제를 선택하세요 (여러 개 가능)"
);

// --- Part 3: 메타데이터 생성 ---
// 사용자가 선택한 토픽들을 YAML 프론트매터에 들어갈 링크 형식(예: - "[[JavaScript]]")으로 변환합니다.
const topicsYAML = selectedTopics.map(topic => `- "[[${topic}]]"`).join('\n');
-%>
---
tags: 개념노트
aliases: []
creation_date: <% tp.date.now("YYYY-MM-DD") %>
status: seeding
type: 
confidence: 
topics:
<% topicsYAML %>
source: ""
---

- 

## My Thought (나의 생각, 통찰)
- <% tp.file.cursor() %>

### 관련 노트 (Related Notes)
> *방금 선택한 주제와 관련된 다른 노트들입니다. 새로운 지식을 연결해 보세요.*

```dataview
LIST
FROM #개념노트 AND (<% selectedTopics.map(t => `"${t}"`).join(' OR ') %>)
WHERE file.name != "<% noteTitle %>"
LIMIT 5
````
