### **단계별 플러그인 세팅 과정**

#### **0단계: 사전 준비**

1. **커뮤니티 플러그인 활성화:** `설정` > `커뮤니티 플러그인` > `커뮤니티 플러그인 켜기`를 활성화해주세요.
2. **플러그인 설치:** `설정` > `커뮤니티 플러그인` > `탐색`에서 위 5개의 플러그인(`Templater`, `Dataview`, `QuickAdd`, `Homepage`, `Linter`)을 모두 검색하여 설치하고, 설치 후에는 옆의 토글을 켜서 **활성화**해주세요.
3. **템플릿 폴더 생성:** 옵시디언 파일 탐색기에서 `_Templates` 라는 이름의 폴더를 하나 만드세요. `_`를 앞에 붙이면 보통 폴더 목록의 최상단에 위치해서 관리하기 편합니다.

### **1단계: 모든 '설계도' 만들기 (Templater 설정)**

**목표:** 각 폴더(`01_Sources`, `02_Notes`)에 맞는 노트와, 필요시 수동으로 생성할 MOC 노트의 '설계도(템플릿)'를 완벽하게 준비합니다.

1. **템플릿 파일 생성:** `_Templates` 폴더 안에, 아래 **세 가지** 템플릿 파일을 만듭니다. (이전 안내에서 드린 코드를 그대로 복사-붙여넣기 하세요.)
    
    - `T - 소스 노트.md`
        
    - `T - 개념 노트.md`
        
    - **`T - MOC.md`**
        
2. **Templater 설정 (폴더 연결):**
    
    - `설정` > `Templater`로 이동합니다.
        
    - `Template folder location`에 `_Templates` 폴더를 지정합니다.
        
    - `Trigger Templater on new file creation` 옵션을 **활성화(On)** 합니다.
        
    - **[가장 중요]** 바로 아래 `Folder Templates` 섹션에서 `Enable folder templates`를 **활성화(On)** 하고, `Add new folder template` 버튼을 눌러 아래 **두 가지 규칙**을 추가합니다.
        
        - **규칙 1 (소스 노트 자동화):**
            
            - **Folder:** `01_Sources`
                
            - **Template:** `_Templates/T - 소스 노트.md`
                
        - **규칙 2 (개념 노트 자동화):**
            
            - **Folder:** `02_Notes`
                
            - **Template:** `_Templates/T - 개념 노트.md`
                
3. **MOC 템플릿 사용법:**
    
    - MOC는 소스/개념 노트처럼 특정 폴더에서 자동으로 만들기보다, **'이 주제의 지도를 만들어야겠다!'** 고 마음먹었을 때 **의식적으로 생성**하는 경우가 많습니다.
        
    - 따라서 MOC를 만들고 싶을 때는, `02_Notes` 폴더에 `네트워크 MOC` 와 같이 새 노트를 먼저 만드신 후, **`Ctrl+P`**로 명령어 팔레트를 열고 **`Templater: 템플릿 삽입하기 (Open insert template modal)`** 명령을 실행하여 `T - MOC.md`를 선택/적용하는 방식을 추천합니다.
        
4. **확인:**
    
    - `01_Sources` 와 `02_Notes` 폴더에서 새 노트를 만들 때 각각의 템플릿이 자동으로 적용되는지 확인합니다.
        
    - `02_Notes`에 빈 노트를 하나 만들고, `Templater: 템플릿 삽입하기` 명령어로 `T - MOC.md` 템플릿이 잘 적용되는지 확인합니다.

**확인:** `01_Sources` 폴더에서 마우스 오른쪽 클릭 > `새 노트`를 만들었을 때, `T - 소스 노트` 템플릿이 자동으로 적용되는지 확인합니다. `02_Notes` 폴더도 동일하게 확인합니다

#### **2단계: Dataview & Homepage - 나만의 '미션 컨트롤' 구축**

**역할:** 옵시디언을 켜자마자 "오늘 무엇을 해야 할지" 명확하게 보여줍니다.

1. **Dataview 설정:**
    
    - `설정` > `Dataview`로 이동합니다.
    - `Enable JavaScript Queries`와 `Enable Inline JavaScript Queries`를 **활성화(On)**합니다.
2. **Homepage 노트 만들기:**
    
    - 옵시디언 최상단(root)에 `⭐ Homepage.md` 라는 이름으로 노트를 하나 만듭니다. (이모지는 구분을 위함입니다.)
        
    - 아래의 `Dataview` 쿼리 코드를 그대로 복사해서 `⭐ Homepage.md` 노트에 붙여넣으세요.
        
        코드 스니펫
        
        ```
        /* ========================
        🔥 처리해야 할 INBOX
        ========================
        "00_Inbox" 폴더에 있는 모든 노트를 보여줍니다.
        */
        dv.header(2, "🔥 처리해야 할 INBOX");
        dv.list(dv.pages('"00_Inbox"')
            .sort(p => p.file.mtime, 'desc')
            .map(p => p.file.link)
        );
        
        /* ========================
        🌱 가공이 필요한 소스 노트
        ========================
        "status"가 "unprocessed"인 소스 노트 목록을 보여줍니다.
        */
        dv.header(2, "🌱 가공이 필요한 소스 노트");
        dv.table(
            ["노트 제목", "생성일"],
            dv.pages('#source and !"_Templates"')
                .where(p => p.status == "unprocessed")
                .sort(p => p.file.ctime, 'desc')
                .map(p => [
                    p.file.link,
                    p.file.ctime.toFormat("yyyy-MM-dd")
                ])
        );
        
        /* ========================
        💎 최근에 만든 개념 노트
        ========================
        최근 7일 동안 만든 개념 노트 목록을 보여줍니다.
        */
        dv.header(2, "💎 최근에 만든 개념 노트");
        dv.list(dv.pages('#concept and !"_Templates"')
            .where(p => p.file.ctime > (dv.date('now') - dv.duration('7 days')))
            .sort(p => p.file.ctime, 'desc')
            .map(p => p.file.link)
        );
        
        /* ========================
        🔗 연결이 필요한 외로운 노트
        ========================
        다른 노트로 나가는 링크도, 들어오는 링크도 없는 노트를 찾아줍니다.
        */
        dv.header(2, "🔗 연결이 필요한 외로운 노트");
        const lonelyPages = dv.pages('"02_Notes"')
            .where(p => p.file.outlinks.length === 0 && p.file.inlinks.length === 0)
            .sort(p => p.file.ctime, 'desc')
            .limit(10)
            .file.link;
        if (lonelyPages.length > 0) {
            dv.list(lonelyPages);
        } else {
            dv.paragraph("👍 모든 노트가 잘 연결되어 있습니다!");
        }
        ```
        
3. **Homepage 설정:**
    
    - `설정` > `Homepage`로 이동합니다.
    - **Homepage:** 방금 만든 `⭐ Homepage.md` 노트를 지정합니다.
    - **확인:** 옵시디언을 다시 시작하거나, `Ctrl+P`로 명령 팔레트를 열어 `Homepage: Open homepage`를 실행했을 때, '처리해야 할 INBOX', '가공이 필요한 소스 노트' 등의 목록이 나타나는지 확인합니다. (처음에는 목록이 비어있을 수 있습니다.)

#### **3단계: QuickAdd - 생각의 속도로 노트 만들기**

**역할:** PDF에서 문장을 복사한 뒤, 단축키 한 번으로 `T - 개념 노트` 템플릿이 적용된 새 노트를 `02_Notes` 폴더에 바로 생성하게 해줍니다.

1. **설정:**
    
    - `설정` > `QuickAdd`로 이동 후 `Manage Macros` 버튼을 클릭합니다.
    - **New Macro** 이름에 `Capture Selection` 이라고 입력하고 `Add macro`를 누릅니다.
    - 방금 만든 매크로 옆의 `Configure`를 누르고, 아래의 코드를 붙여넣습니다. `User Scripts` 폴더를 만들겠냐고 물어보면 `Create`를 누릅니다.
        
        JavaScript
        
        ```
        module.exports = async (params) => {
            const { quickAddApi } = params;
            const selection = quickAddApi.getCopy();
            if (selection) {
                quickAddApi.variables["fileName"] = await quickAddApi.inputPrompt(
                    "노트 제목을 입력하세요:",
                    selection.slice(0, 50) // 처음 50자를 제목 제안으로
                );
            } else {
                quickAddApi.variables["fileName"] = await quickAddApi.inputPrompt(
                    "노트 제목을 입력하세요:"
                );
            }
        };
        ```
        
2. **명령어 만들기:**
    
    - 다시 `QuickAdd` 설정 창으로 돌아옵니다.
    - **Choice** 드롭다운에서 `Template`를 선택하고, 이름은 `새 개념 노트 만들기` 라고 입력 후 `Add Choice` 버튼을 누릅니다.
    - 방금 생긴 `새 개념 노트 만들기` 옆의 톱니바퀴(⚙️)를 눌러 상세 설정을 합니다.
        - **Template Path:** `_Templates/T - 개념 노트.md`를 선택합니다.
        - **File Name Format:** `{{VALUE:fileName}}` 이라고 입력합니다. (매크로에서 입력받은 제목)
        - **Create in folder:** `02_Notes/` 폴더를 지정합니다.
        - **Run Macro on chosen file:** 방금 만든 `Capture Selection` 매크로를 선택합니다.
    - 마지막으로, 명령어 목록에서 `새 개념 노트 만들기` 오른쪽에 있는 **번개 모양 아이콘(⚡️)을 활성화**합니다.
3. **단축키 설정:**
    
    - `설정` > `단축키`로 가서 `QuickAdd: 새 개념 노트 만들기`를 검색합니다.
    - 자신이 원하는 단축키(예: `Ctrl+Shift+N`)를 등록합니다.
**확인:** 아무 웹페이지에서나 문장을 복사(`Ctrl+C`)한 뒤, 옵시디언에서 지정한 단축키를 눌러보세요. 제목 입력창이 뜨고, 제목을 입력하면 `02_Notes` 폴더에 `T - 개념 노트` 템플릿이 적용된 새 노트가 생성되는지 확인합니다.

#### **4단계: Linter - 깔끔한 노트를 자동으로**

**역할:** 노트 저장 시 YAML(---로 둘러싸인 부분)의 날짜를 자동으로 업데이트하거나, 빈 줄을 정리하는 등 귀찮은 서식 작업을 대신해줍니다.

1. **설정:** `설정` > `Linter`로 이동합니다.
2. **Core Settings:**
    - **Lint on save:** **활성화(On)**합니다. 이제 저장(`Ctrl+S`)할 때마다 자동으로 린팅이 실행됩니다.
3. **Rule Settings (추천 설정):** 아래 규칙들을 `Enabled`로 바꿔보세요.
    - `YAML` 섹션 > `YAML Timestamps`: `date-created`와 `date-modified`를 자동으로 추가/수정해줍니다.
    - `Spacing` 섹션 > `Consecutive blank lines`: 연속된 빈 줄을 하나로 줄여줍니다.
    - `Content` 섹션 > `Trailing spaces`: 문장 끝의 불필요한 공백을 제거합니다.
**확인:** 아무 노트나 열어서 일부러 줄바꿈을 여러 번 하거나, 문장 끝에 스페이스를 여러 개 넣은 뒤 저장(`Ctrl+S`)해보세요. 서식이 자동으로 깔끔하게 정리되는지 확인합니다.
이것으로 기본적인 자동화 세팅이 끝났습니다. 처음에는 조금 복잡해 보일 수 있지만, 한번 설정해두면 당신의 지식 생산성은 이전과 비교할 수 없을 정도로 높아질 것입니다.

**목표:** 학습을 실용적인 결과물로 만들고, 그 과정을 추적하며 동기를 부여합니다.

- **핵심 도구:** **`Dataview`** 와 **`Pomodoro Timer`**
- **실행 방법:**
    1. **'미션 컨트롤' 대시보드:** `Homepage` 플러그인을 사용하여 옵시디언을 열 때마다 항상 뜨는 메인 대시보드를 만듭니다.2 이는 '백지 상태의 공포'를 막아주고 즉시 행동에 착수하게 돕습니다.
        - **대시보드 구성 (Dataview 쿼리 활용):**
            - **처리할 원료 (Inbox):** `status: unprocessed` 속성을 가진 소스 노트 목록을 보여줍니다.
                
                코드 스니펫
                
                ```
                LIST FROM "02_Notes" WHERE status = "unprocessed"
                ```
                
            - **최근 가공된 지식:** 최근 생성된 '개념 노트' 목록을 보여주어 성취감을 줍니다.
                
                코드 스니펫
                
                ```
                LIST FROM #concept SORT file.ctime DESC LIMIT 10
                ```
                
            - **학습 진행률 시각화:** 각 과목 MOC에 `progress: 75` 와 같은 속성을 추가하고, 이를 시각적인 진행률 막대로 표시하여 동기를 부여합니다.30
                
                코드 스니펫
                
                ```
                dv.table(["과목", "진행률"],
                    dv.pages("#moc")
                       .where(p => p.progress)
                       .map(p => [
                            p.file.link,
                            `<progress value="${p.progress}" max="100"></progress> ${p.progress}%`
                        ])
                )
                ```
                
    2. **집중력 관리:** `Status Bar Pomodoro Timer` 같은 간단한 뽀모도로 플러그인을 사용하세요.37 25분 집중, 5분 휴식 사이클은 과제 시작의 부담을 줄이고, 번아웃을 방지하는 데 매우 효과적입니다.38
    3. **'꾸미기 함정' 방지:** 일주일에 단 하루, 1시간(예: 일요일 오후)만 '시스템 점검 시간'으로 정해두고, 그때만 플러그인 설치나 테마 변경을 허용하세요.40 학습 시간에는 학습에만 집중하는 규칙이 중요합니다.
