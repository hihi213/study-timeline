# TCP의 특징 - 신뢰성과 연결 지향성

tags: #network/transport-layer #concept 

TCP(Transmission Control Protocol)는 인터넷 프로토콜 스위트의 핵심 프로토콜 중 하나로, 데이터가 **신뢰성 있게, 순서대로, 오류 없이** 전달되는 것을 보장하는 **연결 지향형** 통신을 제공한다.

## 주요 메커니즘
- **[[3-way-handshake]]**: 통신을 시작하기 전에 클라이언트와 서버가 서로의 존재를 확인하고 연결을 설정하는 과정이다. 이 과정을 통해 신뢰성 있는 세션이 수립된다.
- **[[흐름 제어 (Flow Control)]]**: 수신 측이 감당할 수 있는 만큼만 송신 측이 데이터를 보내도록 데이터 전송량을 조절한다.
- **[[혼잡 제어 (Congestion Control)]]**: 네트워크의 혼잡 상태에 따라 데이터 전송량을 동적으로 조절하여 네트워크 전체의 안정성을 유지한다.

이러한 복잡한 메커니즘 때문에 TCP는 [[UDP의 특징 - 비연결성과 속도|UDP]]에 비해 속도가 느리지만, 이메일, 파일 전송, 웹 브라우징처럼 데이터의 무결성이 매우 중요한 서비스에 필수적으로 사용된다.

2. **재료 준비:** 오른쪽 하단 창에서 `[[TCP의 특징 - 신뢰성과 연결 지향성]]` 노트를 엽니다.
3. **'번역'하며 작성하기:** 오른쪽 하단 창에 있는, **이미 당신의 언어로 잘 정리된 내용**을 읽고, 이것을 **블로그 독자를 위한 언어로 '번역'**한다는 느낌으로 왼쪽 창에 작성합니다.
    - **개념 노트 내용:** "TCP는 신뢰성 있는, 연결 지향형 서비스를 제공한다..."
    - **블로그 초고 내용 (번역 후):** "여러분이 친구에게 메시지를 보낼 때, 글자가 깨지거나 순서가 뒤바뀌어 도착하는 일이 거의 없죠? 바로 이 '신뢰의 우체부' 역할을 하는 것이 TCP입니다. TCP는 데이터를 보내기 전에 먼저 상대방과 '잘 받았니?'라고 확인하는 꼼꼼한 약속(연결)을 합니다..."
4. **반복:** 개요의 다음 섹션으로 이동하여, 해당되는 개념 노트를 오른쪽 하단 창에 열고, 같은 방식으로 '번역' 작업을 반복합니다.

_이 단계의 핵심은 **'완벽주의'를 버리고 '완성'을 목표로** 하는 것입니다. 이미 검증된 재료가 있으므로, 막힘없이 글을 채워나가는 속도감을 즐기세요._

### **3단계: 퇴고 및 발행 (다듬고 출하하기)**

**목표:** 조립된 초고를 독자가 읽기 편하도록 다듬고, 사실관계를 확인하여 최종 결과물로 완성합니다.

|   |   |
|---|---|
|**사용 도구**|**옵시디언 읽기 모드, 소스 링크**|

**행동 절차:**

1. **휴식:** 초고를 완성했다면, **최소 1시간 이상 의식적으로 휴식**을 취합니다. 뇌가 초고의 내용에서 벗어나야 새로운 눈으로 글을 볼 수 있습니다.
2. **소리 내어 읽기:** '블로그 초고' 노트를 '읽기 모드'로 전환하고, 처음부터 끝까지 소리 내어 읽어봅니다. 어색한 문장이나 오타를 가장 잘 잡아내는 방법입니다.
3. **흐름 다듬기:** 각 섹션 간의 연결이 자연스러운지 확인하고, 도입부와 결론을 다듬어 글의 완성도를 높입니다.
4. **신뢰성 강화 (Audit Trail 활용):** 글을 다듬다가 '3-way-handshake'에 대한 설명이 정확한지 다시 확인하고 싶어졌습니다. 개념 노트에 있던 `[[3-way-handshake]]` 링크를 클릭하고, 그 노트 안에 있던 `[[[S] Tanenbaum2021...#p.535]]` 와 같은 원본 소스 링크를 클릭하면, 몇 초 만에 Tanenbaum 교과서의 해당 페이지로 돌아가 팩트 체크를 완료할 수 있습니다.
5. **최종 발행:** 모든 퇴고 과정이 끝나면, 완성된 글을 복사하여 당신의 블로그 플랫폼에 붙여넣고 발행합니다.

### **결론: 당신은 '창조자'가 되었다**

이 과정을 되돌아보세요. 당신은 백지 앞에서 고통스럽게 새로운 문장을 '창조'하지 않았습니다. 평소에 꾸준히 수집하고 가공해 둔 **지식의 부품들을, MOC라는 설계도를 보며 목적에 맞게 '조립'했을 뿐입니다.**

이것이 바로 당신의 '두 번째 뇌'가 당신의 성장을 위해 일하는 가장 강력하고 구체적인 방식입니다. 이 워크플로우를 반복할수록, 당신의 `02_Notes`에는 더 많은 '부품'들이 쌓일 것이고, 당신의 '결과물 생산' 속도와 품질은 비약적으로 향상될 것입니다.
