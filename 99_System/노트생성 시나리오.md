```
# TCP의 특징 - 신뢰성과 연결 지향성

tags: #network/transport-layer #concept 

TCP(Transmission Control Protocol)는 인터넷 프로토콜 스위트의 핵심 프로토콜 중 하나로, 데이터가 **신뢰성 있게, 순서대로, 오류 없이** 전달되는 것을 보장하는 **연결 지향형** 통신을 제공한다.

## 주요 메커니즘
- **[[3-way-handshake]]**: 통신을 시작하기 전에 클라이언트와 서버가 서로의 존재를 확인하고 연결을 설정하는 과정이다. 이 과정을 통해 신뢰성 있는 세션이 수립된다.
- **[[흐름 제어 (Flow Control)]]**: 수신 측이 감당할 수 있는 만큼만 송신 측이 데이터를 보내도록 데이터 전송량을 조절한다.
- **[[혼잡 제어 (Congestion Control)]]**: 네트워크의 혼잡 상태에 따라 데이터 전송량을 동적으로 조절하여 네트워크 전체의 안정성을 유지한다.

이러한 복잡한 메커니즘 때문에 TCP는 [[UDP의 특징 - 비연결성과 속도|UDP]]에 비해 속도가 느리지만, 이메일, 파일 전송, 웹 브라우징처럼 데이터의 무결성이 매우 중요한 서비스에 필수적으로 사용된다.
```
