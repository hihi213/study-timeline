## 알림 목록 및 정책

### 알림 목록

시스템/관리: 상벌점 변동(상/벌점 수령), 계정 승인(관리자용). 공용 시설: 세탁실(종료 전/메시지 도착/시간 수정/상태 변경/관리/고장); 냉장고(유통기한 임박/점검 결과 경고/폐기/점검일 변경); 도서관(반납 임박/당일/연체/예약 가능/만료 자동 취소/대출 기한); 다목적실(시작/종료 15분 전/노쇼 신고 - 미등록은 Band 위임).

### 알림 정책 정리

세탁실: 종료 5분 전/상태 변경(관리/신고)/정정 알림. 냉장고: 유통기한 임박(하루 1회 묶음)/점검 결과(경고/벌점)/점검일 변경. 도서관: 반납 전/당일/연체/예약 대출 가능/만료 자동 취소. 다목적실: 시작/종료 전/노쇼 신고. 시스템/관리: 상벌점 변동(임명/공지 미발송 - Band 중복 제거). Band 중복으로 역할 임명/공지 알림 제외, 피로 최소화.

## 알림 구현

웹페이지는 메인(다목적실/세탁실 정보 + 메시지 읽음 표시/팝업), 냉장고/다목적실/도서관/세탁실 메인으로 구성되며, 알림 표시 방법은 4가지(백그라운드 푸시/메인 아이콘 유도/종 모양 버튼/하단 탭 뱃지)입니다. 읽음 상태 아닐 때만 활성화되며, 관련 페이지/팝업 진입 시 자동 읽음 처리로 피로를 줄입니다. Band 소통 중복 고려, 푸시 알림은 PWA 기반(VAPID)으로 무음 금지.

### 탭 뱃지 및 읽음 규칙

탭 뱃지는 미읽음 수(최대 9+)와 점 표시로 유도하며, 관련 화면 진입 시 소거, 24시간 자동 만료합니다.

냉장고 탭: 임박 묶음(09:00 1회 생성/소거)/폐기(영속 유지).

도서관 탭: 임박/당일/예약(09:00 1회/소거)/연체(영속).

Band 중복으로 역할 임명/공지 제외, 피로 높임 방지

## 알림구현

웹페이지는 메인화면, 냉장고,다목적실,도서관,세탁실메인화면으로 구성되어있다.

메인화면에는 당일 사용하는 다목적실의 정보와 현재 사용중/ 종료알림 신청한 세탁실기기의 정보와 메세지 읽음여부 표시하며 각 클릭시 해당 상태제어를 할수있는 버튼과 해당 기기에 관련된 알림/메세지가 표시되는 팝업이 뜬다.

알림을 표시하는건 4가지 방법이 있다

1. 백그라운드 푸시알림
2. 메인화면에서 다목적실, 세탁실기기의 메세지 읽음여부 표시 아이콘으로 기기 상태팝업으로 이동을 유도해 상세 팝업에서 메세지를 읽게함
3. 메인페이지의 종모양 알림버튼
4. 메인화면, 냉장고,다목적실,도서관,세탁실메인화면으로 이동하는 하단탭에서의 뱃지 표시
사용자가 **관련 정보에대해 파악했다고 판단가능한 페이지나 팝업에 진입하는 순간**, 시스템은 해당 알림을 자동으로 '읽음'으로 변경한다.

이미 관리자와 기숙사생들은 band라는 채팅, 게시물 앱으로 소통하고있다.

4가지 알림방법은 읽음 상태가 아닐때 활성화 할려고 한다. 해당알림을 유저의 피곤함 없이 어떻게 표시하려고 한 결과물은 다음과 같다

#### 4. 탭 읽음
- 값: 미읽음 수(최대 9+), 점 표시 허용.
- 규칙: 관련 화면 진입 시 소거. 24시간 경과 시 자동 만료 가능.
- 냉장고탭: (유통기한 임박 묶음이 있다면 오전 9시 이후 기준 1회/폐기물품이 있다면 영속)
- 도서관탭: (대출/도서/예약 임박 묶음이있다면 기준 1회(확인시 사라짐)/연체묶음이 있다면 영속)
- 냉장고: 임박 묶음은 매일 09:00 1회 생성 확인시 소거. 폐기 알림은 해제 전까지 유지.
- 도서관: 임박·당일·예약 가능 묶음은 매일 09:00 1회 생성 확인 시 소거. 연체는 해결 전까지 유지.
