## 개선본 - 리눅스 1교시_2025.10.31

### 📢 수업 공지 및 도입

- **CLI 환경의 중요성:** 개발자로서 서비스(서버, 라우터 등)를 관리하려면 Windows GUI가 아닌 텍스트 기반(CLI) 환경에 익숙해져야 합니다. '소비자'가 아닌 '공급자'의 관점에서 시스템을 제어할 수 있어야 합니다.
- **수업 방향:** 오늘부터 C언어와 시스템 프로그래밍 기초를 다루며, 익숙하지 않은 터미널 환경(Shell) 적응 훈련을 병행합니다.
    

---

### 1. 쉘(Shell)의 개념과 종류

**1) 쉘의 정의**

- 사용자와 리눅스 커널(Kernel)을 연결해 주는 인터페이스입니다.
- 사용자가 입력한 명령어를 해석하여 커널에 전달하고, 결과를 다시 사용자에게 보여줍니다.
- **프롬프트(Prompt):** 쉘이 사용자의 명령 입력을 기다리는 대기 상태(`$`)를 의미합니다.
    

**2) 쉘의 종류**

- **Login Shell:** 로그인 시 자동으로 실행되는 쉘입니다. Ubuntu의 기본 쉘은 **Bash(Bourne Again Shell)**입니다.
- **Dash Shell:** Ubuntu 시스템 내부적으로 (`/bin/sh`) 심볼릭 링크되어 사용되는 가벼운 쉘입니다.
- **Sub Shell:** 현재 쉘 안에서 다른 쉘을 실행한 상태입니다. `exit`나 `Ctrl + D`로 종료하면 이전 쉘로 돌아갑니다.
    

---

### 2. Workflow 쉘 확인 및 변경 실습

**시나리오:** 현재 내가 사용 중인 쉘이 무엇인지 확인하고, 이를 다른 쉘(`sh`)로 변경했다가 다시 복구(`bash`)하는 과정을 실습합니다.

**1) 현재 쉘 확인**

- `ls -l /bin/sh` 명령을 통해 시스템 기본 쉘이 `dash`로 링크되어 있음을 확인합니다.
- `cat /etc/passwd` 명령으로 사용자 계정 정보를 출력합니다. 각 라인의 맨 끝 필드(예: `/bin/bash`)가 해당 사용자의 로그인 쉘입니다.
    - _Tip:_ `grep [사용자명] /etc/passwd`를 사용하면 내 정보만 빠르게 필터링할 수 있습니다.
        

**2) 로그인 쉘 변경 (`chsh`)**

- **쉘 목록 확인:** `cat /etc/shells`를 입력하고 `Tab` 키를 활용하여 사용 가능한 쉘 경로를 확인합니다.
- **변경 시도:** `chsh -s /bin/sh [사용자명]` 명령을 입력하고 암호를 인증합니다.
    - _주의:_ 쉘 경로를 생략하거나 잘못 입력하면 에러가 발생할 수 있습니다.
- **복구:** 다시 `chsh` 명령을 사용하여 `/bin/bash`로 원상 복구합니다. 옵션 없이 `chsh`만 입력하면 대화형 모드로 변경할 수 있습니다.
    

---

### 3. 내장 명령어 vs 외장 명령어

쉘 명령어는 크게 두 가지로 구분됩니다. `whereis` 명령어를 통해 이를 구분해 보았습니다.

- **내장 명령어 (Built-in):** 쉘 프로그램 자체에 포함된 기능입니다. 별도의 실행 파일이 존재하지 않습니다.
    - 예: `cd`, `alias` 등. (`whereis cd` 실행 시 실행 파일 경로가 나오지 않음)
- **외장 명령어 (External):** 별도의 바이너리(실행 파일)로 존재하는 프로그램입니다. 실행 시 새로운 자식 프로세스(Child Process)를 생성하여 동작합니다.
    - 예: `pwd` (일부 환경), `ls` 등. (`/usr/bin/pwd` 처럼 경로가 확인됨)
    - _참고:_ 바이너리 파일은 텍스트가 아니므로 `cat`으로 열면 깨진 문자가 출력됩니다.
        

---

### 4. 특수 문자와 패턴 매칭 (Wildcards)

파일을 효율적으로 찾거나 처리하기 위해 특수 문자를 활용합니다.

- **Asterisk (`*`):** 모든 문자열과 매칭됩니다.
    - `ls *`: 모든 파일 및 하위 디렉토리 내용 출력.
    - `ls *.txt`: 확장자가 txt인 모든 파일.
    - `ls a*`: a로 시작하는 모든 파일.
- **Question Mark (`?`):** 단 한 글자와 매칭됩니다.
    - `ls h??`: h로 시작하고 뒤에 두 글자가 더 있는 파일(총 3글자).
- **Brackets (`[]`):** 괄호 안의 문자 중 하나와 매칭됩니다.
    - `ls data[123].txt`: data1.txt, data2.txt, data3.txt를 찾음.
    - `ls [1-9]*`: 숫자로 시작하는 모든 파일.
        

---

### 5. 디렉토리 이동 단축키

- **Tilde (`~`):** 현재 사용자의 홈 디렉토리를 의미합니다. (`cd ~`)
    - `~[다른사용자]`: 해당 사용자의 홈 디렉토리를 의미합니다. 단, 권한(Permission)이 없으면 파일 접근은 불가능할 수 있습니다.
- **Hyphen (`-`):** 바로 직전에 머물렀던 디렉토리로 이동합니다. (`cd -`)
    - 작업 중 깊은 경로로 이동했다가, 다시 원래 작업하던 곳으로 빠르게 복귀할 때 유용합니다.
        

### 6. 명령어 연결 (Separators)

- **Semicolon (`;`):** 앞의 명령어가 끝나면 순차적으로 뒤의 명령어를 실행합니다.
- **Pipe (`|`):** 앞 명령어의 실행 결과(Output)를 뒤 명령어의 입력(Input)으로 넘겨줍니다. (`ls -l | less` 등)
