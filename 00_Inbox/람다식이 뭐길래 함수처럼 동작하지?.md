## 📜 원본 맥락
![[01_Sources/{S} 인프런 그린코딩 52시간 풀스택+ Gemini.md#^h34lit]]
자바스크립트는 변수에 직접 함수를 저장하고, 자바는 함수처럼 보이는 람다식을 특정 인터페이스를 구현한 익명객체로 다루어 비슷하게 흉내낸다. 그래서 람다식을 함수형인터페이스변수에 저장하고, 람다식을 인자로 전달하거나 람다식을 반환을 한다.

---
## 정리
- 문제: 자바의 규칙: 메소드는 클래스 안에서만 존재해야한다
	- 따라서 자바스크립트처럼 함수 자체를 변수에 저장하거나 전달할 수 없다. 
- 해결: 자바 변수에는 함수 대신에 메소드 딱 하나만 담은 객체로 변수에 저장한다 
- 문제: 메소드를 하나만 가진 객체를 매번 새로 만들어서 변수에 저장해야한다. 
	- 실제 핵심함수의 동작뿐만아니라 쓸데없이 클래스 이름도 정하면서 한뭉텅이로 코드 작성을 매번 해야했다 
- 해결: 선언부(함수형 인터페이스)와 구현부(람다식)를 분리하여 각각 구현한다. 
	- 1. 개발자는 앞으로 필요할 기능들의 선언부만을 함수형 인터페이스로 정의한다
		- "두 개의 숫자를 받아 하나의 숫자를 반환하는 계산기 기능들이 필요하겠군. 이 기능의 타입을 `Calculator`라고 하자."
		```Java
		@FunctionalInterface
		interface MyCalculator {
		    int calculate(int a, int b);
		}
		```
	- 2. 개발자가 그전에 만든 Calculator라는 인터페이스 타입에 맞춰 람다식으로 구현부를 작성한다
		- 이제 `Calculator` 타입으로 '덧셈' 기능과 '곱셈' 기능을 만들어 변수에 저장해두자.
		```java
		// 덧셈 기능 구현
		Calculator adder = (a, b) -> a + b;
		
		// 곱셈 기능 구현
		Calculator multiplier = (a, b) -> a * b;
		```
	- 3. 자바 컴파일러가 람다식을 `Calculator` 인터페이스를 구현하는 익명클래스코드로 자동변환해준다 (개발자가 작성하는 코드가 아님)
		- 컴파일러: 개발자가 `Calculator` 규격에 맞는 덧셈 기능을 원하네. 내가 대신 `Calculator`를 구현하는 익명 객체 코드로 작성해야겠다.
		```Java
		// "MyCalculator 인터페이스를 구현하는 이름 없는 클래스를 만들고,
		// 그 클래스로 객체를 생성해서 adder 변수에 저장하자."
		// 컴파일러가 변환한 코드
		MyCalculator adder = new MyCalculator() {
		    @Override
		    public int calculate(int x, int y) {
		        return x + y; // 람다의 내용이 이곳으로 들어옴
		    }
		};
		```
	- 4. 이제 '덧셈 기능 객체', '곱셈 기능 객체' 등은 **다른 메소드에 데이터처럼 자유롭게 전달**하여 사용할 수 있습니다.
		```Java
		public class Main {
	    // Calculator 타입의 객체를 전달받아 실행하는 메소드
	    public static void executeOperation(int x, int y, Calculator calculator) {
	        int result = calculator.operate(x, y);
	        System.out.println("계산 결과: " + result);
	    }
	
	    public static void main(String[] args) {
	        Calculator adder = (a, b) -> a + b;
	        Calculator multiplier = (a, b) -> a * b;
	
	        // '덧셈' 기능을 executeOperation 메소드에 전달
	        executeOperation(10, 5, adder); // 계산 결과: 15
	
	        // '곱셈' 기능을 executeOperation 메소드에 전달
	        executeOperation(10, 5, multiplier); // 계산 결과: 50
	        
	        // '뺄셈' 기능을 즉석에서 만들어 전달
	        executeOperation(10, 5, (a, b) -> a - b); // 계산 결과: 5
	    }
	}
		```
	- 람다는 익명함수코드 요약하는 문법일뿐이다. 그래서 타입이 없다
