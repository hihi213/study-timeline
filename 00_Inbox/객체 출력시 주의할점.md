## 정리
- 암시적 형변환
	- + 
		- 문자열연결 : 하나라도 문자열이면 다른 모든 피연산자를 문자열로 바꾸어 연결
		- 숫자덧셈
	- - / \* (더하기 제외한 나머지 산술연산자)
		- 항상 피연산자들을 숫자로 바꿈 숫자로 바꿀수없으면 NaN을 반환
			- '10'-
	- ==
		- 타입 맞춰 변환한 후 값 비교
			- 5 == '5'
	- 논리연산자나 if문의 조건문
		- 모든 값이 true 또는 false로 자동변환됨
- 콘솔 메서드
	- `console.log(기본 로그 출력)` : 전달받은 값을 문자열로 변환해 출력
	- `console.dir(객체 속성 탐색)` : 객체를 클릭가능한 트리구조로 출력 
		- DOM요소 볼때 추천
	- console.table(data): 배열이나 객체를 보기 좋은 **표(테이블)** 형태로 출력
	- **`console.time(label)` / `console.timeEnd(label)`**: 특정 작업의 **실행 시간**을 측정
	- **`console.count(label)`**: 특정 코드가 **몇 번 호출되었는지** 횟수를 셉니다
	- **`console.assert(assertion, message)`**: 첫 번째 인자인 `assertion`(조건)이 `false`일 때만 두 번째 인자인 `message`를 출력합니다. 조건이 참인지 확인할 때 사용
	- **`console.trace()`**: 현재 위치의 **호출 스택**을 추적하여 보여줍니다. 함수가 어떤 경로를 통해 호출되었는지 확인할 때 유용합니다.
	- **`console.clear()`**: 콘솔을 깨끗하게 지웁니다.
- console.log(객체+ 문자열) 
	- 객체를 강제로 문자열로 바꾸려고함
- console.log(객체, 문자열) 
	- 독립적인 인자로 전달해야 객체의 내용을 볼수있음
