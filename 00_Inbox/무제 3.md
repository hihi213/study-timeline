# ⚡️ [코딩테스트 필살기] 시간 복잡도 & 알고리즘 선택 가이드

> **핵심 원칙:** 출제자는 $N$의 크기에 맞는 알고리즘을 이미 정해두었습니다. 우리는 $N$을 보고 그 의도를 **역추적**합니다.

### 1. 절대 기준: "1초 = 1억($10^8$) 연산"

코딩테스트의 일반적인 제한 시간은 1초입니다.

내 코드가 총 연산 횟수 1억 번을 넘어가면 가차 없이 **시간 초과(TLE)**입니다.

- **마지노선:** $10^8$ (1억)
- **안전 목표:** $2 \times 10^7 \sim 5 \times 10^7$ (**2,000만 ~ 5,000만**)
    

#### 🔍 N의 크기에 따른 연산량 체감

- **$N = 1,000$ ($10^3$)**
    - $O(N^2) \rightarrow 1,000 \times 1,000 = 100$만 ($10^6$)
    - 👉 **1억보다 작으므로 안전 (가능)**
- **$N = 100,000$ ($10^5$)**
    - $O(N^2) \rightarrow 100,000 \times 100,000 = 100$억 ($10^{10}$)
    - 👉 **1억을 아득히 초과 (불가능)** $\rightarrow O(N \log N)$ 이하로 설계해야 함.
        

---

### 2. 🧮 복잡도 계산법: "본질적인 행동($k$)"

복잡도가 헷갈릴 땐, **"데이터 하나($N$)가 평생 몇 번 사용되는가?"**를 따져보세요.

> **공식:** $\text{총 연산 시간} \approx N \times (\text{데이터 1개당 처리 비용 } k)$

- **질문:** 반복문이 중첩되어 복잡해 보이는데, 결국 데이터 하나는 몇 번 건드려지나?
- **분석:**
    
    1. `if` 조건 체크 (1번)
    2. `while` / `for` 진입 또는 교환 (1번)
    - $\rightarrow$ 데이터 1개당 최대 **2번($k=2$)** 정도 연산됨.
- **결과:** $N \times 2 = 2N$
    - 상수 $2$는 무시되므로 시간 복잡도는 **$O(N)$**입니다.
    - _(투 포인터나 슬라이딩 윈도우가 이 원리입니다.)_
        

---

### 3. ⏱️ $\log_2 N$ 값 "3초 암기법"

시간 복잡도 계산 시 $\log N$이 나오면, 고민하지 말고 아래 **지수(0의 개수)**를 대입해서 곱하세요.

|**N의 크기**|**log2​N 근사치**|**암기 요령**|
|---|---|---|
|**$10^3$** (1,000)|**10**|$2^{10} = 1,024$ (천 십)|
|**$10^6$** (100만)|**20**|백만 스물|
|**$10^9$** (10억)|**30**|십억 삼십|

### 4. 🎯 N의 크기별 필승 공략표 (Algorithm Choice)

문제를 받자마자 **$N$의 최대값**을 확인하고, 표에서 **오른쪽**으로 이동하세요.

|**N의 최대 크기**|**허용 시간 복잡도**|**즉시 떠올려야 할 알고리즘 (Candidates)**|
|---|---|---|
|**$N$ 상관없음**<br><br>  <br><br><small>(수학/규칙)</small>|**$O(1)$**|**[공식 대입]**<br><br>  <br><br>• 수학 공식 (등차수열, 나머지 규칙)<br><br>  <br><br>• Hash (Map/Set) Key 접근<br><br>  <br><br>• 배열 인덱스 직접 접근|
|**$N \ge 10^9$**<br><br>  <br><br><small>(10억 이상)</small>|**$O(\log N)$**|**[범위 좁히기 (반씩 버리기)]**<br><br>  <br><br>• **이분 탐색 (Binary Search)**<br><br>  <br><br>• 거듭제곱 분할 정복 ($A^B$)<br><br>  <br><br>• 유클리드 호제법 (GCD)|
|**$N \le 10^7$**<br><br>  <br><br><small>(1,000만)</small>|**$O(N)$**|**[한 번만 훑기]**<br><br>  <br><br>• **투 포인터, 슬라이딩 윈도우**<br><br>  <br><br>• **Greedy (그리디)**<br><br>  <br><br>• 위상 정렬, DP (1차원)|
|**$N \le 10^6$**<br><br>  <br><br><small>(100만)</small>|**$O(N \log N)$**|**[정렬과 분할]**<br><br>  <br><br>• **Sort (정렬)**, **Priority Queue (우선순위 큐)**<br><br>  <br><br>• **다익스트라 (Dijkstra)**<br><br>  <br><br>• 세그먼트 트리, 분할 정복 (Merge Sort)|
|**$N \le 2,000$**<br><br>  <br><br><small>(이천)</small>|**$O(N^2)$**|**[2중 탐색]**<br><br>  <br><br>• **2중 For문 (완전 탐색)**<br><br>  <br><br>• DP (2차원 격자), BFS/DFS (인접행렬)|
|**$N \le 500$**<br><br>  <br><br><small>(오백)</small>|**$O(N^3)$**|**[3중 탐색]**<br><br>  <br><br>• **플로이드-워셜**<br><br>  <br><br>• 3중 For문 (행렬 곱셈)|
|**$N \le 20$**<br><br>  <br><br><small>(이십)</small>|**$O(2^N), O(N!)$**|**[모든 경우의 수]**<br><br>  <br><br>• **백트래킹 (Backtracking)**<br><br>  <br><br>• **순열 / 조합** (완전 탐색)|

### 5. 🧠 실전 사고 흐름 (Simulation)

시험장에서 문제를 읽었을 때 머릿속에서 일어나야 하는 과정입니다.

#### **Case 1: $N$이 20보다 작다? (매우 작음)**

> _"이건 함정이 아니다. 컴퓨터를 믿고 다 해보자."_

- **행동:** 쫄지 말고 **재귀(백트래킹)**나 **순열/조합**으로 모든 케이스를 다 만드세요.
- **주의:** 괜히 그리디나 DP 같은 어려운 방법을 찾다가 시간 낭비하지 마세요.
    

#### **Case 2: $N$이 10만($10^5$) ~ 50만 정도다? (가장 흔함)**

> _"이중 반복문($O(N^2)$) 쓰는 순간 바로 탈락이다."_

- **행동:** $O(N \log N)$이나 $O(N)$을 써야 합니다.
- **Key:** **정렬(`sort`)**을 할 수 있는지, **우선순위 큐(`PQ`)**나 **투 포인터**를 쓸 수 있는지 확인하세요. 그래프 문제라면 **다익스트라**일 확률이 매우 높습니다.
    

#### **Case 3: $N$이 10억 이상이다? (압도적으로 큼)**

> _"배열을 10억 칸 만들면 메모리 터지고, 반복문 돌리면 시간 터진다."_

- **행동:** $N$을 1씩 증가시키는 건 불가능합니다. 값을 반씩 뚝뚝 짤라내는 **이분 탐색**이나, 규칙을 찾는 **수학($O(1)$)** 문제입니다.

### 6. ⚠️ 언어별 주의사항 (최적화 팁)

알고리즘은 맞는데 시간 초과(TLE)가 난다면?

1. **입출력 최적화 (필수):**
    
    - **Java:** `Scanner` ❌ $\rightarrow$ `BufferedReader`, `StringTokenizer` ⭕
    - **Python:** `input()` ❌ $\rightarrow$ `sys.stdin.readline` ⭕
    - **C++:** `cin`/`cout` 사용 시 `ios::sync_with_stdio(0), cin.tie(0)` 필수.
        
2. **문자열 연산:**
    
    - 반복문 안에서 `String + String` 절대 금지 $\rightarrow$ `StringBuilder` (Java), `join` (Python) 사용.
        
3. **Python:**
    
    - $N=10^6$일 때 `Python3`가 느리면 `PyPy3`로 제출.
    - 재귀 깊이가 깊으면 `sys.setrecursionlimit()` 필수 설정.
