야 시험 3시간 남았는데 졸프준비때문에 시험 준비 못했어 벼락치기로 2시간 실습하고 1시간 이론 암기하려한다

제일 출제 가능성 높은걸로 12문제 구성해주고 남은시간에 실습하고 이론 암기할려고하니까 할것들 중요도 높은걸로 정리해줘

==교수님제공시험정보시작==

실습 파트의 범위는 5장부터 7장까지이며, 이 부분은 대부분 실습 문제로 구성됩니다. 주요 내용은 DDL, DML, 그리고 procedure와 function을 포함하는 PL/SQL 프로그래밍입니다. 시험 범위에는 INSERT, DELETE, UPDATE, ALTER, SELECT 등 모든 DML 및 DDL 쿼리문이 포함됩니다. DCL은 이후 보안 파트에서 다룰 예정이므로 이번 시험 범위에서는 제외됩니다. 오늘 학습한 procedure와 function에서는 FOR문과 IF문을 활용할 수 있는 수준이면 충분합니다. 다만, SELECT뿐만 아니라 INSERT, UPDATE, DELETE 구문을 응용하여 프로그래밍하는 문제가 출제될 수 있습니다.

이론 파트의 범위를 다음과 같이 축소합니다.

1. 1장: '데이터베이스 보안 개요'와 '보안의 기본 개념'은 반드시 학습해야 합니다. 여기서 단답형 또는 서술형 문제가 출제될 것입니다.
2. 2장, 3장: 시험 범위에서 제외합니다.
3. 4장: '데이터베이스 보안 방법'에서는 GRANT, REVOKE 등과 관련된 실습 예제는 추후에 다룰 내용이므로 이번 시험에서는 제외됩니다.

시험 문제 형식에 대해 안내합니다. procedure와 function 코딩 문제의 분량이 길기 때문에, 총 문항 수는 12문제 내외로 조정하겠습니다. 객관식은 없으며, **단답형과 서술형(코딩 포함)**으로만 구성됩니다.

PL/SQL 함수 (function)  개요  함수(function)는 프로시저와 마찬가지로 데이터베이스에 저장되어 사용되는 미니 프로그램  내장 함수: SUM(), AVG(), MAX(), MIN() 등  사용자 정의 함수  프로시저와 다른 점은 사용자 정의 함수는 반드시 SQL문 안에서 사용되어야 하며 반환(return)값이 있음  [OR REPLACE] : 같은 이름 뷰가 없으면 새로 생성, 존재하면 기존 것을 새로 만드는 것으로 대체 CREATE [OR REPLACE] FUNCTION 함수 이름(입력변수 리스트) RETURN 반환 값의 자료형 AS 변수 선언; BEGIN 처리내용 ; RETURN 반환값 ; END ; <문법> PL/SQL 함수 (function)  급여액을 입력하면 높은 연봉(high salary)인지 낮은 연봉(low salary)인지를 알려주는 사용자 정의 함수(2,500 넘으면 높은 연봉) CREATE OR REPLACE FUNCTION f_grade (in_value number) RETURN varchar2 AS v_grade varchar2(20) ; BEGIN v_grade := 'Low salary' ; IF in_value > 2500 THEN v_grade := 'High salary' ; END IF ; RETURN v_grade ; END ; PL/SQL 함수 (function)  함수작성시 주의사항   함수는 연산의 결과를 하나의 값으로 반환하도록 되어 있다. 그리고 RETURN 다음에 반환 값의 자료형을 정의한다. f_grade() 함수를 보면 반환값이 v_grade라는 변수에 저장이 되어 있 다. 따라서 v_grade의 자료형은 RETURN 다음에 정의된 반환 값의 자료형과 일치 해야 한다. CREATE OR REPLACE FUNCTION f_grade (in_value number) RETURN varchar2 AS v_grade varchar2(20) ; BEGIN v_grade := 'Low salary' ; IF in_value > 2500 THEN v_grade := 'High salary' ; END IF ; RETURN v_grade ; END ; 일치해야 함 PL/SQL 함수 (function)   함수에서 입력 변수와 반환값의 자료형에 자리수를 포함하면 컴파일 에러가 발생하므로 자리수를 제외하고 number, varchar2와 같이 자리수를 제외하고 표현한다. 기타 다른 변수의 정의에는 자리수를 포함하도록 한다. CREATE OR REPLACE FUNCTION f_grade (in_value number) RETURN varchar2 AS v_grade varchar2(20) ; BEGIN v_grade := 'Low salary' ; IF in_value > 2500 THEN v_grade := 'High salary' ; END IF ; RETURN v_grade ; END ; 자리수 지정하지 않음 PL/SQL 함수 (function)  SQL Developer의 GUI를 이용한 함수 생성   접속창의 함수 항목에 대한 팝업창에서 [새 함수]를 선택한다. PL/SQL 함수 (function)   다음과 같이 함수이름, 반환값 유형, 입력변수(매개변수)를 입력하고 [확인] 버튼을 클릭한다. TEST   함수 작성 템플릿 화면이 표시되면 함수의 내용을 입력하고 컴파일 아이콘을 클릭한다.   함수 편집 화면 하단의 메시지 로그에 ‘컴파일됨’ 이라는 메시지가 표시되면 정상적으로 함 수 생성 작업이 마무리된 것이다.
