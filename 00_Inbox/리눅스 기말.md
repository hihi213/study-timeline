### 📚 챕터별 출제 예상 포인트 (교수님 강조 사항 중심)

중간고사 이후 범위인 **CHAPTER 05부터 CHAPTER 09까지**가 시험 범위입니다.

#### **CHAPTER 05 셸 사용법** (10.31, 11.7 강의)

셸의 개념과 환경 설정, 명령어 활용이 핵심입니다.

- **셸의 개념:** 커널과 사용자 사이의 명령어 해석기, 로그인 셸 vs 서브 셸의 개념
- **환경 변수 vs 셸 변수:**
    - `export` 명령어를 사용해야 환경 변수(전역)가 됨
    - 주요 변수: `PATH` (실행 파일 경로), `PS1` (프롬프트 설정)
    - 설정 파일: `/etc/profile` (전체), `~/.bashrc` 또는 `~/.profile` (개인, 로그인 시 적용)
- **특수 문자와 와일드카드:**
    - `*` (모든 문자), `?` (한 글자), `[]` (범위)의 차이
    - Backtick(`` ` ``): 명령어 실행 결과로 치환
    - Escape 문자(`\`): 특수 기능 제거
- **리다이렉션(Redirection)과 파이프:**
    - `>`, `>>` (덮어쓰기 vs 추가하기)
    - 표준 에러(2번) 리다이렉션 (`2>`)
    - 파이프(`|`): 앞 명령어의 출력을 뒤 명령어의 입력으로 연결
- **앨리어스(Alias):** 복잡한 명령어를 단축어로 설정 (`alias name='command'`)
    

#### **CHAPTER 06 파일 접근 권한 관리** (11.7 강의)

`ls -l` 해석과 `chmod` 계산 문제가 유력합니다.

- **파일 속성 읽기 (`ls -l`):** 파일 유형(`-` 파일, `d` 디렉터리) 및 `rwx` 권한 해석
- **권한 변경 (`chmod`):**
    - **숫자 모드 (가장 중요):** r=4, w=2, x=1 (예: 755 = rwxr-xr-x)
    - 기호 모드: `u+x`, `go-w` 등의 표기법
- **기본 접근 권한 (`umask`):**
    - 파일 기본(666), 디렉터리 기본(777)에서 umask 값을 뺀 결과
- **특수 접근 권한:**
    - **SetUID (4):** 실행 시 소유자 권한으로 실행 (예: `passwd` 명령어)
    - **Sticky Bit (1):** 공용 디렉터리(`/tmp`)에서 파일 삭제 권한 제한
        

#### **CHAPTER 07 파일 검색과 텍스트 처리** (11.14 강의)

다양한 명령어의 옵션과 동작 원리를 이해해야 합니다.

- **파일 검색:**
    - `find`: 경로, `-name`, `-type`, `-exec`/`-ok` 옵션 활용법
    - `which` vs `whereis`: 실행 파일 위치 및 소스/매뉴얼 검색 차이
- **텍스트 검색 (`grep`):**
    - 정규 표현식(`^`, `$`, `*`, `[]`)을 활용한 패턴 검색
- **파일 정렬 및 처리:**
    - `sort`: 정렬 기준(`-k`), 역순(`-r`), 중복 제거(`-u`)
    - `uniq`: 연속된 중복 라인 제거 (반드시 `sort` 후 사용)
    - `cut`: 특정 필드나 문자열 잘라내기
    - `paste`: 파일 병합 (옆으로 붙이기)
    - `split`: 파일 분할
    - `diff` vs `cmp`: 파일 비교 (텍스트 라인 단위 vs 바이트 단위)
        

#### **CHAPTER 08 프로세스 다루기** (11.21, 11.28 강의)

이론(개념)과 실습(명령어)이 모두 중요한 챕터입니다.

- **이론적 개념 (교수님 강조):**
    - **프로세스(Process) vs 스레드(Thread):** 자원 할당의 독립성 vs 공유, 문맥 교환(Context Switch) 오버헤드 차이
    - **주요 프로세스:** PID 1 (systemd/init - 모든 프로세스의 부모), PID 2 (kthreadd)
    - **프로세스 상태:** 고아(Orphan) 프로세스와 좀비(Zombie) 프로세스의 차이
- **프로세스 관리 명령어:**
    - `ps`: 옵션 `-ef` (전체 상세), `-aux` (BSD 스타일)
    - `kill`: 시그널 번호 중요. **9번 (SIGKILL, 강제 종료)**, **2번 (SIGINT, Ctrl+C)**, 15번 (SIGTERM, 정상 종료)
    - `pkill` vs `killall`: 이름/패턴으로 종료
- **작업 제어:**
    - Foreground vs Background (`&`)
    - `nohup`: 로그아웃 후에도 프로세스 계속 실행
        

#### **CHAPTER 09 사용자 정보 다루기** (11.28, 12.5 강의)

시스템 관리자 관점에서의 사용자 파일과 권한 관리입니다.

- **주요 정보 파일:**
    - `/etc/passwd`: 사용자 계정 정보 (구조 7필드 이해: ID:x:UID:GID:설명:홈:셸)
    - `/etc/shadow`: 암호화된 비밀번호 및 만료 정보 (root만 읽기 가능)
    - `/etc/group`: 그룹 정보
- **사용자 관리 명령어:**
    - `useradd`: 사용자 생성 (교수님 실습: `sudo useradd …`)
    - `passwd`: 비밀번호 변경
    - `su` vs `sudo`:
        - `su`: 사용자 전환 (로그아웃 없이), 옵션 없이 쓰면 root로 전환
        - `sudo`: 일반 사용자가 **일시적으로** root 권한으로 명령 실행
- **사용자 확인:** `who`, `w` (상세 정보), `last` (로그인 기록)

### **2. 챕터별 핵심 출제 포인트 (우선순위 High)**

#### **CHAPTER 05: 셸 사용법**

교수님이 명령어 해석 방식과 환경 변수 설정에 대해 자세히 설명하셨습니다.

- **따옴표의 차이 (매우 중요):**
    - `'` (작은따옴표): 안의 모든 문자를 문자 그대로 취급 (변수 해석 X).
    - `"` (큰따옴표): 변수(`$`) 등 일부 특수문자 해석 O.
    - `` ` `` (백쿼트): 명령어 치환. 안에 있는 내용을 명령어로 실행하여 결과를 대입.
    - `\` (역슬래시): 바로 뒤 문자의 특수 기능을 제거 (Escape).
- **리다이렉션 (Redirection):**
    - `>` (덮어쓰기), `>>` (이어쓰기).
    - 표준 에러(`2>`)와 표준 출력(`1>`)의 차이. 에러 메시지를 버릴 때 `2> /dev/null` 사용법.
    - `2>&1` : 표준 에러를 표준 출력으로 리다이렉션 (합치기).
- **환경 변수:**
    - `export`: 셸 변수를 환경 변수(전역)로 만들어 자식 프로세스에도 상속되게 함.
    - 설정 파일: `/etc/profile` (전체), `~/.bashrc` (사용자 별). 로그아웃 후에도 설정이 유지되려면 파일에 저장해야 함.
        

#### **CHAPTER 06: 파일 접근 권한 관리**

계산 문제나 권한 설정 명령어가 나올 확률이 매우 높습니다.

- **chmod (숫자 모드):**
    - r=4, w=2, x=1. 예: `chmod 755 file` (소유자 rwx, 그룹 rx, 기타 rx).
- **umask 계산:**
    - 파일 기본 생성 권한(666) - umask = 실제 권한.
    - 디렉터리 기본 생성 권한(777) - umask = 실제 권한.
    - 예: umask가 022이면 파일은 644, 디렉터리는 755가 됨.
- **특수 접근 권한 (강조됨):**
    - **SetUID (4000, `s`):** 실행 시 소유자의 권한으로 실행됨 (예: `/usr/bin/passwd`). `ls -l`에서 소유자 권한 자리에 `s`로 표시.
    - **Sticky Bit (1000, `t`):** `/tmp` 디렉터리에 주로 사용. 누구나 파일을 만들 수 있지만, **삭제는 파일 소유자만** 가능.
        

#### **CHAPTER 07: 파일 검색과 텍스트 처리**

정규표현식과 파일 검색 명령어 옵션이 중요합니다.

- **find 명령어:**
    - `-name`, `-type` (f:파일, d:디렉터리), `-user`, `-perm` 등 옵션 암기.
    - `-exec` 옵션: 검색된 파일에 대해 명령 실행 (예: `find … -exec rm {} \;`).
- **grep vs 파일명 패턴의 차이 (강조됨):**
    - 파일 패턴(Globbing)의 `*`: 모든 문자열.
    - grep 정규표현식의 `*`: **앞의 문자가 0번 이상 반복**. (이 차이를 묻는 문제가 나올 수 있음)
    - `grep`의 `.` (한 글자), `^` (시작), `$` (끝).
- **기타 명령어:**
    - `sort`: 정렬 (`-r` 역순, `-k` 필드 지정).
    - `cut`: 특정 필드 추출 (`-c` 문자단위, `-f` 필드단위, `-d` 구분자).
    - `diff`: 파일 비교.
        

#### **CHAPTER 08: 프로세스 다루기**

프로세스의 개념과 시그널 번호를 외워두세요.

- **프로세스 vs 스레드:**
    - 프로세스: 자원 할당의 단위, 독립적 메모리.
    - 스레드: 자원을 공유함(메모리 등), 가벼움.
- **주요 프로세스:**
    - PID 1: systemd (모든 프로세스의 부모).
    - 좀비 프로세스(Zombie): 종료되었으나 부모가 회수하지 않아 테이블에 남아있는 상태.
- **ps 명령어:**
    - `ps -ef` (System V 스타일) 또는 `ps aux` (BSD 스타일) 옵션.
- **kill 시그널 (숫자 암기):**
    - **2 (SIGINT):** `Ctrl+C`와 동일, 인터럽트.
    - **9 (SIGKILL):** 강제 종료 (무시 불가).
    - **15 (SIGTERM):** 기본값, 정상 종료 요청.
- **Job Control:**
    - Foreground vs Background (`&`).
    - `nohup`: 로그아웃 후에도 백그라운드 작업 유지.
        

#### **CHAPTER 09: 사용자 정보 다루기**

설정 파일의 경로와 역할을 묻는 문제가 예상됩니다.

- **주요 파일 (경로와 역할):**
    - `/etc/passwd`: 사용자 계정 정보 (누구나 읽기 가능).
    - `/etc/shadow`: 실제 암호가 암호화되어 저장 (root만 읽기 가능).
    - `/etc/group`: 그룹 정보.
- **명령어:**
    - `su` vs `su -`: `su`는 셸 환경변수 유지, `su -`는 변경된 사용자의 환경변수 로드.
    - `sudo`: 일반 사용자가 root 권한으로 명령 실행.

### **3. 교수님의 "힌트" (놓치면 안 될 포인트)**

- **단축키/특수문자:** `Ctrl+C`는 시그널 2번, `Ctrl+Z`는 작업 정지(suspend) 등 키보드 인터럽트와 시그널의 관계.
- **절대 경로 vs 상대 경로:** `cd` 명령어 사용 시 `~`(홈), `-`(이전 경로), `.`(현재), `..`(상위)의 의미.
- **마운트 개념:** 리눅스는 모든 장치(CD-ROM, HDD 등)를 **파일**로 취급하며 마운트 과정을 거쳐야 함을 강조하셨습니다.
