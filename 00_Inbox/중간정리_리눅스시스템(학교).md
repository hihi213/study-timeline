## 1장: 리눅스 명령 사용법

### 터미널 및 명령행

- `exit` : 터미널을 종료합니다.
- `Ctrl+d` : 터미널을 종료하는 단축키입니다.
- `Ctrl+w` : 명령행에서 단어(공백 기준)를 지웁니다.
- `Ctrl+u` : 명령행의 내용 전체를 지웁니다.
    

### 기초 명령

- `date` : 현재 날짜와 시간을 출력합니다.
- `clear` : 현재 터미널 화면을 깨끗이 지웁니다.
- `man` : 특정 명령의 사용법(매뉴얼)을 자세히 보여줍니다.
- `passwd` : 사용자 계정의 비밀번호를 변경합니다.
- `gedit` : 텍스트 편집기를 실행하는 명령입니다.
    

### 예시에 사용된 명령

- `ls` : 파일 목록을 보여주는 명령으로 예시에 사용되었습니다.
- `cp` : 파일 복사 명령으로 예시에 사용되었습니다.
- `mv` : 파일 이동 명령으로 예시에 사용되었습니다.

## 2장: 디렉터리와 파일 사용법

### 디렉터리 관련 명령

- `file` : 파일의 종류(일반 파일, 디렉터리, 실행 파일 등)를 확인합니다.
- `pwd` : 현재 작업 중인 디렉터리의 위치(절대 경로)를 출력합니다.
- `cd` : 지정한 디렉터리로 이동합니다.
    - `cd [디렉터리]` : 지정한 디렉터리로 이동합니다.
    - `cd ~` : 현재 사용자의 홈 디렉터리로 이동합니다.
    - `cd` (인자 없음) : 홈 디렉터리로 이동합니다.
- `ls` : 디렉터리의 내용(파일, 하위 디렉터리)을 출력합니다.
    - `-a` : 숨김 파일(`.`)을 포함한 모든 파일 목록을 출력합니다.
    - `-d` : 디렉터리 자체의 정보를 출력합니다 (내용물 제외).
    - `-i` : 파일의 inode 번호를 출력합니다.
    - `-l` (소문자 L) : 파일의 상세 정보를 길게 출력합니다.
    - `-A` : `.`와 `..`를 제외한 모든 파일 목록을 출력합니다.
    - `-F` : 파일의 종류를 기호로 표시합니다 (디렉터리 `/`, 실행 파일 `*`, 심볼릭 링크 `@`).
    - `-L` : 심볼릭 링크 파일의 경우 원본 파일의 정보를 출력합니다.
    - `-R` : 하위 디렉터리의 목록까지 재귀적으로 모두 출력합니다.
- `dir` : `ls`와 유사하게 디렉터리 내용을 출력합니다.
- `vdir` : `ls -l`과 유사하게 디렉터리 내용을 상세하게 출력합니다.
- `mkdir` : 새로운 디렉터리를 생성합니다.
    - `-p` : 하위 디렉터리를 생성할 때, 경로상의 중간 디렉터리가 없으면 자동으로 생성합니다.
- `rmdir` : 비어 있는 디렉터리를 삭제합니다.
    - `-p` : 지정한 디렉터리 삭제 후, 부모 디렉터리도 비어 있으면 함께 삭제합니다.
        

### 파일 관련 명령

#### 파일 내용 출력

- `cat` : 텍스트 파일의 내용을 화면에 연속으로 출력합니다.
    - `-n` : 행 번호를 붙여서 출력합니다.
- `more` : 파일 내용을 화면 단위로 끊어서 출력합니다. (Space Bar: 다음 페이지, Enter: 다음 행)
- `less` : `more`와 유사하나, 방향키나 `j`, `k` 키로 이전/다음 내용으로 자유롭게 이동이 가능합니다.
- `tail` : 파일 뒷부분의 내용을 출력합니다 (기본 10행).
    - `+행번호` : 지정한 행 번호부터 파일 끝까지 출력합니다.
    - `-숫자` : 파일 뒷부분에서 지정한 숫자만큼의 행을 출력합니다.
    - `-f` : 파일 출력을 종료하지 않고, 파일에 추가되는 내용을 주기적으로 계속 출력합니다. (`Ctrl+c`로 종료)
        

#### 파일 복사

- `cp` : 파일이나 디렉터리를 복사합니다.
    - `-i` : 복사 대상 파일이 이미 존재하면 덮어쓸 것인지 물어봅니다.
    - `-r` : 디렉터리를 복사할 때 사용합니다 (하위 내용 포함).
        

#### 파일 이동 및 이름 변경

- `mv` : 파일 또는 디렉터리를 이동하거나 이름을 변경합니다.
    - `-i` : 이동 대상 파일이 이미 존재하면 덮어쓸 것인지 물어봅니다.
        

#### 파일 삭제

- `rm` : 파일을 삭제합니다.
    - `-i` : 파일을 삭제하기 전에 정말 삭제할 것인지 확인합니다.
    - `-r` : 디렉터리를 삭제할 때 사용하며, 하위의 모든 파일과 디렉터리를 함께 삭제합니다.
        

#### 파일 링크

- `ln` : 파일의 링크를 생성합니다.
    - `ln [원본] [링크]` : 하드 링크를 생성합니다. (옵션 없음)
    - `-s` : 심볼릭 링크(윈도의 바로가기와 유사)를 생성합니다.
        

#### 기타 파일 명령

- `touch` : 내용이 없는 빈 파일을 생성하거나, 기존 파일의 접근/수정 시간을 현재 시간으로 변경합니다.
    - `-a` : 접근 시간만 변경합니다.
    - `-m` : 수정 시간만 변경합니다.
    - `-t` : 시간을 직접 지정하여 변경합니다 (형식: `[[CC]YY]MMDDhhmm[.ss]`).
- `grep` : 파일 내에서 특정 문자열(패턴)이 포함된 행을 찾아 출력합니다.
    - `-i` : 대소문자를 구별하지 않고 검색합니다.
    - `-l` (소문자 L) : 패턴이 포함된 파일의 이름만 출력합니다.
    - `-n` : 검색된 행의 번호를 함께 출력합니다.
- `find` : 지정한 위치에서 특정 조건에 맞는 파일을 검색합니다.
    - `-name [파일명]` : 파일명으로 검색합니다.
    - `-type [파일종류]` : 파일 종류로 검색합니다.
    - `-user [ID]` : 파일 소유자로 검색합니다.
    - `-perm [권한]` : 파일 접근 권한으로 검색합니다.
    - `-exec [명령] {} \;` : 검색된 파일에 대해 지정한 명령을 실행합니다.
    - `-ok [명령] {} \;` : `-exec`와 같지만, 실행 전 사용자에게 확인을 받습니다.
    - `-print` : 검색된 파일의 절대 경로를 출력합니다 (기본 동작).
    - `-ls` : 검색 결과를 `ls -l` 형식으로 출력합니다.
- `whereis` : 지정된 경로에서 명령어의 바이너리 파일이나 매뉴얼 파일 위치를 찾습니다.
    - `-b` : 바이너리 파일만 검색합니다.
    - `-m` : 매뉴얼 파일만 검색합니다.
    - `-s` : 소스 파일만 검색합니다.
- `which` : `PATH` 환경 변수에 지정된 경로에서 명령어 파일의 위치를 찾아 출력합니다.
- `echo` : (예제에서 사용) `echo $PATH` , `echo $MANPATH` 처럼 환경 변수의 값을 출력합니다.
## 3챕터

### 1. vi 시작 및 종료

- `vi [파일]` : vi를 시작하고 지정한 파일을 엽니다.
- `ZZ` (Shift+zz) : (명령 모드) 작업한 내용을 저장하고 vi를 종료합니다.
- `:w [파일명]` : (마지막 행 모드) 작업한 내용을 저장합니다. 파일명을 지정하면 다른 이름으로 저장합니다.
- `:q` : (마지막 행 모드) 작업한 내용이 없을 때 vi를 종료합니다.
- `:q!` : (마지막 행 모드) 작업한 내용을 저장하지 않고 강제로 종료합니다.
- `:wq` 또는 `:wq!` : (마지막 행 모드) 작업한 내용을 저장하고 vi를 종료합니다.
    

### 2. 모드 전환

- `i` : (명령 모드 → 입력 모드) 현재 커서 자리에 입력합니다.
- `a` : (명령 모드 → 입력 모드) 현재 커서 다음 자리에 입력합니다.
- `o` : (명령 모드 → 입력 모드) 커서가 위치한 행의 다음 행에 입력합니다.
- `I` (대문자) : (명령 모드 → 입력 모드) 커서가 위치한 행의 첫 칼럼으로 이동하여 입력합니다.
- `A` : (명령 모드 → 입력 모드) 커서가 위치한 행의 마지막 칼럼으로 이동하여 입력합니다.
- `O` (대문자) : (명령 모드 → 입력 모드) 커서가 위치한 행의 이전 행에 입력합니다.
- `Esc` : (입력 모드 → 명령 모드) 입력 모드를 종료하고 명령 모드로 돌아갑니다.
- `:` (콜론) : (명령 모드 → 마지막 행 모드) 마지막 행 모드로 전환합니다.
- `/` 또는 `?` : (명령 모드 → 마지막 행 모드) 검색을 위해 마지막 행 모드로 전환합니다.
- `Esc` : (마지막 행 모드 → 명령 모드) 마지막 행 모드에서 명령 모드로 돌아갑니다.
    

### 3. 커서 및 화면 이동

#### 커서 이동

- `k` 또는 `위 방향키(↑)` : 커서를 한 행 위로 이동합니다.
- `j` 또는 `아래 방향키(↓)` : 커서를 한 행 아래로 이동합니다.
- `h` 또는 `왼쪽 방향키(←)` : 커서를 한 글자 왼쪽으로 이동합니다.
- `l` (소문자 L) 또는 `오른쪽 방향키(→)` : 커서를 한 글자 오른쪽으로 이동합니다.
- `w` : 다음 단어의 처음으로 이동합니다.
- `b` : 앞 단어의 첫 글자로 이동합니다.
- `e` : 현재 또는 다음 단어의 마지막 글자로 이동합니다.
- `^` (Shift+6) 또는 `0` (숫자 0) 또는 `Home` : 현재 행의 맨 처음으로 이동합니다.
- `$` (Shift+4) 또는 `End` : 현재 행의 맨 마지막으로 이동합니다.
- `-` (마이너스) : 앞 행의 처음으로 이동합니다.
- `+` (플러스) 또는 `Enter` : 다음 행의 처음으로 이동합니다.
- `H` : 화면의 맨 위 행으로 이동합니다.
- `M` : 화면의 중간 행으로 이동합니다.
- `L` : 화면의 맨 아래 행으로 이동합니다.
    

#### 특정 행 이동

- `G` (Shift+g) : 파일의 마지막 행으로 이동합니다.
- `[행번호]G` : (예: `50G`) 지정한 행 번호로 이동합니다.
- `:[행번호]` : (마지막 행 모드) (예: `:50`) 지정한 행 번호로 이동합니다.
- `:$` : (마지막 행 모드) 파일의 마지막 행으로 이동합니다.
    

#### 화면 이동

- `Ctrl+f` 또는 `Page Down` : 한 화면 아래로 이동합니다.
- `Ctrl+b` 또는 `Page Up` : 한 화면 위로 이동합니다.
- `Ctrl+d` : 반 화면 아래로 이동합니다.
- `Ctrl+u` : 반 화면 위로 이동합니다.
- `Ctrl+e` : 화면을 한 행만 아래로 이동합니다.
- `Ctrl+y` : 화면을 한 행만 위로 이동합니다.
    

### 4. 내용 수정, 삭제, 취소

#### 내용 수정

- `r` : 커서가 위치한 한 글자를 다른 글자로 수정합니다 (명령 모드 유지).
- `cw` : 커서 위치부터 현재 단어의 끝까지 수정합니다 (입력 모드로 전환).
- `#cw` : (예: `3cw`) 커서 위치부터 지정한 수(#)만큼의 단어를 수정합니다.
- `s` : 커서 위치의 글자부터 `Esc`를 누를 때까지 수정합니다 (입력 모드로 전환).
- `#s` : (예: `5s`) 커서 위치부터 지정한 수(#)만큼의 글자를 수정합니다.
- `C` (Shift+c) : 커서 위치부터 행의 끝까지 수정합니다 (입력 모드로 전환).
- `cc` : 커서가 위치한 행의 내용을 모두 수정합니다 (입력 모드로 전환).
    

#### 내용 삭제

- `x` : 커서 위치의 글자를 삭제합니다.
- `#x` : (예: `3x`) 지정한 수(#)만큼 글자를 삭제합니다.
- `dw` : 커서 위치의 단어를 삭제합니다.
- `#dw` : 지정한 수(#)만큼 단어를 삭제합니다.
- `dd` : 커서 위치의 행을 삭제합니다 (잘라내기 기능 포함).
- `#dd` : (예: `3dd`) 지정한 수(#)만큼 행을 삭제합니다.
- `D` (Shift+d) : 커서 위치부터 행의 끝까지 삭제합니다.
    

#### 명령 취소

- `u` (소문자) : 바로 이전의 명령을 취소합니다.
- `U` (대문자) : 해당 행에서 수행한 모든 명령을 취소합니다.
- `:e!` : (마지막 행 모드) 마지막으로 저장한 내용 이후의 모든 수정을 취소하고 파일을 다시 읽어옵니다.
- `Ctrl+z` : (명령 취소가 아님) vi를 잠시 중단하고 셸로 돌아갑니다.
- `fg` : (셸 명령어) `Ctrl+z`로 중단된 vi 작업을 다시 시작합니다.
    

### 5. 복사, 잘라내기, 붙이기

#### 명령 모드

- `yy` : 커서가 위치한 행을 복사합니다 (버퍼에 저장).
- `#yy` : (예: `3yy`) 커서 위치부터 지정한 수(#)만큼의 행을 복사합니다.
- `dd` / `#dd` : 행을 삭제함과 동시에 잘라내어 버퍼에 저장합니다.
- `p` (소문자) : 버퍼의 내용을 커서가 위치한 행의 **아래쪽**에 붙여넣습니다.
- `P` (대문자) : 버퍼의 내용을 커서가 위치한 행의 **위쪽**에 붙여넣습니다.
- `"[버퍼이름]yy` : (예: `"ayy`) 특정 네임드 버퍼에 행을 복사합니다.
- `"[버퍼이름]dd` : (예: `"add`) 특정 네임드 버퍼로 행을 잘라냅니다.
- `"[버퍼이름]p` : (예: `"ap`) 특정 네임드 버퍼의 내용을 붙여넣습니다 (아래).
- `"[버퍼이름]P` : (예: `"bP`) 특정 네임드 버퍼의 내용을 붙여넣습니다 (위).
    

#### 마지막 행 모드

- `:[범위]y` : (예: `:2,4y`) 지정한 범위의 행을 복사합니다.
- `:[범위]d` : (예: `:1,4d`) 지정한 범위의 행을 잘라냅니다(삭제).
- `:[행번호]pu` : (예: `:4pu`) 지정한 행 번호 다음에 버퍼의 내용을 붙여넣습니다.
- **범위 지정자** (마지막 행 모드에서 사용)
    - `%` 또는 `1,$` : 파일 전체 (1행부터 마지막 행)
    - `.` : 현재 커서가 있는 행
    - `1,.` : 1행부터 현재 행까지
    - `.,$` : 현재 행부터 마지막 행까지
    - `10,20` : 10행부터 20행까지
        

### 6. 검색 및 바꾸기 (마지막 행 모드)

- `/문자열` : 커서 위치에서 아래 방향으로 문자열을 검색합니다.
- `?문자열` : 커서 위치에서 위 방향으로 문자열을 검색합니다.
- `n` : (명령 모드) 이전 검색을 같은 방향으로 반복합니다.
- `N` : (명령 모드) 이전 검색을 반대 방향으로 반복합니다.
- `:s/찾을내용/바꿀내용/` : 커서가 위치한 행에서 첫 번째로 일치하는 문자열을 바꿉니다.
- `:[범위]s/찾을내용/바꿀내용/` : (예: `:3,4s/a/b/`) 지정한 범위 내 각 행의 첫 번째 일치 항목을 바꿉니다.
- `:[범위]s/찾을내용/바꿀내용/g` : 지정한 범위 내 모든 일치 항목을 바꿉니다.
- `:%s/찾을내용/바꿀내용/g` : 파일 전체의 모든 일치 항목을 바꿉니다.
- `:[범위]s/찾을내용/바꿀내용/gc` : 범위 내 모든 항목을 바꿀 때마다 사용자에게 확인을 받습니다.
    

### 7. 기타 유용한 명령

- `:r [파일명]` : (마지막 행 모드) (예: `:r exec2.txt`) 현재 커서 위치 다음에 지정한 파일의 내용을 읽어들입니다.
- `:e [파일명]` : (마지막 행 모드) 현재 파일을 닫고 다른 파일을 엽니다 (현재 파일 저장 필요).
- `:e! [파일명]` : (마지막 행 모드) 현재 파일을 저장하지 않고 다른 파일로 전환합니다.
- `:n` : (마지막 행 모드) vi 시작 시 여러 파일을 지정했을 경우, 다음 파일로 작업을 이동합니다.
- `:! [셸 명령]` : (마지막 행 모드) (예: `:! ls`) vi를 종료하지 않고 셸 명령을 실행한 뒤 `Enter`를 눌러 복귀합니다.
- `:sh` : (마지막 행 모드) vi를 잠시 빠져나가 셸을 실행합니다. 셸에서 `exit`를 입력하면 vi로 복귀합니다.
- `J` (Shift+j) : (명령 모드) 현재 행과 아래 행을 하나의 행으로 연결합니다.
- `.` (마침표) : (명령 모드) 바로 직전에 실행했던 명령(커서 이동 제외)을 반복합니다.
- `~` (틸드) : (명령 모드) 커서 위치의 글자를 대문자는 소문자로, 소문자는 대문자로 변경합니다.
- `Ctrl+l` (소문자 L) : (명령 모드) 현재 화면을 다시 출력합니다 (시스템 메시지 등으로 화면이 깨졌을 때).
- `Ctrl+g` : (명령 모드) 현재 커서 위치의 행 번호와 파일 정보를 마지막 행에 표시합니다
