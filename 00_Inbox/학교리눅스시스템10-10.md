## **2025.10.17, 1교시 — 개선본**

저번 시간에 VI 에디터 명령 중 삭제(`dd`)까지 다루었습니다. 오늘은 복사 관련 명령을 다룰 것입니다.

핵심 명령은 `yy` (복사), `p` (아래 붙여넣기), `P` (위에 붙여넣기), `dd` (잘라내기)입니다. Windows 환경과 달리, 복사 시 내용을 버퍼(buffer)에 임시 저장합니다. 버퍼에는 이름이 있는 '네임드 버퍼(named buffer)'와 이름이 없는 '언네임드 버퍼(unnamed buffer)'가 있습니다.

`yy`는 현재 행을 (언네임드) 버퍼에 복사합니다. 앞에 숫자를 붙여 (예: `3yy`) 여러 행을 복사할 수 있습니다. `dd`는 잘라내기(Ctrl+X) 개념입니다. `yy`는 복사(Ctrl+C)입니다.

소문자 `p`는 복사하거나 잘라낸 행을 현재 커서 **아래쪽**에 붙여넣습니다. 대문자 `P`는 현재 커서가 위치한 행의 **위쪽**에 붙여넣습니다.

**주의사항**이 있습니다. `yy`나 `dd`로 버퍼에 내용을 저장한 후, 붙여넣기(`p`/`P`) 전에 다른 명령을 실행하면 버퍼 내용이 손실될 수 있습니다. 언네임드 버퍼는 기본적으로 하나만 사용하며, 새 명령이 들어오면 이전 내용이 덮어쓰기 되기 때문입니다.

`ch04` 디렉터리에서 `vi test.ks` 파일을 엽시다. (실습)

'Ubuntu'라고 쓰인 행에 커서를 놓고 2yy를 입력하면 두 줄(Ubuntu, Hanbit)이 버퍼에 복사됩니다. (실습)

이제 마지막 행('1 2 3 4 5')으로 이동(j, k, l, h 사용)하여 소문자 p를 입력하면, 커서 아래에 복사했던 두 줄이 붙여넣기 됩니다. (실습)

다시 '1 2 3 4 5' 행에 커서를 놓고 대문자 P를 입력하면, 커서 위에 두 줄이 붙여넣기 됩니다. (실습)

이번에는 제일 위 'Ubuntu' 행으로 가서 5dd를 입력해 보세요. 다섯 행이 사라지는데, 실제로는 잘라내기(Ctrl+X) 되어 버퍼에 저장된 것입니다. (실습)

다른 행으로 이동하여 소문자 p를 누르면 아래에, 대문자 P를 누르면 위에 5줄이 붙여넣기 됩니다. (실습)

이러한 언네임드 버퍼의 덮어쓰기 문제를 보완하기 위해 '네임드 버퍼'를 사용할 수 있습니다. 버퍼에 이름을 지정하여 (예: "a) 여러 내용을 독립적으로 저장하는 것입니다.

"ayy는 현재 행을 'a' 버퍼에 복사합니다. "add는 'a' 버퍼로 잘라냅니다.

붙여넣기 할 때도 "ap (a 버퍼 내용을 아래에 붙이기)처럼 사용합니다.

숫자 버퍼도 쓸 수 있지만, `5yy` (5줄 복사) 명령과 `"5yy` (5번 버퍼에 복사)가 헷갈릴 수 있어 잘 사용하지는 않습니다. 그냥 이런 기능이 있다는 정도만 알아두시면 됩니다.

전통적인 VI에는 행 단위 복사/잘라내기만 있었지만, VIM(Vi IMproved)에서는 '비주얼 모드(Visual Mode)'가 추가되어 단어 등 부분적인 범위 지정이 가능해졌습니다.

소문자 v를 누르면 비주얼 모드가 시작됩니다. (실습)

원하는 위치로 이동하여 p를 누르면 커서 다음에 붙여넣기 됩니다. (실습)

대문자 `V`는 행 단위(line-wise)로 비주얼 모드 블록을 지정합니다. (실습)

명령 모드에서도 범위를 지정할 수 있습니다. (예: 10yy - 10줄 복사)

명령행 모드(콜론)에서 삭제 및 붙여넣기도 가능합니다.

이렇게 버퍼에 저장된 내용은 다른 명령을 치면 언네임드 버퍼에서는 복구가 어려울 수 있습니다.

단, VIM에서는 멀티 레벨 undo(u)를 지원하므로 여러 번 되돌리기가 가능합니다. (전통적인 VI는 undo가 1회만 가능했습니다.)

## **2025.10.17, 1교시 — 개념**

1. 한 줄 요약(≤120자)
    
    VIM의 복사(yy), 잘라내기(dd), 붙여넣기(p/P) 명령과 버퍼(Unnamed/Named) 개념, 비주얼 모드(v/V) 및 명령행 범위 지정 방법을 학습합니다.
    
2. **핵심 TL;DR**
    
    - `yy` (Yank): 현재 행을 복사합니다. (Windows: Ctrl+C)
    - `dd` (Delete/Cut): 현재 행을 잘라냅니다. (Windows: Ctrl+X)
    - `p` (Put, 소문자): 버퍼의 내용을 현재 커서 **아래** 행에 붙여넣습니다.
    - `P` (Put, 대문자): 버퍼의 내용을 현재 커서 **위** 행에 붙여넣습니다.
    - **버퍼(Buffer):** `yy` 또는 `dd`로 복사/잘라낸 내용이 임시 저장되는 공간입니다.
    - **언네임드 버퍼(Unnamed Buffer):** 기본 버퍼. 하나의 내용만 저장하며, 다음 `yy` 또는 `dd` 실행 시 이전 내용이 덮어쓰기 됩니다.
    - **네임드 버퍼(Named Buffer):** `"`(큰따옴표) + (이름)을 사용하여 특정 버퍼에 저장합니다. (예: `"ayy` - a 버퍼에 복사, `"ap` - a 버퍼 내용 붙여넣기)
    - **VIM 비주얼 모드(Visual Mode):** 전통 VI에는 없던 기능으로, 블록 지정이 가능합니다.
        - `v`: 문자 단위 비주얼 모드. `v` + 방향키(`h/j/k/l`)로 블록 지정 후 `y` (복사) 또는 `d` (잘라내기).
        - `V`: 행 단위(Line-wise) 비주얼 모드.
    - **명령행 범위 지정:** 콜론(`:`) 모드에서 주소를 사용합니다. (예: `:1,5d` - 1~5행 삭제)
    - **주소 기호:** `.` (현재 행), `$` (마지막 행), `%` (파일 전체, `1,$`와 동일).
    - `:set nu`: VIM 에디터 좌측에 행 번호(Number)를 표시합니다.
    - `u` (Undo): VIM은 다단계(Multi-level) 실행 취소를 지원하지만, 전통 VI는 1회만 지원했습니다.
        
3. **표현 = 표준 용어**
    
    - `yy` (Yank): 행 복사.
    - `dd` (Delete/Cut): 행 잘라내기 (삭제 겸 잘라내기).
    - `p` / `P` (Put): 붙여넣기 (커서 아래 / 커서 위).
    - **Buffer (버퍼):** 복사/잘라내기 내용의 임시 저장소. (표준 용어: **Register**)
    - **Unnamed Buffer (Register):** 이름 없는 기본 버퍼 (`""`). 덮어쓰기 됩니다.
    - **Named Buffer (Register):** `"`로 접근하는 이름 있는 버퍼 (예: `"a` ~ `"z`).
    - **Visual Mode (VIM):** `v` (문자 단위), `V` (행 단위)로 블록을 지정하는 모드.
    - **Command-line Mode (Ex Mode):** `:`로 시작하는 명령 모드.
    - **Range (범위):** 명령행 모드에서 사용되는 주소 (예: `1,10` 또는 `.,$`).
    - `:set nu` (Set Number): 행 번호 활성화.
        
4. 정석 보강 (canon-std)
    
    VIM에서 복사(yy) 또는 잘라내기/삭제(dd)된 텍스트는 **레지스터(Register)**라 불리는 여러 버퍼에 저장됩니다. 사용자가 명령 시 지정하지 않으면 기본적으로 "언네임드 레지스터(Unnamed Register)" ("")에 내용이 저장되며, 이 레지스터는 다음 복사/삭제 명령 시 덮어쓰기 됩니다. (이 강의에서 '언네임드 버퍼'로 지칭함). 영구적인 저장이 필요할 경우 "a (a 레지스터)처럼 **"네임드 레지스터(Named Register)"**를 사용합니다. p (put)는 커서 다음(아래줄/다음칸), P는 커서 이전(윗줄/앞칸)에 내용을 붙여넣습니다.
    
5. **실수·함정**
    
    - `dd`는 '완전 삭제'가 아니라 '잘라내기'(Cut)입니다. 내용은 버퍼(레지스터)에 남아있어 `p`로 붙여넣기가 가능합니다.
    - `yy` (복사) 후 `p` (붙여넣기) 전에 다른 `dd` (잘라내기)를 실행하면, 언네임드 버퍼 내용이 `dd`의 내용으로 덮어쓰기 되어 원래 복사한 내용을 잃게 됩니다.
    - 소문자 `p` (커서 아래)와 대문자 `P` (커서 위)의 붙여넣기 위치를 혼동하기 쉽습니다.
    - VIM의 비주얼 모드(`v`/`V`)는 전통적인(Original) VI에는 없는 기능이므로, 구형 시스템에서는 동작하지 않을 수 있습니다.
    - 비주얼 모드(`v`) 진입 후 `esc`를 눌러 빠져나오지 않고 다른 명령키(예: `.` )를 누르면 의도대로 동작하지 않습니다.
    - 명령행 모드(Ex mode)에서 범위 지정 시 띄어쓰기를 사용하면 안 됩니다. (예: `:1, 5d` (X) -> `:1,5d` (O))
    - 범위 지정 `.,-3`은 '현재 행과 그 위 3줄' (총 4줄)을 의미합니다. (즉, `(현재-3)`행부터 `현재`행까지)
    - 숫자 레지스터(예: `"5yy` - 5번 레지스터에 복사)와 반복(예: `5yy` - 5줄 복사)의 구문이 비슷하여 혼동할 수 있습니다.

## **2025.10.17, 2교시 — 개념**

1. 한 줄 요약(≤120자)
    
    VI(VIM)의 환경 설정을 세 가지 방식(임시, 사용자 .exrc, 시스템)으로 배우고, .exrc 실습 및 :set 관련 명령(nu, list, showmode)을 익힙니다.
    
2. **핵심 TL;DR**
    
    - **VI 환경 설정 3가지:** (1) 현재 세션 임시 설정 (예: `:set nu`), (2) 사용자 영구 설정 (`~/.exrc` 파일), (3) 시스템 전체 설정 (환경 변수, 10장).
    - **`.` (Dot files):** `ls -a`로만 보이는 숨김 파일입니다. (예: `.exrc`, `.bashrc`, `.profile`) 주로 환경 설정 파일로 사용됩니다.
    - **`~/.exrc`:** VI(M) 실행 시 자동으로 로드되는 사용자 전용 설정 파일입니다.
    - **`:set nu` (Number):** 에디터 좌측에 행 번호를 표시합니다.
    - **`:set nonu` (No Number):** 행 번호 표시를 숨깁니다.
    - **`:set list`:** 특수 문자(탭 `^I`, 줄바꿈 `$`)를 시각적으로 표시합니다.
    - **`:set nolist`:** 특수 문자 표시를 숨깁니다.
    - **`:set showmode`:** 현재 모드 (예: --INSERT--)를 화면 하단에 표시합니다.
    - **`:set noshowmode`:** 현재 모드 표시를 숨깁니다.
    - **`:set`:** 현재 VI(M) 세션에 설정된 모든 옵션 값들을 출력합니다.
    - `fileencoding=utf-8`: `:set` 확인 시 보이는 옵션으로, 파일 인코딩이 UTF-8 (유니코드)임을 의미합니다.
    - `EOF` (End Of File): 파일의 끝을 나타내는 마커 개념입니다. `:set list`의 `$`(줄바꿈)와는 구별됩니다.
        
3. **표현 = 표준 용어**
    
    - `~/.exrc`: (Path) VI/VIM 사용자 환경 설정 파일.
    - `ls -a`: (Command) 숨김 파일(Dot files)을 포함한 모든 파일 목록 조회.
    - `:set nu` (Set Number): 행 번호 활성화 (VIM).
    - `:set nonu` (Set No Number): 행 번호 비활성화 (VIM).
    - `:set list`: 특수 문자(줄 끝 `$`, 탭 `^I`) 시각화 (VIM).
    - `:set nolist`: `:set list` 설정 비활성화 (VIM).
    - `:set showmode`: 현재 모드 표시 (VIM).
    - `:set`: (Command) 현재 설정된 모든 옵션 확인.
    - **Dot files (`.` files):** 이름이 점으로 시작하는 숨김 파일 (주로 설정 파일).
    - **Environment Variable (환경 변수):** 시스템 전체 또는 사용자 세션에 영향을 미치는 변수 (예: `EXINIT`).
    - `EOF` (End Of File): 파일의 끝.
        
4. 정석 보강 (canon-std)
    
    VIM 환경 설정은 1) 현재 세션 임시 설정(:set [option]), 2) 사용자 영구 설정(~/.vimrc 또는 ~/.exrc), 3) 시스템 전체 설정(예: /etc/vim/vimrc) 순서로 로드됩니다. VIM은 .vimrc를 우선하며, .exrc는 전통적 VI와의 호환성을 위해 지원됩니다. 설정은 :set [option] (활성화), :set no[option] (비활성화), :set [option]? (값 확인) 형식을 따릅니다. nu (번호), list (특수문자), showmode (모드) 등이 자주 사용됩니다.
    
5. **실수·함정**
    
    - `.exrc` 파일은 `vi`를 실행하는 사용자의 홈 디렉터리(`~`)에 있어야만 자동으로 인식됩니다.
    - `ls` 명령은 기본적으로 `.exrc` 같은 점(`.`)으로 시작하는 숨김 파일을 보여주지 않습니다. `ls -a`를 사용해야 합니다.
    - `.exrc` 파일 수정 후, 이미 실행 중인 `vi`에는 적용되지 않습니다. `vi`를 재시작하거나 새 터미널에서 열어야 적용됩니다.
    - `:set nu`로 보이는 행 번호는 파일 내용 자체가 아니라 에디터가 보여주는 _표시_일 뿐이며, 파일에 저장되지 않습니다.
    - `:set list`로 보이는 `$` 기호는 '줄바꿈 문자(Newline)'를 시각적으로 표시한 것이며, 파일 끝(EOF) 마크와는 다릅니다.
    - VIM 환경에서는 `.exrc`보다 `.vimrc` 파일이 우선적으로 사용되거나 권장됩니다.
    - `:set` 명령으로 변경한 설정은 '임시'입니다. `vi` 세션을 종료하면 해당 설정은 사라집니다. (영구 저장은 `.exrc`에)
    - `.bashrc`나 `.profile`은 셸(bash)의 설정 파일이며, `.exrc` (vi 설정)와는 용도가 다릅니다.
