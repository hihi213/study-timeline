# 🎯 목적: 주어진 PDF에서 등장하는 모든 명령어만 추출
너는 지금 Linux/Unix 명령어 인식 전문가다.  
현재 첨부하는 PDF에서 **등장하는 명령어, 옵션, 명령형 구문**만 정확히 추출하라.
출력 형식은 다음 표를 유지하라:
  
| No  | 명령어 | 전체 구문 예시 | 짧은 기능 설명(한 줄) |
| --- | --- | -------- | ------------- |

규칙:
1️⃣ 코드블록(```…```), 표, 문장 중 백틱(`)이나 굵게(**) 표시된 부분에서 명령어를 우선 추출  
2️⃣ 중복 명령어는 모두 남기되, 나중에 통합 시 중복 제거할 예정  
3️⃣ 한글로 설명된 예: `예: "ls -al" 명령은…` → "ls -al" 전체를 포함하여 추출  
4️⃣ 명령형 표현(예: “사용자는 chmod 명령을 실행한다”)도 명령어로 간주  
5️⃣ 순수 서술문(예: “파일을 본다”)은 제외  

  

출력만 표 형식으로.




# 🎯 목적: 여러 범위에서 추출된 명령어 목록을 하나로 통합하여 정리

아래 표들은 여러 PDF에서 추출된 Linux/Unix 명령어 목록이다.  
이 모든 표를 통합하여 **명령어별로 정리된 마스터 테이블**을 만들어라.

출력 형식:

| No | 명령어 | 주요 옵션 | 대표 사용 예시 | 의미/기능 요약 (한 줄) |
|----|--------|-----------|----------------|--------------------------|

규칙:
1️⃣ 동일 명령어는 중복 제거하되, 서로 다른 옵션·예시를 모두 병합  
2️⃣ 각 명령어의 대표 옵션(-a, -l, --recursive 등)을 나열  
3️⃣ 예시는 실제 문서에서 등장한 문구 중 대표적인 것을 1~2개만 선택  
4️⃣ 의미/기능은 1줄로 요약 (예: “파일 목록을 표시한다.”)  
5️⃣ 문서에 없는 경우 일반적 기능을 보충 가능  
6️⃣ 명령어는 알파벳순으로 정렬  

결과는 표 한 개로 깔끔하게 출력.
