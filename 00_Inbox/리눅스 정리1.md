# **최우선(★5) — 반드시 나옴**

1. **경로·목록·권한 출력 해석**（ls -al / ls -aF）
    

  

- 파일종류 플래그: - d l b c
- 권한 9비트 읽기: rwx r-x r-x = 755
- **심볼릭 링크 표기**: l…… -> 대상
- **링크 카운트** 의미, 아이노드 번호(ls -i)
- **숨김파일**: ls vs ls -a 차이
- **예상형식**: “아래 출력은 어떤 명령 결과인가?”, “빈칸 채우기(파일종류/권한/링크수)”
- 함정: /와 /root, ~와 /home 혼동
    

  

1. **절대/상대 경로·cd 동작 예측**
    

  

- cd /etc(절대) vs cd etc(상대), cd .., cd=HOME
- **예상형식**: “현재가 /usr/local 일 때 다음 명령 후 pwd?”
- 함정: 경로 맨 앞 / 유무
    

  

1. **vi 모드 시뮬레이션**
    

  

- **모드 전환**: 명령↔입력 (i a o O Esc)
- 저장/종료: :w, :q, :wq, :q!, ZZ
- 이동/삭제/수정: h j k l, 0 $, w b, x, dw, dd, D, cw, G, nG
- 붙여넣기: p(아래) / P(위)
- **예상형식**: “키 시퀀스 후 최종 텍스트는?”
- 함정: 입력모드에서 :wq 타이핑(그냥 글자), Ctrl+Z는 undo 아님(작업중지)
    

  

1. **cp/mv/rm/rmdir 기본 규칙**
    

  

- cp \[원본] \[사본], **디렉터리 복사** **-r** **필수**
- mv: 대상 없으면 **이름변경**, 대상이 디렉터리면 **이동**
- **같은 파티션 mv**=이름변경만, **다른 파티션 mv**=실質 cp 후 rm
- rm(파일 삭제, 휴지통 없음), rm -r(재귀, 위험), rm -i(안전)
- rmdir=**빈 디렉터리만**
- **예상형식**: “다음 중 실패하는 명령은?”, “동작 설명”
    

  

1. **하드 링크 vs 심볼릭 링크**
    

  

- **하드 링크**: 같은 inode, **동일 파일**/파일시스템 경계 X/디렉터리 불가
- **심볼릭 링크**: 다른 inode, **경로 포인터**, 파일시스템 경계 O/디렉터리 O, ->
- 원본 삭제 후: 하드링크 OK / 심링크 **깨짐**
- **예상형식**: 개념/표 채우기/상황 판단
    

  

# **매우 중요(★4)**

- **슈퍼블록 / 아이노드 / 데이터블록**

## **함정 포인트 모음(시험용 메모)**

- /(루트) ≠ /root(root의 홈), ~는 내 홈
- cd /etc(절대) vs cd etc(상대)
- ls는 숨김 안 보임, **-a** 필요
- 디렉터리 복사 **cp -r**
- rmdir은 **빈** 디렉터리만
- **sticky bit** **t**: /tmp에서 타인 파일 삭제 제한
- **mv**: 같은 파티션=엔트리 수정, 다른 파티션=복사 후 삭제
- **하드링크**: 디렉터리·다른 파티션 불가 / **심링크**: 경로 포인터
- vi에서 p(아래) / P(위), cw 후 **입력모드** 전환, Ctrl+Z=Undo 아님
- sudo는 “명령 단위” 권한 상승, 무분별 사용 금지
- SSH: 서버(22), PuTTY는 **클라이언트**, ifconfig 쓰려면 net-tools 설치

## **예상 문제 샘플(빠른 복습)**

1. (출력 예측) 다음 중 ls -aF 결과 특징으로 맞는 것은?
    
    A. 디렉터리 뒤에 /가 붙는다 ✔
    
2. (경로) 현재 /usr/local에서 cd etc 후 pwd? → /usr/local/etc
3. (권한) rwxr-x---의 8진수? → **750**
4. (링크) 원본 삭제 후에도 내용 접근 가능한 것은? → **하드 링크**
5. (cp/mv) mv A B에서 B가 없으면? → **A의 이름이 B로 변경**
6. (vi) i hello Esc :wq 수행 결과? → “hello”가 저장 후 종료
7. (파이프) “/etc/services를 페이지로 보기” → cat /etc/services | more 또는 less /etc/services
8. (특수권한) /tmp 권한 끝의 t 의미? → **소유자만 삭제 가능**(sticky bit)
