## 정리
## 💾 자료형 및 연산

### 1. 수 자료형

- **정수형 (Integer Type):** 정수를 표현합니다.
- **실수형 (Floating-Point Type):** 실수를 표현합니다.
    - 소수부가 $0$일 경우 `a = 5.`와 같이 $0$을 생략할 수 있습니다. (결과: `5.0`)
    - 지수 표현 방식(`1e9`)을 사용하여 큰 수를 간결하게 표현할 수 있습니다.
    - 컴퓨터는 이진수 체계를 사용하므로 **실수 덧셈에서 정확한 결과**를 산출하지 못할 수 있습니다.
        - 일반적으로 `round(a, 4)`와 같이 5째 자리에서 반올림하여 처리합니다.
- **수 자료형 연산:**
    - 나누기: `/` (실수 나눗셈)
    - 나머지: `%`
    - 몫: `//` (정수 나눗셈 몫)
    - 거듭제곱: `**` (예: `a ** b`는 $a^b$)
        

```Python
# 실수형 예제
#소수부가 0일 때 0을 생략
a = 5. # 5.0

# 10억의 지수 표현 방식
a = 1e9 # 1000000000.0

# 실수 덧셈 오차 처리
a = 0.3 + 0.6
print(round(a,4))
```

```Python
# 수 자료형의 연산 예제
a = 7
b = 3

print(a / b)  # 나누기
print(a % b)  # 나머지
print(a // b) # 몫
print(a ** b) # 거듭 연산자
```

### 2. 리스트 자료형

- **리스트 초기화:**
    - `a = [1, 2, 3, 4, 5, 6, 7, 8, 9]`와 같이 대괄호(`[]`)를 사용합니다.
    - 빈 리스트는 a <code>=</code> list() 또는 a <code>=</code> \[]로 선언합니다.
    - 크기가 $N$이고 모든 값이 $0$인 리스트는 a = \[0] * n으로 초기화합니다.
- **인덱싱 (Indexing):** 인덱스 값을 입력하여 특정 원소에 접근
    - 파이썬은 양의 정수 인덱스(`a[0]`)와 음의 정수 인덱스(`a[-1]` : 마지막 원소)를 모두 사용합니다.
- **슬라이싱 (Slicing):**
    - `a[시작_인덱스:끝_인덱스]` 형태로 연속적인 위치의 원소들을 가져옵니다. **끝 인덱스의 원소는 포함하지 않습니다.**
        
```Python
# 리스트 인덱싱과 슬라이싱 예제
a = [1,2,3,4,5,6,7,8,9]

print(a[-1])  # 9 (가장 마지막 원소)
print(a[-3])  # 7 (뒤에서 세 번째 원소)
print(a[1:4]) # [2, 3, 4] (인덱스 1부터 3까지)
```

- **리스트 컴프리헨션 (List Comprehension):**
	- `[표현식 for 변수 in iterable if 조건]` 구조를 가집니다.
	    - **iterable**에서 순차적으로 **변수**를 할당받아 **조건**을 만족하는 경우에만 **표현식**을 적용한 결과를 수집하여 새로운 리스트를 생성합니다.
    - **2차원 리스트 초기화 시** 효율적이며, array = \[\[0] * m for _ in range(n)]와 같이 사용됩니다.
        - `_` (언더바)는 반복을 수행하지만 값을 사용하지 않을 때 사용되는 관용적인 변수입니다.
- **2차원 리스트 초기화 유의점:**
    - array <code>=</code> \[\[0] * m] * n와 같이 초기화하는 것은 **잘못된 방법**입니다.
    - 이 방식은 내부적으로 **모든 하위 리스트가 동일한 객체를 참조**하게 되어, 하나의 원소를 변경하면 모든 하위 리스트의 해당 위치 원소가 같이 변경됩니다.
    - **반드시 리스트 컴프리헨션**을 사용해야 각 행이 독립적인 리스트 객체를 가집니다.
제시된 리스트 컴프리헨션과 2차원 리스트 초기화 관련 내용을 기술적 사실에 기반하여 가독성 있게 구조화했습니다. 일반 텍스트의 등호(`=`)는 `<code>=</code>`로 변환되었습니다.

## 📝 리스트 컴프리헨션 (List Comprehension)

리스트 컴프리헨션은 **`[표현식 for 변수 in iterable if 조건]`** 구조를 가지며, 새로운 리스트를 간결하게 생성하는 파이썬 구문입니다.

- **작동 원리:**
    
    - **`iterable`** 객체에서 원소를 순차적으로 **`변수`**에 할당합니다.
        
    - **`조건`**을 만족하는 **`변수`**에 대해서만 **`표현식`**을 적용합니다.
        
    - **`표현식`**의 결과들을 수집하여 최종 리스트를 생성합니다.
        
- **주요 활용:**
    
    - **2차원 리스트 초기화** 시 효율적인 방법론입니다.
        
    - **표준 구문 예시:** `array <code>=</code> [[0] * m for _ in range(n)]`
        
        - **`_` (언더바):** 반복을 수행하나 해당 반복 변수 값이 코드 내에서 명시적으로 사용되지 않을 때 사용되는 관용적 변수입니다.

## ⚠️ 2차원 리스트 초기화 유의점

2차원 리스트 초기화 시 **참조 복사**로 인한 의도치 않은 동작을 방지해야 합니다.

- **잘못된 초기화 방식:**
    
    - `array <code>=</code> [[0] * m] * n`
        
    - 이 방식은 $n$개의 행이 **모두 동일한 하나의 하위 리스트 객체를 참조**하도록 만듭니다.
        
- **결과적 문제:**
    
    - 하나의 원소(`array[1][1]`)를 변경할 경우, 참조된 모든 하위 리스트의 동일한 인덱스 원소가 함께 변경됩니다.
        
- **해결책 (필수 권장):**
    
    - 각 행이 독립적인 객체를 가지도록 **반드시 리스트 컴프리헨션**을 사용해야 합니다.
```Python
# 2차원 리스트 초기화(잘못된 방법)
n = 3
m = 4
array = [[0] * m] * n

array[1][1] = 5 # [[0, 5, 0, 0], [0, 5, 0, 0], [0, 5, 0, 0]]
```

- **리스트 관련 기타 메서드:**
    - `append(x)`: 리스트 맨 뒤에 원소 $x$ 삽입 (시간 복잡도 $O(1)$)
    - `sort()`: 리스트 내부 원소 정렬 ($O(N \log N)$)
    - `reverse()`: 리스트 원소 순서 뒤집기
    - `insert(i, x)`: 인덱스 $i$에 원소 $x$ 삽입 ($O(N)$)
    - `count(x)`: 특정 값 $x$인 데이터 개수 세기
    - `remove(x)`: 리스트에서 **첫 번째** 나타나는 $x$값 데이터 삭제 ($O(N)$)
    - **특정 값을 갖는 원소 삭제 (효율적 방법):** `remove()`는 시간 복잡도가 높으므로, 특정 집합(`remove_set`)에 포함되지 않은 값만 선택하는 **리스트 컴프리헨션** 방식을 권장합니다.
        

```Python
# 특정 값을 갖는 원소 삭제 (효율적 방법)
a = [1,2,3,4,5,5,5]
remove_set = {3,5}

# remove_set에 포함되지 않은 값만을 저장
result = [i for i in a if i not in remove_set] # [1, 2, 4]
```

### 문자열 자료형 (String Type)

- **문자열 초기화:**
    - 작은따옴표(`'`) 또는 큰따옴표(`"`)를 사용하여 초기화합니다.
    - 따옴표 안에 동일한 따옴표를 포함하려면 역슬래시(`\`)로 이스케이프해야 합니다. (예: `"Don\'t"`)
- **문자열 연산:**
    - 문자열 결합: `+` 연산자
    - 반복: `*` 연산자 (예: `a * 3`)
    - 파이썬 문자열은 리스트와 유사하게 처리되므로 **인덱싱 및 슬라이싱**이 가능합니다.
        

### 튜플 자료형 (Tuple Type)

- **특징:**
    - 한 번 선언된 값을 **변경할 수 없습니다 (Immutable)**.
    - 소괄호 `()`를 이용하여 초기화합니다. (리스트는 대괄호 `[]`)
- **활용:**
    - 데이터 변경 불가능 속성이 필요한 경우에 사용됩니다.
    - **그래프 알고리즘** (예: 다익스트라)에서 `(비용, 노드 번호)` 형태로 묶어서 관리할 때 자주 사용됩니다.
        

```Python
# 튜플은 값 변경 불가능
a = (1, 2, 3, 4)
# a[2] = 7 # TypeError 발생
```

### 사전 자료형 (Dictionary Type)

- **특징:** `Key`와 `Value`의 쌍을 데이터로 가집니다.
    - 사전의 `Key`로 **튜플 자료형**을 사용할 수 있습니다.
    - 특정 원소의 존재 여부는 `'원소 in 사전'` 형태를 사용하여 검사할 수 있습니다.
- **관련 함수:**
    - `data.keys()`: 키 데이터만 뽑아서 리스트 형태로 이용합니다.
    - `data.values()`: 값 데이터만 뽑아서 리스트 형태로 이용합니다.
        

```Python
# 사전 자료형 예제
data = dict()
data['사과'] = 'Apple'

if '사과' in data:
    print("'사과'를 키로 가지는 데이터가 존재합니다.")

key_list = data.keys()
for key in key_list:
    print(data[key])
```

### 집합 자료형 (Set Type)

- **특징:**
    - **중복을 허용하지 않습니다.**
    - **순서가 없습니다.**
    - 특정 데이터의 등장 여부를 체크할 때 효율적입니다.
- **초기화:**
    - `data = set([1, 1, 2, 3, 4, 4, 5])` 또는 `data <code>=</code> {1, 2, 3, 4, 5}`
- **연산:**
    - 합집합: `|` (예: `a | b`)
    - 교집합: `&` (예: `a & b`)
    - 차집합: `-` (예: `a - b`)
- **관련 함수:**
    - `data.add(4)`: 새로운 원소 추가
    - `data.update([5, 6])`: 새로운 원소 여러 개 추가
    - `data.remove(3)`: 특정 값을 갖는 원소 삭제

## 💻 제어문

### 조건문 (Conditional Statements)

- **구조:** `if ~ elif ~ else`문을 이용합니다.
- **비교 연산자:** `<code>==</code>`, `!=`, `>`, `<`, `>=`, `<code><=</code>`
- **논리 연산자:** `and`, `or`, `not`
- **기타 연산자:**
    - `in`, `not in`: 리스트, 튜플, 문자열, 사전 등 자료형에 특정 원소가 존재하는지 검사합니다.
- **`pass` 문:** 조건문의 값이 참이더라도 아무것도 처리하고 싶지 않을 때 사용합니다.
- **조건부 표현식 (Conditional Expression):** `result <code>=</code> "Success" if score >= 80 else "Fail"`와 같이 `if ~ else`문을 한 줄에 작성할 수 있습니다.
    - 리스트 컴프리헨션과 결합하여 리스트 원소 값을 간결하게 변경할 때 활용됩니다.
        

```Python
# 조건부 표현식 예제
score = 85
result = "Success" if score >= 80 else "Fail"
print(result) # Success

# in / not in 연산자
X in 리스트    # 리스트 안에 X가 들어가 있을 때 참(True)
X not in 문자열 # 문자열 안에 X가 들어가 있지 않을 때 참(True)
```

### 반복문 (Loops)

- **`while` 문:** 조건이 참인 동안 반복을 수행합니다.
- **`for` 문:**
    - `range(시작값, 끝값 + 1, 증감)` 형태를 사용하여 반복합니다.
    - `continue`: 현재 반복을 중단하고 다음 반복을 진행합니다.
    - `break`: 반복문 전체를 즉시 탈출합니다.
    - **이중 `for` 문:** 플로이드 워셜 알고리즘, 다이나믹 프로그래밍 등 복잡한 문제에서 자주 사용됩니다.
        

```Python
# while문 예제
i = 1
result = 0
while i <= 9:
    result += i
    i += 1
print(result) # 45

# for문 range 예제
result = 0
for i in range(1,10):
    result += i
print(result) # 45
```

## 📝 함수 (Functions)

- **정의:** `def 함수명(매개변수):` 형태로 정의합니다. 동일한 알고리즘의 반복적 수행에 사용됩니다.
- **매개변수 지정:** `add(b <code>=</code> 3, a <code>=</code> 7)`와 같이 매개변수 이름을 직접 지정할 수 있습니다.
- **`global` 키워드:** 함수 안에서 **함수 밖의 전역 변수** 데이터를 변경해야 하는 경우 `global 변수명`을 사용합니다.
- **람다 표현식 (Lambda Expression):**
    - `lambda 매개변수: 표현식` 형태로 한 줄에 함수를 작성할 수 있습니다.
    - **정렬 라이브러리**에서 정렬 기준(`key`)을 설정할 때 자주 사용됩니다.
        

```Python
# global 키워드 예제
a = 0
def func():
    global a
    a += 1

for i in range(10):
    func()
print(a) # 10

# 람다 표현식 예제
print( (lambda a, b: a + b)(3,7) ) # 10
```

## 📥 입출력 (Input/Output)

### 입력

- **기본 입력:** `input()`
- **다중 값 입력:** `map(int, input().split())`을 사용하여 공백으로 구분된 여러 데이터를 입력받고 형 변환합니다.
- **빠른 입력:** `sys.stdin.readline().rstrip()`을 사용합니다.
    - `import sys`가 필요합니다.
    - `readline()`은 줄 바꿈 기호를 포함하므로, `rstrip()`을 사용하여 공백 문자를 제거해야 합니다.
        

### 출력

- **기본 출력:** `print()`는 기본적으로 출력 후 줄 바꿈을 수행합니다.
- **문자열 결합 유의점:** 숫자형 변수를 문자열과 결합할 때는 명시적으로 `str()`로 형 변환해야 합니다. (예: `print("정답은 " + str(answer) + "입니다.")`)
- **f-string (Python 3.6 이상):** `print(f"정답은 {answer}입니다.")`와 같이 간결하게 변수 값을 문자열에 삽입할 수 있습니다.

## 🛠️ 주요 라이브러리

### 1. 내장 함수 (Built-in Functions)

|**함수**|**기능**|**예시**|
|---|---|---|
|`sum(iterable)`|iterable 객체의 합|`sum([1, 2, 3])` <code>=</code> 6|

|`max(*args)`|최댓값 반환|`max(7, 3, 5)` <code>=</code> 7|
|`eval(expression)`|문자열로 표현된 파이썬 수식 실행|`eval("(3+5) * 7")` <code>=</code> 56|
|`sorted(iterable)`|새 리스트로 오름차순 정렬하여 반환|`sorted([9, 1, 8])` <code>=</code> `[1, 8, 9]`|

### 2. `itertools` (반복 가능한 데이터 처리)

- **`permutations(iterable, r)` (순열):** $r$개를 뽑아 나열하는 모든 경우의 수.
- **`combinations(iterable, r)` (조합):** $r$개를 뽑는 모든 조합.
- **`product(iterable, repeat=r)` (중복 순열):** $r$개를 뽑는 모든 순열 (중복 허용).
- **`combinations_with_replacement(iterable, r)` (중복 조합):** $r$개를 뽑는 모든 조합 (중복 허용).
- **유의점:** 모두 **클래스**이므로 사용 시 `list()`로 변환해야 합니다.
    

```Python
from itertools import permutations, combinations

data = ['a', 'b', 'c']

result_p = list(permutations(data, 3)) # 순열
result_c = list(combinations(data, 2)) # 조합

# 결과: [('a', 'b', 'c'), …]
# 결과: [('a', 'b'), ('a', 'c'), ('b', 'c')]
```

### 3. `heapq` (힙 기능)

- **기능:** 최소 힙 (Min Heap) 기능을 제공하여 우선순위 큐를 구현할 때 사용됩니다. 코딩 테스트에서 `PriorityQueue`보다 빠르게 동작합니다.
- **작동 원리:** 최소 힙의 최상단 원소는 항상 **가장 작은** 원소입니다.
- **메서드:**
    - `heapq.heappush(h, value)`: 원소 삽입
    - `heapq.heappop(h)`: 가장 작은 원소 (최상단) 꺼내기
- **최대 힙 (Max Heap) 구현:** 원소에 **음수 부호**를 붙여서 삽입/제거합니다. (예: `heapq.heappush(h, -value)`)
    

```Python
import heapq

h = []
heapq.heappush(h, 5) # 5 삽입
heapq.heappush(h, 1) # 1 삽입

print(heapq.heappop(h)) # 1 (가장 작은 원소)
```

### 4. `bisect` (이진 탐색)

- **기능:** **정렬된 배열**에서 특정 원소를 찾아야 할 때 사용됩니다.
- **메서드:**
    - `bisect_left(a, x)`: 리스트 $a$에 $x$를 삽입할 **가장 왼쪽** 인덱스 반환.
    - `bisect_right(a, x)`: 리스트 $a$에 $x$를 삽입할 **가장 오른쪽** 인덱스 반환.
- **활용:** 특정 범위에 속하는 원소의 개수를 구할 때 `bisect_right(a, right_value) - bisect_left(a, left_value)` 계산에 사용됩니다.
    

```Python
from bisect import bisect_left, bisect_right

a = [1, 2, 4, 4, 8]
x = 4

print(bisect_left(a, x))  # 2 (인덱스 2)
print(bisect_right(a, x)) # 4 (인덱스 4)
```

### 5. `collections` (유용한 자료구조)

- **`deque` (덱):**
    - 양쪽 끝에서 삽입/제거하는 스택, 큐 구현에 사용됩니다.
    - **가장 앞 원소 추가/제거**에서 $O(1)$의 시간 복잡도를 가집니다.
    - 메서드: `data.appendleft(x)`, `data.popleft()`, `data.append(x)`, `data.pop()`
- **`Counter` (카운터):**
    - Iterable 객체 내부의 원소가 몇 번씩 등장했는지 등장 횟수를 세는 기능을 제공합니다.
        

```Python
from collections import deque, Counter

# deque 예제
data = deque([2,3,4])
data.appendleft(1)
print(list(data)) # [1, 2, 3, 4]

# Counter 예제
counter = Counter(['red', 'blue', 'blue'])
print(counter['blue'])  # 2
print(dict(counter))    # {'red': 1, 'blue': 2}
```
