## 정리
- **JSON**: **J**ava**S**cript **O**bject **N**otation (자바스크립트 객체 표기법)의 약자
- JSON.stringify() : 자바스크립트 객체를 JSON 규칙에 맞는 문자열로 만든다
	- **Stringify**: "문자열로 만들다"
	- 프로그램끼리 네트워크를 통해 데이터를 주고받거나, 텍스트 파일에 데이터를 저장하려면 **데이터가 반드시 '문자열' 형태여야 합니다**
	- 복잡한 구조를 가진 객체나 배열을 그대로 네트워크로 전송할 수는 없었죠
	- **어디로든 전송하거나 저장할 수 있는 표준 텍스트 형식(JSON 문자열)으로 '직렬화(serialize)'** 또는 **'포장'**하기 위한 표준 방법으로 도입됨
	- 주로 자바스크립트 애플리케이션이 **API를 통해 외부 서버로 데이터를 전송해야 할 때** 사용됩니다.
		1. 전송할 자바스크립트 객체(예: `user`)가 준비됩니다.
		2. `JSON.stringify(user)`를 호출합니다.
		3. 메소드가 객체의 모든 속성을 재귀적으로 순회하며, JSON 규칙에 맞는 하나의 긴 문자열로 변환합니다.
		4. 완성된 JSON 문자열을 반환하면, 이 문자열을 HTTP 요청의 본문(body)에 담아 서버로 전송합니다.
- JSON.parse() **JSON 형식의 문자열을 분석하여 자바스크립트 객체로 만든다**
	- **Parse**: 문법을 분석하고 구조를 파악한다는 뜻의 영어 단어입니다.
	- 서버로부터 데이터를 받거나 텍스트 파일을 읽어올 때, 데이터는 **'문자열' 형태**로 도착합니다. 자바스크립트는 `'{"name":"홍길동"}'` 같은 문자열에서 `.name`과 같은 방식으로 속성에 접근할 수 없습니다.
	- 따라서 이 문자열 데이터를 **자바스크립트가 실제로 다룰 수 있는 살아있는 객체로 '재구성'** 또는 **'포장을 푸는'** 표준화된 방법이 필요했고, 이를 위해 `JSON.parse()`가 도입되었습니다.
	- 주로 **서버 API로부터 응답을 받아 데이터를 사용해야 할 때** 사용됩니다.
		1. 서버로부터 JSON 형식의 문자열(예: `responseText`)을 수신합니다.
		2. `JSON.parse(responseText)`를 호출합니다.
		3. 메소드가 문자열의 문법이 올바른 JSON 형식인지 분석합니다.
		4. 문법이 올바르다면, 문자열의 구조와 똑같은 새로운 자바스크립트 객체를 메모리에 생성합니다.
		5. 완성된 자바스크립트 객체를 반환하면, 비로소 `.name`과 같은 방식으로 데이터에 접근할 수 있습니다.
