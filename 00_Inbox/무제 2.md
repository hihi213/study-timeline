# **JPA 엔티티/매핑 & 스프링 통합 종합 치트시트**

## **1) 엔티티/테이블 기본 매핑**

### **식별자/PK**

- **@Entity** → **클래스**
- **@Table(name=…, schema=…, indexes=…)** → **클래스**
- **@Id** → **필드/게터**
- **@GeneratedValue(strategy=IDENTITY|SEQUENCE|TABLE|AUTO)** → **필드/게터**

### **컬럼/값 매핑**

- **@Column(name=…, nullable=…, length=…, unique=…)** → **필드/게터**
- **@Basic(fetch=EAGER|LAZY, optional=true|false)** → **필드/게터**
- **@Enumerated(EnumType.STRING)**(권장) / ORDINAL(지양) → **필드**
- **@Lob**(CLOB/BLOB) → **필드**
- **@Transient**(매핑 제외) → **필드**

### **시간/버전**

- **@Temporal(DATE|TIME|TIMESTAMP)** → **필드** _(java.time이면 불필요)_
- **@Version**(낙관적 락) → **필드**

### **접근 방식**

- **@Access(AccessType.FIELD|PROPERTY)** → **클래스** _또는_ **개별 필드/게터**
    - PROPERTY면 **게터**에 붙임.

```
@Entity
@Table(name="member")
@Access(AccessType.FIELD)
public class Member {
  @Id @GeneratedValue
  private Long id;

  @Column(nullable=false, length=50)
  private String name;

  @Enumerated(EnumType.STRING)
  private Status status;

  @Version
  private Long version;

  @Transient
  private String viewOnly;
}
```

### **(선택) 유틸**

- **@Converter**(클래스) / **@Convert(converter=…)**(필드) : 값 변환기
- **@SecondaryTable**(클래스) : 한 엔티티 → 2개 테이블 매핑

## **2) 값 타입(임베디드/컬렉션)**

- **@Embeddable** → **값 타입 클래스**
- **@Embedded** → **소유 엔티티의 필드**
- **@AttributeOverride(s)** → **@Embedded 필드에 함께**(컬럼명 재정의)

```
@Embeddable class Address { String city; String street; }
@Entity class Order {
  @Embedded
  @AttributeOverride(name="city", column=@Column(name="ship_city"))
  private Address shippingAddress;
}
```

- **@ElementCollection**(값 컬렉션) → **필드**
- **@CollectionTable(name=…, joinColumns=@JoinColumn("owner_id"))** → **@ElementCollection 필드에 함께**
- **값 컬렉션 컬럼명 지정**: @Column(name="tag")

## **3) 연관관계 요약(자세한 건 전용 문서에서)**

- **관계 선언**: @ManyToOne / @OneToMany / @OneToOne / @ManyToMany → **연관 필드**
    - 실무 기본 **LAZY** 권장.
- **주인(Owner) 지정**: **FK 가진 쪽**에 @JoinColumn(name="…")
- **거울(Inverse)**: 반대편에 mappedBy="ownerField"
- **복합 FK**: @JoinColumns({ … })
- **연결 테이블**: @JoinTable(name="…", joinColumns=…, inverseJoinColumns=…)
- **공유 PK(주로 1:1)**: 관계 필드에 @MapsId
- **정렬/순서**:
    - DB 정렬: @OrderBy("createdAt DESC")
    - 순서 컬럼 유지: @OrderColumn(name="seq")(INSERT/UPDATE 증가 유의)

```
@Entity
class Order {
  @ManyToOne(fetch=LAZY) @JoinColumn(name="member_id") // 주인
  private Member member;

  @OneToMany(mappedBy="order", cascade=ALL, orphanRemoval=true)
  private List<OrderItem> items = new ArrayList<>();
}
```

## **4) 상속 매핑**

- **전략**: @Inheritance(strategy=SINGLE_TABLE|JOINED|TABLE_PER_CLASS) → **부모 엔티티**
- **판별 컬럼/값**: @DiscriminatorColumn(name="dtype")(부모) / @DiscriminatorValue("BOOK")(자식)
- **공통 매핑 상속 전용**: @MappedSuperclass(테이블 없음, 다형 조회 불가)

```
@Entity @Inheritance(strategy=InheritanceType.JOINED)
@DiscriminatorColumn(name="dtype")
abstract class Item { … }

@Entity @DiscriminatorValue("BOOK")
class Book extends Item { … }
```

## **5) 네임드 쿼리 & 엔티티 그래프**

- **정적 쿼리**: @NamedQuery / @NamedNativeQuery → **엔티티 클래스**
- **페치 그래프**:
    - 정의: @NamedEntityGraph → **클래스**
    - 사용: @EntityGraph(attributePaths="orders") → **리포지토리 메서드**

```
@Entity
@NamedQuery(name="Member.findByName",
  query="select m from Member m where m.name = :name")
@NamedEntityGraph(name="Member.withOrders",
  attributeNodes=@NamedAttributeNode("orders"))
class Member { … }
```

## **영속성 컨텍스트 주입(중요)**

- **@PersistenceContext** → **스프링 빈의 필드/세터**(표준, 권장)
    - type = TRANSACTION(기본) | EXTENDED(상태풀, 드묾)
    - unitName = PU 이름(복수 PU 환경)
- **@PersistenceUnit** → **필드** (필요 시 EntityManagerFactory 주입)

```
@Service
public class OrderService {
  @PersistenceContext
  private EntityManager em; // 트랜잭션 스코프 EM
}
```

> 스프링 부트에선 @Autowired EntityManager도 되지만, 표준은 @PersistenceContext.

## **7) 트랜잭션 & 감사(Auditing)**

- **@Transactional** → **서비스 클래스/메서드**
    - 쓰기: @Transactional
    - 읽기: @Transactional(readOnly=true)
- **감사 설정**
    - **설정 클래스**: @EnableJpaAuditing
    - **베이스 엔티티**: @MappedSuperclass + @EntityListeners(AuditingEntityListener.class)
    - **필드**: @CreatedDate, @LastModifiedDate, @CreatedBy, @LastModifiedBy

```
@Configuration @EnableJpaAuditing class JpaConfig {}

@MappedSuperclass
@EntityListeners(AuditingEntityListener.class)
abstract class BaseTimeEntity {
  @CreatedDate private LocalDateTime createdAt;
  @LastModifiedDate private LocalDateTime updatedAt;
}
```

## **8) 스프링 데이터 JPA 리포지토리**

- **활성화**: @EnableJpaRepositories → **설정 클래스**
- **메서드 어노테이션**
    - @EntityGraph(attributePaths="member")
    - @Lock(LockModeType.PESSIMISTIC_WRITE)
    - @Query(JPQL/네이티브), @Modifying(UPDATE/DELETE)
    - @Param("…")

```
public interface OrderRepository extends JpaRepository<Order, Long> {
  @EntityGraph(attributePaths="member")
  List<Order> findByStatus(OrderStatus s);

  @Lock(LockModeType.PESSIMISTIC_WRITE)
  @Query("select o from Order o where o.id = :id")
  Optional<Order> lockById(@Param("id") Long id);

  @Modifying
  @Query("update Order o set o.status=:s where o.id in :ids")
  int bulkUpdateStatus(@Param("s") OrderStatus s, @Param("ids") List<Long> ids);
}
```

# **✅ 빠른 적용 체크리스트**

- **엔티티 상단**: @Entity (+ 필요 시 @Table)
- **식별자**: @Id @GeneratedValue
- **필드**: @Column, @Enumerated(STRING), 필요 시 @Lob, @Transient
- **값 타입**: @Embeddable/@Embedded (+ @AttributeOverride)
- **연관(주인 쪽)**: 관계 어노테이션 + @JoinColumn
- **상속**: @Inheritance / @MappedSuperclass
- **읽기/쓰기 트랜잭션 분리**: 서비스 메서드에 @Transactional
- **EM 주입**: 서비스에 @PersistenceContext EntityManager em
- **리포지토리**: @Query/@Modifying/@Lock/@EntityGraph
- **감사**: @EnableJpaAuditing + 베이스 엔티티 리스너
- **성능 옵션**: @BatchSize, fetch 전략, N+1 대비
