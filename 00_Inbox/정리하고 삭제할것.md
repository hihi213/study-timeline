## 1. HTML: 웹 페이지의 구조와 의미 뼈대

HTML은 웹 페이지의 뼈대를 만드는 언어입니다. 단순히 텍스트와 이미지를 나열하는 것을 넘어, 각 요소에 **의미(Semantic)를** 부여하여 컴퓨터(검색엔진, 스크린리더 등)가 문서의 구조를 더 잘 이해하도록 돕습니다.

### 기본 문서 구조

모든 HTML 문서는 다음과 같은 기본 구조를 가집니다.
- html태그 :
- Head :

```HTML
<!DOCTYPE html>
<html> 
  <head> 
    <meta charset="UTF-8"> <title>문서의 제목</title>
  </head>
  <body>
    </body>
</html>
```

### 주요 태그와 그 의미




- **입력/상호작용 태그 (`주로 <form>` 내부에서 사용)**
    - `<form>`: 사용자가 입력한 데이터를 서버로 전송하기 위한 전체 양식을 감쌉니다. 사용자가 버튼을 눌렀을때 input태그 안에 입력한 값은 서버(백엔드영역)->데이터베이스로 간다 이 과정을 관리하는 태그
    - `<input>`: 텍스트, 비밀번호, 체크박스 등 다양한 형태의 **입력 필드**를 만듭니다.
	    - 속성 readonly로 직접 키보드로 입력못하게 하고 개발자가 정의한 버튼으로 입력하게 할수있다
		- 속성 direction: ltr; 은 입력방향을 왼쪽에서 오른쪽으로
    - `<button>`: 클릭 가능한 **버튼**을 만듭니다. `type="submit"`으로 설정 시 `<form>`의 데이터를 제출합니다
    - `<label>`: `<input>` 요소에 대한 **설명(이름표)**을 붙여줍니다. `for` 속성을 사용하여 `input`의 `id`와 연결하면 사용성이 향상됩니다.
- **`<table>`** 표 전체를 감싸는 컨테이너
	- **`<tr>` (Table Row)** 표 안의 **가로 한 줄(행)**을 만듭니다. _(엑셀 비유: 1행, 2행 등 가로 한 줄)_
	- **`<td>` (Table Data)** 행(`<tr>`) 안에 들어가는 각각의 **셀(칸)**을 만듭니다. 실제 내용이 이 안에 들어갑니다. _(엑셀 비유: A1, B1 등 개별 칸)_
		- **`colspan` 속성**: 하나의 셀이 지정된 숫자만큼 **여러 개의 가로 칸(열)을 합치도록** 만듭니다. 엑셀의 '셀 병합'과 같습니다.

### 태그 속성: `id`와 `class`

태그에 특별한 정보를 부여하는 역할이며, 주로 CSS 스타일링과 JavaScript 조작의 대상이 됩니다.

- **`id`**: **고유한 식별자**. 하나의 HTML 문서 내에서 단 한 번만 사용해야 합니다. 이미 부여했다면 다른 태그가 이 id 재사용 불가합니다
- **`class`**: **반복 가능한 그룹명**. 여러 태그에 동일한 클래스 이름을 부여하여 공통된 스타일을 적용할 수 있습니다.
    
- 비실무적: 
	- inline style: 태그안에 속성을 기입하며 작성
		- \<h2 style= color: red">
	- 내부스타일: head태그안의 style 태그에 속성을 기입
- 실무적: 외부스타일: 파일.css생성해주고 그 안에 속성을 작성후
	- head태그안에 링크태그를 작성해 연결시키기
	- link rel="stylesheet" href="파일경로"

## 2. CSS: 웹 페이지의 디자인과 레이아웃 🎨

CSS는 HTML로 만든 구조에 색상, 크기, 배치 등 디자인을 입히는 언어입니다.

### CSS 적용 방법과 선택자

- **적용 방법**: 외부 CSS 파일을 `<link>` 태그로 연결하는 **외부 스타일 시트** 방식이 가장 실무적이고 권장됩니다.
    
- **선택자(Selector)**: 스타일을 적용할 HTML 요소를 지정합니다.
    
    - **태그 선택자**: `p { color: black; }`
    - **클래스 선택자**: `.my-class { font-size: 16px; }` (가장 보편적으로 사용)
    - **ID 선택자**: `#my-id { background-color: blue; }`
    
    > **선택자 우선순위**: 스타일 충돌 시 **ID > 클래스 > 태그** 순서로 우선 적용됩니다.
- 한칸 띄어쓰면 공백으로 연결해서 사용하면 뒤에나온 선택자가 하위 개체로 지정.
	- https://padahkim.tistory.com/34 (다중선택자정리)
- for ="Id" 가 속성인 라벨을 클릭했을때 그 Id인 요소가 선택됨
- :focus
	- 포커스됐을때
 ### 핵심 레이아웃 개념
-  하위태그는 부모설정을 따라간다
#### **1. 박스 모델과 `box-sizing`**

모든 HTML 요소는 사각형의 박스로 취급되며, 이 박스는 `content`, `padding`(내부 여백), `border`(테두리), `margin`(외부 여백)으로 구성됩니다.

- **`box-sizing: border-box;`**: **반드시 사용해야 할 핵심 속성**입니다. 이 속성을 적용하면 개발자가 설정한 `width`와 `height` 값에 `padding`과 `border`가 포함되어 계산됩니다. 따라서 레이아웃을 훨씬 예측하기 쉽고 직관적으로 만들 수 있습니다.
    
    ```CSS
    * {
      box-sizing: border-box; /* 모든 요소에 적용하여 레이아웃 계산 방식을 통일 */
    }
    ```
	- `box-sizing`: 박스 크기 계산 방식
		요소의 `width`와 `height`를 어디까지 계산할지 정하는 속성
	- **`content-box` (기본값)**: content 자체 크기로 width, height가 매겨짐(Padding과 Border가 추가되면 박스 크기가 늘어남)
	- **`border-box`**: Padding과 border를 포함한 크기로 width, height가 매겨짐
- content: 내용물
- padding: 뽁뽁이
- border: 상자 두께
- margin: 다른 상자들 사이의 간격

#### **2. `display` 속성: 요소의 배치 방식**
태그마다 display 기본 설정이 다르기 때문에 블로그 찾아가서 알아내기
- **`block`**:
    - 한 줄 전체를 차지하며, 항상 새로운 줄에서 시작합니다. (`<div>`, `<p>`, `<h1>` 등)
    - `width`, `height` 지정이 가능합니다.
- **`inline`**:
    - 콘텐츠 크기만큼만 공간을 차지하며, 다른 요소와 같은 줄에 배치됩니다. (`<span>`, `<a>` 등)
    - `width`, `height` 지정이 **불가능**합니다.
- **`inline-block`**:
    - `inline`처럼 같은 줄에 배치되면서, `block`처럼 `width`, `height`를 지정할 수 있는 하이브리드 속성입니다.
        
#### **3. `position` 속성: 요소의 위치 지정**

`top`, `left` 등의 좌표 속성과 함께 사용하여 요소의 위치를 정밀하게 제어합니다.

- `static`: 일반적인 문서 흐름에 따라 배치되며 좌표 속성이 적용되지 않습니다. 모든요소의 기본값이라 좌표를 적용하려면, 항상`position` 값을 기본값인 `static`이 아닌 다른 값으로 변경해야 합니다.
    
- `relative`: **원래 자신이 있던 위치**를 기준으로 좌표가 적용됩니다.
	- 다른 요소에 영향을 주지 않고 자기 자리에서만 살짝 이동하고 싶을 때 사용합니다.
- `absolute`: **`position`이 `static`이 아닌 가장 가까운 부모 요소**를 기준으로 좌표가 적용됩니다. (기준 부모가 없으면 body가 기준)
    
- `fixed`: 스크롤을 해도 화면의 특정 위치에 계속 고정됩니다. (예: 상단 고정 헤더)

#### **4. Flexbox 레이아웃: 자식 요소 정렬의 표준**

**부모 요소(Flex Container)에** `display: flex;`를 적용하여, 그 안의 **자식 요소(Flex Items)들을** 쉽고 유연하게 정렬하는 방식입니다.

- **`justify-content`**: 주축(**가로**, 수평) 정렬. (`center`, `space-between` 등)
- **`align-items`**: 교차축(**세로** 수직) 정렬. (`center`-가운데, `flex-start`- 시작점 등)
	- **참고**: `align-items: center`가 제대로 동작하려면, 부모 컨테이너에 정렬할 수 있는 `height` 값이 있어야 합니다.
    ```CSS
    .container {
      display: flex;
      justify-content: center; /* 자식들을 가로 중앙에 배치 */
      align-items: center;    /* 자식들을 세로 중앙에 배치 */
      height: 100vh;          /* 세로 정렬을 위해 부모 높이 지정 */
    }
    ```
 - `display: flex;`를 적용하면 부모 컨테이너는 여전히 **블록 레벨 요소**로서 **자신이 위치한 가로 공간을 100% 차지**하게 됩니다. 이는 Flex Container가 자식 요소들을 정렬할 수 있는 **넓은 기준 공간**을 확보한다는 말입니다   

### 실용적인 CSS 팁 및 Best Practice 💡

- **가운데 정렬**: `display: flex;`와 위의 `justify-content`, `align-items`를 사용하는 것이 가장 현대적이고 강력한 방법입니다.
    
- **상대 단위 사용**: 고정 단위인 `px` 대신, 폰트 크기 등에 `rem` 단위를 사용하면 사용자 설정에 반응하는 유연한 디자인을 만들 수 있습니다.
- 높이는 Vh를 사용하자
	- `100vh`는 현재 보이는 브라우저 화면의 전체 높이
- **CSS 변수 사용**: 반복되는 색상이나 값을 변수(`--main-color: #123456;`)로 만들어 사용하면, 나중에 테마를 변경하거나 값을 일괄 수정할 때 매우 편리하여 유지보수성이 향상됩니다.
        
---
- **가운데 정렬**: `display: block`인 요소에 `width` 값을 준 후 `margin: 0 auto;`를 적용하면 수평 가운데 정렬이 됩니다.
- 자식요소 정렬: 부모 요소에 `display: block`이랑 `text-align: center;`를 함께적용하면, 그 안에 있는 `inline` 또는 `inline-block` 자식 요소들이 수평으로 가운데 정렬됩니다
- margin: 0 auto;
	-  **너비(width)가 지정된 block 요소를 부모 요소 안에서 수평으로 가운데 정렬**
	-  첫 번째 값은 **상하(위아래)**, 두 번째 값은 **좌우** 여백을 의미

## 1. HTML: 웹 페이지의 구조와 의미 뼈대 🏛️

HTML(HyperText Markup Language)은 웹 페이지의 **뼈대**를 만드는 언어입니다. 단순히 텍스트와 이미지를 나열하는 것을 넘어, 각 요소에 **의미(Semantic)를 부여**하여 컴퓨터(검색엔진, 스크린리더 등)가 문서의 구조를 더 잘 이해하도록 돕습니다.

> **학습 Tip**: 모든 태그를 암기할 필요는 없습니다. 개발 중 "이런 기능이 필요하다" 싶을 때마다 검색하여 적합한 태그를 찾아 쓰는 것이 더 효율적인 학습 방법입니다. (Webstroyboy가 만든 홈페이지 참고)

### **1. HTML 기본 문서 구조**

모든 HTML 문서는 웹 브라우저에게 문서의 유형과 기본 정보를 알려주는 정해진 양식을 따릅니다.

```HTML
<!DOCTYPE html> <html> html언어로 작성됨을 의미하는 태그
  <head> 제목과 메타정보를 표시하는데 사용
    <meta charset="UTF-8" /> <title>웹 페이지의 제목</title> </head>
  <body>
    </body>
</html>
```
- head태그 
	- title :제목
	- meta : 메타정보(웹페이지 설명하는 정보)
		- UTF-8 로 메타정보를 설정해야 한국어까지 잘 표현됨
### **2. 주요 태그와 그 의미**

의미 없는 `<div>`의 남발 대신, 태그 이름만으로도 **영역의 역할을 명확히 알 수 있는** 시맨틱 태그 사용이 현대 웹 표준의 핵심입니다.

- `<div>` (Division): 특별한 의미 없이 영역을 나눌 때 사용하는 범용 **블록(Block) 컨테이너**입니다.
- <!-- div태그는 div태그안에 또다른 태그나 값을 넣기 전까지는 영역과공간을 가지지를 않습니다. -->
#### **시멘트태그**
- **`<header>`**: 페이지나 특정 섹션의 머리말 영역 (로고, 메뉴 등)
- **`<main>`**: 문서의 핵심 콘텐츠를 담는 유일한 영역
- **`<footer>`**: 페이지나 특정 섹션의 꼬리말 영역 (저작권, 연락처 등)
- **`<nav>`**: 다른 페이지로의 이동을 위한 내비게이션 메뉴 영역
- **`<section>`**: 연관 있는 콘텐츠를 그룹화하는 구획 영역

#### **콘텐츠**
- `<h1>` ~ `<h6>`: 문서의 **제목(Heading)**을 나타내며, 숫자가 작을수록 중요도가 높습니다. 검색엔진 최적화(SEO)에 중요한 역할을 합니다.
- `<p>`: **문단(Paragraph)을** 정의합니다.
- `<span>`: 자체는 아무런 시각적 효과가 없지만, CSS로 스타일을 입힐 특정 영역을 **"구별"하거나 "표시"하는** 역할를 합니다.
	- 주로 텍스트의 일부를 묶어 특정 스타일을 적용할 때 사용하는 **인라인(Inline) 컨테이너**입니다. `<div>`와 달리 줄 바꿈 없이 콘텐츠의 크기만큼만 영역을 차지합니다. 

#### **목록 (List)**

- `<ul>` (Unordered List): 순서가 중요하지 않은 목록
- `<ol>` (Ordered List): 순서가 중요한 목록
- `<li>` (List Item): `<ul>`이나 `<ol>`의 자식 요소로, 실제 개별 항목을 나타냅니다.
	- **목록 스타일 변경** CSS의 `list-style` 속성을 사용하면 목록 항목 앞에 붙는 기호(마커)를 변경하거나 `none` 값으로 제거할 수 있습니다
	- **중첩 목록 (Nested Lists)** `<li>` 태그 내부에 다른 `<ul>`이나 `<ol>`을 포함시켜 계층적인 목록 구조를 만들 수 있습니다

> **JavaScript 연동 예시**: `document.createElement('li')`와 같은 코드로 새 `<li>` 요소를 만들어 `appendChild()`를 통해 목록에 동적으로 추가할 수 있습니다.

#### **상호작용 (Form & Table)**

사용자로부터 데이터를 입력받거나 정보를 구조적으로 보여줄 때 사용합니다.
- `<form>`: 사용자가 입력한 데이터를 서버로 전송하기 위한 양식 전체를 감쌉니다.
    
- `<input>`: 텍스트, 비밀번호, 체크박스 등 다양한 형태의 **입력 필드**를 만듭니다.
    
- `<button>`: 클릭 가능한 **버튼**을 만듭니다. `type="submit"` 속성은 `<form>`의 내용을 제출하는 역할을 합니다.
    
- `<label>`: 입력 필드(`<input>`)에 대한 **이름표**입니다. `<label for="ID">`와 `<input id="ID">`를 연결하면 사용자 경험이 향상됩니다.
    
- `<table>`: 표 전체를 감싸는 컨테이너입니다. `<tr>`(행), `<td>`(셀) 태그와 함께 사용됩니다.
    

### **1.3. 태그 식별자: `id`와 `class`**

태그에 이름을 붙여 CSS 스타일링이나 JavaScript 조작의 대상으로 삼을 때 사용합니다.

- **`id`**: **고유한 식별자**. 하나의 HTML 문서 내에서 **단 한 번만** 사용해야 합니다. (주민등록번호처럼 유일함)
    
- **`class`**: **반복 가능한 그룹명**. 여러 태그에 동일한 클래스 이름을 부여하여 공통된 스타일을 적용할 수 있습니다. (반 학생, 동아리 회원처럼 중복 가능)

## 2. CSS: 웹 페이지의 디자인과 레이아웃 🎨

CSS(Cascading Style Sheets)는 HTML로 만든 구조에 색상, 크기, 배치 등 시각적인 디자인을 입히는 언어입니다.

### **2.1. CSS 적용과 선택자**

#### **적용 방법**

- **외부 스타일 시트 (권장)**: 별도의 `.css` 파일을 만들어 `<link>` 태그로 HTML에 연결하는 방식입니다. 유지보수가 용이하여 **실무에서 사용하는 표준**입니다.
    
    HTML
    
    ```
    <head>
      <link rel="stylesheet" href="style.css" />
    </head>
    ```
    
- **내부 스타일 시트**: HTML `<head>` 안의 `<style>` 태그에 작성합니다.
    
- **인라인 스타일**: 태그에 `style` 속성을 직접 작성합니다. (권장하지 않음)
    

#### **선택자 (Selector)**

스타일을 적용할 HTML 요소를 정확히 "선택"하는 규칙입니다.

- **태그 선택자**: `p { ... }`
    
- **클래스 선택자**: `.my-class { ... }` (가장 보편적으로 사용)
    
- **ID 선택자**: `#my-id { ... }`
    
- **하위 선택자**: `.container p { ... }` (`.container` 클래스 내부에 있는 모든 `<p>` 태그)
    

> **스타일 우선순위**: 스타일이 충돌할 경우, 일반적으로 **ID > 클래스 > 태그** 순서로 우선 적용됩니다. 더 구체적인 선택자일수록 우선순위가 높습니다.

### **2.2. 핵심 레이아웃 원리**

#### **1. 박스 모델과 `box-sizing` (⭐ 가장 중요)**

모든 HTML 요소는 `content`(내용), `padding`(내부 여백), `border`(테두리), `margin`(외부 여백)으로 구성된 사각형 박스로 취급됩니다.

- **`box-sizing: border-box;`**: **반드시 사용해야 할 핵심 속성**입니다. 이 속성을 적용하면 개발자가 설정한 `width`와 `height` 값에 `padding`과 `border`가 **포함**되어 계산됩니다. 따라서 레이아웃을 훨씬 예측하기 쉽고 직관적으로 만들 수 있습니다.
    
    CSS
    
    ```
    * {
      box-sizing: border-box; /* 모든 요소에 적용하여 레이아웃 계산 방식을 통일 */
    }
    ```
    

#### **2. `display` 속성: 요소의 배치 방식**

- **`block`**: 한 줄 전체를 차지하며, `width`/`height` 지정이 가능합니다. (예: `<div>`, `<p>`)
    
- **`inline`**: 콘텐츠 크기만큼만 공간을 차지하며, 다른 요소와 같은 줄에 배치됩니다. `width`/`height` 지정이 **불가능**합니다. (예: `<span>`, `<a>`)
    
- **`inline-block`**: `inline`처럼 같은 줄에 배치되면서, `block`처럼 `width`/`height`를 지정할 수 있는 하이브리드 속성입니다.
    

#### **3. `position` 속성: 요소의 위치 지정**

`top`, `left` 등의 좌표 속성과 함께 사용하여 요소의 위치를 정밀하게 제어합니다.

- `static` (기본값): 일반적인 문서 흐름에 따라 배치됩니다.
    
- `relative`: **원래 자신이 있던 위치**를 기준으로 좌표가 적용됩니다.
    
- `absolute`: **`position`이 `static`이 아닌 가장 가까운 부모 요소**를 기준으로 좌표가 적용됩니다. (기준 부모가 없으면 `<body>`가 기준)
    
- `fixed`: 스크롤을 해도 화면의 특정 위치에 계속 고정됩니다.
    

### **2.3. 현대적인 레이아웃: Flexbox**

**부모 요소(Flex Container)에** `display: flex;`를 적용하여, 그 안의 **자식 요소(Flex Items)들을** 쉽고 유연하게 정렬하는 현대적인 표준 방식입니다.

CSS

```
.container {
  display: flex;
  justify-content: center; /* 자식들을 주축(가로) 중앙에 배치 */
  align-items: center;     /* 자식들을 교차축(세로) 중앙에 배치 */
  height: 100vh;           /* 세로 중앙 정렬을 위해 부모 높이 지정 */
}
```

- **`justify-content`**: 주축(**가로**) 정렬. (`flex-start`, `center`, `space-between` 등)
    
- **`align-items`**: 교차축(**세로**) 정렬. (`flex-start`, `center`, `flex-end` 등)
    

### **2.4. 실용적인 CSS 팁 및 Best Practice 💡**

- **가운데 정렬 종합**:
    
    - **가장 강력한 방법 (Modern)**: `display: flex;`와 `justify-content`, `align-items`를 사용하는 것이 모든 상황에서 가장 효과적입니다.
        
    - **블록 요소 수평 정렬 (Classic)**: `width` 값이 지정된 블록 요소에 `margin: 0 auto;`를 적용하면 부모 안에서 수평 가운데 정렬됩니다.
        
- **상대 단위 사용**: 고정 값인 `px` 대신, 폰트 크기에는 `rem`, 화면 높이에는 `vh` 단위를 사용하면 사용자 환경에 반응하는 유연한 디자인을 만들 수 있습니다.
    
- **CSS 변수 사용**: 반복되는 색상이나 값을 변수(`--main-color: #123456;`)로 만들어 재사용하면 유지보수성이 크게 향상됩니다.
