## ⚡️ 코딩테스트 필살기 N의 크기와 '행동'에 따른 알고리즘 선택 가이드

> **💡 핵심 철학: 시간 복잡도의 진짜 의미**
> 시간 복잡도는 단순히 for 문을 몇 번 썼느냐가 아닙니다.
> **"데이터 1개를 마주했을 때, 어떤 행동(Action)을 취하느냐"**로 결정됩니다.

- O(1): 데이터를 쳐다보지도 않고 주소로 찾아감.
- $\log_2N$: 데이터를 다 보지 않고, 절반씩 버림.
- O(N): 데이터를 하나씩 성실하게 확인 함.
- 정렬함수 sort() 를 쓴다: $N\log_2N$ 확정
	- 그래서 정렬한번이라도 하면 $N\log_2N$으로 껑충 최고복잡도가 올라간다
	- 그렇다고 직접구현한다면 $N^2$ 으로 올라가니 구현은 하지 말자 (정렬함수는 최고의 개발자가 깍아만든 알고리즘..)

### 1. 🎯 N의 크기 & 본질적 행동 매핑 테이블

이 표는 $N$의 크기를 보고 $\rightarrow$ 내가 취해야 할 **행동(Action)**을 결정하는 지도입니다.

| **N의 최대 크기**                                | **허용 시간 복잡도**       | **데이터 1개당 취하는 행동 (Action)**                     | **즉시 떠올려야 할 알고리즘**                                                                       |
| ------------------------------------------- | ------------------- | ----------------------------------------------- | ---------------------------------------------------------------------------------------- |
| **상관 없음**                                   | **$O(1)$**          | **[즉시 접근]**<br>탐색하지 않는다. 주소(Key)로 꽂는다.          | • **Hash (Map/Set)**<br>• 배열 인덱스 접근<br>• 수학 공식 ($1$부터 $N$까지 합 등)                         |
| **$N \ge 10^9$**<br><small>(10억 이상)</small> | **$\log_2N$**       | **[범위 좁히기]**<br>절반을 **버린다**. (Up / Down)        | • **이분 탐색 (Binary Search)**<br>• 유클리드 호제법 (GCD)<br>• 분할 정복 (거듭제곱)                        |
| **$N \le 10^7$**<br><small>(1,000만)</small> | **$O(N)$**          | **[단순 순회]**  <br>모든 데이터를 **1번씩만** 훑는다.          | • **투 포인터 / 슬라이딩 윈도우**  <br>• **Greedy (탐욕법)**<br>• DP (1차원)<br>• 스택 / 큐 / 위상 정렬         |
| **$N \le 10^6$**<br><small>(100만)</small>   | **$O(N \log N)$**   | **[정렬과 분할]**<br>나누거나($\log N$), 줄 세운 뒤($N$) 본다. | • **Sort (정렬)**<br>• **Priority Queue (힙)**<br>• **Dijkstra (다익스트라)**<br>• 세그먼트 트리 / LIS |
| **$N \le 2,000$**<br>                       | **$O(N^2)$**        | **[모든 관계 확인]**<br>나($N$)와 나머지 전부($N$)를 비교한다.    | • **2중 For문 (완전 탐색)**<br>• DP (2차원, 표 채우기)<br>• BFS / DFS (인접 행렬)                        |
| **$N \le 500$**                             | **$O(N^3)$**        | **[3중 탐색]**<br>거쳐가는 모든 경로를 확인한다.                | • **플로이드-워셜**<br>• 행렬 곱셈                                                                 |
| **$N \le 20$**                              | **$O(2^N), O(N!)$** | **[모든 경우의 수]**<br>뽑거나, 안 뽑거나 / 줄 세우기            | • **백트래킹 (Backtracking)**<br>• **순열 / 조합**<br>• 비트마스크 (Bitmask)                          |

### 2. 🧠 '행동'으로 이해하는 알고리즘 검증법

문제를 풀 때 코드를 작성하기 전, 내 로직이 데이터에 어떤 **행동**을 하고 있는지 자문해보세요.

#### **Case 1: "이거 반복문 하나니까 $O(N)$ 아니야?" (❌ 오개념 주의)**

- **상황:** `for`문이 하나지만, 그 안에서 `string.contains()`나 `list.remove(0)` 같은 무거운 연산을 한다.
- **분석:**
    - `list.remove(0)`은 **배열 전체를 한 칸씩 당기는 행동($O(N)$)** 입니다.
    - 즉, 겉보기엔 $O(N)$ 루프지만 실제 행동은 **$O(N) \times O(N) = O(N^2)$**가 됩니다.
- **결론:** $N=10만$일 때 이렇게 짜면 시간 초과입니다. **자료구조(Deque, Set)를 바꿔야 합니다.**
    

#### **Case 2: "데이터가 20억 개네? 루프 못 돌리네."**

- **행동:** $O(N)$(순회)은 불가능합니다.
- **전략:** 데이터를 하나씩 보는 게 아니라, **데이터의 범위를 뭉텅이로 잘라내는 행동($O(\log N)$)**을 해야 합니다.
    - $\rightarrow$ **이분 탐색(Parametric Search)**
        

#### **Case 3: "데이터가 10만 개인데, 정렬($N \log N$) 해도 되나?"**

- **계산:**
    - $N=10^5$
    - 행동: 데이터를 쪼개고($\log N \approx 17$) $\times$ 전체를 훑음($N$)
    - 연산량: $17 \times 100,000 \approx 170$만 번.
- **결론:** 1억 번에 한참 못 미치므로 **매우 안전**합니다. 마음껏 정렬하세요.

### 3. ⏱️ $\log_2 N$ 값 "3초 암기법" (업데이트)

복잡도 계산할 때 $\log N$은 고민하지 말고 아래 숫자를 곱하세요.

- $N = 1,000$ ($10^3$) $\rightarrow$ **x 10**
- $N = 1,000,000$ ($10^6$) $\rightarrow$ **x 20**
- $N = 1,000,000,000$ ($10^9$) $\rightarrow$ **x 30**
    

> 예시: $N=100$만 일 때 $O(N \log N)$ 알고리즘의 연산 횟수는?
>
> $\rightarrow$ $100$만 $\times$ $20$ = 2,000만 번 (1억보다 작으므로 통과!)

## ⚠️ 언어별 주의사항 (함정 카드)

알고리즘은 맞는데 시간 초과(TLE)가 난다면?

- **Java:**
    - `Scanner` 금지 $\rightarrow$ `BufferedReader` 사용.
    - 문자열 잦은 덧셈 금지 $\rightarrow$ `StringBuilder` 사용.
- **Python:**
    - `input()` 금지 $\rightarrow$ `sys.stdin.readline` 사용.
    - $N=10^6$일 때 `Python3`가 느리면 `PyPy3`로 제출.
    - 재귀 깊이가 깊으면 `sys.setrecursionlimit()` 필수 설정.
- **C++:**
    - `cin`, `cout` 사용 시 `ios::sync_with_stdio(0), cin.tie(0)` 필수.
    - `endl` 금지 $\rightarrow$ `\n` 사용.
