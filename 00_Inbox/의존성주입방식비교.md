## 정리

# **TL;DR**

- 기본값: **생성자 주입 + final 필드 + Lombok @RequiredArgsConstructor**
- @Setter 주입은 “테스트에서 임시로 바꿔 끼우기” 같은 **특수 케이스**만.
- 필드 주입은 테스트성·불변성·컴파일 타임 보장 약해서 **지양**.

---

## **1) 주입 방식 비교**

### **A. 필드 주입 (지양)**

```java
@Component
public class MemberService {
  @Autowired private MemberRepository memberRepository;
}
```

- 장점: 코드 가장 짧음.
- 단점: **불변성 없음**, 생성 시점 필수 의존성 보장 X, 단위테스트에서 **목 교체 어려움**.

### **B. Setter 주입 (보조용)**

```java
@Component
public class MemberService {
  private MemberRepository memberRepository;
  @Autowired public void setMemberRepository(MemberRepository repo){ this.memberRepository = repo; }
}
```

- 장점: **중간에 교체 가능**(테스트에서 목/가짜 주입 용이).
- 단점: 런타임 변경 가능성이 열려 **설계가 가변적**이 됨.
- 쓰임새: 선택적 의존성, 레거시 교체, 특수 테스트 등 **예외적 상황**.

### **C) 생성자 주입** 

### **(명시적·수동)**

```java
@Component
public class MemberService {
  private final MemberRepository memberRepository;

  // 단일 생성자면 @Autowired 생략 가능
  public MemberService(MemberRepository memberRepository) {
    this.memberRepository = memberRepository;
  }
}
```

- 장점: 필수 의존성 **컴파일 타임 보장**, 테스트에서 목 주입 쉬움.
- 단점: **보일러플레이트**(생성자 작성) 발생.

---

### **D) 롬복으로 생성자 주입 (최종권장)**

```java
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Service;

@RequiredArgsConstructor
@Service
public class MemberService {
  private final MemberRepository memberRepository; // 필수 의존성은 final
}
```

- 핵심: **@RequiredArgsConstructor + final 필드** → 필수 의존성만 생성자에 포함.
- 효과: C의 모든 장점 유지 + **보일러플레이트 제거**.
- 주의:
    - @AllArgsConstructor는 **모든 필드**를 받아 과주입 위험 → 지양.
    - 선택적 의존성은 final로 두지 말고 별도 Setter/팩토리로 처리.
- **Spring Data JPA 리포지토리·서비스**도 생성자 주입 권장(필드 final).
---
## **2) 테스트 관점**

- 생성자 주입이면:

```java
MemberService svc = new MemberService(new FakeMemberRepository());
```

- → 테스트가 **간단하고 안전**. Setter 주입은 가능하지만 런타임 변경 통로가 열려 있어 기본 전략으론 비추.

---

## **3) 실무 적용 체크리스트**

1. 서비스/도메인 컴포넌트의 **필수 의존성 = final + 생성자 주입**.
2. Lombok **@RequiredArgsConstructor**로 보일러플레이트 제거.
3. 선택적 의존성만 Setter(또는 Optional) 고려.
4. 컨테이너 로딩 시 **조립 완료**(런타임 변경 금지)가 기본 규칙.
5. 새 컴포넌트 만들 때 “필수/선택”을 먼저 구분하고, 필수는 **컴파일 시점 보장**되도록.
#### 스프링/JPA 관련 메모
- **Spring Boot**는 **단일 생성자**면 @Autowired 없이도 주입됨.
- **EntityManager 주입**은 표준으론 @PersistenceContext가 명시적이며, Boot 환경에선 생성자 주입과 조합해도 동작(프로젝트 표준에 맞춰 일관되게 선택).
