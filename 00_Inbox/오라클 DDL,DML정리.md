### 1. UPDATE (데이터 수정)

이미 존재하는 데이터를 **변경**할 때 사용합니다.

- **구조:** `UPDATE` (어디를) $\rightarrow$ `SET` (어떻게) $\rightarrow$ `WHERE` (누구를)
- **설명:**
    
    1. **UPDATE**: 수정할 **테이블**을 선택합니다.
    2. **SET**: **어떤 컬럼을 어떤 값으로 바꿀지** 정합니다.
    3. **WHERE**: **누구(어떤 행)**에게 적용할지 정합니다. (※ 중요: 이게 없으면 모든 데이터가 바뀝니다!)

```SQL
UPDATE 회원테이블        -- [어디를] 회원 테이블에서
SET 비밀번호 = '1234'    -- [어떻게] 비밀번호를 '1234'로 바꿔라
WHERE 아이디 = 'gemini'; -- [누구를] 아이디가 'gemini'인 사람만
```

---

### 2. INSERT (데이터 추가)

새로운 데이터를 **집어넣을 때** 사용합니다.

- **구조:** `INSERT INTO` (어디에) $\rightarrow$ `VALUES` (무엇을)
- **설명:**
    
    1. **INSERT INTO**: 데이터를 넣을 **테이블**을 지정합니다. (괄호 안에 넣을 컬럼들을 나열합니다.)
    2. **VALUES**: 실제로 넣을 **값(데이터)**들을 순서대로 적습니다.
        

SQL

```Java
INSERT INTO 회원테이블 (이름, 나이) -- [어디에] 회원 테이블의 이름, 나이 칸에
VALUES ('김철수', 25);            -- [무엇을] '김철수'와 25라는 값을 넣어라
```

---

### 3. DELETE (데이터 삭제)

데이터를 **지울 때** 사용합니다.

- **구조:** `DELETE FROM` (어디서) $\rightarrow$ `WHERE` (누구를)
- **설명:**
    
    1. **DELETE FROM**: 삭제할 데이터가 있는 **테이블**을 선택합니다.
    2. **WHERE**: 삭제할 **대상**을 정합니다. (※ 중요: 이게 없으면 테이블 안의 모든 데이터가 날아갑니다!)
        
```SQL
DELETE FROM 회원테이블   -- [어디서] 회원 테이블에서
WHERE 이름 = '홍길동';   -- [누구를] 이름이 '홍길동'인 사람을 지워라
```

---

### 4. SELECT (데이터 조회)

데이터를 **가져올 때** 사용합니다. 가장 많이 쓰입니다.

- **구조:** `SELECT` (무엇을) $\rightarrow$ `FROM` (어디서) $\rightarrow$ `WHERE` (누구를)
- **설명:**
    
    1. **SELECT**: 보고 싶은 **컬럼(정보)**을 고릅니다. (`*`은 전부 다 보여달라는 뜻)
    2. **FROM**: 정보를 찾을 **테이블**을 지정합니다.
    3. **WHERE**: 원하는 **조건**에 맞는 데이터만 걸러냅니다.

```SQL
SELECT 이름, 전화번호     -- [무엇을] 이름과 전화번호만 보여줘
FROM 고객테이블          -- [어디서] 고객 테이블에서
WHERE 등급 = 'VIP';     -- [누구를] 등급이 'VIP'인 사람들만
```

### 요약 표 (한눈에 보기)

|**명령어**|**역할**|**1단계 (대상/위치)**|**2단계 (내용/행위)**|**3단계 (조건/필터)**|
|---|---|---|---|---|
|**UPDATE**|수정|`UPDATE` 테이블|`SET` 컬럼 = 값|`WHERE` 조건|
|**INSERT**|추가|`INSERT INTO` 테이블|`VALUES` (값1, 값2)|(없음)|
|**DELETE**|삭제|`DELETE FROM` 테이블|(삭제 행위 포함)|`WHERE` 조건|
|**SELECT**|조회|`SELECT` 컬럼명|`FROM` 테이블|`WHERE` 조건|

> **Tip:** `UPDATE`와 `DELETE`를 사용할 때는 항상 **`WHERE` 절을 먼저 확인하는 습관**을 들이는 것이 좋습니다. 실수로 전체 데이터를 수정하거나 삭제하는 것을 방지할 수 있습니다.



### 1. DML (Data Manipulation Language)

**데이터(내용물)**를 다루는 명령어입니다. (집 안의 **가구**를 배치하거나 버리는 것)

| **명령어**    | **흐름 요약 (직관적 해석)**                                                         |
| ---------- | -------------------------------------------------------------------------- |
| **SELECT** | **(무엇을)** 보고싶은 컬럼을 / FROM **(어디서)** 어느 테이블에서 / WHERE **(누구를)** 어떤 조건의 데이터만 |
| **INSERT** | INTO **(어디에)** 어느 테이블에 / VALUES **(무엇을)** 어떤 값들을                           |
| **UPDATE** | **(어디를)** 어느 테이블을 / SET **(어떻게)** 어떤 컬럼을 무슨 값으로 / WHERE **(누구를)** 어떤 행만    |
| **DELETE** | FROM **(어디서)** 어느 테이블에서 / WHERE **(누구를)** 어떤 행을                            |

#### 예시 코드



```SQL
-- 1. 조회 (SELECT)
SELECT 이름, 나이       -- [무엇을] 이름과 나이만 보여줘
FROM 회원테이블        -- [어디서] 회원 테이블에서
WHERE 나이 > 20;      -- [누구를] 20살 넘는 사람만

-- 2. 삽입 (INSERT)
INSERT INTO 회원테이블  -- [어디에] 회원 테이블에
VALUES ('신입', 20);   -- [무엇을] '신입', 20세라는 데이터를 넣어줘

-- 3. 수정 (UPDATE)
UPDATE 회원테이블       -- [어디를] 회원 테이블을 고칠 거야
SET 등급 = 'VIP'      -- [어떻게] 등급을 VIP로 바꿔줘
WHERE 구매액 > 100만;   -- [누구를] 구매액 100만 넘는 사람만

-- 4. 삭제 (DELETE)
DELETE FROM 회원테이블  -- [어디서] 회원 테이블에서 지울 거야
WHERE 이름 = '탈퇴자';  -- [누구를] 이름이 '탈퇴자'인 사람을
```

### 2. DDL (Data Definition Language)

**테이블(구조)** 자체를 다루는 명령어입니다. (집 **건물** 자체를 짓거나 부수는 것)

DDL은 `WHERE`(조건)가 없는 경우가 많으며, **"어떤 객체를 / 어떻게 바꾼다 / 구체적인 정의"** 순서로 이해하면 좋습니다.

|**명령어**|**흐름 요약 (직관적 해석)**|
|---|---|
|**CREATE**|**(무엇을)** 어떤 테이블을 만듦 / **(이름은)** 뭐라고 짓고 / **(구성요소)** 어떤 컬럼들을 가짐|
|**ALTER**|**(어디를)** 어느 테이블을 고침 / **(어떻게)** 컬럼을 추가/수정/삭제 / **(무엇을)** 대상 컬럼명과 속성|
|**DROP**|**(무엇을)** 어떤 테이블을 부숨 / **(이름은)** 이 테이블을 / (내용 없음) 완전히 삭제|
|**TRUNCATE**|**(무엇을)** 어떤 테이블을 비움 / **(이름은)** 이 테이블을 / (내용 없음) 껍데기만 남기고 내용 전멸|

#### 예시 코드



```SQL
-- 1. 생성 (CREATE)
CREATE TABLE 회원테이블 (  -- [무엇을] '회원테이블'을 만들 거야
    ID VARCHAR(10),      -- [구성요소] ID는 문자열 10자리
    나이 NUMBER           -- [구성요소] 나이는 숫자
);

-- 2. 구조 변경 (ALTER)
-- 2-1. 컬럼 추가 (ADD)
ALTER TABLE 회원테이블     -- [어디를] 회원테이블을 고칠 거야
ADD 이메일 VARCHAR(20);    -- [어떻게] '이메일' 컬럼을 추가할래

-- 2-2. 컬럼 속성 변경 (MODIFY)
ALTER TABLE 회원테이블     -- [어디를] 회원테이블을 고칠 거야
MODIFY 이메일 VARCHAR(50); -- [어떻게] '이메일' 자릿수를 50으로 늘릴래

-- 2-3. 컬럼 삭제 (DROP COLUMN)
ALTER TABLE 회원테이블     -- [어디를] 회원테이블을 고칠 거야
DROP COLUMN 나이;         -- [어떻게] '나이' 컬럼을 없애버릴래

-- 3. 테이블 삭제 (DROP)
DROP TABLE 회원테이블;     -- [무엇을] 회원테이블 자체를 흔적도 없이 날려버려

-- 4. 테이블 초기화 (TRUNCATE)
TRUNCATE TABLE 회원테이블; -- [무엇을] 회원테이블 안의 내용만 싹 다 비워 (통은 남김)
```

### 💡 핵심 차이점 (면접/시험 단골 질문)

1. **DELETE vs TRUNCATE**
    
    - `DELETE` (DML): 데이터를 **하나하나** 지웁니다. 느립니다. 되돌릴 수 있습니다(Rollback 가능).
    - `TRUNCATE` (DDL): 테이블 안을 **한 번에** 비웁니다. 매우 빠릅니다. 되돌릴 수 없습니다(Rollback 불가 - _일부 DB 제외_).
        
2. **DROP vs TRUNCATE**
    
    - `DROP`: 집(테이블) 자체를 철거합니다.
    - `TRUNCATE`: 집은 놔두고 안에 있는 짐(데이터)만 다 갖다 버립니다.
