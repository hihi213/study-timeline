## 정리
- 폴더 선택하고 control+shift+f 하면 그 폴더내에서 모두 검색가능
- 테스트 만들기 :cmd+shift+t

## **🚀 탐색/검색**

- ⇧⇧ → 전역 검색
- **해당 폴더내검색**: 폴더 선택 + ^⇧F
- ⌘⇧A → 액션 찾기
	- 단축키/명령을 이름으로 찾아 실행
- ⌘O / ⌘⇧O / ⌘⌥O → 클래스 / 파일 / 심볼로 바로 이동
- ⌘E / ⌘⇧E → 최근 파일 / 최근 편집 위치
- ⌘P → 파라미터 정보팝업 보기
- F1 → 해당 심볼의 간단한 문서 보기

## **✍️ 편집/자동수정**

- ⌥⏎ → 퀵 픽스
	- 경고/제안 표시 및 자동 수정
- ⌘/ / ⌘⌥/ → 라인 / 선택 블록 주석
- ⌘D / ⌘⌫ → 라인 복제 / 라인 삭제
- ⌥⌘L / ⌥⌘O → 코드정렬 / 임포트 정리
- ^Space / ^⇧Space → 완성 / 스마트 완성
- ⌃G / ⌃⌘G → 다음 동일 토큰 선택 / 동일 토큰 전부 선택

## **🔡 이동/선택(헷갈림 방지 버전)**
### 커서이동
- **단어 이동**: ⌥← / ⌥→
- **줄 처음/끝**: ⌘← / ⌘→
- **파일 위/아래**: ⌘↑ / ⌘↓
### 선택
- **단어 선택+확장**: ⌥⇧← / ⌥⇧→
- **줄 시작/끝까지 선택**: ⌘⇧← / ⌘⇧→
- **문맥 확장/축소**: ^W / ^⇧W
- **블록단위로 점프**: ⌥⌘\[ / ⌥⌘]

### 해당 라인/블럭 이동
- **라인 ‘재배치’**: ⌥⇧↑ / ⌥⇧↓  _(줄 자체 이동)_
- **Statement 이동**: ⌘⇧↑ / ⌘⇧↓  _(문맥 단위 이동)_

### 삭제
- **단어삭제**: ⌥⌫ / ⌥Delete
- 커서부터 줄끝까지 삭제 ⌘Delete
- 줄 전체 삭제 ⌘Backspace

## **🧩 리팩터링(Introduce 계열)**

- ⇧F6 → Rename
- ^T → 리팩터 메뉴
- **⌥⌘V — Introduce Variable**
    - **무엇:** 표현식을 지역 변수로 추출.
    - **언제:** 같은 표현식을 여러 번 쓰거나 의미를 이름으로 부여하고 싶을 때.
- **⌥⌘F — Introduce Field**
    - **무엇:** 표현식을 클래스 필드(보통 상수/공유 값)로 추출.
    - **언제:** 여러 메서드에서 같은 값을 사용하거나 상수화할 때.
- **⌥⌘M — Introduce Method**
    - **무엇:** 선택한 코드 블록을 별도 메서드로 추출.
    - **언제:** 큰 메서드를 역할 단위로 분리하거나 반복되는 블록을 재사용할 때.
- **⌥⌘P — Introduce Parameter**
    - **무엇:** 메서드 내부의 리터럴/값을 메서드 인수로 만들기.
    - **언제:** 하드코딩된 값을 외부에서 주입하거나 메서드를 범용화할 때.
## **▶️ 실행/디버그**

- ^R / ^D → Run / Debug
- ⌘F2 → Stop
- ⌃⌃ → Run Anything
- ⌘1 / ⌘9 → Project / Git 창

## **🔍 찾기/바꾸기**

- ⌘F / ⌘R → 파일 내
- ⌘⇧F / ⌘⇧R → 전역
- **폴더만 검색**: 폴더 선택 + ^⇧F

## **🖋 보너스**

- ⌘⇧8 → 컬럼(직사각형) 선택
- **테스트 파일 생성/ (현재 테스트파일이라면 테스트아닌 클래스로 이동)**: ⌘⇧T

---

### **기억해두면 덜 헷갈리는 3줄**

- **라인이동** ⌥⇧↑↓ vs **Statement이동** ⌘⇧↑↓ (줄 재배치 vs 문맥 단위)
- **단어 이동** ⌥←→ / **줄 끝** ⌘←→
- 모르면 **⌘⇧A**로 검색해서 바로 실행!
