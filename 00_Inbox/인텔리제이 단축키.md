## 정리
- 폴더 선택하고 control+shift+f 하면 그 폴더내에서 모두 검색가능
- 테스트 만들기 :cmd+shift+t

---

## **🚀 탐색/검색**

- **⇧⇧ (Shift 두 번)** → Search Everywhere (파일/클래스/설정/액션 통합 검색)
- **⌘⇧A** → Find Action (이름으로 기능 검색)
- **⌘E** → Recent Files
- **⌘⇧E** → Recent Locations(최근 수정 위치)
- **⌘⇧T** -> Test파일생성/ Test파일일땐 유사한 테스트아닌파일 이동추천
- **⌘O** / **⌘⇧O** / **⌘⌥O** → 클래스/파일/심볼로 바로 가기
- **⌘B** / **⌘⌥B** → 선언/구현으로 이동
- **⌘\[** / **⌘]** → 이전/다음 위치로 이동
- **⌘P** → 파라미터 정보(메서드 인자 팝업)
- **F1** → Quick Documentation(빠른 문서)

## **✍️ 편집/코드 액션**

- **⌥⏎** → 인텐션/퀵픽스(누르면 고쳐줌)
- **⌘/** / **⌘⌥/** → 라인/블록 주석 토글
- **⌘D** / **⌘⌫** → 라인 복제/라인 삭제
- **⌥⌘L** / **⌥⌘O** → 코드 정렬(Reformat) / import 최적화
- **⌘⇧↩** → 문장 자동 완성(세미콜론/괄호 등 마무리)
- **^Space** / **^⇧Space** → 기본/스마트 코드 완성
- **⌃G** / **⌃⌘G** → 다음 선택 항목 추가 / 전체 동일항목 선택(멀티커서)

## **🔡 단어·코드 단위 이동/편집**

- **⌥← / ⌥→** → **단어 단위 좌/우 이동**
- **⌥⇧↑/↓** → 라인 이동
- **⌘← / ⌘→** → **문장(line) 맨 앞으로/뒤로 이동**
- **⌘⇧↑/↓** → 문장(Statement) 이동
- **⌥⇧← / ⌥⇧→** → **단어 단위 선택 확장**
- **⌘⇧← / ⌘⇧→** → **줄(line) 맨 앞/뒤까지 선택**
- **⌘↑ / ⌘↓** → **파일 맨 위 / 맨 아래로 이동**
- **⌥⌘[ / ⌥⌘]** → **코드 블록 단위로 위/아래 점프**
    (메서드 시작/끝, 클래스 블록 단위 이동할 때 유용)
- **⌥Delete / ⌥Backspace** → **단어 단위 삭제**
- **⌘Delete** → **커서 위치부터 줄 끝까지 삭제**
- **⌘Backspace** → **줄(line) 전체 삭제**

---

## **🖋 추가 팁**

- **⌘⇧8 (Column Selection Mode)**

    → 블록 단위(직사각형)로 텍스트 선택. SQL/로그 정리할 때 유용.

- **^W / ^⇧W** → 코드 선택 확장 / 축소

    (변수 → 표현식 → 문장 → 메서드 블록 → 클래스 순으로 확장)

## **🧩 리팩터링 (핵심)**

- **⇧F6** → Rename
- **⌥⌘V / ⌥⌘F / ⌥⌘M / ⌥⌘P**
	- ⌥⌘V: **Introduce** Variable
		- 선택한 표현식(코드 조각)을 새로운 지역 변수로 추출.
	- ⌥⌘F **Introduce** Field
		- 선택한 표현식을 **클래스 필드**로 추출.
	- ⌥⌘M **Introduce** Method
		- 선택한 코드 블록을 새로운 메서드로 추출.
	- ⌥⌘P** **Introduce** Parameter
	    -  메서드 안의 특정 값을 **메서드 인자로 추출**.
- **^T** → Refactor This(리팩터링 메뉴 모음)

## **▶️ 실행/디버그**

- **^R / ^D** → Run / Debug (현재 구성)
- **⌘F2** → Stop
- **⌃⌃ (Ctrl 두 번)** → Run Anything(실행 구성/Gradle 태스크 등 빠른 실행)
- **⌘1 / ⌘9** → Project / Git 창 열기(주요 Tool Window는 ⌘ + 숫자)

## **🔍 찾기/바꾸기**

- **⌘F / ⌘R** → 파일 내 찾기/바꾸기
- **⌘⇧F / ⌘⇧R** → 프로젝트 전역 찾기/바꾸기
