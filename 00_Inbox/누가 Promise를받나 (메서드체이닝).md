### 메서드 체이닝(Method Chaining)이란?

메서드 체이닝은 **하나의 객체에 여러 메서드를 점(`.`)으로 연결하여, 한 줄의 코드로 연속해서 호출**하는 프로그래밍 기법입니다.

이 기법을 사용하면 각 단계의 결과를 별도의 변수에 저장할 필요가 없어, 코드가 간결해지고 가독성이 높아집니다.

---

### 동작 원리: 반환 값의 비밀

메서드 체이닝의 핵심은 **각 메서드가 실행된 후, 다음 메서드를 호출할 수 있는 객체를 반환(`return`)**하는 데 있습니다. 반환되는 객체는 크게 두 종류입니다.

1. **자기 자신(`this`) 반환**: 객체의 상태를 변경하는 메서드들이 주로 사용하는 방식으로, 동일한 객체에 연속적인 설정을 할 때 유용합니다.
    
2. **새로운 객체 반환**: 데이터를 변환하는 메서드들이 사용하는 방식으로, 원본은 유지한 채 새로운 결과물을 만들어 전달합니다. **배열 메서드와 `Promise`가 이 방식에 해당합니다.**
    
    ```JavaScript
    const numbers = [1, 2, 3, 4];
    
    // filter는 '새로운 배열'을 반환하고,
    // map은 그 새로운 배열에 대해 실행된 후 '또 다른 새로운 배열'을 반환합니다.
    const result = numbers.filter(n => n % 2 === 0).map(n => n * 2);
    
    console.log(result); // [4, 8]
    ```
    

---

### Promise와 메서드 체이닝

`Promise`는 메서드 체이닝의 대표적인 예시입니다.

- 비동기 함수(`orderPizza`)가 **`Promise` 객체**를 반환합니다.
- `.then()` 메서드는 그 `Promise`를 받아 실행된 후, **새로운 `Promise` 객체**를 또 반환합니다.
- 그 새로운 `Promise` 객체에 다시 `.catch()`나 다른 `.then()`을 연결하는 것입니다.
    

이처럼 `Promise`는 체이닝 구조를 통해 복잡한 비동기 작업을 순차적이고 읽기 쉽게 표현할 수 있습니다.
