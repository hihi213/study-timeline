## 정리

- **데이터의 존재 여부를 while의 조건문으로 활용**
	- 보통은 인덱스가 끝날때까지와 같은 범위 중심으로 활용하지만 값이 존재하는가? 라는 상태도 활용가능하다.
```Python
#연속된 구간의 길이 측정
while target in num_dict:
    target += 1
    cnt += 1 #연속길이 측정
```
