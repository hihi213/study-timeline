### List 값을 key, 인덱스를 value로 저장
```Python
dict = defaultdict(list) 
for i, value in enumerate(data): 
	dict[value].append(i)
```
### 객체의 진리값 직접 활용해 객체의 길이확인 생략하자
파이썬의 모든 객체는 조건식에서 `bool` 값으로 평가됩니다. `len(stack) > 0`과 같은 수치 비교를 생략하고 객체 자체를 조건문에 넣는 것이 권장됩니다.
> **거짓(Falsy):** `None`, `0`, `0.0`, `""`(빈 문자열), `[]`(빈 리스트), `()`(빈 튜플), `{}`(빈 딕셔너리)
> **참(Truthy):** 위 항목을 제외한 모든 상태 (데이터가 존재할 때)

```Python
# 스택에 값이 있을 때만 꺼내기
if stack: #`len() > 0`과 같은 수치 비교를 생략
    item = stack.pop()

# 스택이 비어 있어야 True 반환
return not stack # len(stack) == 0 대신 'not'을 활용해 가독성 
```

### 데이터가 존재하는 동안에만 반복

- 고정된 횟수(`range`) 대신 데이터의 **존재 여부**를 루프의 조건으로 삼으면 로직이 훨씬 선언적이고 명확해집니다.
- `set`이나 `dict`와 결합할 경우 존재 여부 확인에 $O(1)$의 시간 복잡도가 소요되어 효율적인 탐색이 가능합니다.

```Python
# 다음 연속된 숫자가 해시 맵에 존재하는 동안만 탐색 유지
while next_val in num_set:
    next_val += 1
    length += 1
```

### 안전한 에러 차단과 기본값 할당이 필요할 때, 단축 평가를 활용하자

논리 연산자(`or`, `and`)가 결과가 확정되는 즉시 연산을 멈추는 특성을 활용합니다.

#### **핵심 원리: 값의 반환과 평가 생략**

* **Java와의 차이점:** Java의 `||`, `&&`는 결과로 무조건 `boolean`을 반환하지만, 파이썬은 **결과를 결정지은 값 그 자체**를 반환합니다.
* **평가 생략:** 앞의 조건으로 결과가 확정되면 뒤의 함수 호출이나 연산은 **아예 실행되지 않습니다(Lazy Evaluation).**

#### **활용 A: 안전한 기본값 할당 (Default Value)**

데이터가 없거나(`None`), 비어있을 때 발생할 수 있는 예외 상황을 한 줄로 처리합니다.

```python
# input_name이 Falsy하면 "Anonymous"를 할당
user_name = input_name or "Anonymous"
```

#### **활용 B: 선제적 에러 차단 (Guard Clause)**

에러를 유발할 수 있는 '위험한 연산' 앞에 안전망 조건을 배치합니다.

* **IndexError 방지:** 스택이 비어있는 상태(`not stack`이 True)라면 뒤의 `pop()`은 실행되지 않습니다.
* **AttributeError 방지:** 객체가 `None`인지 먼저 확인한 후 내부 속성에 접근합니다.

```python
# 1. 스택 예외 방지: 비어있으면 뒤쪽 pop()을 실행하지 않고 즉시 True 반환으로 조건문 실행
if not stack or stack.pop() != target:
    return False

# 2. 참조 예외 방지: user가 존재할(Not None) 때만 .name에 접근
if user and user.name == "Admin":
    print("관리자 권한 확인")

```
