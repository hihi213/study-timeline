## 정리

- **데이터의 존재 여부를 while의 조건문으로 활용**
	- 보통은 인덱스가 끝날때까지와 같은 범위 중심으로 활용하지만 값이 존재하는가? 라는 상태도 활용가능하다.
```Python
#연속된 구간의 길이 측정
while target in num_dict:
    target += 1
    cnt += 1 #연속길이 측정
```

- **반환값 및 조건으로 빈 객체는 False, 차있는 객체는 True 이용**
    - 보통은 `len(s) == 0`과 같이 길이를 수치로 명시하여 비교하지만, 파이썬에서는 **'빈 객체는 False, 차있는 객체는 True'**라는 성질을 이용해 더 직관적인 코드로 대체 가능하다.

```Python
# (Valid Parentheses 문제의 마지막 리턴)
# 스택이 비어있음(False) -> not False -> True 반환 (성공)
# 스택이 남아있음(True) -> not True -> False 반환 (실패)
return not stack 
``` 

- **값이 존재할 때만 실행하는 조건문**
    - `if len(list) > 0` 처럼 개수를 세는 대신, **'존재하면 참'**이라는 논리를 사용하여 가독성을 높인다.

```Python
# 리스트에 처리할 원소가 남아있다면 실행
if openstack:
    # pop 등의 로직 수행
    close = openstack.pop()
```
 
- **논리 연산자 `or`를 활용한 간결한 기본값(Default) 할당**
    - 보통은 `if`문으로 값이 비어있는지(`None`, `""`, `0`) 확인하여 처리하지만, 앞의 값이 거짓(Falsy)이면 뒤의 값을 반환하는 `or` 연산자의 성질을 이용해 한 줄로 처리한다.

```Python
# input_name이 빈 문자열("")이나 None이면 False로 취급되어 뒤의 "Unknown"이 할당됨
name = input_name or "Unknown"
```
