## 정리
### 객체의 진리값 직접 활용해 객체의 길이확인 생략하자
> 파이썬의 모든 객체는 내용이 있으면 `True`, 비어있으면 `False`로 평가되는 고유의 성질을 가집니다. 이를 활용하면 `len() > 0`과 같은 수치 비교를 생략할 수 있습니다.

```Python
# 스택에 값이 있을 때만 꺼내기
if stack:
    item = stack.pop()

# 스택이 비어 있어야 True 반환
return not stack
```

### 데이터가 존재하는 동안에만 반복

- `for i in range(n)`처럼 고정된 횟수를 범위내에 반복하는 대신, 특정 값이 **존재하는 동안만** 루프를 지속합니다.
- 해시 기반 자료구조(Set이나 딕셔너리)에서 연속된 데이터 탐색할때 매우 도움됨

```Python
# 다음 연속된 숫자가 해시 맵에 존재하는 동안만 탐색 유지
while next_val in num_set:
    next_val += 1
    length += 1
```

### 넣을 데이터가 없을경우, 기본값을 설정로직을 줄이자
>거짓을 의미함: `None`, `0`, `[]`, `""`
> 파이썬에는 `||`가 없고, 이때 쓰는 `OR`는 다른언어와 달리 추가적인 기능이 있다.
> 1. A를 실행한다.
> 	- 참이라면 b를 실행하지도 않고 바로 A를 반환한다
> 1. A가 거짓이라면 B를 실행한다
> `A or B`에서 `A`가 참이면 `A`를, `A`가 거짓이면 `B`를 반환한다.
> A가 참이면 B는 아예 실행(평가)하지 않는다.
> 그래서 삼한 연산자보다 문법이 간결해지니 OR를 쓰자
```Python
# input_name이 비어있으면(Falsy) "Anonymous"를 할당
user_name = input_name or "Anonymous" 

# not stack이 참이다(비어있다)-> 오른쪽 무시하고 조건문실행
# not stack이 거짓이다(차있다)-> 오른쪽(`stack.pop() != target_value`)을 실행해 판단
#스택이 비어있으면(참이면) 즉시 멈추고 `if`문을 실행해라. 아니면(거짓이면) 그때 비로소 `pop()`을 해라
#비교 연산(`!=`)이 논리 연산(`or`)보다 먼저 적용된다

if not stack or stack.pop() != target_value
	return False
```
