## 내용
- ### **1. IDE(예: 인텔리제이)에서 실행** 
	- 인텔리제이에서 실행하는 방식은 .jar 파일을 만들지 않고, 내부에서 클래스 파일을 컴파일한 뒤 메모리에 직접 올려 실행한다. 이 방식은 빠르고 개발 중 테스트나 디버깅에 적합하다. 다만 배포용으로는 적절하지 않다. 
- --- 
- ### **2. Gradle 빌드 (./gradlew build)** 
	- Gradle은 프로젝트의 build.gradle 파일을 기반으로 컴파일, 테스트, 의존성 다운로드, .jar 파일 생성 등을 수행한다. 
	- 결과물로는 build/libs/ 디렉토리 아래에 실행 가능한 .jar 파일이 생성된다. 이 .jar는 필요한 설정 파일, 라이브러리, 스프링부트 자체 및 내장 톰캣까지 포함된 완성된 실행 파일이다.
	- ### **2_1. jar파일 실행** 
	- 생성된 .jar 파일은 다음과 같이 명령어로 실행할 수 있다. 
	- java -jar hello-spring-0.0.1-SNAPSHOT.jar Java가 설치된 어떤 환경에서든 동일하게 실행할 수 있고, 별도의 WAS 설치 없이 서버처럼 동작한다.
	- ### **2_2. Docker 이미지로 실행** 
	- Docker는 운영체제 환경과 .jar 파일을 함께 묶어서 이미지로 만든다. 이 이미지를 기반으로 컨테이너를 실행하면, 어떤 운영체제에서든 동일한 환경으로 애플리케이션을 실행할 수 있다. 운영 환경에서의 일관성을 보장하고, 배포 자동화(CI/CD)에도 적합하다.
