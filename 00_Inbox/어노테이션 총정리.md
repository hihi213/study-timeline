## 정리

0) 메타 어노테이션(기본 규칙)
	•	@Target : 적용 위치 지정 (TYPE, METHOD, FIELD, PARAMETER 등)
	•	@Retention : 유지 범위 (SOURCE / CLASS / RUNTIME)
	•	@Documented : Javadoc에 포함
	•	@Inherited : 하위 클래스가 상속
	•	@Repeatable : 같은 어노테이션을 여러 번 사용

1) 순수 Java(SE)
	•	@Override : 오버라이드 검증
	•	@Deprecated : 사용 지양 표시
	•	@SuppressWarnings : 경고 억제
	•	@FunctionalInterface : 함수형 인터페이스 보장
	•	@SafeVarargs : 가변 제네릭 안전 선언

2) Jakarta(구 javax) 일반
	•	@PostConstruct / @PreDestroy : 빈 초기화/소멸 훅
	•	@Resource : 리소스 주입(스프링에선 잘 안 씀)

3) Spring Core/Boot
	•	구성/스캔
	•	@SpringBootApplication (메인)
	•	@Configuration + @Bean (자바 설정/빈 등록)
	•	@Component / @Service / @Repository / @Controller / @RestController (빈 역할)
	•	@ComponentScan, @Import, @Profile, @Primary, @Lazy, @Scope, @Order
	•	주입/프로퍼티
	•	@Autowired, @Qualifier (빈 주입)
	•	@Value (단일 값 주입)
	•	@ConfigurationProperties / @ConfigurationPropertiesScan (설정 바인딩)
	•	조건부/자동 설정
	•	@EnableAutoConfiguration
	•	@ConditionalOnProperty / @ConditionalOnClass / @ConditionalOnMissingBean 등

4) Spring MVC(Web)
	•	핸들러 매핑[[00_Inbox/핸들러매핑.md|핸들러매핑]]
	•	@RequestMapping, @GetMapping/@PostMapping/@PutMapping/@DeleteMapping/@PatchMapping
	•	요청/응답 바인딩
	•	@RequestParam, @PathVariable, @RequestBody, @RequestHeader, @CookieValue, @ModelAttribute
	•	@ResponseBody, @ResponseStatus, @CrossOrigin
	•	예외 처리
	•	@ExceptionHandler, @ControllerAdvice, @RestControllerAdvice
	•	검증 훅
	•	@Validated (메서드/컨트롤러 단 검증 트리거) ^8308g9

5) 데이터/JPA(Hibernate 포함)
	•	엔티티/매핑
	•	@Entity, @Table, @Id, @GeneratedValue, @Column, @Enumerated, @Lob, @Transient, @Version
	•	관계
	•	@OneToOne, @OneToMany, @ManyToOne, @ManyToMany, @JoinColumn, @JoinTable
	•	하이버네이트 확장(선택)
	•	@CreationTimestamp, @UpdateTimestamp, @BatchSize, @DynamicInsert, @DynamicUpdate, @Type

6) Bean Validation(검증)
	•	제약
	•	@NotNull, @NotBlank, @NotEmpty, @Size, @Email, @Pattern,
@Positive/@PositiveOrZero, @Negative, @Past/@Future 등
	•	조합
	•	@Valid (중첩 객체 검증)
	•	커스텀 제약: @Constraint + Validator 구현

7) 보안(Spring Security)
	•	구성
	•	@EnableWebSecurity
	•	메서드 권한
	•	@PreAuthorize, @PostAuthorize, @Secured, @RolesAllowed
	•	테스트
	•	@WithMockUser, @WithUserDetails

8) Jackson(JSON 직렬화)
	•	필드/이름/포맷
	•	@JsonProperty, @JsonIgnore, @JsonIgnoreProperties, @JsonInclude, @JsonFormat
	•	생성/값
	•	@JsonCreator, @JsonValue
	•	고급: @JsonSerialize/@JsonDeserialize

9) Lombok(보일러플레이트 제거)
	•	데이터/생성자/빌더
	•	@Getter/@Setter, @ToString, @EqualsAndHashCode, @Data, @Value(불변),
@Builder, @AllArgsConstructor, @NoArgsConstructor, @RequiredArgsConstructor
	•	로깅
	•	@Slf4j 등

10) AOP/스케줄/비동기/캐시/트랜잭션
	•	AOP: @Aspect, @Before, @AfterReturning, @AfterThrowing, @Around, @Pointcut, @EnableAspectJAutoProxy
	•	스케줄: @Scheduled, @EnableScheduling
	•	비동기: @Async, @EnableAsync
	•	캐시: @Cacheable, @CachePut, @CacheEvict, @EnableCaching
	•	트랜잭션: @Transactional, @EnableTransactionManagement

11) 테스트(JUnit 5 + Spring Test)
	•	JUnit 5: @Test, @BeforeEach, @AfterEach, @BeforeAll, @AfterAll, @DisplayName, @Nested, @Disabled, @ParameterizedTest
	•	Spring 테스트: @SpringBootTest, @WebMvcTest, @DataJpaTest, @AutoConfigureMockMvc, @MockBean, @ExtendWith(SpringExtension.class), @ActiveProfiles

⸻

빠른 기억 포인트
	•	설정/구성은 @Configuration, 빈 등록은 @Bean, 역할 구분은 @Component 계열.
	•	웹 레이어는 @RestController + @Get/Post…Mapping + @RequestBody/@PathVariable.
	•	영속성은 @Entity + 관계 매핑 + @Transactional.
	•	검증은 DTO에 Bean Validation + 컨트롤러에 @Validated.
	•	직렬화 제어는 Jackson 어노테이션.
	•	보안 권한은 메서드에 @PreAuthorize("hasRole('ADMIN')") 식으로.

필요하면 특정 카테고리를 깊게(예: JPA 관계 전부, Security 전부) 파고드는 버전도 만들어 줄게.
