## **엔티티/매핑**

- @Entity : JPA가 관리하는 **엔티티 클래스**임을 선언(테이블과 매핑 대상).
    
- @Table(name="...") : 매핑될 **테이블/스키마/인덱스**를 지정.
    
- @Id : **기본키(PK) 필드** 지정.
    
- @GeneratedValue(strategy=...) : PK **생성 전략**(IDENTITY/SEQUENCE/TABLE/AUTO) 지정.
    
- @Column(name="...", nullable=..., length=..., unique=...) : **컬럼명/널/길이/유니크** 등 매핑 옵션.
    
- @Enumerated(EnumType.STRING) : **enum을 문자열로 저장**(ORDINAL은 순서 변경 위험으로 지양).
    
- @Lob : **대용량** CLOB/BLOB 컬럼 매핑.
    
- @Transient : **영속성 제외**(컬럼 생성/저장 안 함).
    
- @Version : **낙관적 락킹**용 버전 컬럼(동시성 충돌 방지).
    

  

## **관계**

- @OneToOne : **1:1 관계**(FK 한쪽에 있음, LAZY 설정 주의).
    
- @OneToMany : **1:N**(보통 **역방향**; 주인은 N쪽, 단방향이면 FK 또는 **조인 테이블** 필요).
    
- @ManyToOne : **N:1**(**주인/ FK 가진 쪽** → 여기 변경이 DB에 반영).
    
- @ManyToMany : **N:N**(기본은 **연결 테이블** 자동; 실무는 **연결 엔티티**로 분해 권장).
    
- @JoinColumn(name="...") : **FK 컬럼** 위치/이름 지정(“여기가 주인/시작점”).
    
- @JoinTable(name="...", joinColumns=..., inverseJoinColumns=...) : **연결(조인) 테이블**로 관계 관리(행 INSERT/DELETE).
    

  

## **하이버네이트 확장(선택)**

- @CreationTimestamp : INSERT 시 **생성시각 자동** 기록.
    
- @UpdateTimestamp : UPDATE 시 **수정시각 자동** 갱신.
    
- @BatchSize(size=...) : 컬렉션/연관 로딩을 **묶음으로 조회**(N+1 완화).
    
- @DynamicInsert : **값 있는 컬럼만 INSERT**(DB default 활용).
    
- @DynamicUpdate : **변경된 컬럼만 UPDATE**.
    
- @Type(...) : 하이버네이트 **사용자 정의/특수 타입** 매핑(JSON 등).
    

  

## **값 타입(임베디드)**

- @Embeddable : **값 타입 정의** — _“이 Address_ **_테이블은 없어_**_._ **_소유 엔티티 테이블에 내장(평탄화)_** _되는 거야.”_
    
    _(소유측에서_ _@Embedded__로 포함해 사용)_
