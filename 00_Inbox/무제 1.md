## 🐍 파이썬 로직 최적화 및 효율적 조건문 정리

### 1. 객체의 진리값(Truthiness) 직접 활용

파이썬의 모든 객체는 조건문에서 참(`True`) 또는 거짓(`False`)으로 평가되는 고유의 성질을 가집니다. 이를 활용하면 `len()` 호출이나 명시적 비교를 생략하여 가독성을 높일 수 있습니다.

- **거짓(Falsy)으로 평가되는 객체:** `None`, `0`, `0.0`, `[]`(빈 리스트), `""`(빈 문자열), `{}`(빈 딕셔너리) 등
- **활용:**
    
    Python
    
    ```sql
    # 리스트에 값이 있는지 확인 (len(stack) > 0 대신 사용)
    if stack:
        item = stack.pop()
    
    # 리스트가 비어있는지 확인 (len(stack) == 0 대신 사용)
    if not stack:
        return "Empty"
    ```
    

### 2. 존재 기반의 동적 반복 (While Loop)

고정된 범위를 순회하는 `for`문과 달리, 특정 조건이나 데이터가 **존재하는 동안만** 루프를 지속해야 할 때 `while`문을 사용합니다. 특히 해시(Set, Dict)와 결합할 때 강력합니다.

- **장점:** 탐색 범위가 가변적일 때 효율적이며, 연속된 데이터의 끝을 모를 때 유용합니다.
    
    Python
    
    ```sql
    # 해시 셋(num_set) 내에 연속된 숫자가 존재하는 동안만 탐색
    while next_val in num_set:
        next_val += 1
        length += 1
    ```
    

### 3. `or` 연산자의 단락 평가(Short-circuit) 및 값 반환

파이썬의 `or`는 단순한 논리 연산 이상의 **선택기(Selector)**와 **안전장치(Guard)** 역할을 수행합니다.

#### ① 기본값 설정 (삼항 연산자 대용)

`A or B` 구조에서 파이썬은 **A가 참이면 A를 반환하고, A가 거짓일 때만 B를 계산하여 반환**합니다.

Python

```sql
# input_name이 비어있으면 "Anonymous"가 최종 할당됨
user_name = input_name or "Anonymous"
```

#### ② 안전장치(Guard Clause)로서의 활용

`if A or B:` 구조에서 A가 참으로 판명되면 B는 아예 실행조차 하지 않는 성질을 이용해 에러를 방지합니다.

- **핵심 로직 분석:** `if not stack or stack.pop() != target_value:`
    
    1. **우선순위:** 비교 연산(`!=`)이 논리 연산(`or`)보다 먼저 적용됩니다.
    2. **안전장치:** `not stack`이 참(비어있음)이면, 오른쪽의 `stack.pop()`은 **실행되지 않습니다.** (IndexError 방지)
    3. **순차 검사:** 스택이 차 있을 때만(`not stack`이 거짓), 오른쪽의 `pop()`을 실행하여 값을 비교합니다.
