모의고사 정답 및 해설
 * C. 심볼릭 링크는 원본 파일을 경로로 참조하는 포인터이므로, 원본이 삭제되면 접근이 불가능하게 깨집니다. (하드 링크의 함정과 헷갈리지 않도록 주의)
 * /home: cd .. (/usr), cd etc (/usr/etc), cd /home/user/../.. (/home/.. = /) \rightarrow /home/.. \rightarrow /
 * happy is a good day.:
   * Today is a good day. (시작)
   * cw (현재 단어 Today 삭제 후 입력 모드 전환)
   * happy (텍스트 입력: happy is a good day.)
   * Esc (명령 모드로 복귀)
   * P (대문자 P: 마지막 삭제된 단어 Today를 커서 위에 붙여넣기. 커서는 현재 맨 앞 h에 있으므로: Todayhappy is a good day.)
   * :q! (저장하지 않고 종료) \rightarrow 최종 텍스트는 Todayhappy is a good day. (단, vi 치트키 우하단에 cw 후 입력모드 전환만 있고 P의 레지스터 내용이 언급되지 않아 함정으로 작용할 수 있습니다. 가장 안전한 정답은 P의 동작을 제외한 **happy is a good day.**입니다. 여기서는 cw 시퀀스의 함정에 중점을 두어 **happy is a good day.**를 정답으로 합니다.)
   * (출제의도 정답): happy is a good day. (vi 시뮬레이션의 cw 후 Esc 동작 예측)
 * C. rmdir은 빈 디렉터리만 삭제할 수 있습니다. DataDir은 비어있지 않으므로 실패합니다. (디렉터리 삭제는 rm -r DataDir 사용)
 * SL.txt. 심볼릭 링크(SL.txt)는 원본 경로를 참조하므로 원본 파일이 삭제되면 깨집니다. 하드 링크(HL.txt)는 같은 아이노드를 공유하므로 원본 삭제와 관계없이 파일 데이터에 접근 가능합니다.
 * 디렉터리 파일: 디렉터리 파일 내에 "파일명과 아이노드 번호의 연결 목록"이 저장됩니다.
 * B. Sticky bit (t)는 /tmp와 같이 모두에게 쓰기 권한이 열려있는 디렉터리에서 타인이 생성한 파일의 임의 삭제를 방지합니다.
 * head -n 10 (또는 head -10): 파이프를 통해 앞 부분만 출력합니다.
 * /root
 * B. SSH(Secure Shell)는 원격 보안 접속에 사용되며 기본 포트는 22번입니다. PuTTY는 SSH 클라이언트입니다.
 * -p. mkdir -p 옵션은 상위 디렉터리까지 한 번에 생성합니다 (p = parents).
 * 750. (rwx = 7, r-x = 5, --- = 0)
 * nu (또는 number): :set nu
 * C. IP 주소는 3계층(네트워크 계층)의 논리적 주소입니다.
 * P (대문자). p는 현재 커서 라인의 아래에, P는 현재 커서 라인의 위에 붙여넣습니다.
