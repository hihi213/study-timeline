### 객체의 진리값 직접 활용해 객체의 길이 확인 연산 생략하자
> 파이썬의 모든 객체는 내용이 있으면 `True`, 비어있으면 `False`로 평가되는 **진리값(Truthiness)**을 가집니다.

```Python
# 스택에 값이 있을 때만 꺼내기
if stack:
    item = stack.pop()

# 스택이 비어 있어야 True 반환
return not stack
```

### 데이터가 존재하는 동안에만 반복

- `for i in range(n)`처럼 고정된 횟수를 반복하는 대신, 특정 값이 **존재하는 동안만** 루프를 지속합니다.
- 해시 기반 자료구조(Set이나 딕셔너리)에서 연속된 데이터 탐색할때 매우 도움됨

```Python
# [지속] 다음 연속된 숫자가 해시 맵에 존재하는 동안만 탐색 유지
while next_val in num_set:
    next_val += 1
    length += 1
```

### 넣을 데이터가 없을경우의 기본값을 설정할때의 로직을 줄이자
> 파이썬에선 OR의 왼쪽 값이 거짓(`None`, `""`, `0`, `[]`)이면 오른쪽 값을 선택하는 성질이 있다.
- **강점:** 복잡한 `if-else` 기본값 할당 로직 대신 데이터의 부재를 **예외 처리의 기회**로 활용합니다.

```Python
# [대체] input_name이 비어있으면(Falsy) "Anonymous"를 할당
user_name = input_name or "Anonymous"
```
