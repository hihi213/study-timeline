제공된 내용을 바탕으로 배열과 개별 변수의 주요 차이점 및 배열의 특징을 정리했습니다.

## 1. 메모리 할당과 접근 방식
컴퓨터는 이름이아닌 오직 주소값으로 메모리에 접근합니다
- **개별 변수 (`int a1, a2, a3;`)**
    - 메모리상에 **연속적으로 위치한다고 보장할 수 없습니다.** 중간에 다른 시스템이 공간을 사용하면 건너뛰게 됩니다.
    - 설령 컴파일러가 연속적으로 배치하더라도, 각 변수의 주소는 독립적이어서 각 변수에 접근하려면 `a1`, `a2`, `a3`의 고유한 주소를 각각 알아야 합니다. (Direct Addressing) 즉 포인터 연산(`a1 + 1`)을 통한 순회가 불가능합니다.
- **배열 (`int a[3];`)**
    - **연속된 메모리 공간** 할당이 보장됩니다.
	- 배열의 이름(`a`)은 그 자체로 시작 주소를 가리키는 **상수 포인터(constant pointer)** 역할을 합니다.
    - **배열:** `grade[50]`을 사용하면, 시작 주소를 **베이스 레지스터(Base Register)** 에, 인덱스 `i`를 **인덱스 레지스터(Index Register)** 에 넣습니다.
    - CPU는 `base + (i * 자료형의 크기)` 공식을 통해 다음 위치를 **계산**하므로, 매번 새로운 주소를 불러올 필요 없이 매우 빠릅니다.

---

## 2. 접근 효율성과 CPU 연산 ⚡

- **개별 변수:** `grade1`, `grade2` 등 50개의 변수에 접근하려면, CPU는 50번의 **직접 주소 지정**을 위해 각 변수의 주소를 메모리 주소 레지스터(MAR)에 개별적으로 실어야 합니다.
- **배열:** `grade[50]`을 사용하면, 시작 주소를 **베이스 레지스터(Base Register)** 에, 인덱스 `i`를 **인덱스 레지스터(Index Register)** 에 넣습니다. CPU는 `base + (i * 자료형의 크기)` 공식을 통해 다음 위치를 **계산**하므로, 매번 새로운 주소를 불러올 필요 없이 매우 빠릅니다.

---

## 3. 배열의 핵심 전제: 동일한 자료형

- 배열이 위와 같이 효율적으로 동작하려면(즉, `+1` 연산이 올바르게 다음 요소를 가리키려면), 모든 원소가 **반드시 동일한 자료형(type)** 이어야 합니다.
- `+1`이라는 상대적 연산은 컴파일러에 의해 '자료형의 크기만큼 건너뛰기'(예: `int`는 4바이트, `char`는 1바이트)로 변환됩니다.
	- 만약 `int`와 `char`가 섞여 있다면, `+1` 연산이 4바이트를 건너뛰어 `char`를 건너뛰고 엉뚱한 메모리 위치를 가리키게 됩니다.
- **구조체 배열** (`struct card c[20];`)도 마찬가지입니다. `struct card`라는 자료형 20개가 연속으로 붙어있는 것이며, `c+1`은 `sizeof(struct card)`만큼 주소를 건너뜁니다.

---

## 4. 포인터 변수의 본질

- `struct card* k`나 `char* cp` 같은 포인터 변수 자체는, 그저 **메모리 주소 값**을 저장하기 위한 공간(예: 32비트 시스템에서 4바이트)일 뿐입니다.
- `struct card*`와 같은 타입은 "이 주소에 가면 `struct card` 구조체가 있다"라고 컴파일러에게 알려주어, 포인터 연산 시 이동할 거리(즉, `sizeof(struct card)`)를 계산할 수 있게 합니다.

---

## 5. 초기화 및 메모리 안전성 ⚠️

- **초기화 (0으로 채우기):** `int a[7] = {2, 3, 5};`처럼 배열 크기보다 적은 값으로 초기화하면, 나머지 원소(`a[3]`~`a[6]`)는 **자동으로 0으로 채워집니다.** (선언만 한 일반 변수의 쓰레기 값과 다릅니다.)
- **초기화 (크기 자동 할당):** `int a[] = {2, 3, 5, 7};`처럼 크기를 생략하면, 초기값의 개수(4개)만큼 크기가 자동으로 할당됩니다.
- **문자열 배열:** `char s[] = "abc";`는 문자열의 끝을 알리는 **널 문자(`\0`)**를 포함하므로, 배열의 크기는 3이 아닌 4가 됩니다.
- **범위 검사 (Bounds Checking):**
    - C언어는 `int a[4];` 선언 후 `a[5]`처럼 범위를 벗어난 인덱스에 접근해도 **오류를 발생시키지 않습니다.** (Java는 `ArrayIndexOutOfBoundsException` 예외 발생)
    - 이는 C의 주요 **메모리 취약점(vulnerability)**이며, 프로그래머는 항상 배열의 범위를 벗어나지 않도록 코딩해야 합니다.
## 6. 배열의 추상 자료형 (ADT)

배열은 다음과 같은 기본 연산을 갖는 추상 자료형으로 볼 수 있습니다.

- **`create`**: 배열을 생성합니다.
- **`retrieve(A, i)`**: 배열 A의 `i`번째 요소를 반환합니다.
- **`store(A, i, item)`**: 배열 A의 `i`번째 위치에 `item`을 저장합니다.
