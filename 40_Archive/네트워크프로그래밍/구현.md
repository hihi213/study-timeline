각 항목을 **어떻게 구현할지**, 구체적인 모듈/함수 구성과 흐름을 단계별로 정리해드릴게요:

---

### **✅ 1. TCP 소켓 + 커스텀 메시지 처리**

  

**목표**: REGISTER, TERMINATE, STATUS, ALERT 명령어 기반 커스텀 프로토콜 구현

```
// Common.h
typedef enum {
    REQUEST_REGISTER,
    REQUEST_TERMINATE,
    REQUEST_STATUS,
    REQUEST_ALERT
} RequestType;

typedef struct {
    RequestType type;
    int resource_id;
    int usage_time;     // 사용 시간 (분)
    int alert_time;     // 알림 시간 (분)
    long timestamp;
} RequestPacket;
```

**서버 흐름**:

```
// server.c
1. socket(), bind(), listen()
2. accept() 후 fork() or select()
3. recv()로 RequestPacket 수신
4. 명령어에 따라 자원 상태 변경
5. 상태 변경 응답 전송
```

---

### **✅ 2. select()/poll() 기반 다중 접속**

  

**목표**: 다수의 클라이언트를 동시에 처리

```
// main.c
fd_set read_fds;
FD_SET(server_fd, &read_fds);
select(max_fd+1, &read_fds, NULL, NULL, NULL);
```

- 클라이언트가 접속 → accept() 후 client_fd를 목록에 추가
    
- recv() → 등록 요청이면 세션 구조체에 등록
    

---

### **✅ 3. 세마포어 + 동시성 제어**

  

**목표**: 여러 클라이언트가 동시에 같은 자원을 등록하거나 수정하지 못하게 함

```
// session.c
sem_t resource_locks[MAX_RESOURCES];
sem_wait(&resource_locks[resource_id]);
// 상태 변경
sem_post(&resource_locks[resource_id]);
```

---

### **✅ 4. 예약 만료 시간 처리 (**

### **alarm()**

###  **or 타이머 스레드)**

  

**목표**: 등록된 자원에 대해 사용 시간 종료 시 자동 알림

```
// timer.c
void* countdown_timer(void* session) {
    sleep(usage_time * 60);
    send_alert_to_client();
}
```

- pthread_create()로 자원마다 타이머 생성
    
- 종료 시 상태를 DONE 또는 ALERT로 변경
    

---

### **✅ 5. 상태 동기화 (Delta Sync)**

  

**목표**: 클라이언트가 재연결했을 때 최신 자원 상태만 전송

```
// sync.c
typedef struct {
    int resource_id;
    MachineStatus new_status;
    long changed_at;
} SyncRecord;

SyncRecord delta_log[MAX];
```

- 자원 상태가 변경될 때마다 delta_log에 저장
    
- 클라이언트가 REQUEST_STATUS 전송 시 해당 시각 이후만 응답
    

---

### **✅ 6. 재연결 로직 (Backoff)**

  

**목표**: 클라이언트가 서버에 연결 실패 시 점진적으로 대기 시간 증가

```
// backoff.c
int retry = 0;
int wait_time = pow(2, retry);  // 1s, 2s, 4s ...
sleep(wait_time);
retry++;
```

- 최대 5회까지 재연결 시도
    
- 연결되면 heartbeat 재개
    

---

### **✅ 7. 단순 알림 구조 (CLI 메시지)**

  

**목표**: 알림 메시지를 콘솔 기반으로 확인

```
// client.c
if (recv_msg.type == REQUEST_ALERT) {
    printf("🔔 알림: 자원 %d 사용 종료가 임박했습니다!\n", recv_msg.resource_id);
}
```

---

### **✅ 전체 흐름 요약 (서버 기준)**

```
[클라이언트] → REGISTER → [서버]
[서버] → 사용 시간 타이머 시작, 세션 등록
[타이머 만료] → 상태 ALERT 전환 + CLI 알림
[클라이언트 재접속] → Delta Sync 전송
[알림 미응답] → 상태 DONE 전환
```
