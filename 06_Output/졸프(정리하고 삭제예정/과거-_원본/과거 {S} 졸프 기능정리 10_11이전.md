# 10주 MVP 기능 정리 (기능 설명만) — **2인 검사 세션 유지 + 폴링 실시간**

*(SSE는 R1 하드닝 스프린트에서 도입)*

## 1) 인증·권한

* **로컬 로그인**: 아이디/비밀번호 → 짧은 수명의 액세스 토큰.
* **내 정보 조회**: 로그인 상태/역할 확인.
* **역할 가드**: `ADMIN / INSPECTOR / USER` 접근 제어.
* **계정 상태**: 비활성 계정 로그인 차단.
* **간단 브루트포스 완화**: 로그인 실패 횟수 제한 및 쿨다운(429).

## 2) 자원(냉장 칸)·물품 관리

* **칸 목록 조회**: 운영 상태(사용 가능/고장) 포함.
* **물품 등록**: 칸+라벨 번호로 등록(활성 중 라벨 번호 중복 불가).
* **물품 검색/필터**: 내 물품, 칸별, 키워드 조회.
* **물품 변경**
  * `수정(adjust)`: 수량/유통기한/메모 갱신.
  * `전량 제거(remove-all)`: 폐기/소진 처리 후 라벨 재사용 가능.
* **번호 충돌 가이드**: 라벨 중복 시 표준 오류 + UI 가이드.

> 참고: **개별 아이템(이름/유통기한/부분 제거)** 은 포스트-MVP.

## 3) 검사(Inspection) — **2인 세션 + 단일 제출**

* **세션 열기/참여/나가기**: 한 칸에 **진행 세션 1개**.
* **동시 참여 인원**: 최대 2명(3번째 거절).
* **검사 중 쓰기 차단**: 해당 칸 일반 등록/변경은 **423 Locked**로 거절.
* **조치 기록**: `PASS / WARNING / DISCARD / DISCARD_WITH_PENALTY`
  (스티커 없는 물품은 ‘미등록 폐기’ 기록 가능)
* **제출(멱등)**: 1회 제출 후 결과 **불변**(수정 시 사유와 리비전 기록).

## 4) 벌점

* **원본 벌점 자동 생성**: 검사 **제출 시** 위반 결과에 따라 자동 반영(수정/삭제 불가).
* **조정 벌점**: 운영자가 +/- 조정(사유 필수, 0 금지).
* **집계 조회**: 원본 합 + 조정 합 = **최종 점수**(사용자별/기간별).

## 5) 실시간(포그라운드 = **폴링**)

* **단일 폴링 엔드포인트**: `GET /events?after=<eventId>&limit=` 커서 기반 증분 수신.
* **대표 이벤트**:
  * 물품: `items.created / items.updated / items.removed`
  * 검사: `inspection.opened / joined / left / locked / action_recorded / submitted`
  * (선택) 벌점: `penalties.adjusted`
* **전달 보장**: **at-least-once**(클라이언트는 `event_id`로 중복 제거).
* **필터**: `resource_id / floor_code` 옵션, **긴 폴링(타임아웃)** 지원.

## 6) 오류·경합 처리(클라이언트 UX 기준)

* **RFC7807 오류 본문**: 코드/필드/사유/재시도 힌트 포함.
* **409/422/423/429** 사용 지침:
  * 409: 상태 충돌(라벨 중복, 동시 변경 등)
  * 422: 규칙 위반(의미적 유효성 실패)
  * 423: 해당 칸 **검사 중** 쓰기 금지
  * 429: 요청 과다(재시도 지시)
* **작성 멱등성**: Idempotency-Key 수용(중복 제출 동일 응답).

## 7) 보안 베이스라인

* **전송 보안**: HTTPS/HSTS, 보안 헤더(CSP 라이트 등).
* **입력 검증**: 스키마 검증 + 페이로드 크기 제한.
* **레이트리밋**: 사용자/IP 기준(로그인 쿨다운 포함).
* **민감정보 마스킹 로그**: 토큰/비번 식별자 마스킹.
* **상태 엔드포인트**: `/healthz`, `/readyz`(DB 연결/마이그 버전).

## 8) 운영·관측

* **구조화 로그(JSON)** + `correlation_id` 전파(요청→응답→이벤트 기록).
* **간단 문서 세트**: OpenAPI 스냅샷, 오류 카탈로그, 운영 런북(락/오류/폴링 재시도).
* **성능 가이드**: 대표 트래픽 p95 < **300ms** 목표.
* **이벤트 로그**: `event_log`에 도메인 이벤트 적재(폴링/향후 SSE 공용 소스).

## 9) 핵심 사용자 여정

* **입주자**: 로그인 → 칸 선택 → 물품 등록/조회/관리 → **폴링으로 변화 반영** → 검사 결과/내 벌점 보기
* **검사자**: 세션 개시/참여(2인) → 조치 기록 → **단일 제출** → 벌점 자동 반영 확인
* **관리자**: 칸 상태(사용/고장) 관리, 벌점 조정

## 10) 포스트-MVP로 이관(명확한 비범위)

* **SSE 실시간**: Last-Event-ID 복구/하트비트/다탭 공유.
* **PWA + Web Push**: 백그라운드 알림/오프라인 읽기.
* **Items v2**: 묶음/개별 분리(개별명/개별 유통기한/부분 제거).
* **권역 권한(층/존)**: 리스트/검사/예약 권역 필터링.
* **감사 로그/키 회전/정식 멱등 저장소** 등 하드닝.

# MVP 이후 기능 정리 (기능 설명만)

(MVP는 **2인 검사 세션 + 폴링 실시간**, 이후 R1에서 **SSE 도입**)

## 공통 원칙

* **실시간 전략**: 포그라운드=SSE, 백그라운드=Web Push(폴링은 폴백).
* **점진 배포**: 기능 플래그 + 카나리 → 점진 롤아웃/롤백.
* **호환 유지**: 기존 API 읽기 호환 기간 운영, 새/구 모델 병행 후 수축.

---

## R1 — 하드닝 ① + **SSE 도입**

* **SSE 실시간**: Last-Event-ID 복구, 하트비트, 중복 억제.
* **다탭 제어**: 단일 탭 공유/경합 최소화(브로드캐스트 기반).
* **작성 멱등성 강화**: Idempotency-Key 기반 동일 응답 보장.
* **오류 표준화**: RFC7807 카탈로그 확정(409/422/423/429 통일 메시지).
* **관측 강화**: API 지연/에러율, SSE 연결·드롭률 가시화.

## R2 — 알림 파이프라인 (이벤트→큐→전송)

* **예약·재시도 알림**: 지수 백오프·중복 억제·멱등 처리.
* **알림센터**: 배지·목록·읽음 처리, 딥링크 이동.
* **시나리오**: 유통기한 D-1, 검사 결과 통지, 운영 알림.
* **전달 채널**: 포그라운드(SSE 배지), 백그라운드(Push).

## R3 — PWA + Web Push

* **PWA 설치/오프라인(핵심 조회)**, 서비스워커 업데이트 전략.
* **푸시 구독/해지** 및 만료 구독 자동 정리.
* **딥링크**: 푸시 탭 → 대상 화면 진입.
* **iOS 가이드**: 홈 화면 추가 등 지원 범위 안내.

## R4 — **Items v2** (개별 아이템 관리)

* **개별 단위**: 아이템별 이름/유통기한/부분 제거.
* **목록/상세**: 개별 D-Day/상태 표시, 그룹↔개별 전환 뷰.
* **무중단 이행**: 확장 → 백필 → 새 API 전환 → 구 구조 수축.
* **실시간 키**: 묶음ID/개별ID 기반 이벤트로 정밀 갱신.

## R5 — 세탁실 ① (기본 사용/완료)

* **자원 타입 확장**: 세탁기/건조기.
* **사용 흐름**: 시작·진행 상태 표시·완료 처리.
* **동시 사용 금지**: 동일 장비 중복 시작 차단.

## R6 — 세탁실 ② (현장 이슈 대응)

* **미등록 사용** 처리 및 자동 복귀.
* **종료 임박 알림**(예: 5분 전).
* **고장 신고/운영 전환**: OUT-OF-SERVICE 시 사용 차단 및 안내.

## R7 — 스터디룸 ① (10분 슬롯 예약)

* **슬롯 생성**: 주간 정기 오픈.
* **예약/취소**: 겹침 방지 규칙, 내 예약 하이라이트.
* **타임라인 뷰**: 실시간 반영.

## R8 — 스터디룸 ② (운영 옵션)

* **합석 옵션** 설정.
* **관리자 강제예약** 및 해제.
* **휴무/블록** 기간 설정과 즉시 반영 알림.

## R9 — 권역 권한(층/존)

* **권역 할당**: 사용자별 접근 범위 지정.
* **권역 필터링**: 리스트/검사/예약 전반에 적용.
* **클라이언트 가드**: `/me` 권역 기반 라우팅/가드.

## R10 — 보안·관측·PWA 폴리싱

* **감사 로그(append-only)**: 고위험 액션 추적/검색.
* **키 회전/JWKS + 토큰 버전 무효화**: 강제 로그아웃/권한 변경 즉시 반영.
* **PWA 폴리싱**: 오프라인 캐시 무효화 전략, 설치/업데이트 UX 개선.
* **운영 대시보드**: 오류율/큐 적체/SSE 건강 상태 일원화.
