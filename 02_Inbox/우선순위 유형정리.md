## A-1. C·Java·Python 코드 실행 결과

가장 먼저 끝내야 할 영역입니다. 최근 기출의 최대 비중이며, 단순 문법 설명보다 **최종 출력값·변수값·자료구조 상태를 계산하는 문제**로 대비해야 합니다.

### C언어 핵심

반드시 풀어야 할 유형:

- 배열과 포인터의 등가 관계  
    `arr[i]`, `*(arr+i)`, `p[i]`
    
- 포인터 증감과 주소 이동
- 문자 배열과 문자열
- 반복문 안에서 배열값 변경
- 구조체와 구조체 포인터  
    `obj.member`, `ptr->member`
    
- 함수에 배열·포인터 전달 후 값 변화
- 2차원 배열의 인덱스 계산
- 전위·후위 증감 연산
- 출력 형식  
    `%d`, `%c`, `%x`, `%o`, 실수 자릿수
- 함수 포인터의 기본 선언·대입·호출

학습 깊이:

- 메모리 구조를 완벽히 설명할 필요는 없습니다.
- **각 줄을 실행했을 때 값이 어떻게 바뀌는지 표로 추적할 수 있는 수준**이면 됩니다.
- 함수 포인터는 복잡한 선언을 전부 암기하지 말고, “어떤 함수를 가리키고 어떤 값을 반환하는가”를 읽을 수 있어야 합니다.
    

### Java 핵심

반드시 풀어야 할 유형:

- 상속 시 생성자 호출 순서
- 오버라이딩과 동적 바인딩
- 오버로딩과 컴파일 시점 메서드 선택
- 부모 타입 참조변수와 자식 객체
- `static` 변수·메서드와 인스턴스 멤버
- 필드 숨김과 메서드 오버라이딩의 차이
- `super`
- 추상 클래스와 인터페이스
- 예외처리와 `finally`
- 문자열 연결 시 연산 순서
- 배열·객체 참조
- 재귀호출의 반환값
    

특히 다음을 구분해야 합니다.

- **오버로딩:** 매개변수의 선언 타입을 기준으로 선택
- **오버라이딩:** 실제 생성된 객체를 기준으로 실행
- **필드:** 참조변수 타입의 영향을 받음
- **인스턴스 메서드:** 실제 객체의 오버라이딩 메서드 실행
    

### Python 핵심

반드시 풀어야 할 유형:

- 슬라이싱  
    `[start:end:step]`, `[::-1]`, `[::-2]`
    
- 음수 인덱스
- 리스트의 별칭과 얕은 복사  
    `b=a`, `b=a[:]`, 중첩 리스트
    
- 리스트 컴프리헨션
- 가변 객체를 함수에 전달했을 때 원본 변경
- `range()`
- `split()`, `join()`
- 리스트·튜플·딕셔너리·집합
- `append`, `extend`, `+=`의 차이
- 문자열 필터링과 역순 처리
- 클래스·상속의 기본 실행 결과
    

2026년 1회에서 Python은 문자열 처리, 역방향 슬라이싱, 중첩 리스트의 얕은 복사처럼 **참조와 자료구조 변화 추적**이 중요하게 나타났습니다.

## A-2. SQL 직접 작성과 실행 결과

코드 다음으로 점수 효율이 높습니다. SQL은 읽기만 해서는 안 되고 **손으로 구문을 완성하는 문제**까지 준비해야 합니다.

### 조회·결과 계산

- `SELECT`, `WHERE`
- `DISTINCT`
- `COUNT(*)`, `COUNT(column)`
- `NULL`이 집계에서 제외되는 원리
- `SUM`, `AVG`, `MAX`, `MIN`
- `GROUP BY`, `HAVING`
- `ORDER BY`
- `LIKE`
- `IN`, `BETWEEN`, `IS NULL`
- 내부 조인
- 외부 조인의 기본 결과
- 서브쿼리
- 조인과 서브쿼리를 결합한 행 수 계산
    

특히 구분할 것:

- `SELECT DEPT`의 행 수
- `SELECT DISTINCT DEPT`의 행 수
- `COUNT(*)`와 `COUNT(컬럼)`
- `WHERE` 적용 전후
- 조인 때문에 행이 증가하거나 사라지는 경우
    

### SQL 직접 작성

- `INSERT`, `UPDATE`, `DELETE`
- `CREATE TABLE`
- 기본키와 외래키
- `CONSTRAINT`
- `FOREIGN KEY`
- `REFERENCES`
- `ALTER TABLE`
- `GRANT`, `REVOKE`
- `COMMIT`, `ROLLBACK`, `SAVEPOINT`
    

외래키는 다음 구조를 바로 쓸 수 있어야 합니다.

```sql
CONSTRAINT 제약조건명
FOREIGN KEY (자식컬럼)
REFERENCES 부모테이블(부모컬럼)
```

2025년 기출에서도 `COUNT`, `NULL`, 조인, 관계대수와 SQL 실행 결과가 반복됐고, 2026년 1회에는 `DISTINCT`, 외래키 DDL, 조인·서브쿼리가 함께 출제됐습니다.

- 함수적 종속

- 정규화는 복잡한 분해보다 “어떤 종속성을 제거하는 단계인가”를 우선합니다.

## A-4. 네트워크 계산과 핵심 프로토콜

네트워크에서는 **계산형 1문제와 용어형 1문제 이상을 방어하는 것**이 목표입니다.

### 서브넷·CIDR 계산

반드시 계산할 수 있어야 하는 것:

- 서브넷 마스크를 `/n`으로 변환
- `/n`에서 호스트 비트 수 계산
- 블록 크기
- 네트워크 주소
- 브로드캐스트 주소
- 사용 가능한 첫·마지막 호스트
- 두 IP가 같은 네트워크인지 판별
- 사용 가능한 호스트 수
    

### 프로토콜·계층

- OSI 7계층과 대표 장비·프로토콜
- TCP와 UDP
- TCP 3-way·4-way handshake
- ARP와 RARP
- DNS, DHCP, ICMP
- HTTP와 HTTPS
- SSH
- 라우팅 프로토콜의 기본 구분
- HDLC 프레임  
    정보·감독·비번호 프레임
    
- HDLC 동작 모드
- CRC·패리티·해밍코드
    

2025년에는 ARP/RARP, TCP, CRC, 서브넷이 출제됐고, 2026년 1회에는 CIDR와 HDLC가 나와 같은 대영역 안에서 세부 주제가 순환하는 흐름이 확인됐습니다.
