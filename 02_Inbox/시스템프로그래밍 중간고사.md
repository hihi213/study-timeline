- fork( ) 함수로 생성한 자식 프로세스에서 execl( ) 함수를 사용해 who 명령을 실행
```c
if (execl("/usr/bin/who", "who", (char *)NULL) == -1) { 
	perror("execl"); 
	exit(1); 
	}
```


## 7주차

> [!question] 문제 01
> 다음과 같이 `fork()` 함수로 자식 프로세스를 생성했다. 이 중 자식 프로세스가 수행하는 부분은?
> 
> ```c
> int main() {
>     pid_t pid;
>     switch (pid = fork()) {
>         case -1 :
>             printf("-1\n");
>             break;
>         case 1 :
>             printf("1\n");
>             break;
>         case 0 :
>             printf("0\n");
>             break;
>         default :
>             printf("default\n");
>             break;
>     }
> }
> ```
> ① case -1
> ② case 1
> ③ case 0
> ④ default

> [!check]-  정답 및 해설
> **정답: ③ case 0**
> 
> **해설:**
> * `fork()` 함수는 호출 시 새로운 프로세스(자식)를 생성하며, 반환값에 따라 부모와 자식을 구분합니다.
>     * **0**: 자식 프로세스에게 반환됩니다.
>     * **0보다 큰 값 (자식의 PID)**: 부모 프로세스에게 반환됩니다.
>     * **-1**: 프로세스 생성 실패 시 반환됩니다.
> * 따라서 자식 프로세스는 `pid` 값이 `0`이 되므로 `case 0` 문을 수행하게 됩니다.

### 📝 연습 문제 02

> [!question] 문제 02
> 프로세스가 종료할 때 `clear_file()` 함수를 실행하도록 지정하려면 어떤 함수를 사용해야 하는가?
> 
> ① `_exit(clear_file)`
> ② `atexit(clear_file)`
> ③ `clear_file(atexit)`
> ④ `clear_file(exit)`

> [!check]- 정답 및 해설
> **정답: ② atexit(clear_file)**
> 
> **해설:**
> * `atexit()` 함수는 프로세스가 정상적으로 종료될 때 호출될 함수를 등록하는 기능을 합니다.
> * 등록된 함수들은 프로그램이 종료될 때 등록된 역순으로 자동 호출되어 마무리 작업(파일 닫기, 임시 파일 삭제 등)을 수행합니다.

### 📝 연습 문제 03

> [!question] 문제 03
> 현재 프로그램을 `ls -l` 명령으로 바꿔서 실행하려고 한다. 올바른 것은?
> 
> ① `execv("ls", "/usr/bin/ls -l", (char *)NULL)`
> ② `execve("/usr/bin/ls", "-l", argv)`
> ③ `execlp("/usr/bin/ls", "-l", (char *)NULL)`
> ④ `execlp("ls", "ls", "-l", (char *)NULL)`

> [!check]- 정답 및 해설
> **정답: ④ execlp("ls", "ls", "-l", (char *)NULL)**
> 
> **해설:**
> * `execlp(file, arg0, arg1, …, NULL)` 형식의 함수입니다.
>     * **첫 번째 인자 (`"ls"`)**: 실행할 파일의 이름입니다. `p`가 붙은 버전이므로 `PATH` 환경 변수에서 해당 파일을 찾습니다.
>     * **두 번째 인자 (`"ls"`)**: 관례적으로 실행되는 프로그램의 이름을 전달하며, 이는 `argv[0]`이 됩니다.
>     * **세 번째 인자 (`"-l"`)**: 명령어의 옵션으로 `argv[1]`이 됩니다.
>     * **마지막 인자 (`(char *)NULL`)**: 인자 리스트의 끝을 알리는 필수 값입니다.
> * 나머지 보기들은 인자 전달 방식이나 함수 형식이 규격에 맞지 않습니다. (예: `execv`는 인자 리스트를 배열 형태로 전달해야 함)



> [!question] 문제 04
> `fork()` 함수로 자식 프로세스를 만들고 이 프로세스에서 `execl()` 함수를 사용해 `pwd` 명령을 실행하려고 한다. 올바른 것은?
> 
> ① `execl("/usr/bin/pwd", "pwd", (char *)NULL)`
> ② `execl("pwd", "pwd", (char *)NULL);`
> ③ `execl("/usr/bin/pwd", (char *)NULL);`
> ④ `execl("pwd", (char *)NULL);`

> [!check]- 정답 및 해설
> **정답: ① execl("/usr/bin/pwd", "pwd", (char *)NULL)**
> 
> **해설:**
> * `execl()` 함수는 실행 파일의 **절대 경로**를 첫 번째 인자로 명시해야 합니다. (환경 변수를 참조하는 `p` 계열 함수와 다름)
> * 두 번째 인자부터는 명령행 인자(`argv`)를 나열하며, 관례상 `argv[0]`은 프로그램 이름 자체를 넣습니다.
> * 인자 리스트의 끝은 반드시 `(char *)NULL`로 표시해야 합니다.
> * ②번의 경우 경로가 누락되었으며, ③, ④번은 `argv[0]` 인자가 생략되어 잘못된 형식입니다.

### 📝 연습 문제 05

> [!question] 문제 05
> 특정 자식 프로세스가 종료하기를 기다리려면 어떤 함수를 사용해야 하는가?
> 
> ① `waitch()`
> ② `waitpid()`
> ③ `pidwait()`
> ④ `waits()`

> [!check]- 정답 및 해설
> **정답: ② waitpid()**
> 
> **해설:**
> * `wait()` 함수는 자식 프로세스 중 아무거나 하나가 종료될 때까지 기다립니다.
> * 반면 `waitpid()` 함수는 인자로 전달된 **특정 PID**를 가진 자식 프로세스가 종료될 때까지 대기할 수 있습니다.

### 💻 실습 과제 06

> [!question] 실습 과제 06
> `fork()` 함수를 사용해 자식 프로세스에서는 현재 디렉터리의 절대 경로를 출력하고 부모 프로세스에서는 현재 디렉터리의 내용을 출력하는 프로그램을 작성하시오. (ex7_06.c)

> [!check]- 정답 및 해설 (코드 구현)
> 
> ```c
> #include <sys/types.h>
> #include <sys/wait.h>
> #include <unistd.h>
> #include <stdlib.h>
> #include <stdio.h>
> 
> int main() {
>     pid_t pid;
> 
>     switch (pid = fork()) {
>         case -1 : /* fork 실패 */
>             perror("fork");
>             exit(1);
>             break;
>         case 0 : /* 자식 프로세스: pwd 실행 */
>             printf("Child Process - My PID:%d, My Parent's PID:%d\n", (int)getpid(), (int)getppid());
>             system("pwd");
>             printf("End of fork\n"); // 자식 프로세스의 종료 지점
>             exit(0);
>             break;
>         default : /* 부모 프로세스: ls 실행 */
>             printf("Parent process - My PID:%d, My Parent's PID:%d, My Child's PID:%d\n", (int)getpid(), (int)getppid(), (int)pid);
>             wait(NULL); // 자식이 끝날 때까지 대기하여 출력이 섞이지 않게 함
>             system("ls");
>             printf("End of fork\n"); // 부모 프로세스의 종료 지점
>             break;
>     }
>     return 0;
> }
> ```
> 
> **해설:**
> * `fork()` 이후 `case 0`은 **자식**이 수행하며, `system("pwd")`를 통해 절대 경로를 출력합니다.
> * `default`는 **부모**가 수행하며, 자식의 PID를 알고 있습니다. `system("ls")`를 통해 디렉터리 목록을 출력합니다.
> * 실행 예시와 같이 출력이 깔끔하게 나오도록 `wait(NULL)`을 사용하여 부모가 자식의 작업 완료를 기다리게 구성할 수 있습니다.
