# C언어
`int a=3, b;` -> a=3, b는 초기화 안됨
`int *p, q;` ->q는 int형 (포인터 아님)
`int *p, *q;` -> 둘다 int 포인터

## 자료형
`float`: 실수, 소숫점 6자리까지 신뢰, 4byte <-> `Int` 정수
`double`: 실수, 소숫점 15자리까지 신뢰, 8byte <-> `Long` 정수

`unsigned int` : 0포함 양수만 저장하는 정수 (양수범위 2배)
	`unsigned int age = 25u;` 
```c
unsigned char a = 5;       // 0000 0101
// ~a= 1111 1010  (비트전부반전연산 ~)
int b= ~a //6, 맨앞비트를 부호비트로 해석, 여러단계거쳐 최종적으론 기존값+1이 결과가 됨
unsigned char c = ~a; //250, 1111 1010 다 더함   
```

`u,l,f`만 접미사 조합임 ex) ul

구조체 멤버가 `unsigned int x;` 로 선언되어있는 경우 접미사 u 잘 붙여주기
	struct Node t1 = { 0, 5u };

```C
int main() {
    char ch = 'A';
    unsigned int u = 5u;
    printf("%d %u", ch + 2, u + 3);
    return 0;
}
//67 8
```
