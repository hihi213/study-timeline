## C언어
### 1. 배열과 포인터의 등가 관계 & 포인터 증감과 주소 이동

> **핵심 가이드:** 배열명 단독 사용은 1차원 포인터(`&a[0]`)와 같으며, `*(p-1)`이나 `p[-1]`이 지시하는 주소와 값의 변화를 따라갈 수 있어야 합니다.

```c
#include <stdio.h>
int main(){
    int a[3] = {1, 2}; 
    int *p = a + 1;   
    
    printf("%d %d %d\n", a[0], a[1], a[2]);
    printf("%d %d %d\n", *a, *(a+1), *(a+2));
    printf("%d %d %d\n", *(p-1), *p, *(p+1));
    printf("%d %d %d\n", p[-1], p[0], p[1]);
    return 0;
}
```

> [!NOTE]- [실행 결과]
> 1 2 0
> 1 2 0
> 1 2 0
> 1 2 0
>
> 해설
> int a[3] = {1, 2}; 크기가 3인 배열에 1, 2가 저장되고 남은 칸은 0으로 초기화됨
> int \*p = a + 1; // p는 a[1]의 주소를 가리킴
>

### 2. 2차원 배열의 인덱스 계산 & 포인터 배열

> **핵심 가이드:** 2차원 배열에서 각 행의 주소를 포인터 배열(`*p[3]`)에 어떤 순서로 대입했는지 파악하고, 참조 연산자(`*`)가 붙었을 때의 값 변화를 묻는 단골 유형입니다.

```c
#include <stdio.h>
int main(){
    int a[3][2] = {{1, 2}, {3, 4}, {5, 6}};
    int *p[3] = {a[2], a[0], a[1]}; 
    
    printf("%d %d %d\n", a[0][0], a[1][0], a[2][0]);
    printf("%d %d %d\n", *a[0], *a[1], *a[2]);
    printf("%d %d %d\n", p[1][0], p[2][0], p[0][0]);
    printf("%d %d %d\n", *p[1], *p[2], *p[0]);
    return 0;
}
```

> [!NOTE] [실행 결과]
>
> 1 3 5
> 1 3 5
> 1 3 5
> 1 3 5
>
> [해설]
> int \*p[3] = {a[2], a[0], a[1]}; // p[0]은 3행, p[1]은 1행, p[2]은 2행을 가리킴

### 3. 문자 배열과 문자열

```c
#include <stdio.h>
int main(){
    char *p = "KOREA";
    
    printf("%s\n", p);   
    printf("%s\n", p+3);  
    printf("%c\n", *p);   
    printf("%c\n", *(p+3));
    printf("%c\n", *p+2);   
    return 0;
}
```

> [!NOTE]- [실행 결과]
> KOREA
> EA
> K
> E
> M
>
> **핵심 가이드:** `%s` 형식을 사용할 때는 포인터가 가리키는 주소부터 `\0`(NULL) 문자를 만날 때까지 연속 출력하고, `%c`일 때는 해당 포인터가 가리키는 단 한 문자만 출력한다는 점에 주의해야 합니다. 마지막 `*p + 2` 처럼 아스키코드 값 자체에 연산을 수행하는 꼼수도 자주 출제됩니다.
### 4. 구조체와 구조체 포인터

```c
#include <stdio.h>
struct Student{
    char gender;
    int age;
};

int main() {
    struct Student s = {'F', 21};
    struct Student *p = &s;
    
    printf("%c %d\n", s.gender, s.age);
    printf("%c %d\n", (&s)->gender, (&s)->age);
    printf("%c %d\n", p->gender, p->age);
    printf("%c %d\n", (*p).gender, (*p).age);
    printf("%c %d\n", p[0].gender, p[0].age);
    return 0;
}
```

> [!NOTE]- [실행 결과]
> F 21
> F 21
> F 21
> F 21
> F 21
> > **핵심 가이드:** 일반 구조체 변수는 온점(`.`), 구조체 포인터 변수는 화살표(`->`)로 멤버에 접근합니다. `(*p).member`나 `p[0].member` 표기법이 모두 동일한 값을 가리킨다는 등가 관계를 묻습니다.

### 5. 함수 포인터의 기본 선언·대입·호출

```c
#include <stdio.h>
void fn1(){ 
    printf("fn1 함수\n"); 
}
int fn2(int a){ 
    printf("fn2 함수:%d\n", a); 
    return 0; 
}

int main(){
    void (*pf1)();    
    int (*pf2)(int);   
    
    fn1();
    fn2(5);
    
    pf1 = fn1;         
    pf2 = fn2;
    
    pf1();             
    pf2(2);            
    return 0;
}
```

> [!NOTE]- [실행 결과]
>
> fn1 함수
> fn2 함수:5
> fn1 함수
> fn2 함수:2
>
> **핵심 가이드:** 선언문 모양이 복잡해 보이지만 `void (*pf1)()`는 매개변수와 반환값이 없는 함수를 가리키는 포인터 변수라는 점만 읽어낼 수 있으면 쉽게 풀립니다.
>
> void (\*pf1)(); // 반환값 void, 매개변수 없는 함수 포인터
> int (\*pf2)(int); // 반환값 int, 매개변수 int 1개인 함수 포인터
> pf1(); // 함수 포인터로 호출 -> fn1 함수
> pf2(2); // 함수 포인터로 호출 -> fn2 함수:2

### 6. 전위·후위 증감 연산

```c
#include <stdio.h>
int main(){
    int x = 3, y = 3;
    printf("%d", x++); 
    printf("%d", x);   
    printf("%d", ++y); 
    printf("%d", y);  
    return 0;
}
```

> [!NOTE]- [실행 결과]
>
> 3444
>
> **핵심 가이드:** `x++`(후위 연산)은 현재 줄의 명령(출력)을 먼저 수행한 뒤 값이 증가하고, `++y`(전위 연산)은 값을 먼저 증가시킨 뒤 다음 명령을 수행합니다.
### 7. 출력 형식 (실수 자릿수 및 정렬)

> **핵심 가이드:** 정밀도 지정(`%f`), 전체 자릿수 채우기 및 정렬 형식을 확실히 짚고 넘어가야 정답을 표기할 때 감점을 피할 수 있습니다.

```c
#include <stdio.h>
int main(){
    float a = 1.234;
    int b = 10;
    
    printf("%f\n", a);   
    printf("%5.1f\n", a);  
    printf("%05.1f\n", a); 
    printf("%-5.1f\n", a); 
    
    printf("%5d\n", b);    
    printf("%05d\n", b);   
    return 0;
}
```

> [!NOTE]- 실행결과
> printf("%f\n", a); // 소수점 둘째 자리까지 반올림 표시 -> 1.23

> printf("%-5.1f\n", a); // 좌측 정렬 -> 1.2  
>
> printf("%5d\n", b); // 전체 5칸 우측 정렬 -> 10
> printf("%05d\n", b); // 빈칸을 0으로 채움 -> 00010

## JAVA
### 1. 상속 시 생성자 호출 순서 & super()

```java
class Parent {
    Parent() {
        System.out.print("A");
    }
    Parent(int x) {
        System.out.print("B" + x);
    }
}

class Child extends Parent {
    Child() {
        super(3);
        System.out.print("C");
    }
    Child(int x) {
        System.out.print("D" + x);
    }
}

public class Main {
    public static void main(String[] args) {
        Child c1 = new Child();
        Child c2 = new Child(5);
    }
}
```

### 정답 및 해설

- **실행 결과**: `B3CD5`
- **핵심 해설**:
    - `new Child()` 실행 시: `Child()` 생성자가 호출됩니다. 내부에서 `super(3)`을 명시적으로 호출하므로 부모의 `Parent(int x)` 생성자가 먼저 실행되어 **B3**이 출력됩니다. 이후 자식 생성자의 나머지 코드인 **C**가 출력됩니다. (결과: `B3C`)
    - `new Child(5)` 실행 시: `Child(int x)` 생성자가 호출됩니다. 생성자 첫 줄에 `super()`나 `this()`가 없으면 컴파일러가 자동으로 부모의 기본 생성자인 `super()`를 호출합니다. 이에 따라 `Parent()`가 실행되어 **A**가 아닌 부모의 기본 출력이 실행되어야 하지만, 여기서는 부모 기본 생성자인 `Parent()`가 호출되면서 **A**를 먼저 출력합니다. 그 뒤 자식 생성자의 내용인 **D5**가 출력됩니다. (결과: `AD5`)
        

## 2. 부모 타입 참조변수와 자식 객체 (필드 숨김 vs 메서드 오버라이딩)

### 문제

Java

```java
class Parent {
    int x = 10;
    void show() {
        System.out.print("ParentShow");
    }
}

class Child extends Parent {
    int x = 20;
    void show() {
        System.out.print("ChildShow");
    }
}

public class Main {
    public static void main(String[] args) {
        Parent p = new Child();
        System.out.print(p.x + "-");
        p.show();
    }
}
```

### 정답 및 해설

- **실행 결과**: `10-ChildShow`
- **핵심 해설**:
    - 필드(멤버 변수)는 참조 변수의 선언 타입(부모 타입 `Parent`)을 따릅니다. 따라서 `p.x`는 부모 클래스에 정의된 `10`을 가리킵니다.
    - **인스턴스 메서드**는 참조 변수의 타입과 관계없이 실제 생성된 객체(자식 객체 `Child`)를 기준으로 작동하여 오버라이딩된 메서드가 호출됩니다. 따라서 `p.show()`는 자식 클래스에서 재정의된 `ChildShow`를 출력합니다.
        

## 3. 오버로딩(Overloading)의 컴파일 시점 메서드 선택

### 문제

Java

```java
class Printer {
    void print(Object obj) {
        System.out.print("Object ");
    }
    void print(String str) {
        System.out.print("String ");
    }
}

public class Main {
    public static void main(String[] args) {
        Printer p = new Printer();
        Object obj = "Hello";
        String str = "World";
        
        p.print(obj);
        p.print(str);
    }
}
```

### 정답 및 해설

- **실행 결과**: `Object String`
- **핵심 해설**:
    - 오버로딩(Overloading)은 **컴파일 시점**에 결정되며, 참조 변수의 **선언 타입을 기준**으로 어떤 메서드를 실행할지 매핑합니다.
    - `obj` 변수에 실제 담긴 객체는 문자열(`"Hello"`)이지만, 변수의 선언 타입이 `Object`이므로 `print(Object obj)` 메서드가 선택되어 `Object` 가 출력됩니다.
    - `str` 변수는 선언 타입이 `String`이므로 `print(String str)` 메서드가 실행되어 `String` 이 출력됩니다.
        

## 4. static 변수·메서드와 인스턴스 멤버의 접근 관계

### 문제

Java

```java
class Counter {
    static int count = 0;
    int localCount = 0;

    Counter() {
        count++;
        localCount++;
    }
    
    static void printCount() {
        System.out.print(count);
    }
}

public class Main {
    public static void main(String[] args) {
        Counter c1 = new Counter();
        Counter c2 = new Counter();
        
        Counter.printCount();
        System.out.print("-");
        System.out.print(c2.localCount);
    }
}
```

### 정답 및 해설

- **실행 결과**: `2-1`
- **핵심 해설**:
    - `static` 변수(`count`)는 클래스에 단 하나만 존재하며 모든 인스턴스가 공유합니다. 인스턴스가 2번 생성(`new Counter()`)되었으므로 `count`는 2가 됩니다.
    - 인스턴스 변수(`localCount`)는 각 객체마다 개별적으로 할당됩니다. `c2` 객체가 생성될 때 독립된 `localCount`가 1로 증가했으므로 `c2.localCount`는 `1`이 됩니다.
        

## 5. 예외처리와 finally의 실행 흐름

### 문제

Java

```java
public class Main {
    static void test(int num) {
        try {
            if (num == 0) {
                throw new ArithmeticException();
            }
            System.out.print("A");
        } catch (ArithmeticException e) {
            System.out.print("B");
            return;
        } finally {
            System.out.print("C");
        }
        System.out.print("D");
    }

    public static void main(String[] args) {
        test(0);
        System.out.print("-");
        test(1);
    }
}
```

### 정답 및 해설

- **실행 결과**: `BC-ACD`
- **핵심 해설**:
    - `test(0)` 실행 시: `num`이 0이므로 예외가 발생하여 `catch` 블록으로 이동하고 **B**가 출력됩니다. `catch` 내부에 `return` 문이 있어 메서드가 즉시 종료되려 하지만, **`finally` 블록은 무조건 실행**되어야 하므로 **C**를 출력한 후 메서드가 완전히 종료됩니다. (결과: `BC`)
    - `test(1)` 실행 시: 예외가 발생하지 않으므로 `try` 안의 **A**가 출력되고, `finally` 안의 **C**가 출력된 후 정상 흐름으로 빠져나와 **D**가 출력됩니다. (결과: `ACD`)

public class Main {

### 8. 추상 클래스와 인터페이스의 다형성 구현

```Java
interface Vehicle {
    void run();
}

abstract class Car implements Vehicle {
    public void run() {
        System.out.print("Car Run-");
        sound();
    }
    abstract void sound();
}

class Sedan extends Car {
    void sound() {
        System.out.print("Vroom");
    }
}

public class Main {
    public static void main(String[] args) {
        Vehicle v = new Sedan();
        v.run();
    }
}
```

### 정답 및 해설

- **실행 결과**: `Car Run-Vroom`
- **핵심 해설**:
    - `Sedan` 객체는 `Car`를 상속받고 `Vehicle` 인터페이스를 간접 구현하므로, 부모 인터페이스 타입인 `Vehicle v` 참조변수에 자식 객체를 대입할 수 있습니다.
    - `v.run()`을 호출하면 실제 생성된 객체 타입의 메서드를 추적해 갑니다. `Sedan`은 `run()`을 오버라이딩하지 않았으므로, 부모 클래스인 `Car` 클래스의 `run()`이 실행되어 Car Run-이 출력됩니다.
    - `run()` 내부에서 호출되는 추상 메서드 `sound()` 역시 오버라이딩 규칙에 따라 실제 생성된 하위 객체인 `Sedan`의 정의를 따라가므로 **Vroom**을 실행 및 출력합니다.
        

## 4. Java: 재귀함수(Recursive)의 연산 흐름

```Java
public class Main {
    static int fn(int n) {
        if (n <= 1) {
            return 1;
        }
        return n + fn(n - 1);
    }

    public static void main(String[] args) {
        System.out.print(fn(4));
    }
}
```

### 정답 및 해설

- **실행 결과**: `10`
- **핵심 해설**:
    - `fn(4)`는 `4 + fn(3)`을 호출합니다.
    - `fn(3)`은 `3 + fn(2)`를 호출합니다.
    - `fn(2)`는 `2 + fn(1)`을 호출합니다.
    - `fn(1)`은 기저 조건(`n <= 1`)에 따라 `1`을 반환하고 재귀 탈출을 시작합니다.
    - 역으로 합산되는 계산식은 다음과 같습니다:
        - $fn(2) = 2 + 1 = 3$
        - $fn(3) = 3 + 3 = 6$
        - $fn(4) = 4 + 6 = 10$
    - 따라서 최종 호출 값은 **10**이 됩니다.
