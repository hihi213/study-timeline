## 특정 값이 리스트의 어디에 위치하는지
### 딕션너리 키: 리스트의 값, 딕셔너리 value: 리스트(해당 값을 가지는 모든 인덱스)
키가 없을 때 자동으로 초기화되는 `defaultdict`를 이용해 진행
```Python
from collections import defaultdict

nums = [1, 5, 2, 1, 5]

# list 타입으로 초기화되도록 설정
dict1 = defaultdict(list) 

# enumerate를 사용하여 인덱스와 값을 동시에 순회
for index, value in enumerate(nums): 
    # key가 없어도 자동으로 빈 리스트가 생성되므로 if/setdefault 불필요
    dict1[value].append(index)

print(dict1)
# 결과: defaultdict(<class 'list'>, {1: [0, 3], 5: [1, 4], 2: [2]})
```
