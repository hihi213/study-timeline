## 정리
- java에서의 return: 계산결과를 되돌려주는 행위  
	- ->스프림 mvc프레임워크가 다음동작을 결정
- spring Controller에서 return: 
	->이 요청에 대해 후속처리를 하도록 스프링 프레임워크에게 지시를 내리는 명령
	->스프림 mvc프레임워크가 해석
- 리액트의 `return`은 쉽게 말하면, return의 JSX문법을 자바스크립트 객체로 변환해, 그리고 리액트의 렌더링 엔진에게 전달해서 메모리에 기억해둔 이전 자바스크립트의 객체와 비교해 그리고 변경사항만 실제 DOM에 딱한번 적용해서 업데이트하자 ^y09tv6
	- [jsx, 자바스크립트객체, DOM, 가상DOM를 구별해보자 그리고 전체동작흐름](jsx,%20자바스크립트객체,%20DOM,%20가상DOM를%20구별해보자%20그리고%20전체동작흐름.md)
- 리액트의 return를 정확히 말하자면 아래와 같다.
	- **반환 (Return)**: `return` 문은 UI 설계도인 JSX를 반환합니다. 이 JSX는 **'새로운 가상 DOM'**이라고 불리는 자바스크립트 객체로 변환됩니다. 
    
	- **비교 (Diffing)**: 리액트는 이 **'새로운 가상 DOM'**을, 메모리에 이미 저장해 둔 **'이전 가상 DOM'**과 비교합니다. 이 비교 과정은 실제 브라우저를 건드리지 않고, 오직 자바스크립트 메모리 안에서만 일어나므로 **매우 빠릅니다.**
    
	- **업데이트 (Commit)**: 비교를 통해 찾아낸 **최소한의 변경사항**만을 **실제 DOM**에 딱 한 번 적용하여 화면을 업데이트합니다.

- return 일반 자바: 값을 호출자에게 전달->호출자가 받음
- return 스프링컨트롤러: 뷰이름을 반환->템블릿 엔진이 처리->viewResolver가 받아서 html만들고 응답
