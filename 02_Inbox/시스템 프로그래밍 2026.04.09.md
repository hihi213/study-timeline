# 정리 한줄 요약을 제목으로 설정
## 🔍 맥락


## 📝 나의 정리
> 여기에 나의 언어로 재작성

## 📝 정리
- 프로세스 그룹: 파이프라인 **`|`** 으로 이어진 프로세스들의 묶임(작업단위)
	- **`cat access.log | grep "404" | wc -l`**
- 세션: 터미널(쉘) 하나의 모든 작업 (프로세스 그룹 여러개를 묶어 관리)
---

| **구분**             | **자신의 정보 (Self)**                   | **타인의 정보 (Other)**          |
| ------------------ | ----------------------------------- | --------------------------- |
| **PID** (자신)       | **`getpid()`**                      |                             |
| **PPID** (부모)      | **`getppid()`**                     | **`/proc/[PID]/status`** 확인 |
| **PGID** (프로세스 그룹) | **`getpgrp()`** 또는 **`getpgid(0)`** | **`getpgid(pid)`**          |
| **SID** (세션)       | **`getsid(0)`**                     | **`getsid(pid)`**           |
