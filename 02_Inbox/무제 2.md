# 🚀 M1 ➡️ M4 클린 이사 가이드: "정예 요원 & 블랙박스 전략"

이번 이사의 핵심은 **"마이그레이션 도우미를 쓰지 않고, 진짜 필요한 알맹이만 직접 챙겨서 클린 설치하는 것"**입니다.

## 📦 1단계: '생존 키트' 만들기 (새 맥북에 바로 풀 정예 부대)

바탕화면에 `Core`이라는 빈 폴더를 하나 만들고, 아래의 핵심 데이터만 쏙쏙 골라 담습니다.

### 1. 터미널 및 숨김 설정 파일 모으기

터미널을 열고 아래 명령어를 한 줄씩 복사해서 실행하세요. (홈 폴더의 중요 설정 파일들을 생존 키트 폴더로 복사합니다.)

```Bash
# 1. 설정 파일을 담을 하위 폴더 생성
mkdir -p ~/Desktop/Core/FROM_HOME_CONFIG

# 2. 중요 설정 파일 복사 (.ssh, .zshrc, .gitconfig 등)
cp -a ~/.ssh ~/.gitconfig ~/.zshrc ~/.zprofile ~/.bash_profile ~/.vimrc ~/.aws ~/.npmrc ~/.p10k.zsh ~/.sqldeveloper ~/Desktop/Core/FROM_HOME_CONFIG/ 2>/dev/null
```

### 2. 출처별 프로젝트 코드 모으기

개발하던 프로젝트들을 '원래 있던 위치'를 이름표 삼아 모아줍니다. (나중에 헷갈리지 않기 위함입니다.)



```Bash
# 1. 바탕화면(Desktop)에 있던 코드들
mkdir -p ~/Desktop/Core/FROM_Desktop
cp -a ~/Desktop/code ~/Desktop/Core/FROM_Desktop/ 2>/dev/null

# 2. 문서(Documents)에 있던 GitHub 프로젝트들 (dormmate_rebuild 등)
mkdir -p ~/Desktop/Core/FROM_Documents
cp -a ~/Documents/GitHub ~/Desktop/Core/FROM_Documents/ 2>/dev/null

# 3. 다운로드(Downloads)에 있던 실습 프로젝트들 (jpashop 등)
mkdir -p ~/Desktop/Core/FROM_Downloads
cp -a ~/Downloads/jpashop ~/Downloads/DormMate-main ~/Downloads/library-app ~/Desktop/Core/FROM_Downloads/ 2>/dev/null

# 4. 인텔리제이 기본 폴더
cp -a ~/IdeaProjects ~/Desktop/Core/ 2>/dev/null
```

### 3. 수동으로 챙겨야 할 필수 아이템

- **옵시디언 (Obsidian):** 사용하시던 마크다운 Vault 폴더를 통째로 복사해서 넣습니다.
- **DBeaver 설정:** DBeaver 앱을 켜고 `[파일] > [내보내기] > [Project]`를 선택해 DB 접속 정보 파일을 저장해서 넣습니다.
- **개발용 폰트:** 즐겨 쓰시는 **D2Coding** 폰트 설치 파일(`.ttf` 또는 `.zip`)을 챙겨 넣습니다.

## ✂️ 2단계: 256GB를 위한 '극한의 다이어트' (매우 중요)

프로젝트를 복사했으니, 그 안에 있는 **수십 GB짜리 찌꺼기(빌드 결과물)**를 날려버릴 차례입니다. 터미널에 아래 명령어를 입력하세요.



```Bash
# 생존 키트 안에 있는 무거운 node_modules, build, target 폴더 일괄 삭제
find ~/Desktop/Core -type d \( -name "node_modules" -o -name "build" -o -name "target" -o -name ".gradle" \) -prune -exec rm -rf {} +
```

> **완료 후 액션:** 이제 날씬해진 `Core` 폴더를 우클릭해서 **[압축]** 하세요. (`Core.zip` 생성)

---

## 🗄️ 3단계: '블랙박스' 만들기 (구글 드라이브 보존용)

생존 키트에 담지 못한 나머지 모든 파일은 **"혹시 나중에 필요할지도 모르는"** 블랙박스로 만듭니다.

- **대상:** `Desktop(데스크탑)`, `Documents(문서)`, `Downloads(다운로드)`, `Pictures(사진)` 폴더의 남은 찌꺼기 전체.
- **방법:** 이 폴더들을 각각 우클릭해서 **[압축]** 하세요. (예: `Desktop_Archive.zip`)
- **주의:** 이 파일들은 새 M4 맥북에 **절대 다운로드하지 않습니다.** 구글 드라이브에만 올려두고, 급할 때 드라이브 웹사이트에서 파일 하나씩만 꺼내 씁니다.
    

---

## ☁️ 4단계: 구글 드라이브 전송 및 이별 준비

이제 짐을 클라우드(2TB 구글 드라이브)로 보내고, M1 맥북을 초기화할 준비를 합니다.

1. **업로드:** 2단계의 `Core.zip`과 3단계의 블랙박스 ZIP 파일들을 모두 구글 드라이브에 업로드합니다.
2. **용량 확인:** 업로드가 끝난 후, 구글 드라이브 웹 브라우저로 접속해 파일이 정상적인 용량으로 다 올라갔는지 **눈으로 꼭 확인**하세요.
3. **[필수] 라이선스 및 계정 해제:**
    
    - **한컴오피스, MS Office:** 앱 내 설정에서 반드시 **로그아웃 / 기기 등록 해제**를 하세요.
    - **Apple ID:** 시스템 설정 > [내 이름] > 맨 아래 **로그아웃** 클릭 (나의 Mac 찾기 해제 필수).
    - **기타:** 카카오톡 대화 백업, iMessage 로그아웃.
        

---

## ✨ 5단계: 새 M4 맥북 맞이하기 (내일의 승현 님에게)

새 노트북 전원을 켜면, 딱 이 순서대로만 하세요.

1. **초기 세팅:** '마이그레이션 도우미(정보 전송)' 화면이 나오면 **과감히 건너뛰기(Skip)**를 누릅니다.
2. **생존 키트 다운로드:** 구글 드라이브에 접속해 **`Core.zip` 딱 하나만** 바탕화면으로 다운받아 압축을 풉니다.
3. **기본 뼈대 세팅:**
    
    - **D2Coding 폰트** 파일부터 더블클릭해서 설치합니다.
    - 터미널을 켜고 **Homebrew**를 설치합니다.
        
4. **내 환경 복구:**
    
    - 생존 키트 안에 있던 `.zshrc` 파일의 내용을 새 맥북의 `.zshrc`에 복사해 넣습니다.
    - `.ssh` 키를 복구하여 깃허브 권한을 살립니다.
        
5. **IDE 설치:** IntelliJ, VS Code를 새로 설치하고 깃허브 계정 등으로 로그인하여 **Settings Sync(설정 동기화)**를 켭니다.
