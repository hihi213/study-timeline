# [System Pro] stat 구조체 데이터 해석 및 무결성 보장 가이드

`stat()` 시스템 콜을 호출하면, 커널은 파일 시스템의 아이노드(Inode)에서 0과 1로 이루어진 비트 그대로 `stat` 구조체에 담아줍니다. 개발자는 이 원시 데이터를 특정 규격에 맞춰 해석(Interpretation)하고 가독성 있는 형태로 변환해야 합니다.

---

## 1. 주요 필드 데이터 변환 매트릭스

|**필드명**|**의미**|**데이터 타입**|**핵심 변환 및 처리 도구**|
|---|---|---|---|
|**`st_mode`**|파일 종류 및 권한|`mode_t` (비트 필드)|`S_ISxxx` 매크로, `%o` (8진수) 포맷|
|**`st_size`**|파일 크기 (Bytes)|`off_t`|`(long long)` 캐스팅, 단위 변환 연산|
|**`st_uid` / `st_gid`**|소유자 / 그룹 ID|`uid_t` / `gid_t`|`getpwuid()`, `getgrgid()` 함수|
|**`st_mtime`**|최종 수정 시간|`time_t` (Epoch)|`localtime()`, `strftime()` 함수|

## 2. st_mode 해석 원리: (unsigned int) 캐스팅과 %o

`printf("Mode: %o\n", (unsigned int)statbuf.st_mode);` 코드는 비트 데이터를 왜곡 없이 처리하기 위한 기술적 장치입니다.

### ① 8진수 포맷(%o)과 3비트 단위 매핑

- 리눅스 권한은 `r`, `w`, `x` 3비트 단위로 작동합니다.
- 8진수($2^{3} = 8$) 한 자리는 정확히 이 3비트 뭉치 하나와 대응하므로, 10진수보다 훨씬 직관적으로 권한을 확인할 수 있습니다.
### ② 부호 확장(Sign Extension) 방지

- **현상:** 일반 파일(`S_IFREG`)의 식별 비트는 최상위 비트가 `1`입니다.
    
- **위험:** 이를 `signed int`로 처리하면 시스템은 이를 **음수**로 오해하여 앞부분을 모두 `1`로 채워버리는 부호 확장을 일으킵니다.
    
- **결과:** `100644`가 나와야 할 자리에 `ffff…`로 시작하는 쓰레기 값이 출력됩니다.
    

### ③ 제로 확장(Zero Extension)을 통한 무결성 확보

- `mode_t`의 크기는 시스템 환경에 따라 다를 수 있습니다.
- **(unsigned int)**로 명시적 캐스팅을 수행하면, 비트 확장 시 부호와 상관없이 앞부분을 `0`으로 채우는 **제로 확장**이 적용되어 원본 비트 값이 그대로 유지됩니다.

## 3. 필드별 변환 구현 (Code Snippets)

### 📁 파일 종류 및 권한 추출 (Bitwise Handling)



```C
// 1. 매크로를 이용한 파일 종류 판별
if (S_ISREG(statbuf.st_mode)) printf("Regular File\n");

// 2. 비트 AND 연산을 이용한 권한 문자열 구성
printf("%c%c%c", 
    (statbuf.st_mode & S_IRUSR) ? 'r' : '-',
    (statbuf.st_mode & S_IWUSR) ? 'w' : '-',
    (statbuf.st_mode & S_IXUSR) ? 'x' : '-');
```

### 👤 시스템 정보 및 시간 포맷팅 (Data Mapping)


```C
// 1. UID/GID를 문자열 이름으로 변환 (pwd.h, grp.h 사용)
struct passwd *pw = getpwuid(statbuf.st_uid);
printf("Owner Name: %s\n", pw->pw_name);

// 2. Epoch Time을 표준 날짜 형식으로 변환 (time.h 사용)
char time_str[20];
strftime(time_str, 20, "%Y-%m-%d %H:%M", localtime(&statbuf.st_mtime));
printf("Last Modified: %s\n", time_str);
```

## 💡 요약

`st_mode`를 포함한 `stat` 구조체 데이터는 비트 단위의 원시 값이므로, **부호 확장**으로 인한 데이터 왜곡을 방지하기 위해 **unsigned** 타입으로 캐스팅하여 처리하며, 이를 **비트 마스크**나 **시스템 라이브러리 함수**를 통해 사람이 이해할 수 있는 정보로 매핑하는 과정이 필수적입니다.
