## 🏗️ [Topic] 시스템 호출과 라이브러리 함수의 에러 처리

### 1. 배경 및 OS 핵심 개념

시스템 프로그래밍에서 자원 요청의 성공 여부와 실패 원인을 파악하는 것은 안정적인 프로그램 작성의 핵심입니다.

**사용 시점(When):** 파일 접근(`access`), 파일 열기(`open`/`fopen`) 등 커널에 자원을 요청하거나 라이브러리를 사용할 때.

### 호출 성공/실패 판정 표준:

| 구분           | 성공 시      | 실패 시          | 비고                  |
| :----------- | :-------- | :------------ | :------------------ |
| **시스템 호출**   | `0` (보통)  | `-1`          | 유저 모드 → 커널 모드 진입    |
| **라이브러리 함수** | 유효한 값/포인터 | `0` 또는 `NULL` | 시스템 호출을 래핑하여 편의성 제공 |
   

---

### 2. 에러 처리 메커니즘 (The Big 3)

오류가 발생하면 OS는 그 원인을 **번호**로 기록하고, 개발자는 이를 **메시지**로 변환하여 확인합니다.

- **`errno` (전역 변수):** 최근 발생한 오류 번호를 저장하는 보관함입니다. (`extern int errno;`)
- **`strerror()`:** 번호를 시스템 정의 메시지(문자열)로 **변환만** 합니다. (로그 기록용으로 유리)
- **`perror()`:** "사용자 메시지 + 시스템 메시지"를 합쳐 **즉시 출력**합니다. (디버깅용으로 유리)
    

#### 📂 관련 헤더 파일 정의

- **리눅스:** `/usr/include/asm-generic/errno-base.h` (기본 에러 정의)
- **유닉스:** `/usr/include/sys/errno.h`

### 3. 실습: `access()`를 이용한 에러 분석

`access()` 함수는 파일의 존재 여부(`F_OK`)나 권한을 확인하는 시스템 호출입니다.

#### 💻 실제 구현 (error_test.c)

C

```sql
#include <stdio.h>
#include <unistd.h> // access() 선언
#include <errno.h>  // errno 변수 및 에러 상수 정의
#include <string.h> // strerror() 선언
#include <stdlib.h>

int main() {
    // F_OK: 파일의 존재 여부(Existence)를 체크하는 플래그
    // 실패 시 -1을 반환하며 errno에 구체적인 이유가 기록됨
    if (access("test.txt", F_OK) == -1) { 
        
        // [방법 1] errno 직접 확인 (정수값)
        printf("1. Direct Errno: %d\n", errno);

        // [방법 2] perror 사용 (시스템 설명 추가 후 자동 출력)
        // 출력 포맷: "사용자 메시지: 시스템 설명"
        perror("2. Error from perror");

        // [방법 3] strerror 사용 (메시지 가공 및 로깅용)
        char *msg = strerror(errno);
        printf("3. Error from strerror: %s (Target: test.txt)\n", msg);
    }
    return 0;
}
```

#### 📊 실행 결과 및 분석

- **출력 내용:**
    
    Plaintext
    
    ```sql
    1. Direct Errno: 2
    2. Error from perror: No such file or directory
    3. Error from strerror: No such file or directory (Target: test.txt)
    ```
    
- **결과 분석:** * `errno 2`는 헤더 파일에 정의된 **`ENOENT`** 상수를 의미합니다.
    - 이는 **"No such file or directory"**, 즉 지정한 경로에 파일이 존재하지 않아 발생한 오류임을 확증합니다.
        

---

### 💡 핵심 요약

1. **`-1`이 반환되면** 즉시 `errno`를 확인하라.
2. **`perror`**는 빠르고 간편하며, **`strerror`**는 메시지를 원하는 대로 가공할 때 쓴다.
3. **`access()`**는 파일 유무를 확인하는 가장 가벼운 시스템 호출이다.
