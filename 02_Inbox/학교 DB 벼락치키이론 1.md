교수님이 제공한 시험 정보와 1장 PDF 파일을 바탕으로 예상 문제와 해답을 정리했습니다.

시험 정보에 따라 1장('데이터베이스 보안 개요', '보안의 기본 개념')의 내용은 **단답형**과 **서술형** 문제로 구성했습니다.

## 1장: DB 보안 개요 (예상 문제 및 해답)

### ✏️ 단답형

문제 1: 보안에서 말하는 '위험(Risk)'의 의미를 서술하시오.

**해답:** 인가를 받지 않은 접근, 변경, 훼손 또는 파괴 등의 행위가 발생할 가능성이나 그 징후1.

문제 2: DB 보안 문제 발생 시 사후 추적을 위해 절대적으로 필요한 기록은 무엇인지 서술하시오.

**해답:** 누가, 언제, 어디서, 어떤 SQL(Structured Query Language)을 DB로 요청하였는지에 대한 기록2.

문제 3: DB 보안에서 추구하는 3대 요소를 쓰시오.

**해답:** 기밀성, 무결성, 가용성3.

문제 4: 기밀성 유지를 위한 대표적인 방안 2가지를 쓰시오.

**해답:** 접근제어와 암호화4.

문제 5: 전체 보안 사고 중 내부자에 의한 정보 유출 비율은 어느 정도이며, '사람에 의한 사고'의 주된 원인은 무엇인가?

해답:

- **비율:** 70~80% 이상 5
- **주요 원인:** 내부 직원의 고의적 유출이나 부주의에 의한 외부인 접근 기회 제공 6

문제 6: 시스템이 지니고 있는 원래 형태 내에서의 보안상의 문제점이나 허점(Security Hole)을 의미하는 용어는 무엇인가?

**해답:** 취약점(Vulnerability)7.

문제 7: 보안 통제(Security Control)의 3가지 구분을 쓰시오.

**해답:** 관리적 보안 통제 8, 논리적(또는 기술적) 보안 통제 9999, 물리적 보안 통제10101010.

문제 8: 데이터 분류 시 고려되는 2가지 요소를 쓰시오.

**해답:** 민감성, 중요도11.

문제 9: DB 보안 요구사항 중 '추론 방지'에서 '추론(Inference)'이란 무엇인지 정의하시오.

**해답:** 기밀성이 없는 데이터로부터 기밀 정보를 얻어내는 가능성12.

### 📜 서술형

문제 10: 정보보안(Information Security)과 컴퓨터보안(Computer Security)의 공통된 목표와 차이점을 각각 서술하시오.

해답:

- **공통 목표:** 정보에 대한 기밀성(Confidentiality), 무결성(Integrity), 가용성(Availability) 보호13.
- **차이점:** 정보보안은 데이터의 기밀성, 무결성, 가용성 등 보호에 초점을 맞추는 반면 14, 컴퓨터 보안은 컴퓨터 시스템의 가용성과 정확한 동작을 보장하는 데 초점을 맞춘다15.

문제 11: DB 보안의 3대 요소인 기밀성, 무결성, 가용성에 대해 각각 약술하시오.

해답:

- **기밀성(Confidentiality):** 선별적인 접근 체계를 만들어 비인가된 개인이나 시스템에 의한 접근과 이에 따른 정보 공개·노출을 막는 것16.
- **무결성(Integrity):** 비정당한 방법으로 데이터가 변경될 수 없도록 데이터의 정확성 및 완전성을 보장하고, 내용이 고의 혹은 악의로 변경되거나 훼손/파괴되지 않음을 보장하는 것17.
- **가용성(Availability):** 정당한 권한을 가진 사용자나 애플리케이션에 대해 원하는 데이터에 대한 원활한 접근을 제공하는 서비스를 지속할 수 있도록 보장하는 것18181818.

문제 12: 위협(Threats), 위험(Risks), 취약점(Vulnerability)의 개념을 각각 정의하시오.

해답:

- **위협(Threats):** 시스템이 관리하는 정보를 유출하거나 수정하여 단위 조직 또는 전사 차원의 업무 목적 달성이나 미션 수행에 대해 예기치 못한 영향을 미치는 적대적 행위19.
- **위험(Risks):** 인가를 받지 않은 접근, 변경, 훼손 또는 파괴 등의 행위가 발생할 가능성이나 그 징후20.
- **취약점(Vulnerability):** 운영체계나 시스템, 응용소프트웨어, DB 시스템 등이 지니고 있는 원래 형태 내에서의 보안상의 문제점이나 허점(Security Hole)21.

문제 13: 보안 통제의 3가지 유형(관리적, 논리적, 물리적)에 대해 각각의 개념과 예시를 1가지씩 서술하시오.

해답:

- **관리적 보안 통제:** 명문화되어 승인된 정책, 절차, 표준, 가이드라인 등으로 구성되며 22, 예시로는 **전사보안정책, 비밀번호정책** 등이 있다23.
- **논리적 (기술적) 보안 통제:** 정보와 정보시스템에 대한 접근을 감시하고 제어하기 위해 소프트웨어와 데이터를 사용하는 것24. 예시로는 **비밀번호, 방화벽, 접근제어목록, 데이터 암호화** 등이 있다25.
- **물리적 보안 통제:** 작업 장소의 환경과 컴퓨팅 장비들을 감시하고 통제하는 것26. 예시로는 **도어락(출입통제장치), 감시카메라** 등이 있다27.

문제 14: 논리적 보안 통제의 중요한 원칙인 '최소권한의 원칙'과 물리적 보안 통제의 중요한 개념인 '의무의 분리'를 각각 설명하시오.

해답:

- **최소권한의 원칙 (논리적 통제):** 사용자가 업무를 수행하는 데 필요한 최소한의 접근권한만을 부여하는 원칙28. (예: 직무 변경 시 이전의 불필요한 권한은 제거해야 함 29)
- **의무의 분리 (물리적 통제):** 개인이 혼자서 핵심적인 업무를 완료할 수 없도록 역할과 책임을 다른 직원에게 분산시키는 것30. (예: 애플리케이션 개발자가 DB 관리자가 될 수 없어야 함 31)

## 4교수님의 시험 정보와 4장 PDF 파일을 바탕으로 예상 문제와 해답을 정리했습니다.

교수님이 4장에서 **GRANT, REVOKE와 관련된 실습 예제는 제외**한다고 하셨는데, 제공된 4장 PDF 자료에는 해당 SQL 명령어(GRANT, REVOKE)에 대한 내용이 없고, '역할 기반 접근 제어(RBAC)'와 같은 개념적 수준에서 권한 관리를 다루고 있습니다1.

따라서 아래 문제들은 이 자료의 내용을 바탕으로 단답형과 서술형으로 구성했습니다.

## 4장: DB 보안 방법 (예상 문제 및 해답)

### ✏️ 단답형

문제 1: 웹 애플리케이션의 보안 취약점을 이용하여 악의적인 SQL 코드를 주입하는 공격 기법을 무엇이라고 하는가?

**해답:** SQL 인젝션 (SQL Injection) 2

문제 2: 심리적 조작을 통해 피해자가 자발적으로 정보나 액세스를 제공하도록 유도하는 공격 기법은 무엇인가?

**해답:** 사회공학적 공격 3

문제 3: 사용자 역할에 따라 접근 권한을 부여하는 제어 방식을 무엇이라고 하는가?

**해답:** 역할 기반 접근 제어 (RBAC: Role-Based Access Control) 4

문제 4: 인터넷 상에서 데이터 전송을 안전하게 보호하기 위해 사용되는 암호화 프로토콜(인터넷 보안 프로토콜)은 무엇인가?

**해답:** TLS (Transport Layer Security) 또는 SSL (Secure Sockets Layer) 5

문제 5: 트랜잭션 관리가 보장해야 하는 4가지 속성(ACID)을 쓰시오.

**해답:** 원자성(Atomicity), 일관성(Consistency), 고립성(Isolation), 영속성(Durability) 6

문제 6: IT 시스템이 지속적으로 운영될 수 있도록 보장하는 방법론과 기술을 의미하며, 장애가 발생하더라도 시스템이 중단되지 않고 계속 작동하도록 보장하는 것을 목표로 하는 용어는 무엇인가?

**해답:** 장애 조치 또는 고가용성 (HA: High Availability) 7

문제 7: 침입 탐지 시스템과 침입 방지 시스템의 약어(영문)를 각각 쓰시오.

해답:

- **침입 탐지 시스템:** IDS (Intrusion Detection System) 8
- **침입 방지 시스템:** IPS (Intrusion Prevention System) 9

문제 8: 데이터베이스 내 활동(로그인, 데이터 접근, 쿼리 실행 등)을 기록하고, '누가, 언제, 무엇을 접근했는지' 추적하는 것을 무엇이라고 하는가?

**해답:** 감사 추적 (Audit trail) 또는 감사(Auditing) 10

문제 9: 통합 보안 모니터링 시스템을 의미하는 약어는 무엇인가?

**해답:** SIEM (Security Information and Event Management) 11

문제 10: 유럽연합(EU)에서 제정한 데이터 보호 법률로, 개인의 개인정보 보호를 강화하고 데이터에 대한 권리를 보장하는 것을 목표로 하는 규정은 무엇인가?

**해답:** GDPR (General Data Protection Regulation) 12

### 📜 서술형

문제 11: 데이터베이스 보안에서 '인증(Authentication)'과 '권한 관리(Authorization)'의 개념을 각각 설명하시오.

해답:

- **인증(Authentication):** 사용자가 자신이 누구인지 증명하는 과정입니다. ID/비밀번호, 생체인식, 2단계 인증 등이 이에 해당합니다13.
- **권한 관리(Authorization):** 인증된 사용자가 특정 자원(테이블, 열, 행 등)에 대해 어떤 작업을 수행할 수 있는지를 제어하고 허가하는 과정입니다. 역할 기반 접근 제어(RBAC)가 대표적인 예입니다14.

문제 12: 데이터 암호화의 두 가지 유형인 '전송 중인 데이터 암호화'와 '저장된 데이터 암호화'에 대해 각각 설명하시오.

해답:

- **전송 중인 데이터 암호화:** 네트워크 상에서 데이터가 전송될 때 암호화하는 것을 의미합니다. TLS/SSL 프로토콜을 사용하여 클라이언트와 서버 간의 데이터를 암호화하여 중간에서 유출되거나 변조되는 것을 방지합니다15151515.
- **저장된 데이터 암호화:** 데이터베이스 내의 데이터 자체를 암호화하는 것을 의미합니다. 디스크 전체, 특정 테이블 또는 특정 컬럼(열) 단위로 암호화하여 데이터가 물리적으로 유출되더라도 내용을 알 수 없게 보호합니다16.

문제 13: 데이터 무결성과 데이터 가용성을 보장하기 위한 방법을 각각 1가지씩 설명하시오.

해답:

- **데이터 무결성 보장 방법:** 트랜잭션 관리를 통해 ACID(원자성, 일관성, 고립성, 영속성) 속성을 보장하거나, 주기적인 백업 및 복구 계획을 수립하여 데이터의 정확성과 완전성을 유지합니다17.
- **데이터 가용성 보장 방법:** 장애 조치(HA)를 구현하여 시스템 장애 시에도 중단 없이 작동하도록 보장합니다. 이는 이중화(데이터 복제), 클러스터링 등을 통해 달성할 수 있습니다18181818.

문제 14: 데이터베이스 접근 제어 방법 중 '네트워크 기반 접근 제어'와 '데이터베이스 레벨 접근 제어'를 비교하여 설명하시오.

해답:

- **네트워크 기반 접근 제어:** 데이터베이스 시스템의 외부 네트워크 레벨에서 접근을 통제하는 방식입니다. 방화벽을 통해 특정 IP나 포트의 접근을 제어하거나, IDS/IPS를 통해 악의적인 네트워크 트래픽을 탐지하고 차단합니다19.
- **데이터베이스 레벨 접근 제어:** 데이터베이스 관리 시스템(DBMS) 자체의 기능을 사용하여 접근을 통제하는 방식입니다. DBMS의 네이티브 기능을 이용해 특정 사용자의 쿼리를 제한하거나, 접근 활동을 로깅(기록)합니다20.
