## 1. 방문 처리 (`visited`) — 그래프의 생존 법칙

트리와 그래프의 가장 큰 차이는 **싸이클(Cycle)**의 유무입니다. 그래프는 길을 따라가다 보면 이전에 왔던 곳으로 다시 돌아올 수 있습니다.

- **왜 하는가?** 방문 처리를 안 하면 무한 루프에 빠져 프로그램이 뻗어버립니다.
- **어떻게 하는가?** 보통 정점의 개수만큼의 크기를 가진 불리언 배열(`boolean[] visited`)을 만들어 사용합니다.
    - 노드에 방문하기 직전이나 직후에 `visited[node] = true`로 체크합니다.
    - 다음 노드로 가기 전, `if (!visited[next])` 인지 반드시 확인합니다.

## 2. BFS vs DFS: 도구와 목적의 차이

이 두 가지는 단순히 '순서'의 차이가 아니라 **'무엇을 해결하고 싶은가'**에 따라 선택이 달라집니다.

### BFS (너비 우선 탐색)

- **핵심 도구:** **큐(Queue)** (FIFO)
- **작동 방식:** 현재 노드에서 갈 수 있는 모든 이웃을 먼저 다 방문하고, 그 다음 층으로 넘어갑니다. (물결이 퍼져나가는 방식)
- **핵심 용도:** **최단 거리(Shortest Path)** 보장. (가중치가 없는 그래프에서 처음 발견한 경로가 무조건 최단 거리임)
    

### DFS (깊이 우선 탐색)

- **핵심 도구:** **재귀(Recursion)** 또는 **스택(Stack)**
- **작동 방식:** 갈 수 있는 데까지 끝까지 파고듭니다. 더 이상 갈 곳이 없으면 뒤로 돌아와서 다른 길을 찾습니다.
- **핵심 용도:** **모든 경로 탐색(완전 탐색)**, 연결된 덩어리 개수 세기, 백트래킹(조합, 순열).

## 3. 방향 벡터 (Direction Vectors) — 격자형 그래프의 핵심

코딩 테스트 단골 문제인 '미로 찾기'나 '지도 탐색'은 정점 리스트를 주지 않습니다. 2차원 배열 자체가 그래프입니다. 이때 **상하좌우**로 이동하기 위한 기술이 필요합니다.

- **방식:** 현재 위치 `(r, c)`에서 이동할 상대적 변화량을 배열로 선언합니다.

    ```Python
    # Python 예시
    dr = [-1, 1, 0, 0] # 행 이동 (상, 하, 좌, 우)
    dc = [0, 0, -1, 1] # 열 이동 (상, 하, 좌, 우)
    
    for i in range(4):
        nr = r + dr[i]
        nc = c + dc[i]
        # 이후 nr, nc가 격자 범위 내에 있는지, 벽이 아닌지 체크
    ```

## 요약 테이블

|**개념**|**BFS**|**DFS**|
|---|---|---|
|**자료구조**|`Queue`|`Recursion` (Call Stack)|
|**탐색 스타일**|가까운 곳부터 넓게|한 놈만 끝까지 깊게|
|**주요 목적**|**최단 거리**, 최소 횟수|**경로 존재 여부**, 모든 조합 찾기|
|**복잡도**|$O(V + E)$|$O(V + E)$|

> **팁:** 시간이 정말 없다면 **BFS**를 먼저 확실히 익히세요. 최단 거리 문제는 BFS로만 풀 수 있는 경우가 많지만, 단순 탐색 문제는 BFS와 DFS 둘 다 가능한 경우가 많기 때문입니다.
