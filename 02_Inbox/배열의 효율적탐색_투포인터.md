## 🚀 [심화] 배열의 효율적 탐색: 투 포인터 (Two Pointers)

배열(Array)의 가장 큰 장점인 **인덱스를 이용한 즉시 접근(Random Access)**을 활용하여 시간 복잡도를 획기적으로 줄이는 알고리즘입니다.

### 1. 핵심 개념

* **정의:** 리스트에 순차적으로 접근해야 할 때, **두 개의 점(포인터)** 위치를 기록하며 처리하는 기법.
* **활용 목적:** 이중 반복문()을 사용해야 할 문제를 **단일 반복문()**으로 해결하기 위함.
* **전제 조건:** 주로 **정렬된 배열(Sorted Array)**에서 두 수의 합, 차이 등을 구할 때 사용됩니다.

### 2. 동작 방식 (양 끝에서 좁혀오기)

1. **시작점(`left`)**은 배열의 맨 앞(0), **끝점(`right`)**은 배열의 맨 뒤(`len-1`)에 둡니다.
2. 두 포인터가 가리키는 값의 연산 결과(합, 차 등)에 따라 포인터를 이동시킵니다.
	* 값이 목표보다 작으면? 값을 키워야 하므로 `left`를 오른쪽으로 (`left++`)
	* 값이 목표보다 크면? 값을 줄여야 하므로 `right`를 왼쪽으로 (`right--`)
3. `left`와 `right`가 교차하거나 만날 때까지 반복합니다.

### 3. 시간 복잡도 비교

* **완전 탐색 (Brute Force):** (모든 쌍을 비교)
* **투 포인터:** **** (리스트를 양쪽에서 한 번만 훑고 지나감)

```python
# [예시] 정렬된 배열에서 두 수의 합이 target이 되는지 확인
def two_sum(nums, target):
    nums.sort() # 투 포인터는 정렬 필수
    l, r = 0, len(nums) - 1
    
    while l < r:
        current_sum = nums[l] + nums[r]
        if current_sum > target:
            r -= 1 # 합을 줄여야 함 (큰 값을 왼쪽으로)
        elif current_sum < target:
            l += 1 # 합을 키워야 함 (작은 값을 오른쪽으로)
        else:
            return True # 찾음
    return False

```
