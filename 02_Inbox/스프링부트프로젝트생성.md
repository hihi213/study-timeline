### 1. Spring Web (`spring-boot-starter-web`)

- **기술적 정의:** RESTful 웹 서비스 및 MVC 애플리케이션 구축을 위한 핵심 라이브러리 모음입니다.
- **핵심 역할:**
    
    1. **임베디드 컨테이너:** 외장 WAS(Web Application Server) 설치 없이 애플리케이션을 실행할 수 있도록 **Tomcat**을 내장하고 있습니다.
    2. **DispatcherServlet:** HTTP 요청(Request)을 받아 적절한 Controller로 라우팅하고, 응답(Response)을 클라이언트에 반환하는 **Spring MVC** 프레임워크를 제공합니다.
    3. **JSON 처리:** Jackson 라이브러리를 포함하여, 자바 객체와 JSON 데이터 간의 직렬화/역직렬화를 자동으로 처리합니다.
        

### 2. Spring Data JPA (`spring-boot-starter-data-jpa`)

- **기술적 정의:** 자바 표준 ORM(Object-Relational Mapping) 기술인 **JPA**를 쉽게 사용할 수 있도록 추상화한 모듈입니다.
- **핵심 역할:**
    
    1. **Repository 추상화:** `JpaRepository` 인터페이스를 통해 단순 CRUD(Create, Read, Update, Delete) 메서드를 자동으로 구현해 줍니다. 개발자가 직접 SQL이나 JDBC 코드를 작성할 필요가 없습니다.
    2. **Hibernate 구현체:** JPA 인터페이스의 실제 구현체로 **Hibernate**를 사용합니다. 내부적으로 자바 객체(Entity)를 분석하여 SQL을 생성하고 실행합니다.
    3. **영속성 컨텍스트 관리:** 엔티티의 생명주기를 관리하고, 1차 캐시 및 쓰기 지연 등을 통해 데이터베이스 접근 성능을 최적화합니다.
        

### 3. PostgreSQL Driver (`postgresql`)

- **기술적 정의:** Java 애플리케이션이 PostgreSQL 데이터베이스 서버와 통신하기 위한 **JDBC(Java Database Connectivity) 드라이버**입니다.
- **핵심 역할:**
    
    1. **프로토콜 변환:** Java 표준 SQL 인터페이스(JDBC API) 호출을 PostgreSQL 고유의 네트워크 프로토콜(Wire Protocol)로 변환하여 DB 서버로 전송합니다.
    2. **연결 관리:** `DriverManager` 또는 커넥션 풀(HikariCP)이 DB와 TCP/IP 연결을 맺을 때 필수적으로 사용되는 구현체 라이브러리입니다.
        

### 4. Lombok (`lombok`)

- **기술적 정의:** Java의 **Annotation Processor** 기능을 이용하여, 컴파일 시점에 상용구 코드(Boilerplate Code)를 자동으로 생성(Generate)해 주는 라이브러리입니다.
- **핵심 역할:**
    
    1. **바이트코드 생성:** 소스 코드(`.java`)에는 어노테이션(`@Getter`, `@Setter`)만 존재하지만, 컴파일된 결과물(`.class`)에는 실제 `getMethod`, `setMethod`, `Constructor` 등의 메서드가 자동으로 삽입됩니다.
    2. **가독성 향상:** DTO나 Entity 클래스에서 단순 반복되는 코드를 제거하여 소스 코드의 복잡도를 낮춥니다.
        

### 5. Validation (`spring-boot-starter-validation`)

- **기술적 정의:** 데이터 유효성 검증을 위한 표준 명세인 **Jakarta Bean Validation (JSR-380)**과 그 구현체인 **Hibernate Validator**를 제공합니다.
- **핵심 역할:**
    
    1. **선언적 검증:** 비즈니스 로직(if문)으로 데이터를 검사하는 대신, 필드 위에 어노테이션(`@NotNull`, `@Email`, `@Size`)을 붙여 제약 조건을 선언합니다.
    2. **AOP 기반 검증 수행:** Controller로 데이터가 들어오는 시점에 인터셉터가 동작하여, 유효하지 않은 데이터일 경우 `MethodArgumentNotValidException` 예외를 발생시키고 400 Bad Request 응답을 유도합니다.
