A등급 영역을 완벽히 소화한 후 B등급으로, B등급 완료 후 C등급으로 넘어가는 방식으로 학습

## 🔥 A등급: 반드시 해야 할 영역

전체 시간의 약 80%를 배정해야 하는 핵심 영역입니다.

### 1. Java·Python 코드 추적

- **선정 이유:** 기존 기본기가 있어 가장 빠르게 점수화 가능하며, 최근에도 지속해서 출제되기 때문입니다.
- **수제비 목차:**
    - `VI 프로그래밍 언어 활용` - `03 자바` (지피지기 기출문제 6-208, 천기누설 예상문제 6-241)
    - `VI 프로그래밍 언어 활용` - `04 파이썬` (지피지기 기출문제 6-299, 천기누설 예상문제 6-309)
- **4일 학습 깊이:** 문법 재학습보다 기출 출력값 문제 반복 (상속·오버라이딩·static·예외, 슬라이싱·참조·얕은 복사 집중)
- **중단 기준:** 한 문제 10분. 틀리면 핵심 원인 한 줄만 기록하고 이동.
    

### 2. SQL·DB 실전

- **선정 이유:** 적은 시간으로 정답률을 올리기 좋고 2026년에도 출제 강세를 보이기 때문입니다.
- **수제비 목차:**
    - `VII SQL 응용` - `02 응용 SQL`, `03 SQL 활용 및 최적화` (지피지기 기출문제 7-64, 천기누설 예상문제 7-68, 7-71)
    - `II 데이터 입출력 구현` - `02 데이터베이스 기초 활용` (지피지기 3-50, 천기누설 3-51)
- **4일 학습 깊이:** 조인·집계·서브쿼리·NULL·DDL을 직접 작성. DB 이론은 설계절차·키·정규화 중심
- **중단 기준:** SQL 한 문제 8분. 문법을 두 번 고쳐도 안 되면 정답 구조 확인 후 이동
    

### 3. C 최소 필수

- **선정 이유:** 난도가 높지만 2~4문제가 반복 출제되어 완전히 포기하는 것은 위험하기 때문입니다.
- **수제비 목차:** `VI 프로그래밍 언어 활용` - `02 C언어` (지피지기 6-99 / 천기누설 6-145)
- **4일 학습 깊이:** 배열, 포인터, 문자열, 구조체까지만 우선순위로 두고 코드 한 줄씩 값 추적
- **중단 기준:** 15분 안에 흐름이 안 보이면 정답 해설에서 핵심 연산만 확인.
    

### 4. 네트워크 계산·핵심 프로토콜

- **선정 이유:** 서브넷은 연습만 해두면 안정적으로 확보 가능한 계산 문제이기 때문입니다.
- **수제비 목차:** `XI 응용 SW 기초 기술 활용` - `02 네트워크 기초 활용하기` (지피지기 11-90 / 천기누설 11-101)
- **4일 학습 깊이:** CIDR, 네트워크 주소, 브로드캐스트, 호스트 범위 계산 및 TCP/UDP, ARP 파악
- **중단 기준:** 한 문제 7분. 두 번 틀리면 계산 절차만 암기.
    

### 5. 보안 공격 시나리오

- **선정 이유:** 단순 정의형보다 상황 판별형으로 꾸준히 반복 출제되기 때문입니다.
- **수제비 목차:** `IX 소프트웨어 개발 보안 구축` - `01 소프트웨어 개발 보안 설계`, `02 소프트웨어 개발 보안 구현` (지피지기 9-31, 9-56 / 천기누설 9-40, 9-59)
- **4일 학습 깊이:** 공격명과 핵심 단서 연결 (세션 하이재킹, 워터링홀, 레이스 컨디션, SQL Injection 등)
- **중단 기준:** 한 개념을 3회 틀리면 암기 목록에만 남기고 이동.
    

### 6. 테스트·설계 핵심 단답

- **선정 이유:** 비교적 짧은 시간 암기하는 것으로 2~3문제를 추가 확보할 수 있기 때문입니다.
- **수제비 목차:**
    - `X 애플리케이션 테스트 관리` (지피지기 기출문제 10-24, 10-42, 10-47, 천기누설 예상문제 10-33, 10-44, 10-48)
    - `VIII 서버 프로그램 구현` - `02 모듈 구현` (지피지기 기출문제 8-19, 천기누설 예상문제 8-23)
- **4일 학습 깊이:** 커버리지, 스텁·드라이버, 응집도·결합도, 대표 디자인 패턴
- **중단 기준:** 패턴 전체 구조를 이해하려 하지 말고 식별 단서 1개만 암기

## 🛡️ B등급: 시간이 허락하면 방어할 영역

A등급 완료 후 여유가 있을 때만 진행하는 영역입니다.

### 1. DB 이론 확장

- **선정 이유:** SQL과 함께 출제되지만 범위가 넓어 효율이 다소 떨어지기 때문입니다.
- **수제비 목차:** `VII SQL 응용` - `01 데이터베이스 기본` (지피지기 7-37 / 천기누설 7-50)
- **4일 학습 깊이:** 트랜잭션 ACID, 이상 현상, 함수적 종속, 무결성
- **중단 기준:** 정의를 한 문장으로 말할 수 있으면 종료.

### 2. 운영체제·리눅스

- **선정 이유:** 회차에 따라 0~3문제로 출제 편차가 크기 때문입니다.
- **수제비 목차:** `XI 응용 SW 기초 기술 활용` - `01 운영체제의 특징` (지피지기 11-38 / 천기누설 11-44)
- **4일 학습 깊이:** 스케줄링, 교착상태, 기본 명령어만
- **중단 기준:** 새로운 계산 유형은 10분 이상 투자 금지.
    

### 3. 요구사항·UML

- **선정 이유:** 공식 출제 범위이며 단답형 출제 가능성이 존재하기 때문입니다.
- **수제비 목차:** `I 요구사항 확인` - `02 현행 시스템 분석`, `III 화면 설계` - `02 설계` (지피지기 1-39, 2-28 / 천기누설 1-43, 2-31)
- **4일 학습 깊이:** 기능 및 비기능 요구사항, 주요 UML 종류 식별
- **중단 기준:** 세부 UML 표기법까지 깊이 들어가지 않음.
    

### 4. C 고난도 일부 & 디자인 패턴 확장

- **선정 이유:** 맞히면 좋지만 들이는 시간 소모가 너무 크거나(C 언어), 같은 패턴보다 인접 패턴이 회전 출제되는 경향(디자인 패턴)이 있기 때문입니다.
- **4일 학습 깊이:**
    - C: 함수 포인터·동적 메모리·이중 포인터를 대표 문제 1개씩만
    - 패턴: Adapter, Bridge, Observer, Strategy, Factory, Singleton 정도
- **중단 기준:** 예제 하나를 따라가지 못해도 추가 탐구 금지. 패턴별 키워드 한 줄만 외우고 클래스 구조 분석 금지.
    

## ✂️ C등급: 과감히 최소화할 영역

투입 시간 대비 점수 회수 가능성이 낮아 방어적으로 쳐내야 하는 영역입니다.

### 1. 통합 구현·화면 설계·제품 패키징

- **선정 이유:** 최근 기출 비중이 극도로 낮고, 그에 반해 암기해야 할 범위는 넓기 때문입니다.
- **수제비 목차:**
    - `IV 통합 구현` (지피지기 기출문제 4-14, 천기누설 예상문제 4-6, 4-17)
    - `III 화면 설계` - `01 UI 요구사항 확인` (지피지기 기출문제 2-8, 천기누설 예상문제 2-10)
    - `XII 제품 소프트웨어 패키징` (지피지기 기출문제 12-7, 천기누설 예상문제 12-8)
- **4일 학습 깊이:** 기출에 실제 나온 용어만 확인
- **중단 기준:** 20~30분 이상 배정 금지

### 2. 인터페이스 세부 비교 (EAI·ESB·SOAP·DRM)

- **선정 이유:** 출제 가능성은 존재하나 16시간 단기 전략 대비 학습 효율이 크게 떨어지기 때문입니다.
- **수제비 목차:** `V 인터페이스 구현` (지피지기 기출문제 5-9, 천기누설 예상문제 5-11)
- **4일 학습 깊이:** 정의와 대표 특징 한 줄
- **중단 기준:** 표 전체 암기 금지
    

### 3. 고난도 완전 정복 (디자인 패턴 23개, 복잡한 C 메모리, 새 알고리즘)

- **선정 이유:** 한 문제를 위해 지나치게 많은 시간을 쓰게 되거나, 시험 직전 투자 대비 정답률 확보가 어렵기 때문입니다.
- **4일 학습 깊이:** A/B 등급에 속한 패턴과 기출에 나온 배열 추적 코드 흐름만 확인
- **중단 기준:** 패턴별 코드 구현 학습 금지, 새로운 정렬·트리·그래프 학습 금지, 15분 초과 시 즉시 포기.
