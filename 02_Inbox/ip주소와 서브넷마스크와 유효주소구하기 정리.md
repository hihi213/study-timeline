## 📘 주요 용어 정리

- **IP 주소 (IP Address):** 네트워크상에서 장치가 가지는 고유한 논리적 주소입니다.
- **서브넷 (Subnet):** 하나의 커다란 네트워크를 효율적으로 관리하기 위해 더 작은 단위로 분할한 **부분 망**입니다.
- **서브넷 마스크 (Subnet Mask):** IP 주소에서 어디까지가 **네트워크 주소**이고, 어디서부터가 **호스트(기기) 주소**인지를 구분하는 기준점입니다.
- **네트워크 주소 (Network ID):** 해당 서브넷의 **시작 주소**이며, 네트워크 자체를 대표하는 주소이므로 개별 장치에 할당할 수 없습니다.
- **브로드캐스트 주소 (Broadcast ID):** 해당 서브넷에 속한 **모든 장치에 동시에 데이터를 전송**하기 위해 사용하는 마지막 주소입니다. 이 또한 개별 장치에는 할당할 수 없습니다.

## 📝 IP 주소 및 서브넷 마스크 풀이

**대상:** `192.168.35.10` / **마스크:** `255.255.252.0`

### 1단계: 마스크 분석을 통한 변동 마디(Octet) 식별

서브넷 마스크를 통해 네트워크와 호스트의 경계가 어느 옥텟(마디)에 있는지 확인합니다.

- **마스크 확인:** `255.255.252.0`
- **경계 식별:** 첫 번째와 두 번째 마디(255.255)는 꽉 차 있는 고정 영역입니다. **세 번째 마디(252)**에서 비트 분할이 일어나므로, 세 번째와 네 번째 마디가 호스트 범위를 결정하는 변동 구간이 됩니다.
    

### 2단계: 블록 크기(Block Size) 산출

하나의 서브넷이 가질 수 있는 IP 가짓수(네트워크 증분값)를 계산합니다.

- **계산식:** $256 - 252 = 4$
- **의미:** 세 번째 마디는 **4씩 증가**하며 새로운 서브넷이 생성됩니다.
    - 서브넷 단위: $0, 4, 8, \dots, 28, 32, 36, \dots$
        

### 3단계: 네트워크 주소(Network ID) 산출

주어진 IP가 속한 그룹의 시작 번호를 찾습니다.

- **대상 숫자:** 세 번째 마디의 `35`
- **연산 과정:**
    
    1. $35 \div 4 = 8.75$
    2. 소수점을 버린 정수값 $8$에 블록 크기 $4$를 곱합니다: $8 \times 4 = 32$
        
- **결과:** 해당 IP가 속한 서브넷의 시작 주소는 **`192.168.32.0`**입니다.
    

### 4단계: 브로드캐스트 주소(Broadcast ID) 산출

해당 그룹의 가장 마지막 번호를 찾습니다.

- **개념:** 다음 네트워크 주소 바로 앞의 주소가 현재 네트워크의 마지막 주소입니다.
- **연산 과정:**
    - **세 번째 마디:** (현재 네트워크 주소 32 + 블록 크기 4) - 1 = **35**
    - **네 번째 마디:** 호스트 비트가 모두 1인 상태이므로 최대치인 **255**가 됩니다.
- **결과:** 해당 서브넷의 마지막 주소는 **`192.168.35.255`**입니다.
    

### 5단계: 수신 및 통신 가능한 IP 범위 확정

실제 컴퓨터나 서버에 할당하여 통신할 수 있는 유효한 IP의 범위입니다.

- **전체 주소 범위:** `192.168.32.0` ~ `192.168.35.255`
- **유효 호스트 범위:** 네트워크 주소(+1)와 브로드캐스트 주소(-1)를 제외한 나머지입니다.
    - **`192.168.32.1` ~ `192.168.35.254`**
