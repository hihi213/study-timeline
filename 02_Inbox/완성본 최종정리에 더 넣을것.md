# 📂 [System Programming] stat 구조체와 파일 메타데이터 분석

`stat()` 시스템 콜은 하드디스크의 **아이노드(Inode)**에 저장된 원시 비트 데이터를 읽어와, 사용자 영역의 **stat 구조체**에 담아 전달하는 과정입니다.

---

## 1. stat 구조체 주요 필드 매트릭스

가장 빈번하게 사용되는 핵심 필드 4가지를 정리했습니다.

|**필드명**|**의미**|**데이터 타입**|**핵심 변환 도구 및 비고**|
|---|---|---|---|
|**`st_mode`**|**파일 종류 및 권한**|`mode_t`|**S_ISxxx** 매크로, **8진수**(%o) 포맷|
|`st_size`|파일 크기 (Bytes)|`off_t`|`(long long)` 캐스팅 필요|
|`st_uid / gid`|소유자 / 그룹 ID|`uid / gid_t`|`getpwuid()`, `getgrgid()` 함수|
|`st_mtime`|최종 수정 시간|`time_t`|`localtime()`, `strftime()` 함수|

---

## 2. st_mode 비트 필드 (16비트) 구조 분석

`st_mode`는 하나의 정수 안에 여러 정보를 밀어 넣은 비트 집합입니다.

### 🏗️ 비트 레이아웃

|**비트 범위**|**15 ~ 12**|**11 ~ 9**|**8 ~ 6**|**5 ~ 3**|**2 ~ 0**|
|---|---|---|---|---|---|
|**역할**|**파일 종류**|**특수 권한**|**소유자(U)**|**그룹(G)**|**기타(O)**|
|**상세**|일반, 디렉터리 등|SetUID, Sticky|r w x|r w x|r w x|

### 🔍 상세 비트 매핑 (주요 값)

- **파일 종류 (상위 4비트):**
    - `1000` (8): 일반 파일 (`-`)
    - `0100` (4): 디렉터리 (`d`)
    - `1010` (10): 심볼릭 링크 (`l`)
- **접근 권한 (하위 9비트):** 3비트씩 묶어 `r(4) w(2) x(1)`로 해석 (예: `110` → `6` → `rw-`)
    

---

## 3. 파일 종류 판별: 비트 마스크 vs 매크로

비트 마스크는 원리를 이해하는 데 좋고, 매크로는 실무적 가독성이 높습니다.

### A. 비트 마스크 방식 (원리)

$S\_IFMT$는 종류 비트만 추출하기 위한 필터(Mask)입니다.

> **연산 로직:** $(st\_mode \ \& \ S\_IFMT) == S\_IFREG$

### B. 매크로 함수 방식 (추천)

내부적으로 위 비트 연산을 수행하여 `True/False`를 반환합니다.

|**파일 종류**|**비트 마스크 상수**|**매크로 함수**|
|---|---|---|
|일반 파일|`S_IFREG`|`S_ISREG(st_mode)`|
|디렉터리|`S_IFDIR`|`S_ISDIR(st_mode)`|
|심볼릭 링크|`S_IFLNK`|`S_ISLNK(st_mode)`|

---

## 4. 권한(rwx) 추출 및 문자열 변환

`ls -l`처럼 10글자(`-rwxr-xr-x`)의 권한 문자열을 만드는 핵심 로직입니다.

C

```sql
char res[11];
mode_t mode = statbuf.st_mode;

// 1. 파일 종류 (매크로 활용)
res[0] = S_ISDIR(mode) ? 'd' : (S_ISLNK(mode) ? 'l' : '-');

// 2. 소유자 권한 (비트 AND 연산)
res[1] = (mode & S_IRUSR) ? 'r' : '-'; // 100 000 000과 비교
res[2] = (mode & S_IWUSR) ? 'w' : '-'; // 010 000 000과 비교
res[3] = (mode & S_IXUSR) ? 'x' : '-'; // 001 000 000과 비교

// … Group(IRGRP..), Others(IROTH..) 반복 …
res[10] = '\0';
```

## 5. 인간 친화적 데이터 변환 (Interpretation)

컴퓨터의 숫자 데이터를 사람이 읽을 수 있는 이름과 날짜로 바꿉니다.

### ① 사용자 및 그룹 이름 (ID → Name)

커널은 숫자로만 관리하므로 시스템 DB(`/etc/passwd`)를 조회해야 합니다.

- **함수:** `getpwuid(statbuf.st_uid)` → 리턴값의 `pw_name` 필드 사용.
    

### ② 시간 정보 변환 (Epoch → String)

1. **1단계 (`localtime`):** 초 단위 정수를 년/월/일/시/분/초가 담긴 `struct tm`으로 분해.
2. **2단계 (`strftime`):** 분해된 정보를 원하는 포맷(예: `%Y-%m-%d`) 문자열로 변환.

## 💡 최종 핵심 요약

> **"비트 연산으로 정보를 추출하고, 시스템 함수로 의미를 부여한다."**
>
> 1. `st_mode`는 **비트 연산(&)**을 통해 종류와 권한을 분리한다.
>     
> 2. 숫자로 된 ID나 시간은 **DB 조회 및 구조체 분해**를 통해 텍스트로 치환한다.
>     
> 3. C언어에서 권한 관련 상수를 직접 다룰 땐 **8진수 표기법(0755 등)**에 유의한다.
>
