# 📂 [System Programming] stat 구조체와 파일 메타데이터 분석

`stat()` 시스템 콜은 하드디스크의 **아이노드(Inode)**에 저장된 파일의 메타데이터를 읽어와 사용자 영역의 **stat 구조체**에 복사하는 과정입니다. 커널이 넘겨주는 0과 1의 **원시 비트(Raw Bits)**를 개발자가 유의미한 정보로 **해석(Interpretation)**하는 것이 핵심입니다.

---

## 1. stat 구조체 핵심 필드 가이드

| **필드명**            | **의미**       | **데이터 타입 (크기)**           | **구현 로직 및 출력 방식 (서식 지정자)**                                                                                                                                                                  |
| ------------------ | ------------ | ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`st_mode`**      | 파일 종류 및 권한   | `mode_t` (32 bit / 유효 16) | **로직:** <br>1. 비트 마스크(`&`)로 플래그를 추출<br>2. 추출된값을 상수와 비교하거나 `S_ISxxx` 매크로를 사용<br><br>**출력:** 부호 확장 방지를 위해 **`(unsigned int)`** 캐스팅 후 **`%o`**(8진수)로 출력함.                                      |
| **`st_size`**      | 파일 크기 (Byte) | `off_t` (**64 bit**)      | **로직:** int처럼 더 작은 타입을 쓰면 데이터 절단(Overflow)되므로 64비트 정수 규격long long 자료형 유지함.<br><br>**출력:** **`(long long)`** 캐스팅 후 **`%lld`**로 출력함.                                                          |
| **`st_mtime`**     | 최종 수정 시간     | `time_t` (**64 bit**)     | **로직:** `localtime()`으로 구조체를 분해한 후 `strftime()`으로 문자열 변환을 수행함.<br><br>**출력:** 최종 결과는 **`%s`**(문자열)를 사용하며, 원시 데이터 출력 시에는 **`%lld`**를 사용함.                                                    |
| **`st_uid / gid`** | 사용자 / 그룹 ID  | `uid_t / gid_t` (32 bit)  | **로직:** `getpwuid()` 또는 `getgrgid()`로 ID를 실제 이름 문자열로 치환함.<br><br>**출력:** 이름 치환 후에는 **`%s`**를 사용하며, <br><br>원시 데이터 출력 시에는 데이터 타입이 음수가 없는 ~이므로 `unsigned int` 취급해  **`%u`**(부호 없는 10진수)를 사용함. |
| **`st_ino`**       | 아이노드 번호      | `ino_t` (**64 bit**)      | **로직:** 파일 시스템 내 유일 식별 번호로 파일의 동일성 판별 로직에 사용함.<br><br>**출력:** 별도 치환 없이 **`%llu`** 또는 **`%lu`**(부호 없는 64비트 정수)로 출력함.                                                                         |
| **`st_nlink`**     | 하드 링크 수      | `nlink_t` (32/64 bit)     | **로직:** 참조 카운트 데이터로, `unlink()` 시스템 콜 호출 시 값이 `0`인지 확인하여 데이터 삭제 여부를 결정함.<br><br>**출력:** 시스템 환경에 따라 **`%lu`** 또는 **`%u`**를 사용함.                                                              |


## 2. st_mode 비트 필드(16비트) 구조 분석

`st_mode`는 하나의 정수 안에 여러 정보를 밀어 넣은 **비트 집합**입니다.

### 🏗️ 비트 레이아웃

|**비트 범위**|**15 ~ 12**|**11 ~ 9**|**8 ~ 6**|**5 ~ 3**|**2 ~ 0**|
|---|---|---|---|---|---|
|**역할**|**파일 종류**|**특수 권한**|**소유자(U)**|**그룹(G)**|**기타(O)**|
|**상세**|일반, 디렉터리 등|SetUID/GID, Sticky|r w x|r w x|r w x|


- **`mode_t` (16~32 bit):** 8진수로 읽어야 하므로 **`%o`**
- **`off_t` / `time_t` (64 bit):** 8바이트 정수이므로 **`%lld`** (캐스팅 포함)
- **`uid_t` / `gid_t` (32 bit):** 부호 없는 정수이므로 **`%u`**
- **`ino_t` (64 bit):** 고유 번호이므로 보통 **`%lu`** 또는 **`%llu



### 🔍 파일 종류 판별: 비트 마스크 vs 매크로

커널에서 받은 `st_mode`에서 파일 형식을 추출하는 두 가지 방식입니다.

- **A. 비트 마스크 방식:** `$statbuf.st_mode \ \& \ S\_IFMT$` 연산을 통해 하위 12비트를 0으로 지우고 상위 4비트만 남겨 비교합니다.
    - `S_IFMT` (Mask): `1111 0000 0000 0000` (8진수 `0170000`)
- **B. 매크로 함수 방식 (권장):** 가독성이 높고 내부적으로 마스크 연산을 수행하여 `True/False`를 반환합니다.
    

|**파일 종류**|**비트 마스크 상수**|**매크로 함수**|**표시(ls)**|
|---|---|---|---|
|일반 파일|`S_IFREG` (1000)|`S_ISREG(m)`|`-`|
|디렉터리|`S_IFDIR` (0100)|`S_ISDIR(m)`|`d`|
|심볼릭 링크|`S_IFLNK` (1010)|`S_ISLNK(m)`|`l`|
|문자 장치|`S_IFCHR` (0001)|`S_ISCHR(m)`|`c`|

## 3. 권한(rwx) 추출 및 문자열 변환 로직

하위 9비트를 3비트씩 끊어 `ls -l` 형태의 문자열로 만드는 과정입니다.

> **작동 원리:** 특정 위치의 비트가 1인지 확인하기 위해 **비트 AND(&)** 연산을 수행합니다. 결과가 0이 아니면 권한이 있는 것입니다.

C

```sql
char res[11];
mode_t mode = statbuf.st_mode;

// 1. 파일 종류 (삼항 연산자 활용)
res[0] = S_ISDIR(mode) ? 'd' : (S_ISLNK(mode) ? 'l' : '-');

// 2. 접근 권한 (비트 AND 연산 반복)
res[1] = (mode & S_IRUSR) ? 'r' : '-'; // 소유자 읽기
res[2] = (mode & S_IWUSR) ? 'w' : '-'; // 소유자 쓰기
res[3] = (mode & S_IXUSR) ? 'x' : '-'; // 소유자 실행
// … 그룹(GRP), 기타(OTH)도 동일 패턴 적용
res[10] = '\0';
```

## 4. 인간 친화적인 데이터 변환 (ID & 시간)

숫자 형태의 커널 데이터를 텍스트로 치환하여 사용자에게 보여줍니다.

### ① 사용자/그룹 이름 (ID → Name)

커널은 숫자로만 관리하므로 시스템 DB(`/etc/passwd`, `/etc/group`)를 조회해야 합니다.

- **사용자:** `struct passwd *pw = getpwuid(statbuf.st_uid);` → `pw->pw_name`
- **그룹:** `struct group *gr = getgrgid(statbuf.st_gid);` → `gr->gr_name`
    

### ② 시간 정보 변환 (Epoch → String)

초 단위의 정수를 포맷팅된 문자열로 바꿉니다.

1. **`localtime()`**: `time_t`를 년/월/일/시/분/초가 분해된 `struct tm`으로 변환.
2. **`strftime()`**: 분해된 정보를 사용자가 원하는 형태(예: `%Y-%m-%d %H:%M`)로 치환.

## 🛠️ 실무 요약 (Summary)

> **커널 데이터 처리 프로세스**
>
> **비트 연산**을 통한 정보 추출 → **시스템 함수**를 통한 의미 부여(치환) → **포맷팅** 출력

- **Tip:** C언어에서 `0755`처럼 숫자 앞에 `0`을 붙이면 **8진수**로 인식되며, 이는 권한 비트를 다룰 때 매우 직관적입니다.
- **주의:** `stat()`은 심볼릭 링크의 대상을, `lstat()`은 링크 자체의 정보를 가져온다는 점을 기억하세요.
