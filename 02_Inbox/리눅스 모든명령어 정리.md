## 1) 셸 명령어 (옵션 보강)

|**명령어**|**추가/보강 옵션**|**대표 사용 예시**|**의미/기능 요약 (PDF 기반)**|
|---|---|---|---|
|**touch**|-a, -m, -r|`touch -a file`|-a (접근 시간만 변경), -m (수정 시간만 변경), -r (참조 파일의 시간으로 설정)|
|**grep**|-i, -l|`grep -i root file`|-i (대소문자 무시), -l (패턴 포함 파일명만 출력)|
|**find**|-type, -perm, -ok, -print, -ls|`find . -type d, find . -ok rm {} \;`|-type (파일 종류), -perm (권한), -ok (실행 전 확인), -print (경로 출력), -ls (상세 목록)|
|**whereis**|-b, -m, -s|`whereis -b ls`|-b (바이너리 파일만 검색), -m (매뉴얼 파일만 검색), -s (소스 파일만 검색)|
|**tail**|+행번호|`tail +10 file`|+행 번호 (지정한 행부터 끝까지 출력)|
