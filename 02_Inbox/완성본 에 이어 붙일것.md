## 1. 데이터 보호: 왜 `(unsigned int)`인가?

`printf("Mode: %o\n", (unsigned int)statbuf.st_mode);`

- **8진수 포맷(`%o`)의 이점**: 리눅스 권한은 **3비트(rwx) 단위**로 설계되었습니다. 8진수 한 자리($2^3=8$)는 이 3비트 뭉치 하나와 정확히 일치하므로, `0644` 같은 출력이 10진수보다 훨씬 직관적입니다. 그래서 `printf`의 `%o` 서식 지정자를 사용하여 정수 데이터를 8진수 문자열로 출력합니다.
	- **예:** `0644` → `6(rw-)`, `4(r--)`, `4(r--)`
- **부호 확장(Sign Extension) 방지**: `st_mode`에서 파일 종류를 나타내는 최상위 비트(MSB)가 1일 경우, 이를 `int`로 출력하면 시스템이 음수로 판단해 빈 공간을 모두 `f`로 채워버려 쓰레기값이 앞에 추가됩니다. `unsigned int` 캐스팅은 앞부분을 0으로 채우는 **제로 확장(Zero Extension)**을 강제하여 비트 원본을 보존합니다.

## 2. 파일 종류 판별: 비트 마스크 vs 매크로

`st_mode` 비트 필드에서 상위 4비트는 파일의 형식을 결정합니다. 이를 추출하는 두 가지 방법을 비교합니다.

### A. 비트 마스크 방식 (원리 이해)

`S_IFMT`(0170000)라는 마스크와 `&` 연산을 해 파일 종류를 나타내는 비트만 분리합니다. 그 결과값을 미리 정의된 파일 타입 상수들과 비교합니다.

- **예시**: `(statbuf.st_mode & S_IFMT) == S_IFDIR` (디렉터리인가?)

### B. 매크로 함수 방식 (실무 권장)
> 비트마스크방식은 가독성이 좋지 않다!

내부적으로 비트 마스크 방식을 수행해 해당 종류인지 `True/False`를 반환하는 매크로를 사용하자.

|**파일 종류**|**비트 마스크 상수**|**매크로 함수**|
|---|---|---|
|**일반 파일**|`S_IFREG`|`S_ISREG(m)`|
|**디렉터리**|`S_IFDIR`|`S_ISDIR(m)`|
|**심볼릭 링크**|`S_IFLNK`|`S_ISLNK(m)`|
|**문자 장치**|`S_IFCHR`|`S_ISCHR(m)`|
`if (S_ISDIR(statbuf.st_mode)) printf("디렉터리입니다.\n");`

## 3. 권한(rwx) 추출 및 문자열 변환 로직

파일의 접근 권한은 `st_mode`의 **하위 9비트**에 기록되어 있습니다. 이는 다시 **소유자(User), 그룹(Group), 기타 사용자(Others)**의 3비트씩 세 그룹으로 나뉩니다.

이 9비트를 `ls -l` 명령어처럼 문자열로 변환하는 핵심 로직은 다음과 같습니다.

### 권한 비트 검사 과정

1. **비트 AND 연산**: 특정 위치의 비트가 1인지 확인합니다.
	각 권한 비트 위치에 해당하는 상수와 `&` 연산을 수행하여 결과가 0이 아니면 권한이 있는 것입니다.
	- **소유자(User):** `S_IRUSR`(읽기), `S_IWUSR`(쓰기), `S_IXUSR`(실행)
	- **그룹(Group):** `S_IRGRP`(읽기), `S_IWGRP`(쓰기), `S_IXGRP`(실행)
	- **기타(Others):** `S_IROTH`(읽기), `S_IWOTH`(쓰기), `S_IXOTH`(실행)
2. **삼항 연산자 활용**: 비트가 있으면 문자(`r, w, x`), 없으면 `-`를 배열에 저장합니다.
	10글자의 배열(`res[11]`)을 준비하고 순차적으로 비트를 체크하여 문자를 채웁니다.

```C
char res[11];
// 1. 파일 종류 표시
res[0] = S_ISDIR(mode) ? 'd' : (S_ISLNK(mode) ? 'l' : '-');

// 2. 소유자 권한 (User)
res[1] = (mode & S_IRUSR) ? 'r' : '-';
res[2] = (mode & S_IWUSR) ? 'w' : '-';
res[3] = (mode & S_IXUSR) ? 'x' : '-';

// … (Group, Others 동일 로직 반복)

// 3. 문자열 마무리
res[10] = '\0'; 
```

## 4. 메타데이터 시각화: ID와 시간의 변환

커널이 관리하는 '숫자' 데이터를 사람이 읽을 수 있는 '텍스트'로 변환하는 최종 단계입니다.

### ① 사용자 및 그룹 이름 (ID to Name)

시스템의 패스워드 파일(`/etc/passwd`)과 그룹 파일 등을 조회하여 UID/GID 숫자를 이름으로 바꿉니다.

- **UID → Name**: `getpwuid(statbuf.st_uid)` → `pw_name`
- **GID → Name**: `getgrgid(statbuf.st_gid)` → `gr_name`

### ② 시간 정보 (Epoch to String)

1970년 1월 1일부터 흐른 초 단위 시간(`time_t`)을 우리가 아는 날짜 형식으로 변환합니다.

|**단계**|**함수**|**설명**|
|---|---|---|
|**1단계**|`localtime()`|초 단위 시간을 년/월/일/시/분/초 구조체(`struct tm`)로 분해|
|**2단계**|`strftime()`|분해된 정보를 사용자가 원하는 포맷(`%Y-%m-%d` 등) 문자열로 생성|

```C
// 실무 적용 예시
struct passwd *pw = getpwuid(statbuf.st_uid);
char time_buf[20];
strftime(time_buf, sizeof(time_buf), "%Y-%m-%d %H:%M", localtime(&statbuf.st_mtime));

printf("소유자: %s | 수정시간: %s\n", pw->pw_name, time_buf);
```
