## 정리
## **핵심 한 줄**

- **IP = “어디로” (경로/네트워크 주소, L3)**
- **MAC = “누구에게” (같은 링크에서 실제 전달 대상, L2)**

## **딱 필요한 차이**

- **범위**: IP는 인터넷 전체 경로에서 의미 유지 / MAC은 **같은 LAN/VLAN** 안에서만 의미.
- **변경성**: IP는 DHCP/NAT로 **자주 바뀜** / MAC은 NIC별로 **거의 고정**(변경·랜덤화 가능).
- **라우팅**: 라우터는 **IP 프리픽스(예: /24, /64)** 단위로 경로 결정.
- **전달**: 실제 프레임은 **목적지 MAC**으로 보냄(홉마다 **MAC은 바뀜**, IP는 유지).

## **보내는 흐름(암기 포인트)**

1. **같은 서브넷**에 보낼 때 → ARP/NDP로 **상대 MAC** 알아내서 **직접 전송**
2. **다른 서브넷**에 보낼 때 → **게이트웨이 IP의 MAC**을 알아내서 **게이트웨이로 전송**

    (다음 홉에서 MAC 다시 갈아끼움, IP 목적지는 계속 동일)

## **“네트워크(서브넷)”의 기준**

- **IP 프리픽스**가 네트워크를 정의: 192.168.1.0/24, 2001:db8::/64 같은 형태.

## **지금 내 상태 빠르게 확인(우분투)**

```sql
ip -br a     # 내 IP/프리픽스
ip route     # 라우팅(게이트웨이 등)
ip neigh     # ARP/NDP: IP ↔ MAC 매핑
```

## **자주 헷갈리는 점 정리**

- **IP = 장비 ID** ❌ (바뀜/NAT 공유) → 자산/신원은 보통 호스트명·키·인증서로 식별
- **MAC = 전세계 유일** ❌ (VM/랜덤화/스푸핑 가능)
- **같은 스위치면 다 같은 LAN** ❌ (VLAN 다르면 다른 L2 → 라우터 필요)

## **VM(당신 환경)에서 기억할 것**

- 게스트(우분투/윈도우) NIC는 **가상 MAC**을 가짐.
- 보통 **사설 IP(192.168.x.x)** 를 받아 **게이트웨이(맥/공유기)** 로 나감.

### **10초 셀프 체크**

- 인터넷으로 나갈 때 **ARP로 누구의 MAC을 찾나요?** → **게이트웨이 MAC**
- 라우터를 지나면 **무엇이 바뀌고 무엇이 유지되나요?** → **MAC 바뀜 / IP 유지**
- **하나의 “네트워크”를 정의하는 건?** → **IP 프리픽스(서브넷)**
	- 최종 목적지는 IP주소인데 ip주소에 가기위해서 같은 네트워크 스위치에 연결되어있는 컴퓨터를 구분할 mac주소가 필요한것
	- **같은 LAN(스위치/와이파이/VLAN) 안에서 “누구냐”** → **MAC 주소**
	- **라우터를 넘어 “어디로 가야 하냐”** → **IP 주소(서브넷/프리픽스)**
> **IP는 경로 선택(라우팅)의 단위**, **MAC은 같은 L2 구간에서 실제 전달(스위칭)의 단위**예요.
