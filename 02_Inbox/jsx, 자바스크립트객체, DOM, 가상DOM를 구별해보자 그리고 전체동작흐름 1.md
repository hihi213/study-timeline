## 정리
### 한눈에 보는 비교

| 구분        | JSX                      | 자바스크립트 객체 (가상 DOM)                                   | DOM (실제 DOM)                                |
| --------- | ------------------------ | ---------------------------------------------------- | ------------------------------------------- |
| **정체**    | JavaScript를 확장한 **문법**   | Key-Value 구조의 일반 자바스크립트 객체                           | 수많은 속성과 API를 가진 **브라우저 전용 객체** **문서 객체**    |
| **존재 위치** | `.jsx` 코드 파일             | JavaScript 엔진 메모리                                    | 브라우저 메모리                                    |
| **처리 주체** | Babel 같은 **트랜스파일러**가 처리함 | **React**가 처리함                                       | **브라우저 렌더링 엔진**이 처리함                        |
| **조작 비용** | (해당 없음)                  | **매우 저렴함**                                           | **매우 비쌈** (리플로우/리페인트 유발)                    |
| **목적**    | 개발자가 UI 구조를 **선언**       | UI 구조를 메모리상에서 **표현** ,실제 DOM 변경을 최소화하기 위한 **중간 설계도** | 실제 화면에 UI를 **출력**, 실제 사용자에게 보여지는 **최종 결과물** |
- 실제 DOM의 구조를 흉내 낸 순수한 **자바스크립트 객체**를 가상DOM이라고 한다. 
- 브라우저가 화면을 그리기 위해 사용하는 **문서 객체 모델** 이다.

### 전체 동작 흐름

1. **JSX 작성**: 개발자는 `.jsx` 파일 안에 HTML과 유사한 **JSX** 문법으로 UI가 어떻게 생겨야 하는지 선언합니다.
    
    ```JavaScript
    const ui = <div className="greeting">Hello</div>;
    ```
    
2. **JSX 변환**: 코드가 실행되기 전, Babel 같은 트랜스파일러가 **JSX**를 `React.createElement()` 함수 호출로 변환합니다.    
    ```JavaScript
    // 변환된 코드
    const ui = React.createElement('div', {className: 'greeting'}, 'Hello');
    ```
    
3. **가상 DOM 생성**: `React.createElement()` 함수가 호출되면, UI의 구조와 속성을 설명하는 순수한 **자바스크립트 객체**가 생성됩니다. 이것이 **가상 DOM**을 구성하는 요소입니다.
    ```JavaScript
    // 생성된 객체의 모습 (개념적)
    {
      type: 'div',
      props: {
        className: 'greeting',
        children: 'Hello'
      }
    }
    ```
    
4. **재조정 (Reconciliation)**: 리액트는 상태가 변경될 때마다 이 새로운 **가상 DOM(자바스크립트 객체)**을 이전 버전의 가상 DOM과 비교하여 변경 사항을 계산합니다.
    
5. **실제 DOM 업데이트**: 리액트는 계산된 최소한의 변경 사항만을 브라우저 API를 통해 **실제 DOM**에 적용합니다. 이로써 브라우저는 화면을 다시 그립니다.
