**순수 학습 240분, 휴식 별도**

|  시간 | 학습 내용         | 실제 행동                                                         |
| --: | ------------- | ------------------------------------------------------------- |
| 55분 | **DB 핵심 이론**  | 설계 단계, 키·무결성, 함수적 종속, 이상 현상, 정규화, ACID를 공부한 뒤 수제비 해당 목차 기출 풀이 |

## 각 영역을 공부하는 방식

각 소주제마다 다음 순서를 적용합니다.

1. [[정처기 이론질문리스트]]을 보고 먼저 답해보기
2. 답이 안 나오면 노트 해당 부분만 읽기
3. 수제비의 해당 목차 기출 **1문제** 풀기
4. 틀리면 비슷한 문제 **최대 2문제 추가**
5. 연속 2문제를 맞히면 즉시 종료

## 1일 차 완료 기준

- DB 핵심 단답 15개 이상
- 테스트·설계·요구사항 단답 25개 이상
- 서브넷 문제 4개 중 3개 이상
- 보안 시나리오 15개 중 10개 이상 즉답

완벽 암기가 아니라 **설명을 보고 용어를 판별할 수 있으면 완료**입니다.

# 2일 차 — Java·Python·SQL 점수화

**순수 학습 240분**

|시간|학습 내용|실제 행동|
|--:|---|---|
|65분|**Java**|상속·생성자, 오버라이딩·오버로딩, 필드 숨김, static, 예외·finally, 재귀 문제 풀이|
|50분|**Python**|슬라이싱, 음수 인덱스, 별칭·얕은 복사, 리스트 변경, 컴프리헨션, 문자열 처리|
|85분|**SQL**|NULL·COUNT·AVG, GROUP BY/HAVING, 조인, 서브쿼리, 외래키 DDL 및 DML 직접 작성|
|20분|**C 인출 복습**|배열·포인터, 문자열, 구조체, 함수 포인터에서 각 1문제|
|20분|**1일 차 이론 재시험**|전날 틀렸거나 답이 늦었던 단답 20개만 재확인|

## Java에서 반드시 끝낼 것

- 부모 생성자 → 자식 생성자 실행 순서
- 부모 타입 참조변수와 자식 객체
- 필드는 선언 타입, 오버라이딩 메서드는 실제 객체
- 오버로딩은 선언된 매개변수 타입
- `static` 공유 여부
- `return`이 있어도 `finally` 실행
- 재귀 반환 순서
    

## Python에서 반드시 끝낼 것

- `[start:end:step]`
- `[::-1]`, `[::-2]`
- `b=a`와 `b=a[:]`
- 중첩 리스트의 얕은 복사
- 함수에서 리스트를 수정했을 때 원본 변화
- `append`, `extend`, `+=`
- `split`, `join`
    

## SQL에서 반드시 끝낼 것

- `COUNT(*)`와 `COUNT(컬럼)`
- `AVG`에서 NULL 제외
- `WHERE → GROUP BY → HAVING`
- 내부·외부 조인의 행 변화
- 서브쿼리 안쪽부터 계산
- 외래키 문법 직접 작성
- `INSERT INTO`, `UPDATE SET`, `DELETE FROM`
- `GRANT TO`, `REVOKE FROM`
    

## 2일 차 완료 기준

- Java 대표 문제 6개 중 4개 이상
- Python 대표 문제 6개 중 4개 이상
- SQL 결과 계산 5문제 중 4개 이상
- SQL 직접 작성 4문제 중 3개 이상
- C는 새 학습 없이 기존 감각 유지

# 마지막 반나절 — 2026년 1회 실전 점검

**순수 학습 120분**

## 1. 2026년 1회 전체 풀이 — 70분

정답과 해설을 가리고 20문제를 풉니다.

- 1차 제한: 문제당 **3분**
- 막히면 `△` 표시 후 즉시 이동
- 마지막 10분에 △ 문제만 재도전
- 모든 문제에 `확신 / 추측 / 모름` 표시
- 답을 몰라도 관련 용어 또는 추정 답을 적기
    

2026년 1회는 코드, SQL·DB, CIDR, 보안, 패턴, 요구사항, 테스트가 섞여 있어 지금까지 공부한 A범위의 최종 혼합 점검에 적합합니다.

## 2. 채점 및 오답 분류 — 20분

오답을 다음 다섯 분야로만 분류합니다.

- 언어
- SQL·DB
- 네트워크
- 보안
- 테스트·설계·요구사항
    

맞혔지만 추측한 문제도 오답처럼 표시합니다.

## 3. 최약점 한 영역 보정 — 20분

오답이 가장 많은 **한 영역만** 보충합니다.

- 언어 → 수제비 해당 언어 기출 2문제
- SQL·DB → 수제비 기출 3문제
- 네트워크 → 서브넷 2문제
- 보안 → 시나리오 단답 10개
- 설계·테스트 → 단답 15개
    

두 번째 약점까지 손대지 않습니다.

## 4. 마지막 백지 인출 — 10분

노트를 보지 않고 다음을 적습니다.

- 정규화 단계와 제거 대상
- 외래키 SQL 문법
- 하향식–스텁 / 상향식–드라이버
- 응집도·결합도 순서
- 대표 패턴 식별 단서
- CIDR 계산 순서
- 자주 틀린 보안 공격 5개
