### [예시] 192.168.1.45/26과 192.168.1.70/26은 같은 네트워크인가?

1. **조건 확인**: 두 IP 모두 `/26`이므로 0의 개수는 6개.
2. **블록 크기**: 2^6 = **64**
3. **네트워크 범위 쪼개기 (64의 배수)**:
   - [0번 동네] 0 ~ 63
   - [1번 동네] 64 ~ 127

4. **두 IP의 위치 확인**:
   - 끝자리 **45**가 속한 구간: 0 ~ 63 ➔ 네트워크 주소: 192.168.1.0
   - 끝자리 **70**이 속한 구간: 64 ~ 127 ➔ 네트워크 주소: 192.168.1.64

🎯 **결론**: 두 IP의 네트워크 주소가 다르므로 "다른 네트워크에 속한다"가 정답입니다.
