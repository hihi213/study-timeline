### 🏛️ [소프트웨어 설계] 문제 은행

> [!note]- 1. 웹과 컴퓨터 프로그램에서 용량이 적은 데이터를 교환하기 위해 데이터 객체를 속성·값의 쌍 형태로 표현하는 형식은? (① Python ② XML ③ JSON ④ WEB SERVER)
>
> **정답:** ③ JSON
>
> **해설:**
>
> JSON(JavaScript Object Notation)은 텍스트 기반의 데이터 포맷으로, 자바스크립트의 객체 문법을 따릅니다. XML보다 가볍고 가독성이 좋아 현재 API 통신 등에서 가장 널리 쓰입니다.

> [!note]- 2. XP(eXtreme Programming) 개발 프로세스에 대한 설명으로 옳지 않은 것은?
>
> **정답:** ④ 사용자 스토리: 사용자의 요구사항을 적어놓은 것으로, 스크럼(Scrum)의 사용자 스토리와는 다르다.
>
> **해설:**
>
> XP와 스크럼 모두 애자일(Agile) 방법론에 뿌리를 두고 있으며, '사용자 스토리'는 두 방법론 모두에서 사용자의 요구사항을 간략히 기술한 것으로 그 개념과 목적이 본질적으로 동일합니다.

> [!note]- 3. 럼바우(Rumbaugh)의 객체지향 분석 절차를 가장 바르게 나열한 것은?
>
> **정답:** ① 객체 모형 $\rightarrow$ 동적 모형 $\rightarrow$ 기능 모형
>
> **해설:**
>
> 럼바우 분석 기법(객·동·기) 순서:
>
> 1. **객체(Object) 모형:** 시스템의 정적 구조(Class Diagram).
>     
> 2. **동적(Dynamic) 모형:** 상태 변화 및 흐름(State Diagram).
>     
> 3. **기능(Functional) 모형:** 데이터 흐름 및 가공 과정(DFD).
>     

> [!note]- 4. 정형 기술 검토(FTR)의 지침으로 틀린 것은? (① 의제 제한 ② 논쟁 제한 ③ 문제 영역 명확 표현 ④ 참가자 수 무제한)
>
> **정답:** ④ 참가자의 수를 제한하지 않는다.
>
> **해설:**
>
> FTR은 효율적인 검토를 위해 참가자 수를 보통 3~5명(최대 10명 이내)으로 적절히 제한하는 것을 원칙으로 합니다. 인원이 너무 많으면 집중력이 흐트러집니다.

> [!note]- 5. 프로그램 설계도인 NS Chart(Nassi-Shneiderman)에 대한 설명으로 가장 거리가 먼 것은?
>
> **정답:** ③ 화살표나 GOTO를 사용하여 이해하기 쉽다.
>
> **해설:**
>
> NS 차트는 **GOTO 문(강제 이동)을 사용하지 않는 것**이 가장 큰 특징입니다. 화살표를 쓰지 않고 박스 형태의 상자 안에서 연속, 선택, 반복 구조를 표현합니다.

> [!note]- 7. 폭포수 모형(Waterfall Model)의 특징으로 거리가 먼 것은? (① 요구사항 수시 반영 ② 순차적 접근 ③ 산출물 명확 ④ 성공사례 많음)
>
> **정답:** ① 개발 중 발생한 요구사항을 쉽게 반영할 수 있다.
>
> **해설:**
>
> 폭포수 모형은 단계별 선행 작업이 끝나야 다음으로 넘어가는 방식이므로, 중간에 요구사항이 변경되면 다시 이전 단계로 돌아가기가 매우 어렵고 비용이 많이 듭니다.

> [!note]- 8. LOC 기법 계산: 총 라인 50,000 / 월 평균 생산성 200 / 프로그래머 10명일 때 개발 기간은?
>
> **정답:** ① 25개월
>
> **해설:**
>
> 계산식: $\frac{총\ 라인\ 수}{프로그래머\ 수 \times 월\ 생산성}$
>
> $\frac{50,000}{10 \times 200} = \frac{50,000}{2,000} <code>=</code> 25$개월

> [!note]- 9. 프로젝트의 위험 요소를 사전에 예측하고 대비하는 관리 활동은? (① CPM ② Risk Analysis ③ WBS ④ Waterfall)
>
> **정답:** ② Risk Analysis (위험 분석)
>
> **해설:**
>
> 프로젝트 수행 과정에서 발생할 수 있는 잠재적 위험을 식별, 분석, 평가하고 이를 관리하는 기술적 활동입니다.

> [!note]- 10. 사용자의 자연스러운 움직임을 인식하여 정보를 주고받는 인터페이스는? (① GUI ② OUI ③ NUI ④ CLI)
>
> **정답:** ③ NUI (Natural User Interface)
>
> **해설:**
>
> 멀티 터치, 음성 인식, 동작 인식 등 인간의 자연스러운 감각이나 행동을 그대로 입력 수단으로 사용하는 차세대 인터페이스입니다.

> [!note]- 11. 소프트웨어 비용 추정 모형(Estimation Models)이 아닌 것은? (① COCOMO ② Putnam ③ Function-Point ④ PERT)
>
> **정답:** ④ PERT
>
> **해설:**
>
> PERT(Program Evaluation and Review Technique)는 프로젝트의 **일정 관리 및 분석**을 위한 도구입니다. 나머지 1, 2, 3번은 비용 산정(규모 산정) 모형입니다.

> [!note]- 12. 다음 중 성격이 다른 설계 패턴(Design Pattern)은? (① 브리지 ② 팩토리 메소드 ③ 프로토타입 ④ 싱글톤)
>
> **정답:** ① 브리지(Bridge) 패턴
>
> **해설:**
>
> - **생성 패턴:** 팩토리 메소드, 프로토타입, 싱글톤, 빌더, 추상 팩토리.
>     
> - **구조 패턴:** **브리지**, 어댑터, 컴포지트, 데코레이터, 퍼사드 등.
>     
>     12번 문제에서 브리지만 **구조 패턴**이며 나머지는 모두 **생성 패턴**입니다.
>     

> [!note]- 13. UML 사물(Things)의 종류가 아닌 것은? (① 주해 사물 ② 구조 사물 ③ 행동 사물 ④ 그룹 사물 외 오답)
>
> **정답:** ④ (보통 '관계'나 '다이어그램' 등이 오답으로 나옵니다.)
>
> **해설:**
>
> UML 사물의 4종류: **구조(Structural), 행동(Behavioral), 그룹(Grouping), 주해(Annotation)** 사물입니다.

> [!note]- 14. 미들웨어(Middleware)에 대한 설명으로 틀린 것은?
>
> **정답:** ② 미들웨어의 서비스 이용을 위해 사용자가 정보 교환 방법 등의 내부 동작을 쉽게 확인할 수 있어야 한다.
>
> **해설:**
>
> 미들웨어의 핵심 목표 중 하나는 **투명성(Transparency)**입니다. 사용자가 내부의 복잡한 동작 방식을 알 필요 없이 서비스를 이용할 수 있도록 추상화되어야 합니다.

> [!note]- 15. 결합도(Coupling) 단계를 약한(좋은 설계) 순서에서 강한(나쁜 설계) 순으로 나열한 것은?
>
> **정답:** ④ Data $\rightarrow$ Stamp $\rightarrow$ Control $\rightarrow$ Common $\rightarrow$ Content
>
> **해설:**
>
> 암기 팁: **데·스·제·외·공·내** (Data, Stamp, Control, External, Common, Content)
>
> 오른쪽으로 갈수록 결합도가 강해져 모듈 간 독립성이 떨어집니다.

> [!note]- 16. 객체지향 프로그램에서 데이터를 추상화하는 단위는? (① 메소드 ② 클래스 ③ 상속성 ④ 메시지)
>
> **정답:** ② 클래스 (Class)
>
> **해설:**
>
> 클래스는 객체지향 프로그래밍에서 공통된 속성(데이터)과 행위(메서드)를 가진 객체들을 추상화하여 정의한 틀입니다. 자바 개발 시 가장 기본이 되는 단위입니다.

> [!note]- 17. 테스트 케이스 자동 생성 도구를 이용하여 테스트 데이터를 찾아내는 방법이 아닌 것은? (① 스터브와 드라이버 ② 입력 도메인 분석 ③ 랜덤 테스트 ④ 자료 흐름도)
>
> **정답:** ① 스터브(Stub)와 드라이버(Driver)
>
> **해설:**
>
> 스터브와 드라이버는 통합 테스트를 위해 필요한 **테스트 하네스(Test Harness)** 구성 요소이지, 테스트 데이터를 추출하는 논리적 분석 방법은 아닙니다.

> [!note]- 18. 생명주기 모형 중 요구사항 변경이 어렵고 단계별 결과가 명확해야 다음으로 넘어가는 선형 순차적 모형은? (① Waterfall ② Prototype ③ COCOMO ④ Spiral)
>
> **정답:** ① Waterfall Model (폭포수 모형)
>
> **해설:**
>
> 소프트웨어 개발의 고전적 모형으로, 각 단계의 산출물이 명확해야 하지만 후반부에 발견된 요구사항 반영이 매우 어렵다는 단점이 있습니다.
>

> [!note]- 19. S/W 라인 수의 비관치, 낙관치, 기대치를 측정하여 예측치를 구하고 비용을 산정하는 기법은? (① Effort Per Task ② 전문가 감정 ③ 델파이 ④ LOC 기법)
>
> **정답:** ④ LOC (Lines of Code) 기법
>
> **해설:**
>
> 낙관치, 비관치, 기대치를 이용한 계산식은 다음과 같습니다.
>
> $$예측치 = \frac{낙관치 + 4 \times 기대치 + 비관치}{6}$$

> [!note]- 20. 계획 수립, 위험 분석, 개발과 검증, 고객 평가 순서로 반복하며 진행하는 개발 모델은?
>
> **정답:** 나선형 모형 (Spiral Model)
>
> **해설:**
>
> 보엠(Boehm)이 제안한 모델로, 점진적으로 프로젝트를 확장하며 특히 **위험 분석** 단계가 강조되는 것이 특징입니다.
>

> [!note]- 21. 익스트림 프로그래밍(XP)의 5가지 핵심 가치에 속하지 않는 것은? (① 의사소통 ② 단순성 ③ 피드백 ④ 고객 배제)
>
> **정답:** ④ 고객 배제
>
> **해설:**
>
> XP의 5가치: **의사소통(Communication), 단순성(Simplicity), 피드백(Feedback), 용기(Courage), 존중(Respect)**입니다. 고객은 개발 과정에 적극적으로 참여해야 합니다.

> [!note]- 22. 주어진 한 모듈을 제어하는 상위 모듈의 수를 나타내는 용어는? (① Fan-out ② Coupling ③ Fan-in ④ Cohesion)
>
> **정답:** ③ Fan-in
>
> **해설:**
>
> - **Fan-in:** 나를 호출하는 상위 모듈 수 (높을수록 재사용성이 좋음)
>     
> - **Fan-out:** 내가 호출하는 하위 모듈 수 (높을수록 설계가 복잡함)
>     

> [!note]- 23. 코드 인스펙션(Code Inspection)과 관련한 설명으로 틀린 것은? (① 정적 확인 ② 품질 향상 ③ 동적 테스트 시에만 활용 ④ 코딩 표준 준수 검사)
>
> **정답:** ③ 동적 테스트 시에만 활용하는 기법이다.
>
> **해설:**
>
> 인스펙션은 프로그램을 실행하지 않고 명세서나 코드를 읽으며 검토하는 **정적 테스트(Static Test)** 기법입니다.

> [!note]- 24. 애자일(Agile) 기법에 대한 설명으로 맞지 않는 것은? (① 소통 중시 ② 계획 고수 및 변경 지양 ③ 실행 소프트웨어 가치 ④ 고객 피드백 중시)
>
> **정답:** ② 계획에 중점을 두어 변경 대응이 난해하다.
>
> **해설:**

> [!note]- 25. UML 상태 다이어그램에서 상태 변화를 일으키는 외부 자극은?
>
> **정답:** 이벤트 (Event)
>
> **해설:**
>
> 특정 상태에서 다른 상태로의 전이(Transition)를 유발하는 현상을 이벤트라고 합니다.

> [!note]- 26. 스마트폰 터치 제스처 종류로 가장 거리가 먼 것은? (① drag ② flick ③ press ④ flow)

>
> **해설:**
>

> [!note]- 27. 송·수신 연계 기술 중 통신을 위한 포트를 할당하고 클라이언트 연결을 처리하는 기술은? (① DB 링크 ② 소켓 기술 ③ 스크럼 ④ 프로토타입)

> [!note]- 28. 항목의 물리적 수치(중량, 면적 등)를 이용하여 만든 코드는? (① 순차 코드 ② 10진 코드 ③ 표의 숫자 코드 ④ 블록 코드)

> [!note]- 29. 디자인 평가를 위해 실제 화면과 유사하게 만든 정적인 형태의 모형은? (① 스토리보드 ② 목업 ③ 프로토타입 ④ 유스케이스)

### 🏛️ [소프트웨어 설계] 문제 은행 (30번 ~ 35번)

> [!note]- 30. CPM(Critical Path Method) 네트워크가 다음과 같을 때 임계 경로(Critical Path)의 소요 기일은? (① 10일 ② 12일 ③ 14일 ④ 16일)
>
> **정답:** ④ 16일 (제시된 강의 데이터 기준)
>
> **해설:**
>
> 임계 경로는 프로젝트의 시작부터 끝까지 이르는 여러 경로 중 **가장 긴 소요 시간이 걸리는 경로**를 의미합니다. 이 경로상의 작업이 지연되면 전체 프로젝트 일정이 지연됩니다.

> [!note]- 1. 은행가 알고리즘(Banker’s Algorithm)은 교착상태의 해결 방법 중 어떤 기법에 해당하는가? (① Avoidance ② Detection ③ Prevention ④ Recovery)

> 3. **Detection(발견):** 시스템을 감시하여 교착 상태를 찾아냄.
>     
> 4. **Recovery(회복):** 교착 상태 발견 후 프로세스 종료나 자원 선점으로 해결.

```Java
public class Gisafirst {
	public static void main(String[] args) {
		int a=1, b=2, c=3, d=4;
		int mx, mn;
		mx = a;
		if(mx==1) {
			mn = a>mx ? b : a;
		}

		}

	}
```

> [!note]- 1. 다음 JAVA 프로그램이 실행되었을 때의 결과는? (① 1 ② 2 ③ 3 ④ 4)

>
> **해설:**
>
> 1. $mx = 1$이 할당됩니다.
>     
> 2. `if(mx==1)` 조건이 **참**이므로 내부 문장이 실행됩니다.
>     
> 3. 삼항 연산자 `a>mx ? b : a`에서 $1>1$은 **거짓**이므로 `:` 뒤의 값인 `a`(1)가 `mn`에 저장됩니다.
>     
> 4. 최종적으로 1이 출력됩니다.
>

>

```Java
public class Gisafirst {

    	int a=1, sum=0;
    	while(a++ <= 5) {
    		if(a%2 != 0) 
    			continue;
    		sum = sum+a;
    	}
    	System.out.printf("%d", sum);
    }

```

> [!note]- 3. 다음 java언어 프로그램에서 최종 출력값은? (① 6 ② 8 ③ 10 ④ 12)

>

>     
> - 4회전: $4 \le 5$ (참), $a=5$. $5\%2 \neq 0$이므로 `continue`
>     
> - 5회전: $5 \le 5$ (참), $a=6$. $6\%2==0$이므로 `sum = 6+6 = 12`

| **포인터**       | 메모리의 주소값을 저장하는 변수 (`*p`는 값, `p`는 주소)      |

### 🛠️ [프로그래밍 언어 활용 & 네트워크] 추가 문제

> [!note]- 1. 리눅스(LINUX)에서 파일의 권한을 변경하여 소유자에게는 읽기/쓰기/실행 권한을, 그룹과 기타 사용자에게는 읽기/실행 권한만 부여하는 명령어는? (① chmod 777 ② chmod 755 ③ chown 755 ④ chown 777)
>
> **정답:** ② chmod 755
>
> **해설:**
>
> - **chmod (Change Mode):** 파일이나 디렉토리의 권한을 변경합니다.
>     
> - **권한 계산:** 읽기(4) + 쓰기(2) + 실행(1).
>     
>     - 소유자: $4+2+1 = 7$
>         
>     - 그룹: $4+0+1 = 5$
>         
>     - 기타: $4+0+1 = 5$
>         
> - 따라서 `755`가 정답입니다. `chown`은 소유자를 변경하는 명령어입니다.
>     

> [!note]- 2. TCP/IP 4계층 모델 중 응용 계층과 인터넷 계층 사이에서 프로세스 간의 신뢰성 있는 연결을 담당하며, 데이터의 흐름 제어 및 오류 제어를 수행하는 계층은? (① 네트워크 인터페이스 계층 ② 인터넷 계층 ③ 전송 계층 ④ 응용 계층)
>
> **정답:** ③ 전송 계층 (Transport Layer)
>
> **해설:**
>
> - **전송 계층:** TCP(신뢰성)와 UDP(속도) 프로토콜이 동작하며 종단 간 데이터 전송을 관리합니다.
>     
> - **인터넷 계층:** IP 주소를 기반으로 최적의 경로를 설정(라우팅)합니다.

```C
int main() {
    int i = 0;
    for( ; ; ) {
        if(i > 10) break;
        i++;
    }
    return 0;
}
```

> [!note]- 3. 위 C언어 코드의 `for( ; ; )` 구문에 대한 설명으로 옳은 것은? (① 조건이 없으므로 컴파일 에러 발생 ② 루프를 단 한 번만 실행 ③ 무한 루프를 생성하며 내부에 탈출 조건이 필요 ④ i가 0이므로 실행되지 않음)
>
> **정답:** ③ 무한 루프를 생성하며 내부에 탈출 조건이 필요
>
> **해설:**
>
> C언어에서 `for( ; ; )`는 조건식을 생략할 경우 항상 '참'으로 간주되어 무한 루프가 됩니다. `while(1)`과 동일한 역할을 수행하며, 코드 내의 `break` 문을 통해 루프를 탈출할 수 있습니다.

> [!note]- 4. 네트워크 장비 중 '더미 허브(Dummy Hub)'에 대한 설명으로 옳지 않은 것은? (① OSI 1계층(물리 계층) 장비이다 ② 네트워크에 연결된 모든 장비에 데이터를 전송(Flooding)한다 ③ 충돌(Collision)이 발생할 가능성이 높아 네트워크 성능을 저하시킬 수 있다 ④ 수신측 MAC 주소를 학습하여 특정 포트로만 데이터를 보낸다)
>
> **정답:** ④ 수신측 MAC 주소를 학습하여 특정 포트로만 데이터를 보낸다.
>
> **해설:**
>
> - **더미 허브:** 단순히 신호를 증폭하고 전달하는 1계층 장비로, 들어온 데이터를 무조건 모든 포트로 뿌립니다.
>     
> - **스위칭 허브(Switch):** MAC 주소를 학습하여 해당 장비가 있는 포트로만 데이터를 보내는 2계층 장비입니다.
