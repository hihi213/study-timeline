## 1. 냉장고 보관기능

- **물품 추가**
  - 물품이름, 유통기한, 메모를 입력하고 등록
  - 등록 시 총 세 자리 식별알파벳+번호가 부여됨 → 스티커에 기입해 부착
  - 식별번호로 유저와 검사관이 물품 상세페이지를 검색/확인 가능
  - 메모는 본인만 확인 가능
  - 본인 물품은 수정/삭제 가능
- 묶음 추가 
	1.	묶음명 입력
		예: “마카롱 세트”, “딸기마카롱”, “초코마카롱” 등
	2.	수량(갯수) 지정
		버튼으로 원하는 만큼 수량 추가
		예: 3개, 5개 등
	3.	각 물품의 세부명/유통기한 입력란 자동 생성
		1번: 딸기마카롱 / 2025-06-20
		2번: 초코마카롱 / 2025-06-21
		3번: 레몬마카롱 / 2025-06-19
		필요시 메모 입력란도 제공
	4.	등록 버튼 클릭 시, 한 번에 여러 물품 등록
	5. 스티커 부착 방식
		•	묶음 전체에 스티커 한 장만 부착
		•	스티커에는 “묶음명(갯수)”와 식별번호가 표시
		•	예: `마카롱 세트(3) 12번`
		•	개별 물품에는 스티커를 따로 붙이지 않아도 됨
		•	검사관/유저는 묶음 스티커로 전체 묶음을 식별
	- **묶음일경우 세부검사 대상** 자동 분류
		  - 검사일 이후 추가된 항목
		  - 검사일 이후 수정된 항목
		  - 유통기한 지난 물품

- **검사자(층별장) 기능**
  - 일반 유저의 모든 기능 + 냉장고 검사 추가 권한
  - 검사: 포장 상태, 유통기한/제품 이름 정확성 확인
  - 자동 분류된 검사대상 우선 검사
  - 검사대상에 분류되지 않은 물품은 포장상태만 확인, 포장 불량일 경우 식별번호 조회해 제재
  - 이전 검사일 벌점 기록 확인
  - 본인이 부여한 벌점은 최종 제출 후 수정 불가(청탁 방지)
  - 검사 종료 시 당사자들에게 일괄 알림
