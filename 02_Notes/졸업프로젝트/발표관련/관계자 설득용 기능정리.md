## 1. 냉장고 보관기능

- **물품 추가**
  - 물품이름, 유통기한, 메모를 입력하고 등록
  - 등록 시 총 세 자리 식별알파벳+번호가 부여됨 → 스티커에 기입해 부착
  - 식별번호로 유저와 검사관이 물품 상세페이지를 검색/확인 가능
  - 메모는 본인만 확인 가능
  - 본인 물품은 수정/삭제 가능
- 묶음 추가 
	1.	묶음명 입력
		예: “마카롱 세트”, “딸기마카롱”, “초코마카롱” 등
	2.	수량(갯수) 지정
		버튼으로 원하는 만큼 수량 추가
		예: 3개, 5개 등
	3.	각 물품의 세부명/유통기한 입력란 자동 생성
		1번: 딸기마카롱 / 2025-06-20
		2번: 초코마카롱 / 2025-06-21
		3번: 레몬마카롱 / 2025-06-19
		필요시 메모 입력란도 제공
	4.	등록 버튼 클릭 시, 한 번에 여러 물품 등록
	5. 스티커 부착 방식
		•	묶음 전체에 스티커 한 장만 부착
		•	스티커에는 “묶음명(갯수)”와 식별번호가 표시
		•	예: `마카롱 세트(3) 12번`
		•	개별 물품에는 기존처럼 스티커를 따로 붙이지 않아도 됨
		•	검사관/유저는 묶음 스티커로 전체 묶음을 식별
	- **묶음일경우 세부검사 대상** 자동 분류
		  - 검사일 이후 추가된 항목
		  - 검사일 이후 수정된 항목
		  - 유통기한 지난 물품

- **검사자(층별장) 기능**
  - 일반 유저의 모든 기능 + 냉장고 검사 추가 권한
  - 검사: 포장 상태, 유통기한/제품 이름 정확성 확인
  - 이전 검사일 벌점 기록 확인
  - 본인이 부여한 벌점은 최종 제출 후 수정 불가(청탁 방지)
  - 검사 종료 시 당사자들에게 일괄 알림

---

## 2. 세탁기 사용 인증

- **세탁 전**
  - 사용 가능한 기기 상태/남은 시간 확인

- **다른 사람이 사용 중인 기기**
  - 상세페이지에서 종료 전 알림 신청 가능

- **남은 시간 수정**
  - 잘못된 남은 시간 수정 시, 수정인·수정된 시간 알림 전송
  - 해당 시간에 맞춰 종료 알림도 자동 수정

- **사용 종료**
  - 이전 사용자에게 “빼놨어요” 알림, “먼지 필터 치워주세요” 알림 전송 가능

- **기기 사용 등록**
  - 상세페이지에서 사용 등록
  - 사용시간, 종료 5분 전 알림 여부 설정

- **회수 미이행 시**
  - 사용 종료 미처리 시 “기다리고 있어요”, “빼놨어요” 알림 전송 가능

- **미등록 사용**
  - 미등록 사용 시 대신 시간 등록 가능(다른 사용자 헛걸음 방지)

- **고장 신고**
  - 고장 신고 시 사용 차단 및 관리자 알림
  - 신고자·신고사유 기록(장난 신고 방지)

---

## 3. 도서 대출

- **도서 목록/검색**
  - 전체 도서(예약/대출/번호순) 나열
  - 제목·저자 일부로도 검색 가능
  - 클릭 시 상세 모달팝업(책이름, 번호, 출판년도, 저자, 상태)

- **대출/예약/반납/연장**
  - 대출·예약 상태면 현재 대출인·예약인 표시
  - 본인 대출 중인 경우 연장 신청 가능

- **알림/벌점**
  - 연체 시 자동 벌점 및 알림
  - 반납일 3일 전 알림

---

## 4. 스터디룸 예약

- **예약 현황**
  - 주간 예약 대시보드 제공
  - 매주 월요일 일주일 예약 오픈

- **예약/취소**
  - 빈 시간 클릭 시 10분 단위 예약 모달
  - 예약정보(본인정보, 사용시간, 시작/종료시간, 이용사유) 입력
  - 예약된 시간 클릭 시 상세 모달
  - 예약 당사자만 취소 가능

## 5. 내 이용내역

- **이용목록**
  - 냉장고, 세탁기, 스터디룸, 도서관 이용내역 확인

- **내 기록**
  - 벌점/신고/제재기록(1년간)
  - 이용기록, 알림(휴관 전까지)

1. 벌점 정책
- 1.1 벌점 부과 기준
	-  도서관 연체시 실제 벌점을 부과하실건가?
	-  냉장고 규칙위반시 실제 벌점을 부과하실건가?
		-  폐기처리
			- 등록 안 된 상태
			-  스티커 미부착
		- 폐기처리(등록됨, 폐기상태로 변경)
			- ✔️ 유통기한 지남
			- ✔️ 포장상태 불량
		- 경고처리(등록됨, 경고상태로 변경)
			- ✔️ 오입력
			- ✔️ 미일치
			•	UI 반영: 경고 팝업 및 벌점 부과 알림 표시

	•	운영자에게만 기록 전달 → 관리자 페이지에서 처리

	•	최종 제출 후 벌점 수정 불가 (청탁 방지)
	•	검사 결과 일괄 알림 전송
	•	운영자:
	•	벌점 수정 권한 보유
	•	벌점 사유/대상자 확인 후 조정 가능

		•	보관물품 자체 관리 유도(스스로 양조절)
		•	개인정보 보호:
