# **6주 MVPㅡ 배포**

## **Phase 1: 기반 시스템 및 핵심 기능 (냉장고)**

> **목표**: 로그인, RBAC, 냉장고 핵심 흐름(등록→조회/수정→점검) 완성.

1. **코어 시스템**
    - Spring Boot(Java 21) 프로젝트/프로필, Flyway, PostgreSQL 연결.
    - 공통 예외 규약(409/422/423/429), 에러 응답 스펙.

2. **인증·권한(RBAC)**
    - Spring Security + JWT.
    - 역할: **ADMIN_ROOT/ADMIN/INSPECTOR/RESIDENT**.
    - 활성 사용자만 로그인.

3. **DB 마이그 ① (핵심)**
    - users/roles/user_roles, resources(FRIDGE_COMP).
    - item_bundles + 활성 라벨 부분 UNIQUE.
    - inspection_sessions/participants/results + 리비전/트리거.
    - resource_locks(자원 잠금 TTL 기본 5분), penalties_*, 인덱스 필수셋.

4. **냉장고: 물품 등록(입주자)**
    - 단일/묶음 등록 API.
    - **스티커 코드 SNNN** 자동 발급: resource_id + label_no 충돌 방지.
    - 생성 이벤트 적재(event_log).

5. **냉장고: 물품 관리(입주자)**
    - 내 물품 목록/상세/수정/제거.
    - 라벨·이름·유통기한 필터. 임박 목록(D-1) 조회.

6. **냉장고: 점검(층별장)**
    
    - 세션 시작/참여(좌석 1,2), 칸 단위 점검 락 발급.
    - PASS/WARNING/DISCARD 처리, 사유·이력 저장.
    - 제출 후 수정 시 **사유 필수 + 리비전** 누적.

---

## **Phase 2: 사용자 경험 및 실시간 연동**

> **목표**: 포그라운드 실시간 반영과 최소 알림.

7. **SSE(포그라운드)**
    
    - GET /events 스트림, Last-Event-ID 재접속, 하트비트.
    - 토픽: items.*, inspection.*, penalties.changed.
    - 폴백: GET /event-log?sinceId= 주기 폴링.

8. **알림 UX(포그라운드 한정)**
    
    - 브라우저 Notifications API 허용 시 배너 표시.
    - 알림 클릭 딥링크 처리(앱 내부 라우팅).

9. **마이페이지(요약)**
    
    - 내 이벤트 타임라인, 벌점 합계 뷰(v_penalties_totals).
    - 알림/푸시 동의 상태 저장(플래그만. 실제 푸시는 이후 단계).

---

## **Phase 3: 관리자·운영 최소 기능**

> **목표**: 운영 필수만 탑재. 확장 작업은 보류.

10. **자원 관리(최소)**
    
    - FRIDGE_COMP 생성/라벨 수정/상태 변경(ACTIVE/OUT_OF_SERVICE).
    - 층 코드 floor_code 세팅/일괄 갱신.

11. **운영/관측(최소)**
    
    - pg_stat_statements 확인용 쿼리, 슬로우쿼리 로그 레벨.
    - 기본 대시(건수·지연·에러율) API.

12. **배포**
    
    - Docker Compose(앱+DB), Nginx 리버스 프록시, HTTPS.
    - GitHub Actions: 테스트→빌드→배포.

## **6주 이후(포스트-MVP)**

## **Phase 4: 백그라운드 알림 파이프라인(Web Push)**

> **목표**: 앱 미실행 시에도 중요한 이벤트 전달.

1. **Service Worker + VAPID**
    
    - push_subscriptions 보관, 구독/해지 API.
    - showNotification() + 딥링크.

2. **Outbox/스케줄러**
    
    - due_tasks 워커(백오프/재시도/중복억제).
    - 정책: **유통기한 D-1 묶음**, 점검 결과 묶음, 과다 푸시 방지.

3. **전송 가용성**
    
    - Collapse key, TTL, 장애 시 폴백(SSE/폴링 안내).

---

## **Phase 5: 공용 시설 확장**

> **목표**: 세탁실→다목적실→도서관 순으로 점진 확장.

4. **세탁실**
    
    - 리소스 타입 추가(WASHER/DRYER) + 상태 코드 매핑.
    - 사용 시작/종료 등록, 남은시간 계산, 고장 신고.
    - SSE로 남은시간 갱신, 종료 푸시.

5. **다목적실**
    
    - 예약 테이블(+ EXCLUDE 사용 검토).
    - 주간 타임라인 조회, 예약/취소, 오픈 스케줄러.
    - 노쇼 신고, 관리자 강제 예약.

6. **도서관**
    
    - 도서 메타/검색(TRGM 선택적), 대출/반납/연장/예약(대기열 1).
    - 연체 벌점 자동 부과, 알림 연동.

---

## **Phase 6: 관리자 고도화·관측·성능**

> **목표**: 운영 신뢰성·확장성 강화.

7. **관리자 기능 고도화**
    
    - 층별장 임명/해제, 벌점 수동 조정 이력화.
    - 휴관 모드, 전 시설 상태 일괄 변경.

8. **관측/알림**
    
    - Prometheus/Grafana, Sentry.
    - 알림 실패/락 경합/슬로우쿼리 경보.

9. **성능·데이터**
    
    - 인덱스 **CONCURRENTLY** 보강, TRGM 도입 시점화.
    - 이벤트/로그 보관 주기, 파티셔닝·아카이빙 검토.
