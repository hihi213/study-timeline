# **사용자 기능 (End-user)**

## **U1. 계정·세션**

- 로그인(아이디/비번) 및 토큰 세션 관리
- 내 정보(/me) 조회: 역할·권역·상태 확인
- PWA 설치, 오프라인 핵심 조회, 딥링크(알림→화면)

## **U2. 냉장 칸·물품**

- 칸 선택후 필터링(기한임박,기한넘김)
- 물품 등록(칸+라벨 중복 방지), 검색(내 물품/칸/키워드)
- 물품 수정(adjust: 수량/유통기한/메모), 전량 제거(remove-all)
- (개별 아이템 이름/유통기한/부분 제거, 그룹↔개별 전환)

## **U3. 검사(Inspection)**

- 검사 세션 참여(칸당 1세션, 동시 2인), 조치 기록 [MVP]
- 단일 제출(멱등), 제출 후 결과 확인 [MVP]

## **U4. 벌점**

- 내 벌점 집계 조회(원본+조정=최종) [MVP]

## **U5. 실시간/알림**

- 이벤트 폴링 기반 실시간 반영(증분·디듀프) [MVP]
- SSE 기반 실시간(UI 배지/갱신), 알림센터(배지/목록/읽음) [Post:R1,R2]
- Web Push(백그라운드 알림, 구독/해지) 및 만료 정리 [Post:R3]
- 시나리오: 유통기한 D-1, 검사 결과, 운영 알림 [Post:R2]

## **U6. 세탁실**

- 장비 사용 시작→진행→완료, 중복 사용 차단 [Post:R5]
- 종료 임박 알림(예: 5분 전), 미등록 사용 자동 복귀 [Post:R6]

## **U7. 스터디룸**

- 주간 슬롯 예약/취소(겹침 방지), 타임라인 뷰 [Post:R7]
- 합석 옵션, 휴무/블록 반영, 관리자 강제예약 반영 보기 [Post:R8]

# **관리자 기능 (Admin/Operator)**

## **A1. 권한·권역 운영**

- 역할 가드 적용 리소스 관리(ADMIN/INSPECTOR/USER) [MVP]
- 권역(층/존) 할당·변경 및 리스트/검사/예약 필터링 [Post:R9]

## **A2. 자원 카탈로그·상태**

- 냉장 칸/세탁기/건조기/스터디룸 등록·편집 [MVP(칸)] / Post(나머지)]
- 상태 전환(사용 가능/OUT-OF-SERVICE/블록), 즉시 반영 알림 [MVP(칸 기본)/Post(확장)]

## **A3. 검사 운영**

- 검사 세션 현황 모니터링(참여자/락/제출 로그) [MVP(기본 로그)]

## **A4. 벌점 운영**

- **조정 벌점**(±, 사유 필수, 0 금지) 생성/수정 [MVP]
- 사용자·기간별 집계 조회, 감사 추적 연계 [MVP]

## **A5. 알림/시나리오 설정**

- 이벤트→큐→전송 파이프라인 정책(예약·재시도·중복 억제) 파라미터 관리 [Post:R2]
- 알림센터 운영(템플릿/딥링크) [Post:R2]

## **A6. 스터디룸 운영**

- 슬롯 생성/오픈 스케줄, 합석 옵션 [Post:R7,R8]
- 강제예약/해제, 휴무·블록 기간 설정 [Post:R8]

## **A7. 세탁실 운영**

- 고장 신고 처리→OUT-OF-SERVICE 전환, 미등록 사용 정책 관리 [Post:R6]

# **시스템 (플랫폼/인프라/품질)**

## **S1. 인증·보안 베이스라인**

- HTTPS/HSTS, 보안 헤더(CSP 라이트), 스키마 검증/페이로드 제한 [MVP]
- 레이트리밋(사용자/IP, 로그인 쿨다운), 민감정보 마스킹 로그 [MVP]
- 키 회전/JWKS, 토큰 버전 무효화(강제 로그아웃) [Post:R10]
- 감사 로그(append-only)로 고위험 액션 추적/검색 [Post:R10]

## **S2. 권한·접근 제어**

- 역할 가드 전 구간 적용 [MVP]
- 권역 가드/라우팅(/me 기반) [Post:R9]

## **S3. 실시간 전달 레이어**

- 단일 폴링 엔드포인트(커서·at-least-once·필터·긴 폴링) [MVP]
- SSE(Last-Event-ID, 하트비트, 다탭 제어, 중복 억제) [Post:R1]
- 이벤트 스키마: items.* / inspection.* / penalties.adjusted ... [MVP]

## **S4. 알림 파이프라인**

- 큐 기반 전송(예약·재시도 지수 백오프·멱등·중복 억제) [Post:R2]
- Web Push 구독 수명주기 관리(구독/해지/만료) [Post:R3]

## **S5. 데이터·모델 이행**

- Items V1→V2 무중단 이행(확장→백필→새 API→구 구조 수축) [Post:R4]
- 실시간 키 정밀화(묶음ID/개별ID) [Post:R4]

## **S6. 오류·경합·멱등 UX 표준**

- RFC7807 오류 본문(코드/필드/사유/재시도 힌트) [MVP]
- 409/422/423/429 사용 지침·락 정책 [MVP]
- Idempotency-Key 동일 응답 보장(작성 멱등) [MVP→R1 강화]

## **S7. 관측·운영·배포**

- 구조화 로그(JSON)·correlation_id 전파, event_log 적재 [MVP]
- 지표: p95<300ms, API 지연/에러율, SSE 연결·드롭률, 큐 적체 [MVP→R1/R2 확장]
- 상태 엔드포인트(/healthz, /readyz), OpenAPI 스냅샷, 오류 카탈로그, 런북 [MVP]
- 기능 플래그·카나리 롤아웃/롤백, 구·신 모델 병행 후 수축 [MVP→상시]
- PWA 서비스워커 업데이트/캐시 무효화 전략 폴리싱 [Post:R10]
