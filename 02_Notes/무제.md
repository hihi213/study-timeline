# **① 푸시**

- 목적: 즉시 행동 유도, 시간 민감.
- 조건: 백그라운드 + 개인 영향 있음.
- 형식: 제목 10~16자, 본문 1문장, •로 보조정보.
- 템플릿
    - 세탁 5분 전 • {기기명} / {기기명} {남은분}분 뒤 완료
    - 세탁 완료 • {기기명} / {기기명} 수거하세요
    - 예약 15분 전 • {방이름} / {시작시각} 시작
    - 종료 15분 전 • {방이름} / {종료시각} 종료
    - 연체 발생 • {제목} / 연체료 부과될 수 있음
    - 대출 가능 • {제목} / 오늘 수령
    - 냉장고 경고/폐기 • {품목} / 상태 확인  

# **② 메인 아이콘**

- 목적: 홈에서 즉각 상태 인지.
- 대상: 세탁·스터디 전용.
- 형식: 2~4자 키워드 또는 남은분.
- 템플릿
    - 세탁: 5분 전 | 완료 | 정지
    - 스터디: 곧 시작 | 곧 종료
- 생략: 냉장고·도서관은 미할당.

# **③ 종(알림함 목록)**

- 목적: 인앱 히스토리와 처리 허브.
- 형식: 제목(행동/상태) + 본문(대상·시간·수량) + 타임스탬프.
- 묶음 규칙: 동일 타입은 외 {n}건.
- 템플릿
    - 세탁 종료 임박: 세탁 종료 임박 / {기기명} {남은분}분 남음
    - 세탁 완료: 세탁 완료 / {기기명} 수거 필요
    - 세탁 상태 변경: 기기 상태 변경 / {기기명} → {상태}
    - 미등록 사용: 미등록 사용 감지 / {기기명} 사용 등록 필요
    - 스터디 시작 임박: 이용 시작 임박 / {방이름} {시작시각}
    - 스터디 종료 임박: 이용 종료 임박 / {방이름} {종료시각}
    - 노쇼 신고: 노쇼 신고 접수 / {예약코드} 세부 사유 확인
    - 반납 임박(묶음): 반납 임박 {권수}권 / D-{남은일수} 확인
    - 반납 당일(묶음): 오늘 반납 {권수}권 / 오늘 중 반납
    - 연체 발생: 연체 발생 / {제목} 연체 중
    - 예약 가능: 예약 도서 대출 가능 / {제목} 오늘 수령
    - 예약 만료: 예약 만료 / {제목} 보관 종료
    - 냉장고 경고: 점검 경고 / {품목} 상태 확인
    - 냉장고 폐기: 폐기 완료 / {품목} 폐기됨
    - 유통기한 임박(묶음): 유통기한 임박 {개수}개 / 오늘 확인

# **④ 탭 배지**

- 목적: 영역 단위 존재감.
- 값: 미읽음 수(최대 9+), 점 표시 허용.
- 규칙: 관련 화면 진입 시 소거. 24시간 경과 시 자동 만료 가능.
- 예시
    - 세탁 탭: 1(종료 임박/완료/상태 변경)
    - 스터디 탭: 1(시작/종료 임박, 신고)
    - 도서관 탭: 2(반납 임박, 연체)
    - 냉장고 탭: 1(경고/폐기, 유통기한 임박 묶음)

# **라우팅 요약**

- 긴급·행동유도: ① + ③ + ④, 메인아이콘은 세탁·스터디만 ②.
- 정보성·묶음: ③ + ④만. ①,②는 생략.
- 동일 이벤트 중복 방지: 화면 표시 중이면 ① 억제, ②·③·④만 갱신
